固定侧边栏布局 FIXED SIDEBAR

一条 240px 的常驻侧边栏，主区只负责滚动内容。

240px 常驻栏56px 工具栏12px 圆角1px 描边150ms 过渡

固定侧边栏是一种结构风格而非视觉风格：导航常驻左侧 240px（收起时 64px），主内容区独立滚动，顶栏只放搜索与账号。

视觉上它几乎是中性的——白卡、浅描边、一级阴影、8 到 12px 圆角，全部为结构与可扫描性让路。选中项用主色 10% 底配主色文字，hover 只加深到 6%，150ms 内完成。密度是关键：侧边栏项目高 40px、主区卡片内边距 24px。

布局实演

左边是常驻侧栏，右边是内容区，两边各自滚动。点工具栏最左边的按钮可以把侧栏收成 64px 的图标条——选中态、文字、图标位置都不变，只是宽度变了。

颜色

整套界面几乎没有颜色：石墨蓝是侧栏底色，纸灰是内容区底色，白是唯一的高光面。主蓝只做选中项、链接与焦点环，绝不做大面积填充；绿与红只在计数与图标上出现，各占几个像素。

  • Slate Ink侧边栏底色、标题与主按钮。深而不黑，避免长时间使用疲劳。
    #1e293b--color-slate-ink
  • Paper Grey主内容区底色。白卡浮在它上面。
    #f8fafc--color-paper-grey
  • Card White卡片、面板与浮层。全站唯一的高光面。
    #ffffff--color-card-white
  • Primary Blue选中项、链接与焦点环。不做大面积填充。
    #3b82f6--color-primary-blue
  • Status Green在线与成功状态，小面积圆点或徽标。
    #10b981--color-status-green
  • Alert Red错误与未读数，只用于计数与图标。
    #ef4444--color-alert-red

表面层级：0 Sidebar Ink #1e293b，1 Paper Grey #f8fafc，2 Card White #ffffff。阴影两级：卡片 0 1px 2px rgba(15,23,42,0.06)、hover 0 8px 20px rgba(15,23,42,0.08)。

字体

全站唯一字体 Inter，字级偏小（13 到 14px 为主），这是应用密度而非网页密度。

间距与版面

基础单位 4px，密度 compact。左侧 240px 固定栏加右侧自适应内容区，顶栏 56px 固定在内容区顶部。内容区最大宽度 1200px、内边距 24px，卡片间距 16px。断点 1024px 以下侧边栏收起为 64px，768px 以下改为抽屉。

组件

Sidebar Rail

常驻侧边导航。宽 240px（收起 64px）、石墨蓝填充、白字 70%、固定不随内容滚动。项目高 40px、8px 圆角、水平内边距 12px、图标 18px、图标与文字间距 10px。选中项用白 10% 底配纯白文字，hover 用白 6% 底，过渡 150ms。分区之间留 24px 并加一条 1px 白 8% 分隔线。

Content Card

主区内容卡与列表容器。白底、12px 圆角、1px #e4e4e7 描边、内边距 24px、阴影 0 1px 2px。标题 20px/600，正文 14px 灰。hover 上浮 2px、阴影升到 0 8px 20px，过渡 150ms。上面布局实演里的三张卡都是它。

Search Field

顶栏搜索。纸灰底、1px #e4e4e7 描边、8px 圆角、高 36px、左内边距 36px 放 16px 图标、13px 字。聚焦时描边转主蓝并加 2px 主蓝 20% 外环。

Toolbar

顶栏。高 56px、白底、底部 1px #e4e4e7 描边、无阴影。左侧面包屑 13px，中间搜索框最大 360px，右侧图标按钮 32px 见方、8px 圆角。顶栏只放搜索、面包屑与账号，不堆超过三个动作。

可为与不为

可为

  • 侧边栏固定，内容区独立滚动
  • 侧边栏项目 40px 高，保持应用密度
  • 选中态用主色 10% 底而不是实色
  • 卡片用 1px 描边加一级阴影
  • 顶栏只放搜索、面包屑与账号
  • 过渡 150ms，快而不突兀

不为

  • 不要让侧边栏跟随内容滚动
  • 不要把主内容塞进侧边栏
  • 不要用超过 12px 的卡片圆角
  • 不要在顶栏堆超过三个动作
  • 不要用大面积主色填充
  • 不要在侧边栏用两套以上图标风格

图像

以界面截图、头像与图标为主，几乎不出现摄影。侧边栏允许 18px 线性图标，主区允许产品截图。不使用装饰性插画与大图，它们会挤掉结构感。
