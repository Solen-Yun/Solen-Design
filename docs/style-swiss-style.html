风格 15 · 浅色版面

瑞士国际风格 SWISS INTERNATIONAL

网格、左对齐、无衬线、三原色——让结构本身成为装饰。

严格网格左对齐唯一红强调无卡片框

瑞士国际风格来自 1950 年代的平面设计：一切对齐到一张严格的网格，文字一律左对齐（从不居中），字体只用无衬线的常规与粗体两档，装饰被彻底删掉，只留下黑、白与三原色。页面的秩序来自栏线与留白的节奏，而不是卡片边框。

交互也保持结构感：hover 时左侧的引导线从灰变红、底色轻微变灰，等于把那条结构线「激活」，而不是加阴影或位移。下面就是一张按规格跑的索引列表——把指针放上去，看那条线变红。

配色方案

  • Black#000000
  • White#ffffff
  • Signal Red#ff0000
  • Ultramarine#0057b8
  • Cadmium Yellow#ffcc00
  • Rule Grey#d4d4d4

颜色

黑承担全部结构与文字，白是画布且不做灰度渐变。红是唯一强调色：编号、激活线、关键数据，面积控制在一个字符宽；蓝给链接，与红同屏时只出现一种；黄只做大面积分区色块，不参与强调。结构线默认 #d4d4d4，激活才变红。

  • Black正文、标题与栏线。瑞士风格允许纯黑，因为它追求印刷级对比。
    #000000--color-black
  • White页面画布，不做任何灰度渐变。
    #ffffff--color-white
  • Signal Red唯一的强调色：编号、激活线、关键数据。面积控制在一个字符宽。
    #ff0000--color-red
  • Ultramarine链接与可点击标记。与红同屏时只出现一种。
    #0057b8--color-blue
  • Cadmium Yellow大面积色块与海报式区块，用于分区而非强调。
    #ffcc00--color-yellow
  • Rule Grey结构线的默认色，hover 时被「激活」为红。
    #d4d4d4--color-rule

和包豪斯一样是一套没有阴影的系统：elevation: none。分隔用 1px 或 2px 黑线，不用卡片框；层次完全由字号与栏宽承担。

字体

全站唯一字体 Helvetica Neue，只用 400 与 700 两档，层级完全由字号与栏宽承担。字号跨度大：11px 到 88px。

组件

Structural List Row

列表、目录与索引行。无背景、无圆角、无阴影：左侧 2px 竖线默认 #d4d4d4，行高 64px，内边距左 16px；编号 11px/700 红色，标题 20px/700 左对齐。hover 时竖线变红、背景变 #f0f0f0，过渡 200ms；不做位移。上方索引列表即此组件。

把指针放到上面任意一行，看结构线被激活。

Section Label

栏目编号与分类标签。11px、700 字重、0.08em 字距、全大写；编号与标题之间用一条 24px 的黑色短线连接。不接受胶囊形状与圆角。

05SECTION LABEL

Inline Button

行动按钮与链接按钮。无填充、无描边、无圆角，左对齐，文字 13px/700 全大写 0.08em，下方一条 2px 黑线。hover 时线变红、文字保持黑色，200ms；按下时线加粗到 3px，不做其他变化。

Color Field

分区色块与海报区。整块填充红、蓝或黄，无圆角、无阴影、无渐变；块内文字一律白色或黑色（按对比度选），字号至少 32px/700，左对齐并贴齐色块内边距 48px。色块在一屏内不超过一块。

一块黄，一屏只允许一次。

可为与不为

可为

  • 一切左对齐，永不居中
  • 只用 400 与 700 两档字重
  • 红作为唯一强调，控制在一个字符宽
  • 分隔用 1px 或 2px 黑线，不用卡片框
  • hover 激活结构线，不加阴影与位移
  • 字号跨度大：11px 到 88px

不为

  • 不要用圆角
  • 不要用阴影与渐变
  • 不要居中排版
  • 不要让红与蓝同时作为强调
  • 不要用超过两档字重
  • 不要用卡片包裹内容

图像

黑白摄影、几何构图、大字号排版本身即是图像。允许整版单色块。不使用彩色摄影、插画、图标墙与任何柔和过渡。
