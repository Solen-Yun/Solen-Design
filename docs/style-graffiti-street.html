风格 103 · 深色版面

涂鸦街头 GRAFFITI STREET

喷漆罐在砖墙上：撞色、粗边、随手歪着的字。

错位砖墙纹理900 全大写随机旋转零模糊喷漆晕边4px 粗边硬影

涂鸦街头模拟砖墙与沥青墙面上的喷漆：深灰近黑底、高饱和撞色（玫红、青、黄、紫、橙）、文字用 900 字重全大写并随机旋转 -3 到 3 度、喷漆扩散靠多层 drop-shadow 模拟、按钮与标签用 4px 粗边框加硬偏移阴影。

它的规则是「乱但可读」——每个元素都歪，但文字始终清楚。

STREET

砖墙与沥青，所有字都歪着，但都还读得出来。

颜色

玫红是主色，给主按钮、主标签与最抢眼的字；沥青灰模拟夜里的砖墙与沥青，做页面底；青是第二撞色，与玫红形成最强对比；黄像荧光喷漆，管高亮与描边；紫是第三撞色，用来让画面失去统一色；橙是第四撞色与警示，出现频率中等。

硬偏移两支：6px 6px 0 #ff2d55 与 6px 6px 0 #00e5ff，按下归零。喷漆晕边用零模糊的 drop-shadow，不做真实模糊光晕。

字体

只有 900 一个字重，全大写。标题压到行高 1.0 并带随机旋转，像手喷上去的。

组件

Spray Tag

喷漆标签（核心组件）。透明底、4px 撞色描边、零圆角、14px/900 全大写、字距 0.04em、padding 6px 14px，带随机旋转 -3 到 3 度与 6px 6px 0 的硬阴影。文字用 2 到 3 层 drop-shadow（同色、偏移 1px、模糊 0）模拟喷漆的边晕。

Brick Wall

砖墙底纹。用 repeating-linear-gradient 画错位的砖块（砖 64×24px、缝 4px、缝色更深），整体不透明度 40%。它必须错位（第二行砖从 32px 处开始），否则会看起来像地砖而不是砖墙。本页背景就是。

Thick Button

行动按钮。玫红填充、黑字、零圆角、4px 黑描边、18px/900 全大写、padding 12px 28px，硬阴影 6px 6px 0 青。hover 时填充硬切到黄、阴影换紫；按下时位移 6px 6px 且阴影归零。过渡 80ms linear。

Spray Underline

喷漆划线。文字下方一条 4px 的撞色横线（text-decoration 或伪元素），长度比文字宽 4%，略微倾斜 1 到 2 度，颜色取与文字对比的撞色。它是这套风格最常用的强调手段——hero 里 STREET 底下那道就是。

Sticker Blob

喷漆圆斑。一个 24 到 96px 的圆或不规则块，用 radial-gradient 从实色渐隐到透明，边缘不锐利（模糊 6 到 12px），像喷漆的扩散。颜色取一支撞色，不透明度 40% 到 70%，放在文字背后或角落。单屏 3 到 6 处。

可为与不为

可为

  • 深灰底加四支高饱和撞色
  • 文字 900 全大写并随机旋转
  • 喷漆晕边用零模糊的 drop-shadow
  • 4px 粗边框加硬偏移阴影
  • 砖墙纹理必须错位
  • 乱但可读

不为

  • 不要用棚拍产品与干净影像
  • 不要用圆角
  • 不要给喷漆加真实模糊光晕
  • 不要让旋转超过 3 度
  • 不要让纹理变成地砖
  • 不要牺牲可读性

图像

街头摄影与涂鸦作品：砖墙、卷帘门、地铁车厢、手绘 tag。必须高对比、有街头痕迹。允许把照片压成高饱和双色调再叠喷漆效果。不使用棚拍产品、柔和插画与无痕迹的干净图像。
