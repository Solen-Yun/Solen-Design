风格 109 · 深色版面

巫术核心 WITHCORE

月相、塔罗、紫水晶与金符文：一次摆在深夜桌面上的占卜。

深紫到午夜黑渐变金符文 8px 微光月相与塔罗语汇星尘缓慢闪烁

巫术核心是神秘学美学：深紫到午夜黑的垂直渐变作底，金色符文文字带 0 0 8px 的微光，边框是 30% 的金色半透明细线、hover 时升到 60%，卡片用 #0d0b14 的 80% 加轻微模糊营造朦胧感，紫水晶作次级信息色，背景点缀星尘。

衬线字体加宽字距，让文字有仪式感。月相、塔罗牌、水晶与草药是它的图形语汇。

Waning Crescent

第三夜的月亮。塔罗说这一张适合提问，不适合回答。

颜色

黄昏的深紫是渐变顶端，往午夜黑过渡；带紫的午夜黑是渐变底端与卡片底；金是符文、边框与所有发光，仪式感的来源；紫水晶管次级信息与月光语义；草药绿管草药与「生长」语义，出现频率较低；嫩绿最亮，只在草药细节与「新增」标记上出现。

  • Midnight渐变底端与卡片底。带紫的近黑。

组件

Haze Card

朦胧卡片（核心组件）。午夜 80% 填充、8px 模糊、12px 圆角、1px 金 30% 描边、内边距 32px。标题 36px/600 金并带 0 0 8px 金字微光，正文 17px 白 80%。hover 时描边升到 60%、金字光晕扩到 24px。hero 里那张就是。

Rune Label

符文标签。透明底、1px 金 30% 描边、8px 圆角、14px/600、字距 0.24em、padding 4px 12px，文字金色带 0 0 8px 微光。左右可各放一个 6px 的金色菱形作为符文分隔。

✦ THE READING ✦

Moon Phase Row

月相装饰。一排 5 到 8 个 16px 的月相图标（新月到满月），间距 12px，颜色金或紫水晶，当前相带 0 0 12px 微光。它既是装饰也是「现在处于哪一阶段」的指示，用于章节与状态——hero 卡顶部那排就是。

Tarot Frame

塔罗牌卡片。竖向 2:3 比例、12px 圆角、1px 金 40% 描边、内边距 20px，午夜 90% 填充。顶部与底部各一条 1px 金线内框，中央放图形（月相、水晶、草药线稿）。hover 时卡片上浮 4px、金线描边升到 80%、并让星尘在 600ms 内亮起。

Stardust Bed

星尘背景。在渐变底上叠 20 到 40 个 1 到 2px 的白色或淡金光点（radial-gradient 或 box-shadow 多重投影），不透明度 20% 到 50%，分布不均。可做极慢的闪烁（每点周期 4 到 8 秒、错峰），但绝不做快速闪烁。

可为与不为

可为

  • 深紫到午夜黑的垂直渐变
  • 金色符文配 8px 微光
  • 边框 30% 金，hover 升到 60%
  • 卡片 80% 午夜加轻微模糊
  • 衬线加宽字距
  • 月相与塔罗作图形语汇

不为

  • 不要用明亮摄影
  • 不要用高饱和图像
  • 不要让星尘快速闪烁
  • 不要用粗边框
  • 不要用现代无衬线作标题
  • 不要让星尘承载内容

图像

神秘学图像：塔罗牌面、月相、水晶、草药、烛光、星图。必须暗调、金紫配色、有朦胧感。不使用明亮摄影、现代插画与高饱和图像。
