霓虹渐变 NEON GRADIENT

深紫底上一张张渐变卡片，边缘发着光。

双极渐变 135°发光与渐变同色渐变文字 ≤2 处background-size 200%

霓虹渐变是近年 SaaS 与年轻品牌最常见的视觉：深紫黑底上放一张张渐变填充的卡片（紫到粉、青到绿等对角渐变），卡片用 16 到 24px 的大圆角与粗彩色描边，边缘带同色霓虹发光。它的规则是「渐变必须有明确的两极」——从一支饱和色到另一支饱和色，不允许三色以上的浑浊过渡。

而且发光必须与渐变同色，否则会显脏。右边这张渐变卡是真的：hover 时渐变转 180 度、发光扩到 40px。

颜色

带紫的近黑让所有渐变都显得更亮；紫是渐变的第一极，也是主按钮的起点；粉是第二极，与紫成对出现；青是第二组渐变的冷极，用于数据与科技语义；青柠是第二组的暖极与成功状态；琥珀是第三组渐变与徽标高亮。

组件

Gradient Card

渐变卡片（核心组件）。135 度的双极渐变填充（紫到粉，或青到青柠）、24px 圆角、1px 白 20% 描边、内边距 28px，外发光 0 0 32px 紫 45%——发光必须取渐变的主极色。标题纯白 34px/700，正文白 85%。hover 时渐变角度转为 180 度并让发光扩到 40px。hero 里的卡片就是。

Gradient Button

主行动按钮。紫到粉横向渐变、白字、16px 圆角、无描边、17px/600、padding 12px 28px，外发光 0 8px 32px 紫 50%。hover 时渐变横向位移（background-position 从 left 到 right）、发光扩到 40px；按下缩放 0.98。渐变必须设 background-size: 200% 才有可动的余量。

Gradient Text

渐变标题。用 background: linear-gradient(90deg, 紫, 粉) 配 background-clip: text 与 color: transparent。只用于首屏与关键区块标题，且同一页不超过两处——用多了整页会失去重点。绝不用于正文。

BRIGHTER, EVERY SPRINT

Glow Border

发光描边。1px 渐变描边（用 padding 1px 的渐变层加内层深底实现），外带 0 0 24px 的同色发光。用于次级卡片与输入框，替代实色描边。描边颜色必须与卡片的渐变同族。

Sparkle Badge

徽标与图标底。999px 全圆或 12px 圆角的小块，填渐变或渐变 20% 底，内放一个 16 到 20px 的线性图标（星、火箭、闪光）。图标用白色，绝不用彩色图标压在彩色渐变上——那会糊。

可为与不为

可为

  • 渐变必须有两个饱和极
  • 发光与渐变同色
  • 卡片圆角 24px，按钮 16px
  • 渐变文字最多两处
  • 按钮渐变设 background-size 200%
  • 同屏渐变不超过三组

不为

  • 不要用三色以上的浑浊渐变
  • 不要让发光与渐变不同色
  • 不要在正文用渐变文字
  • 不要用彩色图标压彩色渐变
  • 不要用写实摄影抢亮度
  • 不要用锐角

图像

以渐变、抽象图形与图标为主。允许产品截图放在渐变卡片里。不使用写实摄影、灰度图像与柔和插画，它们会与渐变抢亮度。
