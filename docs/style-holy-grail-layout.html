圣杯布局 HOLY GRAIL LAYOUT

页头、三栏、页脚：网页布局的原型，二十五年没过时。

240/弹性/280 三栏grid stretch 等高sticky 页头窄屏折叠

圣杯布局是最早被讨论的网页结构：固定页头、等高的三栏中段（左导航、中间主内容、右侧边栏）、固定页脚。它的价值不在视觉而在分配——中间列用弹性宽度吃掉剩余空间，两侧列固定宽度，页头页脚不随内容滚动。

视觉必须保持中性：白卡、1px 描边、一级阴影、8 到 12px 圆角，全部为可读性让路。中段三列高度必须相等，靠 grid 的 stretch 而不是 min-height 硬撑。下面就是一台按规格搭的三栏应用。

布局实演

页头 56px、中段三栏（240px / 弹性 / 280px）、页脚 48px。窄于 1024px 时右栏折叠到主内容下方，窄于 768px 时左栏变为抽屉。

颜色

结构型布局需要一支足够稳的深色：板岩墨承担标题、主按钮与页头；浅雾做三栏共同底色，白卡浮在其上；主蓝是三栏里唯一允许的强调色——主行动、链接与焦点环；绿黄红各管一种状态，只出现在徽标与计数上。

间距与版面

基础单位 4px，密度 compact。页头 56px、中段三栏（240px / 弹性 / 280px）、页脚 48px，整页上限 1440px、内边距 24px。中段最小高度为视口高度减去页头页脚。三栏各自独立滚动是可选项，但默认整页滚动。

组件

Three Column Grid

中段三列容器。grid-template-columns: 240px minmax(0, 1fr) 280px；列间距 24px；三列高度由 grid 的 stretch 拉齐，禁止用 min-height 硬撑；窄于 1024px 时右栏折叠到主内容下方，窄于 768px 时左栏变为抽屉。上方实演的中段即此组件——切换视口看它怎么折叠。

Content Card

主内容卡。白底、12px 圆角、1px #f1f5f9 描边、内边距 20px、阴影 0 1px 2px；标题 20px/600，正文 14px；hover 上浮 2px、阴影升到 0 4px 12px，过渡 150ms ease-out。实演主列里那两张卡都是它。

Rail Panel

侧栏面板（左导航与右信息栏）。白底、12px 圆角、无描边（靠底色差区分）、内边距 16px；分组标签 12px 全大写 0.04em 灰字，项目高 32px、8px 圆角、hover 浅雾底；选中项用主蓝 8% 底配主蓝文字。实演两侧的白色面板都是它。

Sticky Header + Fixed Footer

页头：高 56px、白底、底部 1px #e2e8f0 描边、阴影 0 1px 2px，sticky 固定在顶部；左侧字标 16px/600，中间导航 13px、间距 24px，右侧一个主按钮与一个头像。页脚：高 48px、白底、顶部 1px 描边、12px 灰字；左侧版本号，右侧三到四条链接，与主内容同为 1440px 上限对齐。实演的顶条与底条即此。

可为与不为

可为

  • 中列弹性、两侧固定
  • 三列等高用 grid stretch
  • 页头页脚固定，不随内容滚动
  • 焦点环 2px 带 offset
  • 动效不超过 200ms
  • 窄屏折叠右栏，再窄转抽屉

不为

  • 不要用 min-height 硬撑三列高度
  • 不要在主内容列加大幅位移动画
  • 不要让三列各自滚动加页面滚动
  • 不要在三栏里塞第四栏
  • 不要省略页头的 sticky
  • 不要用超过 12px 的面板圆角

图像

以图标、头像与产品截图为主，几乎没有大图。允许在主内容列放一张宽度铺满的截图。不使用全幅摄影、背景纹理与插画，它们会挤压三栏的可用宽度。
