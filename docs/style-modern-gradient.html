风格 09 · 深色版面

现代渐变风 MODERN GRADIENT

深靛夜空上的一束紫粉光，玻璃卡片把光切成层次。

深靛底玻璃拟态流动渐变极光光斑500ms 慢动效

渐变有方向

颜色随 hover 流动，而不是简单换色——光是从一端滑到另一端的。

玻璃有层次

模糊、描边与填充缺一不可——少了任何一层，玻璃在深底上就会消失。

光斑不铺满

极光只出现在首屏与少数区块——整页发光就等于没有光。

配色方案

  • Violet#8b5cf6
  • Deep Indigo#1e1b4b
  • Fuchsia#ec4899
  • Cyan#06b6d4
  • Amber#f59e0b
  • Glass White10% white

颜色

深靛底比纯黑暖，能让紫光显得是在发光而不是发灰。玻璃白必须配描边与模糊同时出现；Fuchsia 只与紫同时出现，构成那条光；Amber 全屏不超过一处。

  • Violet渐变起点与主强调。所有发光效果都从它出发。
    #8b5cf6--color-violet
  • Deep Indigo页面底色。比纯黑暖，能让紫光显得是在发光而不是发灰。
    #1e1b4b--color-deep-indigo
  • Fuchsia渐变终点与 hover 态。只与紫同时出现，构成那条光。
    #ec4899--color-fuchsia
  • Cyan数据、图表第二序列与对比高亮。与紫形成冷暖对位。
    #06b6d4--color-cyan
  • Amber稀缺提示与徽标。全屏不超过一处，用来打破冷色。
    #f59e0b--color-amber
  • Glass White卡片填充。必须配描边与模糊，否则在深底上会消失。
    10% white--color-glass

表面层级：0 Deep Indigo #1e1b4b，1 Glass rgba(255,255,255,0.10)，hover 升到 0.15。发光只有三档：按钮 0 8px 20px rgba(167,139,250,0.30)、hover 0 15px 30px rgba(217,70,239,0.40)、卡片悬停 0 20px 50px rgba(167,139,250,0.18)。

字体

全站唯一字体。标题 700 与紧字距压住发光背景，正文 400 保证暗底可读——对比度不低于 4.5:1，渐变不落在正文文字上。

间距与版面

基础单位 8px，密度 comfortable。上限 1200px、12 栏、容器内边距 24px，区块间距 112px。hero 居中且占满首屏，标题不超过两行；功能区用三栏玻璃卡片；整页保持深色，只在页脚允许一次反色。

组件

Gradient Button

主行动按钮。紫→品红→紫三色线性渐变、宽度 200%、白字、16px 圆角、无描边；字级 16px、字重 700、字距 0.02em、padding 16px 32px。hover 时背景位置滑到右端（渐变反向流动）、阴影扩到品红 40%、上浮 4px、放大 1.02；按下缩放 0.95。过渡 500ms ease-out。页头、首屏与下面都是它。

Glass Card

功能卡与内容卡。10% 白填充、20px 模糊、1px 20% 白描边、24px 圆角、内边距 32px；图标块 56px 渐变填充、白图标。hover 时填充升到 15%、描边转紫 50%、上浮 8px、放大 1.02、注入紫色光晕，图标块放大 1.1 并旋转 12 度。首屏三连卡即此组件。

Gradient Input

表单与订阅输入。8% 白填充、10px 模糊、1px 18% 白描边、16px 圆角、padding 14px 18px；占位符白 45%。聚焦时描边转紫 60%，并加一圈 3px 紫 25% 外环。

Aurora Backdrop

首屏背景光。深靛底上两到三个 600px 半径的径向渐变光斑（紫 40%、品红 30%、青 20%），模糊 120px，整体不透明度 60%。只出现在首屏与一两个区块，滚动时固定不动——本页的背景就是它。

可为与不为

可为

  • 渐变必须有方向，hover 时让颜色流动
  • 玻璃卡片必须同时有模糊、描边与填充
  • 深靛底，不用纯黑
  • 动效 500ms，配合上浮与 1.02 放大
  • 光斑只在首屏与少数区块出现
  • 正文对比度不低于 4.5:1

不为

  • 不要用纯黑背景
  • 不要用无描边的玻璃卡片
  • 不要让渐变出现在正文文字上
  • 不要同时用三支以上强调色
  • 不要用快速过渡，光不会瞬移
  • 不要让光斑铺满整页

图像

抽象渐变、光斑、3D 渲染的几何体。允许把产品界面裁切后叠在渐变上。不使用人物摄影、写实插画或纯色平面背景——没有光就没有这套风格。
