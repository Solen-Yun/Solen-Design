风格 106 · 浅色版面

立体主义 CUBISM

把同一件东西从三个角度看，再压回一个平面。

clip-path 切碎面多视角叠加2px 粗边无渐变无阴影

立体主义来自毕加索与布拉克：把对象拆成棱角分明的几何块，从多个视角同时呈现，再用 skew 与 rotate 把这些碎片压回画面。配色是低饱和的大地色，边框 2px 粗线、圆角只有 2 到 4px、布局刻意不对称并带倾斜，文字用粗体全大写字强调几何感。

它禁止柔和渐变与模糊——立体主义是硬的。

颜色

棕是主色，管文字、粗边框与最深色块；像旧画布的米色做页面底与浅色面；赭是中间调色面，用来制造第三个明度层；灰蓝是冷侧碎面，与棕形成分析立体主义的冷暖交错；砖红是最暖的碎面，用于强调与关键块；苔绿是第四碎面色，出现频率最低。

  • Cream页面底与浅色面。像旧画布的米色。

层次靠叠放而非阴影：none — planes stack by overlap, not shadow。碎面一律不加阴影。

字体

粗无衬线 Inter、全大写。字形必须方正，因为立体主义的文字也是被切的块。

间距与版面

基础单位 8px，密度 comfortable。上限 1120px、容器内边距 24px，区块间距 96px。允许元素重叠、倾斜与错位，角度只用 -3、-1.5、+2 三档。布局必须不对称——居中对称会立刻失去立体主义。

组件

Fragmented Panel

碎片化面板（核心组件）。一个容器被 clip-path 切成 3 到 5 个不规则多边形，每块填不同的大地色，块与块之间留 2px 的米色缝（模拟画布的底色透出）。整块 rotate(-2deg) 或 skewX(-4deg)。零阴影。hero 左上那组碎面就是。

Multi-View Block

多视角叠加。同一内容的副本叠两层：一层正常、一层偏移 8px 并 skewX(-8deg)、不透明度 45%，形成「同时从两个角度看」的错觉。仅用于标题与图像，正文绝不叠加——hero 里 TROIS 那两行就是。

Angular Button

行动按钮。棕填充、米色文字、2px 圆角、2px 棕描边、14px/900 全大写、字距 0.06em、padding 14px 28px，无阴影。用 clip-path 切掉右上角 12px。hover 时填充换砖红；按下时位移 2px 2px。过渡 150ms linear。

Skewed Card

倾斜卡片。米色或大地色填充、4px 圆角、2px 棕描边、内边距 28px。整张卡 skewX(-3deg) 并 rotate(1deg)，相邻卡片角度不同（-3、+2、-1 度），刻意不对称。内容在内层反向 skew 以保持文字直立。

Fragmented Edge

碎片边缘。用 clip-path 的一个不规则多边形让图像的边缘像被打碎，或沿边缘叠 3 到 4 个小的三角与梯形色块。它替代圆角与装饰边框。

可为与不为

可为

  • 大地色系，低饱和
  • 用 clip-path 把面切成碎片
  • 多视角叠加同一内容
  • 2px 粗边框、2 到 4px 圆角
  • 布局不对称并倾斜
  • 粗体全大写字

不为

  • 不要用柔和渐变与模糊
  • 不要用对称居中布局
  • 不要用大圆角
  • 不要用过亮的饱和色
  • 不要把完整照片直接放上
  • 不要给碎面加阴影

图像

图像必须被切碎：把照片用 clip-path 分成多块并各自偏移、或转成大地色的多面体构成。允许同一张脸的三个角度并置。不使用完整清晰的照片、柔和插画与渐变图像。
