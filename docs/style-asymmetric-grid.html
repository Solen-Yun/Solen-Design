布局模式 10 · 张力版面

非对称网格 ASYMMETRIC GRID

列宽不相等、元素互相压着：张力来自失衡，而不是来自装饰。

1fr 2.2fr 0.6fr 列比负位移重叠字号差 10 倍硬阴影 6px 6px 0

非对称网格用不等的列宽制造张力：grid-template-columns 写成 1fr 2fr 0.6fr 这样的比例，元素用 -translate 与 z-index 互相压着，字号层级拉开极大的差距（小到 12px、大到 120px），阴影用硬边偏移强化「物理剥离感」。它的禁令是可操作的质量线——不许所有列宽相等、不许元素整齐对齐毫无变化、不许忽略移动端、不许过度杂乱失去可读性、不许所有元素大小相近。

颜色

组件

Uneven Grid

不等宽网格（核心结构）。grid-template-columns 用 1fr 2.2fr 0.6fr 或 2fr 1fr 1.4fr 这类比例，绝不出现三等分。12 栏基准、间距 16px，但每行的列组合可以不同。移动端降为单列并取消负位移。上方实演就是 1fr 2.2fr 0.6fr。

Overlap Block

重叠色块。一个填色块用 -translate-x-8 与 -translate-y-4 压到相邻元素上，z-index 显式设定（相邻两层差 10）。零圆角，硬阴影 6px 6px 0 墨或红。重叠量控制在 16 到 48px，超过就吃掉内容。实演里的红块位移了 (-32px,-16px)。

Contrast Headline

极端对比标题。120px/900、行高 0.95、字距 -0.03em，与其下方的 12px 标签形成 10 倍的尺寸差。允许标题跨越两列并压在其他元素上，但文字必须始终在最上层且保持可读。

Label Chip

小标签。警示黄填充、墨色文字、零圆角、12px/700、字距 0.06em、padding 4px 10px。它常被压在重叠区的边缘，作为「这块是什么」的说明，与大标题形成尺寸反差。青色变体用于窄列锚点。

12PX LABEL

Edge Button

行动按钮。张力红填充、白字、零圆角、16px/700、padding 14px 28px，硬阴影 6px 6px 0 墨。hover 时阴影换到信号青；按下时位移 6px 6px 且阴影归零。过渡 120ms linear。

可为与不为

可为

  • 列宽必须不相等
  • 用负位移与 z-index 做重叠
  • 字号层级拉开到 10 倍
  • 硬边偏移阴影强化剥离感
  • 移动端降单列并取消重叠
  • 重叠量控制在 16 到 48px

不为

  • 不要让列宽完全相等
  • 不要让元素整齐对齐毫无变化
  • 不要忽略移动端响应式
  • 不要杂乱到失去可读性
  • 不要让元素大小相近
  • 不要让重叠吃掉内容

图像

图像可以尺寸悬殊：一张横跨三列的巨图配一张 120px 的小图。允许裁切与局部特写。不使用等尺寸网格与整齐对齐的画廊式排列。
