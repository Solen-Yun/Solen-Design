布局模式 02 · 瀑布版面

瀑布流布局 MASONRY LAYOUT

高度不一的卡片顺着列往下淌，扫描线永远不是水平的。

高度错落多列瀑布图片主体单一间距hover 只动图

瀑布流是一种排布策略：卡片宽度固定、高度随内容变化，用多列容器让它自然错落。它的视觉语言必须让位给内容——卡片白底、8 到 16px 圆角、极浅描边，图片占卡片 60% 以上面积。

间距必须严格一致（16px），否则错落会变成混乱。hover 时图片以 1.05 倍缓慢放大并叠加一层 4% 的黑，卡片本身不上浮也不加阴影，因为任何位移都会破坏列的稳定。筛选条用胶囊按钮，选中态填主色。下面就是一条按规格跑的瀑布。

布局实演

列间距与行间距是同一个值（16px），卡片高度由内容决定、不做统一裁切，hover 只动图片不动卡片。列数随断点退化：桌面 4 到 5 列、平板 3 列、手机 2 列。用上方按钮切换视口看退化，整条筛选横向滚动、不换行。

颜色

白卡让图片成为唯一的视觉重量，卡片本身不参与竞争。玫红是全站唯一的高饱和色，只给喜欢、收藏与选中胶囊；薄荷绿只在徽标里出现；琥珀是高亮与推荐位，面积不超过一张卡片的 10%；靛蓝与玫红形成冷暖对位，承担链接与次级动作。

间距与版面

基础单位 8px，密度 comfortable。上限 1440px、容器内边距 16px；列间距与行间距必须是同一个值（16px），卡片高度由内容决定，不做统一裁切。列数随断点变化：≥1280 五列、≥1024 四列、≥768 三列、移动两列；筛选条固定在顶部下方 8px，横向滚动不换行。

组件

Masonry Card

瀑布流中的任意一张卡片。白底、16px 圆角、1px #e8e8e8 描边、无阴影，内边距 16px。图片占卡片高度 60% 以上、12px 圆角、懒加载；图下依次是 15px/600 标题（最多两行）与 13px 灰色说明（最多一行）。hover 图片放大 1.05 并叠 4% 黑，卡片不动，过渡 400ms ease-out。上面布局实演里全是它。

悬停任意卡片：只有图片在动，卡片纹丝不动。

Filter Pill

顶部筛选项。全圆角、高 36px、padding 0 16px、13px/500。默认白底 1px 描边；选中态午夜填充白字；hover 只加深描边与文字，不改填充。整条筛选横向滚动，不换行。

Search Bar

顶部搜索。浅雾底、12px 圆角、1px #e8e8e8 描边、高 40px、左内边距 40px 放 16px 图标、13px 字。聚焦时描边转午夜并加 2px 午夜 12% 外环。

Column Container

瀑布流容器。桌面 4 到 5 列、平板 3 列、移动 2 列，列间距与行间距都固定 16px。用 CSS columns 或 grid 的 row-span 实现，禁止用绝对定位。卡片高度不做统一，但同一列的相邻卡片间距必须等于行间距。布局实演用的就是它（CSS columns）。

可为与不为

可为

  • 列间距与行间距必须是同一个值
  • 卡片高度由内容决定，不做统一裁切
  • 图片占卡片 60% 以上
  • hover 只动图片，不动卡片
  • 筛选条横向滚动不换行
  • 用 CSS columns 或 grid，不用绝对定位

不为

  • 不要用绝对定位模拟瀑布流
  • 不要让卡片上浮，会打乱列的对齐
  • 不要混用两种间距
  • 不要把标题写成三行以上
  • 不要给卡片加阴影
  • 不要用统一裁剪比例

图像

图片是主体，占卡片 60% 以上。风格可以混杂（摄影、插画、截图），但尺寸比例必须由内容决定，不做裁切统一。不使用大面积纯色占位与装饰图形。布局实演里的渐变色块即图片占位，正式接入时替换为真实图片。
