风格 101 · 深色版面

极繁主义 MAXIMALISM

多就是多：撞色、双层边框、多层阴影、图案叠图案。

五支撞色并用双层虚线粗边多层错位实色影零圆角

极繁主义是对极简的正面反抗：深紫底上铺满高饱和撞色（玫红、金黄、蓝、紫、薄荷），边框用 border-double 或虚线粗边，阴影是多层错位的实色（4px 金黄加 8px 蓝），背景可叠对角渐变，标题用 6xl 以上的全大写加宽字距，元素允许 rotate 与 skew。

它禁止灰度中性色作主色——灰在极繁里等于缺席。唯一的克制是「每一层都必须可见且不互相糊掉」。

颜色

深紫底深到能让五支撞色同时跳出来；玫红是第一撞色，给主区块与最抢眼的标题；金黄是撞色里最亮的一支，做第一层阴影与高亮；蓝是第二层阴影与冷侧色块；紫是渐变的中间站与第三撞色；薄荷是第四撞色与成功状态。灰度中性色一律不作主色。

字体

粗无衬线 Inter，标题 6xl 以上、全大写、字距 0.24em。大与小之间的落差本身是装饰。

组件

Layered Panel

多层面板（核心组件）。撞色填充、零圆角、4px 金与蓝的双层描边（border-double 或两层 box-shadow inset）、内边距 28px，外阴影 4px 金黄加 8px 蓝。整体 rotate(-1deg)。内部再叠一层对角渐变（玫红→紫→蓝，不透明度 25%）与一层图案（点或斜线，不透明度 10%）。hover 时阴影扩到三层（加 12px 紫）。hero 里的面板就是。

Stacked Button

行动按钮。玫红填充、金黄文字、零圆角、3px 虚线金黄描边、20px/900 全大写、字距 0.24em、padding 14px 32px，外阴影 4px 金黄加 8px 蓝。hover 时填充硬切到紫、阴影扩到 12px；按下时位移 8px 8px 且阴影收到 4px。过渡 120ms linear。

Pattern Overlay

图案叠层。用 repeating-linear-gradient（45 度斜线，8px 间隔）或 radial-gradient（6px 点阵）叠在区块上，颜色取一支撞色、不透明度 8% 到 12%。图案层永远不承载内容，它的职责是让平面不平。

Sticker Badge

贴纸徽章。48 到 72px 的全圆或星形，填一支撞色、2px 金黄描边、旋转 -8 到 8 度，压在卡片边缘并跨出 12px。里面放 11px 全大写的两行字（如「NEW / 2026」）。单屏 3 到 5 个——hero 右上那颗就是。

Mixed Type Block

混合字体块。同一区块内故意混用尺寸与朝向：88px 的标题、28px 的副标、14px 的标签，各自带不同的旋转（-3、0、+2 度）与不同底色条。文字不是被排版，而是被贴上墙。

可为与不为

可为

  • 五支高饱和撞色并用
  • 双层或虚线粗边框
  • 多层错位实色阴影
  • 图案叠图案
  • 标题 6xl 以上全大写
  • 允许 rotate 与 skew

不为

  • 不要用灰度中性色作主色
  • 不要让层与层糊在一起
  • 不要用极简留白
  • 不要用单层阴影
  • 不要用圆角
  • 不要只用一个强调色

图像

高饱和拼贴：图案、插画、照片、贴纸全部混用，且必须互相重叠。允许把照片压成高饱和双色调再叠图案。不使用灰度摄影、极简构图与留白式的图像。
