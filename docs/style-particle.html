风格 88 · 深色版面

粒子系统 PARTICLE

深空里漂浮的点与连线：数据在流动，界面只是玻璃。

距离阈值连线玻璃卡承载内容光晕代替投影离屏自动暂停

粒子系统用一层漂浮的点与连接线表达「数据在流动」：深蓝黑底、冷调强调色（蓝、青绿、紫）、粒子之间按距离阈值连线、靠近时脉冲加亮。界面本身要退到玻璃卡后面——半透明白加背景模糊，让粒子从卡片后面透出来。

它的禁令很具体：不用暖色与土色、不用粗边框、不用与粒子动画抢视觉的图案、不用常规投影（阴影改用光晕）。粒子层必须尊重 reduced-motion 并在离屏时暂停。

网络在呼吸

玻璃卡只是载体，流动的粒子才是主角。

颜色

略偏蓝的蓝黑让粒子与连线在暗处仍有层次；墨青比底色再深一点，做次级区块与玻璃卡的衬底；带蓝调的近白管主文字与最亮的粒子；数据蓝是连线与粒子主色，是「数据流动」的视觉主体；脉冲青比数据蓝更亮一档，管脉冲与「命中」反馈；星云紫做远层粒子与次级强调，制造纵深。

组件

Particle Canvas

粒子层（签名组件）。一个满幅 canvas 固定在内容之后、页面底之上。粒子数按面积计算（每 10000px² 一个，上限 120 个），半径 1 到 3px，颜色取数据蓝或星云紫并带 8px 光晕。两粒子距离小于 140px 时连线，线宽 1px、不透明度按距离线性衰减到 0。靠近指针的粒子在 200px 半径内轻微外推。所有绘制在 requestAnimationFrame 内完成，离屏时用 IntersectionObserver 暂停，prefers-reduced-motion 时画一帧静态分布。hero 里点与连线就是它的静态化。

Glass Card

内容卡与数据面板。雾白 6% 填充、16px 圆角、1px 雾白 12% 描边、内边距 24px，20px 背景模糊，外发光 0 0 40px 数据蓝 25%——绝不用常规投影。标题 24px/600 雾白，正文 14px 雾白 70%。hover 时填充升到 10%、发光扩到 60px。hero 里的玻璃卡就是。

Glow Button

主行动按钮。数据蓝 12% 填充、1px 数据蓝 40% 描边、12px 圆角、雾白文字 15px/500、padding 12px 24px，外发光 0 0 24px 数据蓝 30%。hover 时填充升到 20%、发光扩到 40px、文字转纯白。过渡 200ms。

Pulse Ring

脉冲指示与选中反馈。以元素中心为原点，扩散一圈 1px 的脉冲青环：半径从 8px 扩到 48px、不透明度从 100% 降到 0，时长 1.2s ease-out，循环或在点击时触发一次。同一屏最多三处同时脉冲。hero 玻璃卡左上那圈就是。

Nebula Field

远层星云背景。在粒子层之后再叠一层径向渐变（星云紫 8% 与数据蓝 6% 各一团，模糊 120px），位置随机但固定在首次渲染时，不随滚动移动。它提供纵深，不与粒子抢运动。

可为与不为

可为

  • 深蓝黑底配冷调强调
  • 粒子层离屏时暂停
  • 连线透明度按距离衰减
  • 纵深用光晕，不用常规阴影
  • 内容压在玻璃卡上
  • 尊重 reduced-motion

不为

  • 不要用暖色或土色作主调
  • 不要用粗边框
  • 不要用与粒子竞争的图案
  • 不要用浅色背景
  • 不要用常规投影
  • 不要超过三个同时脉冲

图像

图像即粒子层本身，不用摄影与插画。允许数据可视化（网络图、流向图）作为卡片内容。不使用静态背景图与几何装饰，它们会与粒子抢注意力。
