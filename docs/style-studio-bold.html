颜色

墨黑做深色区块底与浅色区上的文字，是整套风格的骨架；纸白做浅色区块底，比纯白暖，避免与纯白文字混淆；珊瑚是唯一强调色，只给 CTA、hover 态与 hero 里被高亮的关键词；纯白只做文字，绝不当底色；石墨做深色区里的次级文字与分隔线；近黑给页头页脚，在深色区之间再分一层。

  • Ink深色区块底与浅色区上的文字。骨架色。
    #1a1a1a--color-ink
  • Paper浅色区块底。比纯白暖。
    #f5f5f0--color-paper
  • Coral唯一强调色：CTA、hover 与 hero 高亮词。
    #ff6b6b--color-coral
  • White只用于文字，绝不作底色。
    #ffffff--color-white
  • Graphite深色区里的次级文字与分隔线。
    #333333--color-graphite
  • Near Black页头页脚，比区块底再深一层。
    #0d0d0d--color-near-black

静止时零阴影：none at rest — blocks do the separating。只有两处 hover 才出现阴影——卡片 0 25px 50px rgba(0,0,0,0.25)、CTA 0 20px 40px rgba(255,107,107,0.3)。

字体

全站无衬线。标题用 700 到 900 并压到行高 0.95，正文用 300 到 400，两者之间的差距本身就是层级。衬线字体一律不用。

组件

Hero Display

超大首屏标题（核心）。96 到 128px、900 字重、行高 0.95、字距 -0.04em，左对齐并可跨行。其中一到两个关键词用珊瑚色，其余白或墨。绝不小于 48px——小于这个尺寸就失去冲击力。hero 里那块就是。

Coral CTA

主行动按钮。珊瑚填充、白字、零圆角、无描边、18px/700、padding 16px 32px，无静态阴影。hover 时填充加深到 #e55a5a、阴影 0 20px 40px 珊瑚 30%、上浮 2px；按下缩放 0.98；过渡 300ms。

Project Card

项目卡。浅色纸底、零圆角、overflow hidden、无边框。图片 4:3 或 16:9，文字压在图片下方（不在图上），项目名 24 到 32px/700、客户名 14px/300 灰。hover 时整体放大 1.02 并加 0 25px 50px 阴影，图片再放大 1.04；过渡 300ms。

Section Switch

区块底色切换，也就是分隔手段。区块之间不加边框也不加阴影，直接用底色切换：深（#1a1a1a）→ 浅（#f5f5f0）→ 深。切换本身就是分隔符，而且它比线更有力量。整页通常三到五个色块。

Testimonial Block

客户引文。最大宽度 64rem 居中、内边距 64px 左右 48px，引文 24 到 30px 斜体、行高 1.6、墨色，下方 14px 的姓名与职位。无引号图标、无边框。

可为与不为

可为

  • hero 标题不小于 48px，通常 96 到 128px
  • 零圆角，头像除外
  • 全站无衬线
  • 区块靠底色切换分隔
  • 珊瑚贯穿全站作唯一强调
  • 卡片 hover 放大 1.02

不为

  • 不要用小号或标准字号做 hero
  • 不要用圆角
  • 不要用衬线字体
  • 不要用细边框分割区块
  • 不要用纯白背景
  • 不要把文字压在作品图上

图像

项目作品图与团队肖像。作品图必须高质、可裁切、不带圆角与边框，比例 4:3 或 16:9。允许客户 logo 墙（灰度或单色）。不使用装饰插画与背景纹理。
