风格 39 · 浅色版面

浮世绘数字风 UKIYO-E DIGITAL

靛蓝、朱红、金箔压在粗线条里：一版套一版的木刻。

三色套印3px 粗描边硬边偏移位移零圆角零模糊

浮世绘数字风来自日本木版画的套色工艺：靛蓝、朱红、金箔三色为主，形用粗线条勾出，色块平涂，构图取北斋式的斜向动势与波浪纹。它的交互语言也照搬版画——hover 时元素做硬边偏移位移（像第二版印歪了一点），绝不允许柔和模糊。

禁令很硬：不许渐变阴影与柔和模糊、不许透明度与玻璃效果、不许西式圆角与圆形按钮、不许霓虹、不许弹簧回弹与丝滑动效。右边这张版画卡是真的——移上去看第二版印歪的那一下。

颜色

靛蓝是木版画里的「蓝摺」——文字、粗线条与深色区块都归它；米白和纸做底，所有色块压在它上面；朱红是画面里唯一的暖色重音，管印章、日出与警示；金箔面积必须小，像贴上去的；群青比主靛更亮，画水与远景；若草管植物与苔，频率最低。

  • Indigo主色：文字、粗线条与深色区块。木版画里的「蓝摺」。

  • Washi纸底。米白的和纸色，所有色块压在它上面。

  • Vermilion第一强调：印章、日出与警示。是画面里唯一的暖色重音。
    #d4553a--color-vermilion
  • Gold Leaf贵重与高光，面积必须小，像贴上去的金箔。
    #c9a227--color-gold-leaf
  • Ultramarine第二层蓝，用于水与远景，比主靛更亮。
    #2a5a8c--color-ultramarine
  • Young Grass植物与苔，出现频率最低。
    #747800--color-young-grass

阴影只有套版偏移：4px 4px 0 #1a3055、hover 6px 6px 0 #1a3055；按下归零。没有模糊，没有透明度。

组件

Woodblock Card

版画卡片（核心组件）。和纸填充、零圆角、3px 靛蓝描边、内边距 32px，硬阴影 4px 4px 0 靛蓝；顶部或底部用 4px 的朱红横条压边。hover 时硬阴影扩到 6px 并整体位移 2px 2px（模拟第二版印歪），过渡 150ms linear。上方演示卡即此组件。

Seal Button

行动按钮。朱红填充、和纸文字、零圆角（绝不是圆形）、3px 靛蓝描边、20px/700、字距 0.2em、padding 14px 32px，硬阴影 4px 4px 0 靛蓝。hover 时阴影扩到 6px 且整体位移 2px 2px；按下时阴影归零并下沉。过渡 120ms linear。

Wave Pattern + Gold Seal

波浪纹装饰：用重复的圆弧画出北斋式波浪，线宽 3px、靛蓝或群青，高度 48 到 120px；只出现在区块的上下边，单屏不超过两处——标题下那条就是。印章标记：32px 见方的朱红或金箔方块（4px 圆角）、内嵌 20px 的和纸色衬线单字、边缘做 1px 的残缺；用于标记章节与「已阅」——演示卡右上角那枚就是。

Cartouche Label

题签标签。靛蓝填充、和纸文字、零圆角、16px/700、字距 0.2em、padding 6px 14px，左侧加一条 3px 金箔竖线；用于栏目名与编号，位置常在区块左上。

其ノ一

可为与不为

可为

  • 靛蓝、朱红、金箔三色为主
  • 3px 粗描边勾形
  • 硬边偏移阴影，零模糊
  • 零圆角，绝不圆形按钮
  • hover 做版画式偏移位移
  • 粗衬线配宽字距

不为

  • 不要用渐变阴影或柔和模糊
  • 不要用透明度与玻璃效果
  • 不要用西式圆角与圆形按钮
  • 不要用霓虹或高饱和现代色
  • 不要用弹簧回弹
  • 不要用丝滑的现代动效

图像

木版画风插画：波浪、富士、花鸟、人物侧面，必须粗描边加平涂。允许把照片处理成三色木刻效果。不使用柔和渐变、写实摄影与玻璃质感。
