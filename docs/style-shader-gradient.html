颜色

画布底是近黑但不纯黑，好让虹彩有暗部可以沉下去。主要文字用略带冷的白。紫色是唯一的 UI 强调色，只给主按钮、聚焦态与图标；着色器里的青与粉只属于着色器场，用来给渐变做冷暖过渡——它们不算 UI 色，也不允许出现在界面控件上。

组件

Violet CTA

主行动按钮。紫色填充、白字、12px 圆角、无描边，16px/500、padding 12px 24px，阴影 0 8px 30px 紫 35%。hover 时填充提亮到 #8f72ff；按下缩放 0.98。过渡 300ms。全页只有一个——hero 里那个就是。

Glass Card

内容卡与特性卡。白 6% 填充、24px 模糊、16px 圆角、1px 白 10% 描边、内边距 24px，阴影 0 20px 60px 黑 45%。左上角一个 36px 的紫色 20% 底图标块（8px 圆角、1px 紫 30% 描边）。标题 20px/600 白色，正文 14px 白 60%。

Shader Field

实时着色器画布（签名组件）。一个满幅 canvas 固定在最底层，运行片元着色器渲染三支色（紫、青、粉）的网格渐变，颜色随时间缓慢呼吸（周期 20 到 30 秒）。必须给 devicePixelRatio 设上限（通常 2），必须用 IntersectionObserver 在离屏时暂停 requestAnimationFrame，WebGL 不可用时回退为一张静态渐变图（同一配色），prefers-reduced-motion 时只渲染单帧。全页只能有一个 canvas。

Glass Input

邮箱与表单输入。白 6% 填充、12px 模糊、12px 圆角、1px 白 12% 描边、padding 12px 16px、16px 字。占位符白 40%。聚焦时描边转紫 70%、填充升到 9%、加 2px 紫 25% 外环。

Scrim Layer

文字可读性遮罩。在着色器与文字之间必须有一层遮罩：垂直渐变从黑 60% 到透明，或一块 24px 模糊的玻璃面板。目的只有一个——保证文字与场的对比度至少 4.5:1。禁止省略。

可为与不为

可为

  • 用真实的 WebGL 片元着色器
  • 给 devicePixelRatio 设上限
  • 离屏时用 IntersectionObserver 暂停 rAF
  • 提供 WebGL 不可用的静态回退
  • 文字下必须有玻璃板或遮罩
  • UI 只用一支紫色强调

不为

  • 不要用静态渐变图冒充实时着色器
  • 不要不限 DPR（会掉帧）
  • 不要在离屏时继续跑 rAF
  • 不要忽略 reduced-motion 与 WebGL 回退
  • 不要让文字直接压场
  • 不要放多个 canvas 或多支抢眼强调色

图像

图像即是着色器本身，不使用摄影与插画。允许产品截图放在玻璃面板内。禁止额外的背景图，它会与场打架。
