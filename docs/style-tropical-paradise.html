热带天堂 TROPICAL PARADISE

棕榈叶、芒果黄、珊瑚红：一张度假村的海报。

暖黄底 + 蓝绿圆角 16–24px阴影带蓝绿色棕榈叶遮挡构图

热带天堂来自度假村的视觉：暖黄底、蓝绿主色、珊瑚红与芒果黄作强调、叶绿作植物。圆角放大到 16 至 24px 甚至全圆，传达柔和的度假感；阴影带颜色而不是灰；标题用圆润的大字并压紧字距；hover 用明快的亮色变化。

棕榈叶与花瓣是主要图形，允许大面积遮挡构图。

颜色

蓝绿是主色，管主按钮、文字与海水的语义；像阳光下的沙地的暖黄做页面底；珊瑚红是第一强调，给主 CTA 与花；芒果黄是第二强调与高亮，像果肉与阳光；叶绿管棕榈叶与植物语义；橄榄是压在黄上的文字，也是沙的暗部。

字体

圆润无衬线 Nunito，标题用 800 并压紧字距到 -0.02em。字形不能尖，度假不该有棱角。

组件

Island Button

行动按钮。珊瑚红填充、白字、999px 全圆角、无描边、16px/700、padding 14px 32px，彩色阴影 0 4px 20px 蓝绿 20%。hover 时填充转芒果黄、文字转橄榄、阴影扩到 32px；按下缩放 0.97。过渡 180ms ease-out。

Resort Card

内容卡与行程卡。白底、24px 圆角、无描边、内边距 28px，彩色阴影 0 4px 20px 蓝绿 20%。标题 28px/700 蓝绿，正文 16px 行高 1.65。图片 24px 圆角铺满卡宽、4:3。hover 时阴影扩到 32px、上浮 4px，图片放大 1.03。

Palm Frond

棕榈叶装饰（签名）。一片 160 到 400px 的棕榈叶（用 SVG path 画 8 到 12 片羽状小叶），填叶绿的 60% 到 100%，允许从页面角上斜插进来并遮挡部分内容。它是最能标识这套风格的图形，单屏 1 到 2 片——hero 左侧那片就是。

Sun Circle

太阳与光斑。一个 120 到 240px 的圆，填芒果黄到珊瑚红的径向渐变，不透明度 70%，配 3 到 5 个更小的光斑（各 24 到 48px、20% 不透明度）。放在区块角落作为氛围，不做动画或只做极慢的明暗呼吸——hero 右上那颗就是。

Pill Field

表单输入。白底、999px 全圆角、1px 蓝绿 25% 描边、padding 12px 22px、16px 字。占位符蓝绿 50%。聚焦时描边转蓝绿 80% 并加 3px 的蓝绿 15% 外环。

可为与不为

可为

  • 暖黄底配蓝绿与珊瑚红
  • 圆角 16 到 24px 或全圆
  • 阴影带蓝绿颜色而不是灰
  • 棕榈叶大面积遮挡构图
  • 标题圆润大字并压紧字距
  • hover 用明快亮色变化

不为

  • 不要用暗调或冷色摄影
  • 不要用锐利直角
  • 不要用灰黑阴影
  • 不要用小于 12px 的圆角
  • 不要用衬线字体
  • 不要超过两片棕榈叶

图像

度假场景摄影：海滩、棕榈、水果、泳池、热带植物。必须高亮、暖调、饱和。允许俯拍平铺。不使用暗调摄影、冷色图像与写实人物特写。
