漫画风格 COMIC STYLE

粗墨线、硬阴影、对话气泡与爆炸字：屏幕上的一本漫画分镜。

4px 墨线套印硬阴影对话气泡100ms 跳切

漫画风格把印刷漫画的语汇搬到界面上：4px 纯黑墨线包围每个元素，4px 零模糊阴影模拟套印偏移，网点（halftone）作为背景纹理，信息装在对话气泡里而不是卡片里。

字体必须粗、必须全大写、字距放宽，像标题框。动效要夸张但短：hover 时元素放大 1.05 并旋转 1 度，时长不超过 100ms，像分镜之间的跳切。圆角只允许给气泡，其它一律直角。

颜色

墨线是这套风格唯一的结构语言：边框、阴影、正文与气泡描边全归它。纸白保持印刷纸的干净，网点才显得出来；红标记「这一格很重要」，黄管高亮与爆炸效果，蓝管链接与「系统」语义，绿管「过关」，出现频率最低。

阴影就是套印偏移：4px 4px 0 #1a1a1a 常态、4px 4px 0 #ff3333 强调；按下归零。网点纹理 radial-gradient(#1a1a1a 1px, transparent 1px) 6px，整体 12% 不透明度。

字体

间距与版面

基础单位 8px，密度 comfortable。上限 1120px、2 到 3 列分镜格、12px 间隙，页面外留 48px 白边。区块之间用一条贯穿的 4px 墨线分隔，像翻页。首屏通常是一整格全幅标题加一个对话气泡。

组件

Ink Button

主行动按钮。纸白填充、4px 墨黑边框、零圆角、4px 硬阴影、18px 全大写粗体、字距 0.08em、padding 14px 28px。hover 时填充硬切到漫画黄、放大 1.05、旋转 1 度、时长 100ms；按下时位移 4px 4px 且阴影归零。

Speech Bubble

信息容器（替代卡片）。纸白填充、3px 墨黑描边、24px 圆角（唯一允许圆角的元素）、内边距 20px、4px 硬阴影；用两个伪元素画尾巴：一个 3px 描边的三角，一个盖住描边的白色三角，形成中空的对话尖端；文字 15px、行高 1.55。首屏那个气泡即此组件。

Halftone Panel + Burst Lettering

背景分镜块：白底叠一层 6px 间距的径向网点（半径 1px、墨黑），整体 12% 不透明度；面积不超过一屏的 40%，块本身可加 4px 墨线边框形成分镜格。冲击字：漫画字体 40 到 56px、全大写、填漫画红或黄、2px 墨黑描边、4px 4px 墨黑偏移阴影，可旋转 ±3 度，一屏最多一处——首屏的「WHAM!」就是。

Panel Grid

分镜格容器。2 到 3 列网格、12px 间隙、每格 4px 墨线边框、零圆角；格子高度可以不同，允许一格跨两列作为主镜头；网格外留 48px 白边，模拟印刷页的页边距。

可为与不为

可为

  • 4px 墨线包住每个元素
  • 硬阴影模拟套印偏移
  • 圆角只给对话气泡
  • 网点作为背景纹理
  • 动效不超过 100ms，动作要夸张
  • 标题用漫画体，全大写

不为

  • 不要用 2px 以下的细边框
  • 不要用柔和阴影
  • 不要把渐变当主要视觉
  • 不要给卡片加圆角
  • 不要用超过 100ms 的动效
  • 不要用正式的无衬线体做标题

图像

漫画分镜与原稿风格的插画：粗描边、平涂、网点阴影。允许把照片处理成网点单色后放入分镜格。不使用写实摄影、渐变与柔和阴影。
