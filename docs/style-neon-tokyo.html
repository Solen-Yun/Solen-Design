风格 110 · 深色版面

霓虹东京 NEON TOKYO

雨后的歌舞伎町：招牌一层压一层，光倒映在湿沥青上。

多层光晕叠加招牌叠层 -4px卡片 80% 玻璃湿地反光

霓虹东京与赛博朋克霓虹的区别在于「真实城市」而不是科幻：它模拟歌舞伎町的夜景，招牌一层压一层、多色霓虹边框交替、光晕多层叠加、湿沥青反光。底色是深夜蓝黑到紫黑的渐变，主色霓虹粉，辅以青、橙与紫。

卡片用 80% 半透明加深模糊模拟玻璃反射，粗体无衬线配日文假名作装饰元素，标题可做粉到青的渐变文字。

颜色

霓虹粉是主色，管招牌、主按钮与最主要的发光；像雨后没有星星的夜空做页面底；霓虹青是第二霓虹色，管数据、链接与冷侧光；霓虹橙模拟暖色招牌与灯笼；霓虹紫用于让招牌层失去统一色；淡蓝是文字的反光与次级高亮，最柔的一支。

光晕三档：粉 0 0 12px / 0 0 28px、青同规格、混色 0 0 16px / 0 0 32px / 0 0 48px。绝不只用一个霓虹色。

间距与版面

基础单位 8px，密度 compact。上限 1240px、容器内边距 16px，区块间距 64px。允许招牌叠层与元素重叠，圆角保持小值（2 到 8px）。整页保持暗场，霓虹只在需要被看到的地方亮。

组件

Sign Card

招牌卡片（核心组件）。深夜蓝黑 80% 填充、8px 模糊、8px 圆角、1px 霓虹粉 50% 描边、内边距 24px，多层光晕（粉 12px、粉 28px）。标题 38px/900 霓虹粉并带 0 0 10px 粉 60% 的文字发光；正文 13px 白 80%。hover 时描边换青、光晕转混色（粉加青加紫）。hero 里那张就是。

Gradient Headline

渐变标题。背景为粉到青的横向渐变配 background-clip: text 与透明字色，再加 0 0 10px 粉 40% 的文字发光（用 filter: drop-shadow 而不是 text-shadow，因为文字已透明）。只用于首屏标题，单页最多一处。

Sign Stack

招牌叠层。3 到 5 块窄长的招牌（各 120 到 200px 宽、40 到 64px 高）垂直叠放，各自不同底色（粉、青、橙、紫之一）、2px 圆角、不同光晕，块与块之间负边距 -4px 让它们挤在一起。每块里放 12px 全大写的短字。它模拟歌舞伎町的招牌墙——hero 左侧那列就是。

Wet Reflection

湿地反光。在区块底部放一条 60 到 120px 高的区域，把上方的霓虹色以 10% 到 20% 不透明度垂直翻转模糊地重复一次（用 transform: scaleY(-1) 加 blur 8px 与线性渐变遮罩淡出）。它让页面像刚下过雨。

Neon Button

行动按钮。透明底、1px 霓虹粉 60% 描边、4px 圆角、11px 等宽全大写 0.16em、padding 10px 24px，光晕 0 0 12px 粉 60%。hover 时填充粉 12%、描边升到 100%、光晕扩到 28px；按下时位移 1px 且光晕收到 6px。过渡 120ms linear。

可为与不为

可为

  • 深夜蓝黑到紫黑的渐变底
  • 多色霓虹边框交替
  • 光晕多层叠加
  • 招牌叠层模拟招牌墙
  • 卡片 80% 半透明加深模糊
  • 湿沥青反光

不为

  • 不要用白天摄影与自然风景
  • 不要用大圆角
  • 不要用柔和插画
  • 不要只用单色霓虹
  • 不要让光晕盖过文字
  • 不要做科幻感的界面元素
