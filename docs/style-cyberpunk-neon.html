风格 16 · 深色版面

赛博朋克霓虹 CYBERPUNK NEON

近黑底上的霓虹光管：只有发光，没有阴影。

发光代替阴影近黑底4px 扫描线青主品红对

赛博朋克霓虹的第一条规则是「禁止普通阴影」——所有纵深都由发光表达，用 0 0 20px 的彩色光晕代替投影。底色近黑（#0a0a0f），扫描线以 4px 间隔叠在上面，暗示 CRT。颜色是高饱和的青、品红、黄、绿，其中青色是主色（界面骨架），品红用于对抗性强调。

圆角必须小（不超过 8px），因为霓虹灯管是硬的；字体用等宽加全大写，像终端输出。右边的面板可以悬停：描边升到 60%、填充升到 8%、光晕扩大——每一条信息都有自己的发光层级。

颜色

青是主色，界面骨架全部由它勾出；品红是对抗性强调，管危险、敌对与第二层级，与青形成经典对位；黄负责警告与数据高亮，绿像老式荧光屏一样管成功与在线，红是唯一允许的暖色，出现即过载。底色带一点蓝，让青光看起来是在发亮而不是发灰。

没有投影，只有三档发光：0 0 20px rgba(0,255,255,0.5) 青光、0 0 20px rgba(255,0,255,0.45) 品红光、0 0 8px rgba(0,255,255,0.6) 文字光晕。扫描线：repeating-linear-gradient(0deg, rgba(0,255,255,0.04) 0 1px, transparent 1px 4px)，整层 60% 不透明度。

组件

Neon Button

主行动按钮。透明底、2px 霓虹青描边、2px 圆角、无阴影色块；字级 12px、700、全大写、0.14em。静态带 0 0 12px 青色光晕，hover 填充升到 12%、光晕扩到 24px；按下光晕收到 6px、填充升到 20%。过渡 150ms。

Data Panel

卡片与数据面板。青 4% 填充、1px 青 30% 描边、4px 圆角、内边距 20px、无阴影；标题 18px 青色带文字光晕，正文白 70%；左上角可加 8px 直角切角制造硬件感。hover 时描边升到 60%、填充升到 8%、光晕 0 0 16px。上方演示面板即此组件。

Terminal Input

输入与命令行。近黑底、1px 青 40% 描边、2px 圆角、14px 等宽；左侧一个闪烁的青色方块光标（1 Hz、steps 缓动）。聚焦时描边升到 100% 并加 0 0 12px 光晕。

Scanline Overlay + Glitch Heading

全屏 CRT 纹理：固定覆盖层每 4px 一条 1px 青色 4% 横线，pointer-events none，整层 60% 不透明度——本页每一寸都叠着它。故障标题：文字用青色叠两个伪元素副本（-2px 红、+2px 青，screen 混合、70% 不透明度），仅在 hover 或每 6 秒一次抖动 60ms，其余时间静止。本页 H1 即故障标题，移上去试试。

可为与不为

可为

  • 用发光表达纵深，禁用普通阴影
  • 近黑底，不用纯黑
  • 圆角不超过 8px
  • 青色为主，品红为对抗
  • 叠一层 4px 扫描线
  • 全大写等宽，宽字距

不为

  • 不要用浅色或白色背景
  • 不要用低饱和色
  • 不要用普通投影（shadow-md 一类）
  • 不要用暖色，除警报红外
  • 不要用大圆角
  • 不要用柔和温暖的设计语言

图像

夜景城市、电路纹理、扫描线与全息投影。允许把照片压成高对比双色调后叠青色光晕。不使用白天摄影、柔和渐变与暖色插画。
