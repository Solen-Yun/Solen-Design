风格 25 · 浅色版面

千禧风格 Y2K

铬金属、透明塑料、彩虹渐变：一个对未来过度乐观的界面。

多段铬渐变透明塑料壳玻璃气泡彩虹只给一处

千禧风格来自 1999 到 2003 年的数码美学：一切都要亮、要反光、要像刚从包装盒里拆出来。技术上靠三件事模拟——铬金属用多段线性渐变做出镜面反射，透明塑料用半透明白底加 1px 亮边和顶部高光，气泡用径向渐变加内高光做出球体感。

颜色是高饱和的粉、青、品红与天蓝，常常叠在银灰底上。圆角极大（胶囊与球体），排版偏几何无衬线加宽字距，模拟当年的产品名。右边这张塑料卡可以悬停——它会像刚拆封一样反光。

颜色

铬金属承担面板与按钮底——必须叠多段渐变才有镜面感，单色会变成灰；泡泡糖粉是千禧审美最典型的颜色，管主强调与气泡；电子青管高光、边缘光与数据；品红是彩虹渐变的中段；天蓝代表那个年代的「科技蓝」，做渐变起点与背景。

间距与版面

基础单位 8px，密度 comfortable。上限 1120px、容器内边距 24px，区块间距 80px。允许元素大范围重叠与浮动，气泡可以溢出容器。首屏常见为居中标题加左右各一个大气泡。整体密度中等，但视觉元素很多。

组件

Chrome Button

主行动按钮。999px 全圆角、多段铬渐变（#f5f5f5 → #c8c8c8 → #9e9e9e → #e6e6e6）、深灰文字、1px #8a8a8a 描边，阴影带塑料壳双层与铬唇边；14px/700、0.1em 字距、padding 10px 28px。hover 时渐变整体上移（模拟光源变化）；按下时渐变反向并压暗。过渡 150ms。

Plastic Card

内容卡与产品卡。55% 白填充、24px 圆角、1px 白 80% 描边、内边距 24px，阴影 0 8px 24px 深蓝 18% 加内高光；hover 时填充升到 70%、阴影扩到 32px；卡片右上角可放一个 96px 的彩虹气泡。上方演示卡即此组件。

Bubble Element

装饰气泡与图标底。全圆角球体，径向渐变从左上白 80% 过渡到主色 100%，再叠一层深色内阴影与白色内高光，形成玻璃球质感；尺寸 48px 到 160px，可浮动在卡片外。本页三个气泡都是它。

Rainbow Border + Pill Input

彩虹边框与选中态：2px 的彩虹渐变（天蓝→青→品红→粉→天蓝）作为边框，背景保持白色；实现上用 1px padding 的渐变层加内层白底覆盖；只允许出现在一个主行动上——上方演示卡的描边就是。胶囊输入框：白 70% 填充、999px 全圆角、1px #b8d8e8 描边；聚焦时描边转电子青并加青色 30% 外环，同时叠一层顶部白色高光。

可为与不为

可为

  • 铬金属用多段渐变，单色会变灰
  • 透明塑料必须有亮边与顶部高光
  • 气泡用径向渐变加双层内阴影
  • 圆角大：胶囊与球体
  • 彩虹渐变只给一个主行动
  • 全大写加宽字距的产品名

不为

  • 不要用哑光纯色面板
  • 不要让铬金属只有单色
  • 不要把彩虹渐变用在多处
  • 不要用小圆角
  • 不要用沉静或极简的语言
  • 不要让气泡遮挡正文
