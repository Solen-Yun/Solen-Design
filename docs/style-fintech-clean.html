金融科技风 FINTECH CLEAN

紫、深海军蓝与一层网格底纹：把金融基础设施画成工程图纸。

40px 网格底纹两段叠加阴影深海军蓝正文紫只给行动

金融科技风的可信感来自克制与精度的组合：主色紫（#635bff）只出现在行动与链接上，正文用深海军蓝（#0a2540）而不是黑，底色是带一点蓝的浅灰（#f6f9fc）。标志性手法是 40px 网格底纹——它把页面变成图纸，暗示严谨。

卡片用两段叠加的柔和阴影制造浮起（而不是单层），hover 时上浮并让阴影扩散；按钮带内高光，按下时换成内阴影，形成实体按压感。右边这张卡是真的——移上去试试那个图标块。

颜色

紫是全站唯一的品牌色，一屏只出现两到三处；深海军蓝比黑柔和，读起来像印刷油墨；带蓝的浅雾底上叠 40px 网格线，白卡浮在其上；青只与紫搭配出现在渐变与图表第二序列，丁香紫是同一色相提亮一档的 hover 态。

两段阴影是这套风格的浮起公式：卡片 0 2px 10px rgba(0,0,0,0.06) 加 0 4px 20px rgba(0,0,0,0.04)，hover 扩到 0 12px 30px rgba(0,0,0,0.08)；按钮 0 2px 5px rgba(99,91,255,0.40) 加内高光 inset 0 1px 0 rgba(255,255,255,0.20)。

组件

Primary Button

主行动按钮。条纹紫填充、白字、8px 圆角、无描边；字级 14px、500 字重、padding 10px 24px。阴影为外阴影 0 2px 5px 紫 40% 加内高光；hover 时填充转深紫 #5851ea、上浮 2px、外阴影扩到 10px；按下缩放 0.98 并换成内阴影。过渡 300ms ease-out。

Floating Card

功能卡与产品卡。白底、12px 圆角、无描边、内边距 24px；阴影用两段叠加：0 2px 10px 6% 加 0 4px 20px 4%；图标块 40px 见方、10px 圆角、紫 10% 底。hover 时上浮 4px、阴影扩到 0 12px 30px 8%、图标块放大 1.1，过渡 400ms ease-out。上方演示卡即此组件。

Grid Backdrop

页面底纹与 hero 背景。两层 40px 线性渐变网格交叉，颜色为紫 10%，叠在浅雾底上，整体不透明度 40%；只出现在首屏与少数区块，不做全页铺满，否则会盖过内容。本页背景就是它。

Code Block

API 示例与配置片段。深海军蓝底、白字 90%、12px 圆角、内边距 20px、等宽 13px、行高 1.7；左上角允许一个圆点行（三个 8px 圆点）；不描边、不加阴影。

可为与不为

可为

  • 紫只给行动与链接，一屏两到三处
  • 正文用深海军蓝而不是黑
  • 卡片用两段叠加阴影
  • 网格底纹只铺首屏
  • 按钮带内高光，按下换内阴影
  • 代码块用深海军蓝底

不为

  • 不要把紫用于大面积背景
  • 不要让网格铺满全页
  • 不要用单层阴影，会失去浮起感
  • 不要引入第二支独立强调色
  • 不要用纯黑正文
  • 不要用超过 12px 的卡片圆角
