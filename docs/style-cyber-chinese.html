风格 47 · 深色版面

赛博中华风 CYBER CHINESE

朱红与金压在霓虹青紫上：灯笼挂在赛博街道。

朱红金 × 霓虹青紫格窗直角扫描光带印章与云纹

赛博中华风是两套语言的碰撞：朱红与金黄来自传统，霓虹蓝与霓虹紫来自赛博，底是近黑。造型一律直角无圆角，让它显得锐利；霓虹发光绝不可省略，但发光必须与朱红金箔共存而不是取代它们。

交互反馈带东方赛博的特质——hover 时一道短促的扫描光带或云纹流光掠过，绝不用弹簧回弹、俏皮抖动或大幅缩放，控件过渡不超过 400ms。右边这块格窗面板是真的——移上去，扫描光带会掠过它。

颜色

朱红是传统那一侧的重心——印章、主按钮与关键强调；金黄管金箔、描边与贵重标记；近黑深到让霓虹与朱红同时发光；霓虹青是赛博那一侧的主色，管扫描光带、数据与链接；霓虹紫做层叠光晕与云纹流光；淡紫是最亮的一站，做文字反光。

字体

标题用粗衬线加宽字距，像匾额；正文同族更细，保证长读。数据、坐标与状态码用 JetBrains Mono——是赛博那一侧的字体。

组件

Lattice Panel

格窗面板（核心组件）。朱红 6% 填充、零圆角、1px 金黄 45% 描边、内边距 24px，双色霓虹外发光（青 16px 加紫 40px）；四角各放一个 12px 的金黄直角角标（像窗棂收头）。hover 时一道 40px 宽、青色 25% 的斜向扫描光带从左掠到右（400ms linear），同时发光 amplify。上方演示面板即此组件。

Vermilion Button

主行动按钮。朱红填充、近黑文字、零圆角、1px 金黄 70% 描边，14px/700、字距 0.2em、padding 12px 28px，外发光 0 0 20px 朱红 40%。hover 时描边升到 100% 并加青色扫描光带，发光转青；按下时填充压暗并缩到 0.98。过渡 240ms。

Seal Stamp + Neon Data Row

印章标记：32px 见方朱红方块、零圆角、内嵌 20px 近黑衬线单字，外带 0 0 12px 朱红 50% 的发光，边缘 1px 残缺；用于标记章节与「已核」——演示卡右上角那枚就是。霓虹数据行：等宽 13px、字距 0.06em，左侧标签金黄、右侧数值霓虹青带文字发光；行高 32px，行间 1px 金黄 15% 分隔；数值必须以静态文本存在。

Cloud Motif

云纹流光装饰。用重复的回纹或云纹 path（stroke 1px、金黄 40%），沿区块边缘流动：用 background-position 或 clip-path 上的遮罩从左到右扫过，周期 3 秒、linear；仅用于装饰，单屏不超过两处。

可为与不为

可为

  • 朱红与金黄配霓虹青紫
  • 直角无圆角，造型锐利
  • 霓虹发光不可省略
  • hover 用扫描光带或云纹流光
  • 控件过渡不超过 400ms
  • 数值用等宽并带文字发光

不为

  • 不要用明亮白色背景
  • 不要用柔和圆润造型
  • 不要省略霓虹发光
  • 不要用纯西式装饰元素
  • 不要用弹簧回弹或俏皮抖动
  • 不要用超过 400ms 的控件过渡
