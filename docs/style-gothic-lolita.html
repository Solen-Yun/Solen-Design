风格 46 · 深色版面

哥特萝莉风 GOTHIC LOLITA

黑缎带、蕾丝边、十字与玫瑰：暗色浪漫的精细装饰。

蕾丝扇边框缎带燕尾按钮对称玫瑰十字浅灰白非纯白

哥特萝莉风把哥特建筑装饰与洛丽塔的精致细节缝在一起：黑底上装深紫与血红，文字用浅灰白，衬线字体带装饰性，图案必须是严格对称的哥特花纹、十字架与玫瑰，边框用蕾丝扇边或缎带。

它的禁令是：不许明亮鲜艳的颜色、不许可爱卡通元素、不许现代极简、不许过于圆润的形状——圆润会把它推向甜系，而它要的是暗。右边这张蕾丝框是真的——缎带按钮的两端是剪出来的燕尾。

颜色

深紫是缎带、边框与强调区块的主色，是黑与血红之间的过渡；血红管玫瑰、十字与关键强调；纯黑做整套风格的暗色基础；浅灰白不是纯白——带一点灰的缎面光；中紫比主紫亮一档，做抬升面与次级装饰。

  • Deep Violet主色：缎带、边框与强调区块。黑与血红之间的过渡。

  • Blood Red第二主色：玫瑰、十字与关键强调。

  • Black页面底与主体裁。整套风格的暗色基础。
    #1a1a1a--color-black
  • Pale Silver文字与蕾丝。不是纯白，带一点灰的缎面光。
    #e5e5e5--color-pale-silver
  • Mid Violet抬升面与次级装饰，比主紫亮一档。
    #6b2d5b--color-mid-violet

没有投影——深度来自装饰本身；唯一的「光」是缎带的外发光：0 0 20px rgba(74,26,74,0.60)。

字体

装饰性衬线 Cormorant Garamond：标题加 0.22em 的宽字距像蕾丝边，正文行高 1.75。

组件

Lace Frame

蕾丝扇边框架（核心组件）。深紫填充、4px 圆角、1px 浅灰白 25% 描边、内边距 32px；四边用 radial-gradient 做 8px 半径的扇贝边（间隔 16px），四角各放一个 16px 的对称哥特纹（十字或卷草，用 1px 浅灰白线画）。上方演示框即此组件。

Ribbon Button

行动按钮。深紫填充、浅灰白文字、2px 圆角、1px 浅灰白 30% 描边、14px/600、字距 0.22em、padding 14px 32px；两端用 clip-path 切出缎带的燕尾（各 10px），外发光 0 0 20px 深紫 60%。hover 时描边升到 60%、文字转血红、发光扩到 32px；按下时缩到 0.98。过渡 300ms。

Rose Motif + Cameo Portrait

玫瑰与十字装饰：48 到 96px 的对称玫瑰（8 到 12 片花瓣，双层）或十字，用 1px 线稿或平涂血红；必须严格左右对称，放在框架四角或标题两侧，单屏 2 到 3 处。浮雕头像框：96 到 160px 的椭圆框、2px 浅灰白 40% 描边、内部填深紫或放灰度肖像、外圈再加一层 4px 的深紫描边；模仿维多利亚时代的浮雕胸针。

Cross Divider

十字分隔线。一条 1px 浅灰白 30% 的横线，中央嵌一个 16px 的血红十字，两侧各有一个 4px 的菱形；用于区块之间，替代普通分隔线——本页那条就是。

可为与不为

可为

  • 黑底配深紫与血红
  • 装饰必须严格对称
  • 用蕾丝扇边与缎带
  • 装饰性衬线加宽字距
  • 文字用浅灰白而非纯白
  • 玫瑰与十字作标记

不为

  • 不要用明亮鲜艳的颜色
  • 不要用可爱卡通元素
  • 不要现代极简
  • 不要用过于圆润的形状
  • 不要用不对称装饰
  • 不要用纯白

图像

暗调摄影与插画：蕾丝、缎带、玫瑰、烛台、十字架、哥特建筑细节。必须低饱和、暗部丰富，允许棕黑单色。不使用明亮摄影、可爱插画与彩色卡通。
