CHAPTER 01 · 心动的开始

少女漫画风把日本少女漫画的视觉语汇搬到界面上：樱花粉主调、网点纹理作背景、花瓣与蕾丝扇边作边框、缎带横幅作章节标题、金色多角星作闪光点缀。它的密度比其它风格高——装饰不是可选项而是身份，边角必须有花或星。

圆角一律放大（按钮全圆、卡片 16px、面板 24px），底色保持珍珠白。禁止深色背景、禁止冷硬几何、禁止无装饰的裸卡片。右边这张蕾丝卡是真的——星星带柔光，卡片会轻轻歪一下。

今天，心动了。

网点、缎带、花瓣边——每一格都在心跳。

配色方案

  • Sakura#ffb7c5
  • Peach Rose#f8a9d7
  • Petal#fecdd3
  • Lavender#c4b5fd
  • Starlight#fde68a
  • Pearl White#fff5f7

颜色

樱花粉是第一语言——缎带、边框与主行动；带一丝粉的珍珠白比纯白更接近少女漫画的纸张；薰衣草紫管梦境与幻想场景的强调；星光金必须带 4px 柔光，否则不像星星；花瓣粉做大面积柔和区块；桃玫瑰是情绪最强的一支，给「心动」时刻的关键按钮。

  • Sakura主色：缎带、边框与主行动。整套风格的第一语言。
    #ffb7c5--color-sakura
  • Pearl White页面底。带一丝粉的暖白，比纯白更接近少女漫画的纸张。
    #fff5f7--color-pearl
  • Lavender第二色，用于梦境与幻想场景的强调。
    #c4b5fd--color-lavender
  • Starlight闪光与点缀。必须带 4px 的柔光，否则不像星星。
    #fde68a--color-starlight
  • Petal大面积柔和区块与网点底色。
    #fecdd3--color-petal
  • Peach Rose情绪最强的一支，用于「心动」时刻的关键按钮。
    #f8a9d7--color-peach-rose

柔影只有粉：0 8px 24px rgba(255,183,197,0.35)；闪光柔光 0 0 4px rgba(253,230,138,0.90)。网点不超过 35%，否则文字会糊。

字体

标题与按钮用 Quicksand——圆润的几何无衬线自带柔软感，是这套风格的基础语气；正文与对白用 Nunito，行高 1.75，读起来像漫画的旁白框。

间距与版面

基础单位 8px，密度 comfortable。上限 1080px、容器内边距 24px，区块间距 96px。允许卡片轻微旋转（-2 到 2 度）与错位堆叠。标题区常为居中缎带，内容以两列或三列卡片展开。装饰密度高于常规，但正文行宽不超过 34em。

组件

Ribbon Banner

缎带标题（识别核心）。樱花粉填充、零描边，主体高 40px、左右内边距 32px，两端各用 clip-path 切出 V 形燕尾（各 16px 宽）；文字用 Quicksand 700、18px、珍珠白、字距 0.1em；缎带下方可加一条 1px 的粉色投影线增加厚度。本页标题下那条缎带就是。

Lace Card

内容卡（带蕾丝扇边）。白底、16px 圆角、1px 樱花粉 40% 描边、内边距 32px、阴影 0 8px 24px 粉 35%；顶部或四边用 radial-gradient 做 8px 半径的波浪扇边（间隔 16px）；左上角放一个 14px 的樱花粉花朵图标作为角饰。上方演示卡即此组件。

Sparkle + Screentone Bed

多角星闪光：四角星形状（两个交叉的细长菱形或 SVG），8px 到 20px，填星光金并带 4px 柔光；散布在卡片角落与标题旁，单屏 3 到 6 个，不做动画或只做 4 秒的缓慢明暗呼吸。网点背景层：4px 间隔、半径 0.8px 的花瓣粉网点，整体不透明度 25% 到 35%；它是漫画印刷的暗示，不可超过这个强度，否则文字会糊——本页背景就是。

Pill Button

行动按钮。桃红或樱花粉填充、珍珠白文字、999px 全圆角、无描边、15px/700、padding 12px 28px，阴影 0 6px 16px 粉 40%；hover 时填充提亮并放大到 1.03；按下缩到 0.97。过渡 250ms ease-out。

可为与不为

可为

  • 樱花粉为主调
  • 边角必须有花或星
  • 章节标题用缎带横幅
  • 叠一层 25% 到 35% 的网点
  • 圆角放大：按钮全圆、卡片 16px
  • 闪光必须带柔光

不为

  • 不要用深色或暗调背景
  • 不要用冷硬几何
  • 不要做无装饰的裸卡片
  • 不要让网点超过 35%
  • 不要用小圆角
  • 不要用写实摄影

图像
