颜色

暖奶油底承载全部内容。粉彩色只用于分组与状态提示，绝不作为大面积装饰：一整块只用一种粉彩。深紫是粉彩里唯一足够深的颜色，负责主按钮、标签与链接；深灰负责标题与正文，保证对比度在 4.5:1 以上。珊瑚出现频率最低，只做情感化反馈与聚焦环。

  • Deep Violet主色：主按钮、标签与链接。
    #66508f--color-deep-violet
  • Cream页面底。温暖的白，比纯白柔和。
    #fff8f0--color-cream
  • Ink标题与正文，保证 4.5:1 以上对比。
    #332d3d--color-ink
  • Lilac第一分组色，用于精选类区块底。
    #d9c7ff--color-lilac
  • Mint第二分组色与成功状态。
    #cbefdf--color-mint
  • Butter提醒与收藏状态，只在小组件上出现。
    #ffe49a--color-butter
  • Coral情感化反馈与聚焦环，出现频率最低。
    #ffb5a7--color-coral

两层柔和阴影：0 4px 12px rgba(102,80,143,0.1) 给卡片，0 6px 16px rgba(102,80,143,0.2) 给按钮。

字体

全站一种字体，字级偏移动端：正文以 13 到 17px 为主，标题 21 到 26px，标签 12px 全大写 0.16em。

组件

Pastel Button

主行动按钮。深紫填充、白字、16px 圆角、无描边，15px/600、padding 12px 20px，阴影 0 6px 16px 紫 20%。hover 时上浮 2px；按下缩到 0.98。触控高度不小于 44px。过渡 200ms。

Group Card

内容卡与分组块。粉彩填充（薄荷、淡紫或黄油之一）、24px 圆角、1px 深紫 10% 描边、内边距 20px，阴影 0 4px 12px 紫 10%。上方 12px 全大写 0.16em 的深紫 70% 标签，中间 21px/600 深灰标题，下方 13px 正文深灰 80%。一整块只用一种粉彩。

Soft Field

搜索与输入。奶油填充、16px 圆角、1px 深紫 20% 描边、padding 12px 16px、15px 字，聚焦时加 4px 的珊瑚 40% 外环。占位符深灰 60%。

Action Cluster

决策点快捷操作。横向三个 44px 的全圆按钮，间距 12px，分别用淡紫、薄荷、珊瑚的 30% 底配深紫图标。位置固定贴在内容卡的右下角或底部条，保证用户在读完内容时手就在那里。

Bottom Sheet

移动端底部弹层。奶油底、顶部 24px 圆角、顶部 1px 深紫 10% 描边、阴影 0 -12px 40px 深紫 12%。顶部中央 36px × 4px 的深紫 20% 抓手。内边距 20px，最大高度 88vh。

可为与不为

可为

  • 暖奶油底承载全部内容
  • 粉彩只用于分组与状态
  • 文字用深紫与深灰保证对比
  • 触控目标不小于 44px
  • 快捷操作贴着决策点
  • 圆角 16 到 24px

不为

  • 不要用荧光色或高饱和渐变覆盖整页
  • 不要用过小的触控目标
  • 不要用密集的横向表格
  • 不要让粉彩承担正文
  • 不要在桌面端加宽成多栏
  • 不要在同一卡混两种粉彩

图像

以图标、头像与轻量插画为主。允许粉彩几何图形作为分组标识。不使用深色大图与高饱和摄影，移动端的图像只用于识别而非装饰。
