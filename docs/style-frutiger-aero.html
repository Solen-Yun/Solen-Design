Frutiger Aero FRUTIGER AERO

天蓝玻璃、水滴与草叶：一个相信科技会让世界更清透的年代。

天蓝渐变铺底玻璃配亮边高光0.95 果冻按压气泡草叶点缀

Frutiger Aero 是 2004 到 2012 年的系统美学：那一代桌面系统、早期手机系统与游戏主机的默认皮肤。它的配方固定——天蓝渐变作底，面板是半透明白玻璃配 1px 亮边与顶部高光，圆角大而圆润（16 到 24px），再点缀水滴、气泡、草叶与光晕。

按压是要有弹性的：active 时缩到 0.95，像果冻被按了一下，这个「jelly press」是它与后来扁平化最明显的分歧。右边这张玻璃卡是真的：hover 时填充升到 65%、阴影扩到 32px。

颜色

天蓝是渐变起点与主背景，整套风格的情绪由它决定；深天蓝低两档，压住画面，做渐变终点与按钮底；玻璃白必须配 1px 亮边与顶部高光，否则会显得脏；淡蓝雾色用于在同一玻璃上再分一层；草绿管自然语义与成功状态，也是草叶装饰的颜色；亮蓝管高光、链接与光晕，让元素显得在发光。

组件

Jelly Button

主行动按钮。深天蓝填充、白字、16px 圆角、1px 白 60% 描边，阴影 0 4px 12px 深蓝 30% 加 inset 0 1px 0 白 80%。15px/600、padding 10px 24px。hover 时填充提亮 6%、阴影扩到 16px；按下时缩到 0.95 并压暗填充，这是果冻按压。过渡 200ms ease-out。焦点环用白色 2px 加 2px offset，offset 色取天蓝以在蓝底上可见。

Aero Panel

卡片与窗口面板。55% 白玻璃填充、24px 圆角、1px 白 60% 描边、内边距 24px，阴影 0 8px 24px 深蓝 22% 加 inset 0 1px 0 白 90%。面板内可再叠一层淡蓝雾色的小卡。hover 时填充升到 65%、阴影扩到 32px。hero 里的玻璃卡就是。

Gloss Input

搜索与表单输入。白 70% 填充、16px 圆角、1px 白 70% 描边，内阴影 inset 0 2px 4px 深蓝 15% 制造轻微凹陷，padding 10px 16px、14px 字。聚焦时描边转亮蓝并加 2px 亮蓝 40% 外环。

Gloss Nav

顶部导航。高 64px、白 45% 玻璃、16px 模糊、底部 1px 白 40% 描边、无阴影。字标 16px/600，链接 14px、间距 24px，hover 时链接下方出现 2px 亮蓝下划线。右侧放一个果冻按钮。

Bubble Ornament

水滴与气泡装饰。24px 到 96px 的圆，径向渐变从左上白 90% 到亮蓝 20%，加 inset 0 -3px 6px 深蓝 25% 与 inset 0 3px 6px 白 90%，形成透明水泡。斜向置于面板角落，可半透出背景。单屏不超过五个——hero 里那两颗就是。

可为与不为

可为

  • 天蓝渐变铺满整个页面
  • 玻璃必须配亮边与顶部高光
  • 圆角 16 到 24px
  • 按压用 0.95 的果冻缩放
  • 焦点环 offset 取底色，保证可见
  • 用气泡与草叶点缀自然感

不为

  • 不要用深色或黑色背景
  • 不要用锐角与硬边几何
  • 不要用霓虹或刺眼色
  • 不要用等宽字体
  • 不要用无玻璃效果的哑光面
  • 不要用 0.98 的轻按压，果冻要更明显

图像

天空、水面、草叶、玻璃与水滴的高清照片或渲染。允许 40% 到 60% 的不透明度叠在渐变上。不使用深色照片、噪点纹理与扁平插画。
