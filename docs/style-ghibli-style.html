风格 28 · 浅色版面

吉卜力风格 GHIBLI STYLE

手绘的天空与草地，暖到发甜的绿，一切都慢半拍。

手作痕迹0.8 度倾斜暖棕代黑500–700ms 缓动

吉卜力风格来自动画场景美术：天空从浅蓝渐变到奶油，云是几块模糊的白，地面是带纹理的鼠尾草绿。它的核心不是配色而是「手作痕迹」——圆角一律很大，边界带 2px 半透明描边，卡片与按钮在 hover 时会轻微倾斜（0.8 度），像被人拿起来看了一眼。

颜色全部低饱和、偏暖，最深的文字用暖棕（#5a4a3a）而不是黑。动效慢，500 到 700ms，缓入缓出，允许缩放与旋转这种「有机」的位移，而不是机械的上下平移。右边这张场景卡是真的——拿起它看看。

颜色

鼠尾草绿是草地的绿，也是整套系统的主色；奶油让画面有「被夕阳照过」的暖度；暖棕替代黑色，避免破坏画面的暖调；珊瑚橙管夕阳与暖色强调；天青是渐变的上半段；玫瑰灰只在小面积出现，管情感强调。

  • Sage主行动与自然语义。草地的绿，也是整套系统的主色。

  • Cream卡片与地平线。让画面有「被夕阳照过」的暖度。

阴影轻而暖：卡片 0 8px 30px rgba(90,74,58,0.06)、hover 转绿 0 16px 40px rgba(124,185,168,0.18)、按钮 0 8px 20px rgba(124,185,168,0.30)。不用阴影做主要分层。

组件

Journey Button

主行动按钮。天青到鼠尾草的纵向渐变、白字、999px 全圆角、2px 描边（主色 25% 不透明度）；字级 18px、字重 500、padding 16px 32px，阴影 0 8px 20px 绿 30%。hover 时上浮 4px、放大 1.01、旋转 0.8 度、阴影扩到 30px；按下时缩放 0.98 且角度归零。过渡 500ms ease-in-out。

Story Card

内容卡与场景卡。奶油到浅琥珀的斜向渐变（90% 不透明）、24px 圆角、1px 描边（#d4c49a 45%）、内边距 32px、10px 模糊；图标块 64px 圆形、天青到鼠尾草渐变、内部阴影。hover 时上浮 6px、反向旋转 0.8 度、放大 1.01、阴影转绿 18%，图标放大 1.05 并旋转 6 度。过渡 700ms ease-in-out。上方场景卡即此组件。

Story Input

表单与写作输入。奶油 60% 填充、2px 描边（#d4c49a 40%）、16px 圆角、padding 16px 20px、15px 字、暖棕文字；聚焦时描边转鼠尾草、填充升到 80%，过渡 300ms。

Cloud Layer

首屏云层与背景装饰。三到五块白色 40% 到 60% 的椭圆（宽高比 2:1），模糊 4px，分布在天空渐变的上三分之一，位置错落不重叠；不做动画或只做极慢的横向漂移（60 秒以上一个循环）。本页顶部那几朵云就是它。

可为与不为

可为

  • 用暖棕替代黑色文字
  • 圆角大：按钮全圆角、卡片 24px
  • hover 允许 0.8 度旋转与 1.01 放大
  • 动效 500 到 700ms，缓入缓出
  • 用天空渐变与云层建立场景
  • 正文行高 1.75，读起来像旁白

不为

  • 不要用纯黑与高饱和色
  • 不要用锐利直角
  • 不要用快速过渡或线性缓动
  • 不要让云层重叠成一大块
  • 不要在画面里加科技感元素
  • 不要用阴影做主要分层手段

图像

手绘感插画与动画场景美术：天空、草地、小屋、云。允许纸张或水彩纹理叠加 5% 到 10%。不使用锐利摄影、3D 渲染与高饱和色块。
