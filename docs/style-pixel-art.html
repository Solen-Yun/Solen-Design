风格 13 · 浅色版面

像素艺术风 PIXEL ART

没有过渡的世界：所有状态变化都是硬切，像 8-bit 游戏机。

零圆角4px 黑框调色板硬切transition-none

像素艺术风的美学来自硬件限制：只有几种颜色、没有抗锯齿、没有过渡。落到网页上就是三条硬规则——零圆角、4px 纯黑边框、4px 零模糊的偏移阴影。最关键的一条是 transition-none：像素游戏是状态机而不是动画引擎，hover 与按下必须瞬间完成，任何淡入淡出都会毁掉这个错觉。

交互语义也照搬游戏：hover 直接把调色板里的某一个颜色换成另一个（红的按钮变蓝），按下时元素位移 4px 且阴影归零，像按钮被真正按到底。右边的按钮和卡片都按这个规则跑——移上去、按下去试试。

LEVEL 1

硬切，不淡入。

状态机，不是动画引擎。

颜色

调色板就六支，不许调出界。深靛承担全部结构：边框、阴影、正文与导航；纸白只与深靛配对，不做灰度过渡。红管主行动与危险，蓝管链接与 hover 替换，绿管成功与生命值，黄只给需要立刻被看到的小元素。

  • Deep Indigo所有边框、阴影、深色区块与正文。8-bit 调色板里最暗的一档。
    #1a1c2c--color-deep-indigo
  • Paper面板填充。只与深靛配对，不做灰度过渡。
    #ffffff--color-paper
  • Pixel Red主行动与危险动作。hover 时会被换成像素蓝。
    #ff004d--color-pixel-red
  • Pixel Green成功与生命值，游戏语义里的正向状态。
    #00e436--color-pixel-green
  • Pixel Blue链接、选中态与 hover 替换色。
    #29adff--color-pixel-blue
  • Pixel Yellow金币、得分与高亮，用于需要立刻被看到的小元素。
    #ffec27--color-pixel-yellow

阴影只有两档硬偏移：4px 4px 0 #1a1c2c 与 hover 的 4px 4px 0 #ff004d；按下时归零。没有第三档，也没有模糊。

字体

标题与按钮用像素字体 Press Start 2P，全大写；正文用等宽字体保持可读。字距必须偏宽，否则像素会粘在一起。字号只取 8-bit 值：10、12、16、24、32。

组件

Pixel Button

主行动按钮。像素红填充、纸白字、4px 深靛边框、零圆角、4px 硬偏移阴影；字级 12px、全大写、字距 0.12em。hover 时填充硬切到像素蓝、阴影硬切到像素红；按下时位移 4px 4px 且阴影归零。全程 transition-none。

Pixel Card

内容卡与关卡卡片。纸白填充、4px 深靛边框、零圆角、24px 内边距、4px 硬阴影；标题 24px 全大写，正文 12px 等宽。hover 时边框与阴影硬切到像素红、标题同步变红，元素本身不位移。上方演示卡即此组件。

移上去看调色板替换——没有淡入。

Pixel Input

输入框。纸白填充、4px 深靛边框、零圆角、padding 12px 16px、12px 等宽全大写，占位符用深靛 50%。聚焦时用 2px 像素蓝的内描边（inset 0 0 0 2px），不改外框尺寸。

Pixel Nav

顶部导航。深靛填充、底部 4px 像素红边框、白字全大写、字距 0.05em；链接 12px，hover 直接换成纸白（硬切），选中项用像素黄。高度 56px，无圆角无阴影。页面底部这条即此组件。

可为与不为

可为

  • 零圆角、4px 边框、4px 硬阴影
  • 全程 transition-none，状态硬切
  • hover 做调色板替换，不做淡入
  • 按下位移等于阴影偏移量
  • 字号取 8-bit 值：10、12、16、24、32
  • 所有尺寸是 4 的倍数

不为

  • 不要用任何圆角
  • 不要用渐变或柔和阴影
  • 不要用 transition-* 除 none
  • 不要用细边框
  • 不要在 hover 里做 opacity 过渡
  • 不要用超出调色板的颜色

图像

像素画与 8-bit 图标是唯一图像语言。允许把照片降采样成像素图。不使用矢量插画、柔和摄影与任何抗锯齿图形。
