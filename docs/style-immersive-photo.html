风格 53 · 深色版面

沉浸摄影 IMMERSIVE PHOTO

照片就是界面：它不装饰内容，它就是内容本身。

全幅照片主角可读性遮罩20s Ken Burns唯一琥珀金强调

沉浸摄影把所有界面元素减到最少，让全幅照片占据视口，文字浮在可读性遮罩之上。它的技术纪律比视觉更重要——每张图必须有 aspect-ratio（防 CLS）、用 AVIF 或 WebP 配 srcset、首屏给 LQIP 占位再淡入、缓慢的 Ken Burns 漂移只用 transform（8 秒起，且尊重 prefers-reduced-motion）。

强调色只有一支，而且必须从照片的暖光里采样（例如琥珀金），不允许硬塞品牌色去和照片打架。右边这张摄影卡是真的——照片会以 1200ms 缓慢放大。

颜色

近黑但不纯黑的墨色做遮罩与空隙，避免与照片暗部糊在一起；暖白在照片之外提供呼吸；琥珀金是唯一强调色——从照片的暖光采样，只给关键 CTA 与小标签；深灰比墨亮一档做分层；雾色管图注与元数据，永远不与琥珀金同屏竞争。

  • Ink遮罩、页脚与照片之间的空隙。近黑但不纯黑，避免与照片的暗部糊在一起。

  • Paper浅色区块与图注。暖白，用于在照片之外提供呼吸。
    #f4f1ea--color-paper
  • Amber唯一强调色，从照片的暖光采样。只用于关键 CTA 与小标签。
    #e8b04b--color-amber
  • Deep Grey次级区块底与卡片，比墨亮一档，用于分层。
    #1a1c22--color-deep-grey
  • Mist图注、元数据与次级文字。永远不与琥珀金同屏竞争。
    #b8bcc4--color-mist

遮罩是硬纪律：linear-gradient(to top, rgba(0,0,0,0.70), transparent)；文字对比至少 4.5:1。摄影卡阴影 0 24px 60px rgba(0,0,0,0.35)、hover 0 32px 80px rgba(0,0,0,0.45)。

字体

全站唯一字体 Inter：照片上的标题用 44 到 64px、500 字重，图注用 11px 全大写加 0.16em 字距。

组件

Photo Stage

首屏与全幅图片区块。100vh 高、object-fit: cover、带 aspect-ratio（首屏 16:9，卡片 4:5），底部到顶部叠一层从黑 70% 到透明的渐变遮罩；图片带 20s 的 Ken Burns 漂移（scale 1.00 到 1.06，只用 transform，ease-out），prefers-reduced-motion 时静止；加载前显示 LQIP 模糊占位并在 400ms 内淡入。

Caption Block + Photo Grid

图片说明与元数据：贴在图片底部或左下方，距边 24px；上方 11px 全大写 0.16em 的琥珀金系列标签，中间 18 到 28px 白色标题，下方 12px 雾色元数据（地点、时间、器材）；文字必须落在遮罩较暗的一侧。画廊与作品列表：两到三列、间距 16px、每张卡片固定 4:5 比例、16px 圆角、overflow hidden；图片 hover 时 scale 到 1.05、过渡 1200ms ease-out，卡片阴影同时加深；卡片内不加边框。上方演示卡即此组件。

Amber CTA

关键行动按钮。琥珀金填充、墨色文字、999px 全圆角、无描边，14px/600、padding 12px 28px，阴影 0 8px 24px 琥珀 30%。hover 时填充提亮 8%、阴影扩到 32px；按下缩放 0.98。全页只允许一个。

Minimal Nav

顶部导航。绝对定位在首屏之上，高 72px、透明底、无边框；字标与链接为白色，11px 全大写 0.16em；hover 时链接转琥珀金；滚动后切换为墨色 90% 底加 12px 模糊。

可为与不为

可为

  • 每张图必须有 aspect-ratio
  • 用 AVIF 或 WebP 配 srcset
  • 首屏给 LQIP 占位再淡入
  • Ken Burns 只用 transform，8 秒起
  • 文字必须落在遮罩暗侧
  • 尊重 prefers-reduced-motion

不为

  • 不要把照片当背景再铺卡片挡住它
  • 不要让文字直接压在图上不加遮罩
  • 不要用未优化的全尺寸 JPG
  • 不要用无 aspect-ratio 的图片
  • 不要引入第二个强调色
  • 不要用快于 8 秒的漂移

图像

全部是全幅摄影，且照片必须具备明确的光线方向与可安放文字的暗部。允许同一位摄影师的一组作品形成系列感。不使用插画、图标墙、渐变背景与非摄影图像。
