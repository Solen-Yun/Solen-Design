布局模式 07 · 扫读版面

F 型布局 F-PATTERN LAYOUT

按眼动轨迹排版：先横扫顶部，再下移横扫，最后沿左缘直落。

关键词前置65–75 字符行宽左缘竖条列表极简强调

F 型布局来自眼动研究：读者先横向扫过顶部，再往下横扫一次，最后沿左边缘纵向跳读，轨迹像字母 F。所以它把最重要的信息放在顶部两行、把关键词放在每段的句首、把行宽压到 65 到 75 字符。

视觉上它必须安静：白底、深色标题、极少的强调色，因为任何装饰都会打断扫描。它的价值不在好看，而在让一屏能多读 30% 的内容——适合文档、博客、新闻列表与长页说明。下面就是一张按 F 轨迹排的页面。

布局实演

页面结构固定为：顶横（标题加导语）→ 中横（三到四项）→ 竖笔（列表）。重要内容永远在左上，右下角只放次要信息。

扫读先于阅读：F 型的三段轨迹

读者不会读完每一个字——他们扫过顶部、横扫中段、沿左缘直落，然后才决定读哪里。

顶部第一横扫标题与导语承担全部结论。
中段第二横扫三到四项并列，句首即结论。
左缘纵向直落竖条列表沿左缘跳读。
先横扫顶部两行关键词必须出现在标题前三个词之内。
再下移一次横扫中横的三到四项承接次级结论。
最后沿左缘直落左缘竖条帮助视线定位每一个条目。
行宽压到 65–75 字符过长会把 F 的中横拉断。

颜色

深而不黑的墨色让长读不刺眼；极浅冷白把文字对比拉到最大；朱红是唯一的高强调，只给关键结论与必须被扫到的词；钢蓝管链接与次级标题；松绿管「可执行」，频率最低；沙金只做行内高亮，标记关键短语。

  • Ink标题与正文。深而不黑，长读不刺眼。

字体

全站唯一字体 Inter：层级靠四级字号加两档字重建立，不靠颜色。正文行高 1.7，长读不疲劳。

组件

Scan Header

页面顶部标题区（F 的顶横）。标题 36px/700 单行、行宽不超过 34 字符；其下 16px 导语最多两行；再下一条 1px #e2e8f0 横线；整块左对齐，顶部内边距 48px。关键词放在标题前三个词内。上方实演的标题区即此组件。

Scan Row

横向扫描行（F 的中横）。三到四项横向排列，每项：12px 全大写标签在上、20px/600 标题在中、14px 摘要在下（最多两行）；项与项之间 32px 间距，整行高度不超过 160px。左对齐，不居中。

Article List

纵向列表（F 的竖笔）。每行左侧一条 2px 宽、48px 高的强调色竖条（朱、钢蓝或松绿），右侧 16px/600 标题与 14px 摘要；行高 88px、行间 1px 分隔。hover 时竖条加宽到 4px、背景转白。上方实演的列表即此组件——悬停任意一行试试。

hover 让竖条加宽，视线跟着左缘走。

Inline Highlight + Measure Column

行内高亮：淡沙金底（35%）、无圆角、padding 0 2px，只在行内使用、不加粗，一篇不超过三处——本句里就有一处关键的锚点。正文列宽容器：最大 760px、行宽 65 到 75 字符（约 34em）、左内边距 0、段间距 20px、段首不缩进、禁止居中。

可为与不为

可为

  • 关键词放在标题前三个词
  • 正文行宽 65 到 75 字符
  • 每段首句承担结论
  • 强调色只用于必须被扫到的词
  • 重要内容放左上
  • 用标题层级、列表与分段提升可扫描性

不为

  • 不要把重要内容放右下角
  • 不要居中大段文字
  • 不要忽视内容优先级
  • 不要写没有分段的长文
  • 不要在左侧留过多空白
  • 不要用超过三处高亮

图像

以文字为主，图像必须服务于扫读：图表、截图、缩略图（统一 16:10）。不使用装饰性大图与背景图，它们会把 F 的轨迹切断。
