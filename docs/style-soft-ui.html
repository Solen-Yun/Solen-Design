风格 07 · 浅色版面

柔和界面风 SOFT UI

大圆角、彩色柔光阴影、低饱和配色，让人第一眼就想点。

彩色柔光大圆角低饱和浮起交互亲和动效

柔和界面风服务消费级产品：社交、生活方式、面向普通用户的工具。它的做法是把所有硬的东西变软——圆角从 16px 起、卡片 24px；阴影不只是暗，而是带主色相的彩色柔光（靛蓝 25% 透明度、24px 以上模糊）；颜色一律低饱和，纯黑和纯饱和色都被排除。

交互靠浮起表达：hover 时元素上移、阴影扩大、主色加深，按下时先落回再轻微内凹。动效允许慢到 300 至 500ms，因为柔和本身就是被感知的时长。右边的卡片和按钮都是真的，悬停、按下试试。

人人都想点

圆角、柔光与低饱和，让第一次接触就没有门槛。

配色方案

  • Indigo#6366f1
  • Mist#f1f5f9
  • Cloud White#ffffff
  • Blossom#ec4899
  • Mint#10b981
  • Amber#f59e0b

颜色

配色一律低饱和，排除纯黑与纯饱和色。靛蓝是唯一的品牌色，承担主行动与选中态；Blossom 是情绪化强调，不与靛蓝同时作为主色；Amber 出现频率最低，靠面积小来控制存在感。

  • Indigo主行动、选中态与链接。柔和不等于没有主色，它需要一支明确的品牌色。
    #6366f1--color-indigo
  • Mist页面画布与输入框底。比白更柔，让白色卡片有依托。
    #f1f5f9--color-mist
  • Cloud White卡片与浮层填充。柔和风格里最亮的一层，但不刺眼，因为阴影把它托起来。
    #ffffff--color-cloud
  • Blossom情绪化强调：收藏、喜欢、社区反馈。不与靛蓝同时作为主色。
    #ec4899--color-blossom
  • Mint成功与完成状态。用于进度、勾选、已保存。
    #10b981--color-mint
  • Amber提醒与待办。出现频率最低，靠面积小来控制存在感。
    #f59e0b--color-amber

表面层级：0 Mist #f1f5f9，1 Cloud White #ffffff。阴影全部带色相：卡片静置 0 12px 32px rgba(148,163,184,0.25)，悬停转靛蓝 0 24px 48px rgba(99,102,241,0.20)；按钮静置 0 10px 24px rgba(99,102,241,0.25)，按下内凹 inset 0 4px 10px rgba(67,56,202,0.28)。

字体

全站唯一字体，字重 600 承担亲和型标题，700 只用于数字与强调；不用纯黑文字，正文用 #1f2937。

间距与版面

基础单位 8px，密度 airy。12 栏、上限 1200px，容器内边距 24px；区块间距 96px，卡片间距 24px，元素间距 24px。留白是风格的一部分：宁可少放一个模块，也不要压缩间距；卡片可以错落，但每行不超过三张。

组件

Soft Button

主行动按钮。靛蓝填充、白字、16px 圆角、无描边；字级 16px、字重 500、padding 12px 24px，静态阴影 0 10px 24px 靛蓝 25%。hover 上浮 4px、阴影扩到 0 18px 32px 35%；按下回落并内凹，同时缩放 0.96。过渡 300ms ease-in-out。页头与下面的样本都是它。

Soft Card

功能卡与内容卡。白底、24px 圆角、无描边、内边距 32px，阴影石板灰 25%。图标块 56px 圆形、靛蓝 10% 底；hover 时卡片上浮 8px、阴影转靛蓝 20%、图标块放大 1.1 且底色变浅，过渡 500ms。首屏右侧即此组件。

Soft Input

表单输入。雾灰底、无描边、16px 圆角、padding 14px 20px。聚焦时底色转白、加一圈 4px 靛蓝 20% 的外环，并补一层 0 10px 26px 靛蓝 14% 的柔光。过渡 300ms，不改变尺寸。

Icon Chip

功能图标与状态标记。圆形（999px）、40px 或 56px 直径、主色 10% 底、图标用主色本身。不做边框与阴影，靠底色区分。hover 时底色升到 16%，图标不动。

可为与不为

可为

  • 圆角 16px 起，卡片 24px
  • 阴影带主色相而不是纯黑，模糊 24px 以上
  • 配色一律低饱和，排除纯黑与纯饱和色
  • hover 上浮 4px 到 8px，按下回落并内凹
  • 卡片间距至少 24px，宁可减少模块
  • 动效 300ms 起，500ms 用于卡片级位移

不为

  • 不要用直角或小于 16px 的圆角
  • 不要用纯黑文字 #000000
  • 不要用无模糊的硬阴影
  • 不要用 1px 实色描边切分区块
  • 不要用高饱和纯色做大面积填充
  • 不要压缩间距换取信息密度

图像

明亮、低饱和的摄影与 3D 柔光图形。人物可用，但必须温和、日常、无强对比。允许渐变色块作为背景柔光。不使用硬边插画、纯黑背景或高饱和摄影。
