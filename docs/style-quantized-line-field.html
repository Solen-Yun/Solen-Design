风格 01 · 浅色版面

量化线场 Quantized Line Field

把一张标记的明暗翻译成四档竖线，结构和留白都交给它。

竖线四档线宽亮度场品牌卡片Canvas 2D

量化线场是一套生成式身份系统：任意一张标记图被采样成网格，每个格子的亮度被量化到四档之一，再用对应线宽的竖线画出来。核心规则是「不允许连续线宽」——只有四档，一旦变成渐变就失去了它的机械感。

线场会缓慢漂移，交互时给一次带衰减的弹簧位移，并尊重 prefers-reduced-motion。版面上纸面是暖白（#fafaf8），线场装在 17px 圆角的卡片里，卡片底色决定对比：浅灰、纯蓝或近黑。文字三层：衬线标题、无衬线界面文字、等宽坐标。

组件

        

          

            
Line Field Card

            
线场容器与作品卡。17px 圆角、内边距 28px、宽高比 0.70、最小高度 460px、overflow hidden。底色三选一（#eeeeeb、#2152e7、#111212），不在同一屏重复，不在同一卡片混两种底色。线场画布铺满卡片，线条只有四档宽度（1px、2px、3px、4px），颜色取卡片底色的对比色。hover 时线场给一次带衰减的弹簧位移（幅度 8px），并加一层 8% 的阴影。上方演示卡即此组件。

          

          

            
Source Button

            
揭示来源与次级行动。透明底、1px #d9dbd5 描边、999px 全圆角、padding 10px 20px、14px 无衬线。hover 时描边转检测蓝；聚焦时 2px 检测蓝外环、offset 4px。无填充变化，过渡 150ms。

            
          

          

            
Parameter Input

            
参数与项目名输入。纸面底、1px #d9dbd5 描边、12px 圆角、padding 12px 16px、14px 无衬线。标签 14px 置于上方 8px。聚焦时 2px 检测蓝外环、offset 2px，不改变盒子尺寸。越界时描边转信号红。

            
          

          

            
Studio Nav

            
顶部导航。纸面底、底部 1px #d9dbd5 描边、水平内边距 24px、垂直 20px。左侧字标用衬线 24px，右侧链接 14px 无衬线加下划线（offset 4px）。无阴影、无背景变化。

            
量化线场作品参数来源

          

          

            
Annotation Footer

            
作品注释与参数条。顶部 1px #d9dbd5 描边、padding 24px、12px 无衬线、字色 #686b64。左右两端对齐摆放注释与说明，参数值用等宽字体，与说明之间用 16px 间距分隔。上方演示卡的底注即此组件。

          

        

      


      

        
可为与不为

        

          

            
可为

            
    
              
  • 线段只有四档宽度
    • 
              
  • 线场尊重 prefers-reduced-motion
    • 
              
  • 卡片圆角固定 17px
    • 
              
  • 三种字体各司其职：衬线、无衬线、等宽
    • 
              
  • 卡片底色三选一，不在同一屏重复
    • 
              
  • 交互位移用带衰减的弹簧
    • 
            

          

          

            
不为

            
    
              
  • 不要用连续线宽或渐变线
    • 
              
  • 不要把线场裁切成非原比例
    • 
              
  • 不要在同一卡片混两种底色
    • 
              
  • 不要用大幅位移或旋转
    • 
              
  • 不要把检测蓝用作填充
    • 
              
  • 不要在减少动效模式下仍漂移
    • 
            

          

        

      


      

        
图像

        
图像即线场：所有视觉由四档竖线构成，不允许位图与插画。允许把真实标记（logo、字形）采样后重建为线场。不使用摄影作为主体，最多作为线场的采样来源。线场画布必须与容器同宽高，不做裁切。
