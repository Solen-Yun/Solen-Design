风格 84 · 浅色版面

反设计 ANTI-DESIGN

把界面设计的所有规矩一次违反掉，但每一条都违反得有意。

4–8px 不对称粗框最高饱和原色8px 硬偏移混乱必须可复现

反设计是故意对抗 UI 常规的实验性野兽派：4 到 8px 的超粗黑边框包住一切，边框不对称（右与下更厚），只用直角，阴影是 8px 的硬偏移，颜色用最高饱和的原色（红蓝黄品红青绿），间距与对齐刻意不一致，字体大小忽大忽小。

它的「乱」是有成本核算的——每条违规都必须可复现、可解释，而不是随手乱放。这也是它与普通劣质页面的区别：反设计的混乱是受控的。

配色方案

  • Black#000000
  • Red#ff0000
  • Blue#0000ff
  • Yellow#ffff00
  • Magenta#ff00ff

颜色

纯黑承担超粗边框、硬阴影与文字，是整套结构的重量来源；纯白保留画布，让原色更刺眼；红是第一撞色，常与黑边并存于同一块；蓝是第二撞色与链接色；黄做高亮底，让黑字跳出来；品红打破红蓝黄的三原色秩序；青常作背景，让其他色块浮起来。

  • Black超粗边框、硬阴影与文字。整套结构的重量来源。
    #000000--color-black
  • Red第一撞色，常与黑边并存于同一块。
    #ff0000--color-red
  • Blue第二撞色与链接色。
    #0000ff--color-blue
  • Yellow高亮底，用于让黑字跳出来。
    #ffff00--color-yellow
  • Magenta第三撞色，用于打破红蓝黄的三原色秩序。
    #ff00ff--color-magenta
  • Cyan第四撞色，常作背景让其他色块浮起来。
    #00ffff--color-cyan

硬偏移只有黑：8px 8px 0 #000000（小号 4px），按下归零。渐变在这里是失格的。

组件

Asymmetric Frame

不对称粗框（核心组件）。4 到 8px 纯黑边框，四边不等宽（例如上 4、右 8、下 8、左 4），零圆角，内边距 20px，硬阴影 8px 8px 0 黑。填充一支原色。同一屏的所有框必须用同一套不对称规则，否则就只是杂乱。hero 里的红块就是。

Slam Button

行动按钮。原色填充（红或蓝）、白或黑字、4px 黑边、零圆角、28px/900、padding 12px 24px，硬阴影 8px 8px 0 黑。hover 时填充硬切到另一个原色并让阴影扩到 12px；按下时位移 8px 8px 且阴影归零。过渡 80ms linear。

Broken Grid

刻意的错位网格。12 栏网格，但元素按规则偏移 1 到 3 栏（不是随机）：每行至少有一个元素越界，且偏移方向交替。间距在 4、12、20、36 之间跳动。偏移规则一旦写定就必须全局一致。

Oversized Numeral

超大数字与字母。110px/900 的数字或单个字母，填原色或黑，可旋转 0 到 12 度，压在区块角落或跨在边框上。用于章节标记与装饰，它的尺寸与旁边的 11px 标签形成极端对比——hero 右上角的 84 就是。

Raw Marquee

生硬跑马灯。内容复制两份、24s linear 无限循环 translateX 0 到 -50%，字用 48px/900 全大写加原色底。hover 时暂停。不装饰、不淡出，就这么滚过去。

可为与不为

可为

  • 4 到 8px 超粗黑边，四边不等宽
  • 零圆角，只用直角
  • 8px 硬偏移阴影
  • 最高饱和的原色
  • 间距与对齐刻意不一致
  • 混乱必须可复现、有规则

不为

  • 不要用任何圆角
  • 不要用低饱和或柔和的颜色
  • 不要用一致的对齐
  • 不要用柔和阴影
  • 不要用渐变
  • 不要随手乱放——违规必须有规则

图像

图像本身也要反设计：低分辨率截图、被拉伸的照片、贴错位置的图标、ASCII 图形。允许把图像故意压到 20% 质量。不使用精致摄影与柔和插画，因为「精致」在这里是失格。
