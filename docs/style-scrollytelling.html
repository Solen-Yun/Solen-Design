布局模式 12 · 叙事版面

滚动叙事 SCROLLYTELLING

滚动手势就是时间轴：画面钉住，文字一步步走过，每步换一个状态。

sticky 画布 100vhIntersectionObserver 离散切换只改 transform/opacity数值有静态 DOM

滚动叙事是数据长报道的语法：一个 sticky 画布钉在视口里，文字步骤从它旁边滚过，每一步触发一次离散的状态变化（数字滚动、形状变形、图层点亮）。它与「滚动擦洗」的关键区别在于离散而非连续——用 IntersectionObserver 检测每一步进入视口再切换状态，绝不在 scroll 事件里读 offsetTop 或 getBoundingClientRect 做连续计算，那会卡顿。画布只改 transform 与 opacity，绝不改 top、width、height。数值必须有 DOM 里的静态文本作为真实来源，因为计数器读屏与 SEO 都读不到。

组件

Sticky Canvas

钉住的画布（核心组件）。外层高 300vh，内层 sticky top-0、高 100vh、含一个 canvas 或 SVG。每一步由 IntersectionObserver 触发，把画布切到该步的离散状态（不做连续擦洗）。所有状态切换只改 transform 与 opacity，绝不改 top、width、height。prefers-reduced-motion 时直接跳到各步的终态。实演左侧的柱状图就是。

Step Block

叙事步骤块。左侧 2px 信号蓝竖线、内边距 0 0 0 24px，行高 96px 以上。上方 11px 等宽全大写步骤编号（Step 02），标题 24 到 36px/600，正文 17px 暖白 70%、最大宽度 28rem。当前步骤的竖线与编号升到 100% 不透明度，非当前降到 30%。

Progress Rail

进度轨。固定在视口右侧中部，宽 2px、高 40vh，底槽为暖白 15%。已完成部分填信号蓝，高度按当前步骤索引递增。旁边等宽显示「02 / 07」——实演右侧那条就是。

Figure Label

图注与数值标注。图注 11px 等宽全大写、暖白 50%、位于图下方 12px。关键数值必须同时以静态 DOM 文本存在（而不是只由计数器渲染），字体 13px 等宽、信号蓝。

Next Button

章节推进按钮。信号蓝填充、白字、6px 圆角、14px/600、padding 10px 20px，hover 时填充加深到 #2560d4；按下缩放 0.98。焦点环 2px 信号蓝 50% 且 offset 必须取深底色，否则在暗底上看不见。

可为与不为

可为

  • 用 IntersectionObserver 触发离散状态
  • 画布只改 transform 与 opacity
  • 一步只讲一个新信息
  • 数值必须有静态 DOM 文本
  • 只用两个强调色
  • reduced-motion 时跳到终态

不为

  • 不要在 scroll 里读 offsetTop 做连续擦洗
  • 不要一步塞多个新信息
  • 不要改画布的布局属性
  • 不要让计数器成为唯一数值来源
  • 不要在移动端让画布挤掉文字
  • 不要超过两个强调色

图像

图表即图像：折线、面积、散点、地图与流程，全部由画布绘制并随步骤切换状态。允许一条底线示意与少量标注。不使用装饰摄影与插画，任何图像都必须承担数据。
