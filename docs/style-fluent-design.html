风格 30 · 浅色版面

流利设计 FLUENT DESIGN

光、深度、动效、材质、尺度：五个元素叠出一套跨平台的界面语汇。

亚克力面板2px 圆角克制焦点环带 offset150–250ms 响应

Fluent 是那套「材质 + 光」的系统：界面不是平的，而是由亚克力面板、极小的圆角与一层极轻的深度构成。它只用一支主蓝（#0078d4），其余颜色只在状态里出现（黄、红、绿）。圆角刻意做得克制——按钮 2px、卡片 8px、输入 2px，这是它与圆角化风格的区分点。

每个可交互元素都必须有 2px 的焦点环并带 offset，这是无障碍底线而非装饰。动效 150ms 到 250ms，强调「响应」而非「表演」。右边这张亚克力卡可以悬停：填充升到 85%、上浮 4px。用 Tab 键走走看，焦点环始终在。

克制的材质感。

模糊、描边、深度，一样不少。

颜色

Fluent 蓝是唯一的品牌色，不做渐变；深蓝是同色相压暗一档的 hover 与按下态；亚克力白必须配 20px 模糊才成立；黄、红、绿只作为状态出现在图标与徽标上，不是装饰色。

  • Fluent Blue主行动、链接与焦点环。唯一的品牌色，不做渐变。

  • Caution Yellow警告与需要注意的状态，只用于图标与徽标。
    #ffb900--color-caution
  • Error Red错误与删除。出现即表示不可撤销。
    #e81123--color-error
  • Success Green成功与完成，多用于对勾与状态条。
    #00cc6a--color-success

焦点环是硬底线：0 0 0 2px #ffffff, 0 0 0 4px #0078d4。卡片阴影两层：0 2px 4px rgba(0,0,0,0.04) 与 0 8px 16px rgba(0,0,0,0.08)，hover 升到 16px 32px 档。

字体

组件

Fluent Button

主行动按钮。Fluent 蓝填充、白字、2px 圆角、1px 同色描边；字级 14px、字重 600、padding 10px 24px，阴影 0 2px 4px 蓝 30%。hover 时填充转深蓝、上浮 2px、阴影扩到 0 4px 8px 蓝 40%；按下缩放 0.97、位移归零、阴影移除。焦点环为 2px 蓝加 2px offset。过渡 150ms ease-out。

Acrylic Card

内容卡与设置面板。70% 白填充、20px 模糊、1px 白 30% 描边、8px 圆角、内边距 24px，双层阴影；图标块 48px 见方、主蓝填充、8px 圆角。hover 时填充升到 85%、描边到 50%、上浮 4px、阴影升到 16px 32px 档。过渡 200ms ease-out。上方演示卡即此组件。

Fluent Input

表单与搜索。白底、1px #d1d1d1 描边、2px 圆角、padding 8px 12px、14px 字；下方始终预留 1px 的强调线空间。聚焦时描边转 Fluent 蓝、强调线变 2px 并加 2px offset 焦点环，不改变盒子尺寸。

Acrylic Flyout

下拉、菜单与通知浮层。85% 白填充、30px 模糊、1px 白 40% 描边、8px 圆角、内边距 8px，阴影 0 8px 24px 12%；菜单项高 36px、圆角 4px、hover 白 50% 填充并加左侧 3px 主蓝指示条。

外观 主题与颜色 透明效果

可为与不为

可为

  • 只用一支主蓝，其余颜色只作为状态
  • 圆角克制：按钮 2px、卡片 8px
  • 焦点环必须 2px 且带 offset
  • 卡片用亚克力填充加模糊与描边
  • 动效 150ms 到 250ms，强调响应
  • 所有间距对齐 4px 网格

不为

  • 不要用大圆角，会失去 Fluent 的硬朗
  • 不要把黄红绿当成装饰色
  • 不要省掉焦点环
  • 不要用玻璃卡片却不加模糊
  • 不要用超过 250ms 的动效
  • 不要用纯黑文字，用深灰

图像

产品截图、系统图标与抽象几何。允许大面积的柔和光斑作为 hero 背景。图标必须是线性 1.5px 描边，与界面同一套几何语言。不使用写实摄影与装饰插画。
