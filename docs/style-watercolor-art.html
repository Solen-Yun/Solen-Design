风格 51 · 浅色版面

水彩艺术风 WATERCOLOR ART

颜料在水里散开：边缘是渗的，颜色是层叠的，纸是湿的。

颜料池化渗化边缘纸纹叠加极低透明度层叠

水彩艺术风模拟真实水彩的物理行为：颜料从中心向边缘池化（用 radial-gradient 做按钮）、边缘不规则地渗开、颜色以极低不透明度层层叠加、纸面有颗粒纹理（feTurbulence）。它的技术参数刻意压到极低——边框只有 8% 到 18% 不透明度、阴影极柔且带色、圆角 24px 以上。

禁令也很明确：禁止硬边偏移阴影、禁止 2px 以上粗边框、禁止纯黑与霓虹、禁止等宽字体、禁止全大写，因为水彩里没有尖锐的东西。右边这枚湿按钮是真的——悬停它，颜料继续往纸里渗。

颜色

薄薄的赭红是主色——主按钮与主要色块；带纹理的暖白模拟水彩纸；水蓝画水与天空的意象；叶绿管植物语义与成功状态；花紫管情绪化强调与花卉点缀；藤黄是高光与阳光的一层，最常做叠加色。

组件

Wet Button

行动按钮（颜料池化）。藕粉填充并叠一层 radial-gradient（中心亮 110%、边缘降到 90%）模拟颜料池化、24px 圆角、1px 藕粉 18% 描边、衬线 15px、字距 0.14em、padding 16px 40px，阴影 0 4px 20px 藕粉 30% 加 inset 0 1px 0 白 20%。hover 时填充加深到 #c99595、阴影扩到 40px；按下缩到 0.98 并加内阴影。过渡 500ms ease-in-out。

Wash Card

内容卡（多色层叠）。白底上叠两层极淡色块（第一层 10% 藕粉、第二层 8% 水蓝，各自用 radial-gradient 从一角散开）、32px 圆角、1px 藕粉 12% 描边、内边距 36px，柔阴影 0 4px 20px 藕粉 30%；三层叠加后边缘应显得不匀，模仿湿画法。上方演示卡即此组件。

Bleed Edge + Paper Grain

渗化边缘装饰：用 SVG 的 feTurbulence 加 feDisplacementMap（baseFrequency 0.02、scale 8）作用在色块或图片边缘上，让边界轻微抖动与晕开；只作用于装饰块，绝不作用于文字。纸纹叠加层：全页固定覆盖一层 2% 到 4% 不透明度的噪点纹理，pointer-events: none，混合模式 multiply；这层让所有色块看起来是画在纸上的。

Botanical Sprig

植物水彩点缀。一枝 64 到 160px 的水彩叶或花（半透明、边缘渗开），颜色取叶绿或花紫并降到 40% 到 60%，置于卡片角落或标题旁；单屏最多三处。本页角落的三枝就是。

可为与不为

可为

  • 边框只有 8% 到 18% 不透明度
  • 用 radial-gradient 做颜料池化
  • 叠一层 2% 到 4% 的纸纹
  • 圆角 24px 以上
  • 阴影极柔且带色
  • 过渡 500ms ease-in-out

不为

  • 不要用硬边偏移阴影
  • 不要用 2px 以上边框
  • 不要用纯黑或霓虹色
  • 不要用等宽字体
  • 不要用全大写文字
  • 不要给文字加渗化滤镜

图像

水彩画与湿画法插画：植物、风景、静物，必须有渗化边缘与颜色层叠。允许把照片处理成水彩效果。不使用硬边矢量插画、高饱和图像与纯黑背景。
