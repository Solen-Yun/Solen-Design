风格 17 · 浅色版面

复古怀旧风 RETRO VINTAGE

旧纸张不会浮起：一切安静地待着，只有颜色在缓慢氧化。

棕褐主色奶油纸底禁止浮起慢过渡

复古怀旧风模拟的是印刷品的年代感：棕褐主色、奶油纸底、粗边框、老式排版（全大写加宽字距的衬线标题）。它有两条几乎所有其它风格都没有的禁令——第一，任何元素都不做 scale 或 translate-y，因为旧纸张不会浮起（Antique Stillness）；第二，过渡时长不得快于 150ms，因为氧化是地质过程（Slow Passage）。

颜色全部低饱和、偏黄，四支辅色（砖红、深绿、沙、橄榄）来自七十年代的印刷油墨。右边这张卡可以悬停——但只有描边会加深，元素一动不动，这是这套风格最重要的品格。

EST. 1974

纸上的年代感。

描边会加深，纸不会动。印刷红、包装绿、旧沙色，全都来自那台老印刷机。

颜色

整套系统的年代感全部来自棕褐这一支：标题、边框与主强调都是它。奶油纸底比纯白暖两档，砖红是印刷红而非屏幕红，深绿是七十年代常见的包装绿，沙色让层次不依赖对比，橄榄只给标签与邮戳式装饰，出现频率最低。

没有投影——一切平贴在纸上：elevation: none，最多一圈 inset 0 0 0 1px rgba(139,69,19,0.25) 的压印线。过渡一律 300ms ease-out，绝不快于 150ms。

字体

两套字各司其职：标题与字标用衬线 Playfair Display，多用全大写与 0.16em 宽字距，衬线的笔画对比是复古印刷的关键；正文用中性的 Inter，行高拉高到 1.65，模拟旧书的排字。

间距与版面

基础单位 8px，密度 comfortable。上限 1120px、容器内边距 32px，区块间距 96px。允许居中的老式对称版面（这与现代左对齐不同），标题常与细线装饰成组。信息可以密，但每块之间用装饰横条隔开。

组件

Letterpress Button

行动按钮。棕褐填充、奶油文字、2px 同色描边、4px 圆角、无阴影；15px/500、全大写、0.16em 字距、padding 14px 28px。hover 时填充换成深一档的棕并保持位置不变（不位移不缩放）；按下时改为 2px 描边的透明按钮。过渡 300ms ease-out，绝不快于 150ms。

Paper Card

内容卡与菜单卡。奶油底提亮一档、2px 棕褐 25% 描边、4px 圆角、内边距 32px；内部可加 1px 虚线分隔（模拟票券）；标题衬线 28px 全大写 0.16em。hover 只加深描边到 40%，元素不动。上方演示卡即此组件。

悬停试试：只有描边在氧化，纸一动不动。

Stamp Badge

标签与邮戳式标记。橄榄或砖红填充、奶油文字、999px 全圆角、无描边，12px/500、全大写、0.16em 字距、padding 4px 12px；可叠一层内阴影模拟压印（inset 0 1px 0 白 30%）。

FIRST ISSUE LIMITED

Ticker Rule

分隔与装饰横条。高 32px，棕褐底上重复小花纹（圆点或斜线），或 2px 纯棕褐实线；用于区块之间，替代大片留白，页边宽度 24px。不做滚动动画。

可为与不为

可为

  • 所有元素保持静止，不做位移与缩放
  • 过渡不短于 150ms
  • 标题全大写、0.16em 宽字距
  • 边框 2px 起，用棕色系
  • 配色全部低饱和偏黄
  • 用纸纹与压印暗示年代

不为

  • 不要用任何 scale 或 translate-y
  • 不要用快于 150ms 的过渡
  • 不要用现代渐变与玻璃态
  • 不要用霓虹或高饱和色
  • 不要用极简扁平语言
  • 不要用大圆角

图像

老照片、印刷品扫描、木刻版画。允许叠一层纸纹与 5% 的泛黄。图像边缘可以是粗描边框或邮票齿孔。不使用现代摄影、3D 渲染与高饱和色。
