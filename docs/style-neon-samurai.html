风格 61 · 深色版面

霓虹武士风 NEON SAMURAI

一刀的斜线、朱红鸟居、霓虹发光：浮世绘撞进了霓虹街。

斩击线收细鸟居区块框架甲片 16px 切角纵深只用发光

霓虹武士把武士美学与赛博霓虹缝在一起：深海军底上，朱红作主色，紫与天蓝作双色霓虹，金作刀光高光。图形语汇固定四件——刀的斜斩线（末端收细）、鸟居作区块框架、甲片式的多边角卡片、书法笔触作分隔线。它禁止常规投影，纵深只能靠发光表达。

右边这张甲片是真的：右上与左下各切 16px，hover 时双色发光扩大、八个赤色墨点在 300ms 内散开。

居合 · 一刀两断

斩击只有一次。

颜色

朱红是武士的赤，管鸟居、斩击线与主按钮；深海军底深到让朱红与双色霓虹同时发亮；霓虹紫是第一霓虹色，管甲片边缘与 hover 光晕；天蓝是第二霓虹色，管数据、刀光冷侧与链接；金是画面里唯一的暖光，给刀光与高光；霓虹粉管警示与溅射特效，出现频率最低。

间距与版面

组件

Slash Line

斩击线（签名图形）。一条 2 到 4px 的斜向长线（角度 -20 到 -35 度），从 4px 收细到 1px，颜色朱红或金并带 0 0 16px 发光。横跨区块并允许溢出容器。它是最能标识这套风格的元素，单屏一到两条，绝不多。

Armor Card

甲片卡片（核心组件）。赤 8% 填充、零圆角、1px 朱红 40% 描边、内边距 28px，四角用 clip-path 切出不等边的斜角（右上 16px、左下 16px），外带双色霓虹发光。hover 时发光扩到 32/64px 并让溅射墨点爆发一次（8 个 4px 的赤色圆点在 300ms 内散开并淡出）。hero 里的面板就是。

Torii Frame

鸟居框架。区块顶部一条水平朱红梁（高 10px、两端各外伸 32px、带 0 0 20px 发光）加两根立柱（各 6px 宽、向下延伸 40 到 64px），构成鸟居轮廓。它作为区块的框架边界，每屏最多两处。

Brush Divider

书法分隔线。一条 2 到 6px 的横向不规则笔触（用 clip-path 或 SVG path 做出起笔粗、收笔细的效果），颜色朱红或金并带霓虹发光。它替代普通分隔线，暗示书法的一横。

Neon Button

行动按钮。深海军填充、朱红文字、零圆角、1px 朱红 60% 描边、12px 等宽全大写 0.22em、padding 12px 28px，双色外发光。hover 时描边升到 100%、发光转紫加天蓝；按下时位移 1px 并让光晕收到 8px。过渡 200ms。

可为与不为

可为

  • 朱红配深海军与双色霓虹
  • 斩击线单屏一到两条
  • 鸟居作区块框架，最多两处
  • 甲片用 16px 不等边切角
  • 书法笔触作分隔线
  • 纵深只用发光，不用投影

不为

  • 不要用常规投影
  • 不要用圆角
  • 不要让斩击线超过两条
  • 不要用西方肖像
  • 不要让发光失去克制
  • 不要混用两种切角尺寸

图像

武士与刀、鸟居、甲片、书法笔触、霓虹街景。允许把浮世绘或书法扫描件叠霓虹发光。不使用西方肖像、柔和插画与无发光的写实摄影。
