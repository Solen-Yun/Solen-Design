风格 38 · 深色版面

超现实主义风 SURREALISM

梦境里的时间：一切都慢，一切都稍微歪着，光从不该来的方向来。

700–1000ms 梦境时间skew 不 scale玫瑰色光晕阴影融化与漂浮

超现实主义借用达利的语汇：午夜蓝与沙漠金的意外配色、不合逻辑的空间关系、融化与变形的形状、以及从不该来的方向打来的光。它有两条独有的时间与位移规则——第一，所有过渡必须是 700 到 1000ms 的 ease-in-out（Timeless Easing），因为梦境的时间是弹性的。

第二，hover 绝不允许 scale，只能用 skew 与 rotate 扭曲现实。阴影也不能是黑色，必须用玫瑰或金色的漫射光晕——黑色阴影会瞬间把梦叫醒。右边这块面板是歪的，悬停它，让它慢慢回正。

时间在这里是弹性的。

光晕是玫瑰色的，从不该来的方向漫过来。

颜色

午夜蓝深到接近黑但仍保留蓝的呼吸；骨白像梦里发灰的骨白；沙漠金是天上那束不该存在的阳光；尘玫瑰是所有投影的替代色——黑色阴影被禁止；深紫用于融化的形体；苔绿是唯一的一抹生机，打破梦的窒息感。

间距与版面

基础单位 8px，密度 airy。上限 1120px、容器内边距 24px，区块间距 144px。严禁严格对称网格：允许元素偏离网格 16 到 48px、允许重叠、允许旋转 -3 到 3 度。但阅读顺序必须仍然清晰——梦境可以歪，不能读不懂。

组件

Melting Panel

卡片与内容面板。紫色 40% 填充、32px 圆角、1px 沙漠金 20% 描边、内边距 36px，外加一层玫瑰色漫射光晕，绝不使用黑色阴影；默认整体旋转 -1 度并轻微 skewX(-1.5deg)。hover 时旋转到 1 度、skew 归零、光晕扩到 80px，过渡 1000ms ease-in-out。上方演示面板即此组件。

Distorted Button

行动按钮。沙漠金填充、午夜蓝文字、999px 全圆角、无描边，18px/600、0.1em 字距、padding 14px 36px，光晕 0 12px 40px 金 28%。hover 时 skewX(-6deg) 并 rotate(-2deg)、光晕扩到 60px，绝不允许 scale；按下时 skew 归零并整体下沉 2px。过渡 700ms ease-in-out。

Color Orb + Soft Field

装饰光球：24px 到 160px 的圆形，径向渐变从沙漠金或玫瑰的中心渐隐到透明，无边框，绝对定位在卡片边缘并允许溢出 20% 到 40%；颜色在 2000ms 内缓慢扩散与收缩（Color Melting），绝不允许 transition-none；单屏最多四个——本页两角各有一个。输入框：午夜蓝 60% 填充、24px 圆角、1px 紫罗兰 40% 描边；聚焦时描边转沙漠金 60% 并加 3px 金 15% 外环，过渡 700ms。

Floating Epoch

漂浮的层级错位。把同一内容复制成两到三层，每层偏移 8 到 16px、各自不同透明度（100%、45%、20%）与不同角度（-3、0、+4 度）；仅用于标题或首屏主视觉，营造「同一个东西在时间里被看见三次」的错觉。

可为与不为

可为

  • 所有过渡 700 到 1000ms ease-in-out
  • hover 用 skew 与 rotate，不用 scale
  • 阴影一律用玫瑰或金色光晕
  • 午夜蓝配沙漠金的反常配色
  • 形状允许融化与变形
  • 标题可用斜体衬线

不为

  • 不要用过于明亮的纯色
  • 不要用严格对称的网格
  • 不要做现代极简的无装饰设计
  • 不要用刺眼的霓虹
  • 不要用 hover:scale-105
  • 不要用黑色投影

图像

融化的钟表、漂浮的石头、室内长出的海、比例错位的物体。图像必须带不合逻辑的空间关系与来自错误方向的投影。不使用写实纪实摄影与扁平图标。
