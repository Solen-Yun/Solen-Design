风格 97 · 浅色版面

印度节庆 INDIAN FESTIVE

朱红、藏红花橙、金线曼陀罗：排灯节的一盏灯。

象牙底朱红藏红花金色大量使用曼陀罗与油灯允许铺满重叠

印度节庆来自排灯节与洒红节的视觉：象牙白底、朱红与藏红花橙作主强调、金大量用于装饰线与光晕、皇家紫与孔雀绿作辅色。曼陀罗、油灯、花瓣与珠宝纹样是主要图形，圆角取 12px 传达柔和，标题粗体加宽字距。

与伊斯兰几何的精密不同，这里允许铺满与重叠——节庆本身就是密的。

排灯节之夜

油灯一盏盏亮起来，粉色的花瓣落在石阶上。

颜色

朱红是主色，给主按钮、纱丽红与最抢眼的区块；象牙白像节日里的灯光照在墙上，做页面底；藏红花橙是第二强调，管花瓣、油灯火与渐变的一极；金承担装饰线、描边与光晕，是节庆感的来源，可以大量使用；皇家紫是辅色与深色区块，用来压低整体的暖度；孔雀绿是辅色与「成功」语义，是画面里唯一偏冷的色。

间距与版面

基础单位 8px，密度 comfortable。上限 1120px、容器内边距 24px，区块间距 96px。允许装饰铺满与重叠——节庆的密度是内容的一部分。标题常居中，正文可左对齐。

组件

Mandala Card

曼陀罗卡片（核心组件）。白或象牙填充、12px 圆角、1px 金 50% 描边、内边距 32px，外带 0 0 20px 金 35% 的柔光。顶部中央放一个 96 到 160px 的曼陀罗（同心圆加 8 到 16 片对称花瓣，1px 金线绘制，中心一个朱红点）。标题 40px/700 朱红，正文 17px 暖灰。hero 里的卡片就是。

Festive Button

行动按钮。朱红填充、象牙文字、12px 圆角、1px 金 60% 描边、17px/700、字距 0.16em、padding 14px 32px，外带 0 0 20px 金 35% 柔光。hover 时填充转藏红花橙、描边升到 100%；按下缩放 0.98。过渡 250ms ease-out。

Diya Lamp

油灯装饰。一个 32 到 64px 的陶碗形（border-radius 40% 40% 50% 50%），填朱红或金，碗口上方放一个 16px 的水滴形火焰（藏红花橙到黄的径向渐变）并带 0 0 16px 橙 60% 的柔光。它是最能标识节庆的元素，单屏 2 到 4 盏——hero 卡右下那盏就是。

Jewel Gradient

珠宝色渐变带。一条横向渐变带（朱红经藏红花到金，或紫经孔雀绿到金），高 8 到 16px，用于区块之间或卡片顶部。渐变必须平滑且只有三站，越界会变成浑浊。

Petal Scatter

花瓣散落装饰。8 到 20 片小的花瓣或圆形（各 8 到 16px），颜色取藏红花、朱红或金，不透明度 40% 到 80%，随机散布在区块上并各自旋转 0 到 90 度。它模拟洒红节的彩粉与花瓣，单屏 1 到 2 组。

可为与不为

可为

  • 象牙底配朱红与藏红花橙
  • 金可大量用于装饰线与光晕
  • 曼陀罗与油灯作图形语汇
  • 圆角 12px
  • 渐变带恰好三站
  • 允许装饰铺满与重叠

不为

  • 不要用冷调摄影
  • 不要用极简构图
  • 不要让渐变超过三站
  • 不要用锐角
  • 不要让装饰压过文字
  • 不要混用两套圆角

图像

节庆摄影与装饰图：油灯、花瓣、纱丽纹样、珠宝、曼陀罗、彩粉。必须暖调、饱和、可见金色。允许把照片处理成暖金调。不使用冷调摄影、极简构图与无装饰图像。
