风格 67 · 深色版面

日式 RPG JRPG

斜面边框、金色标题、蓝底渐变：一个 1995 年的菜单窗口。

2px 边框斜面浮雕金色标题选中分段血条90ms 硬切

日式 RPG 界面来自 16 位到 32 位时代的游戏菜单：深海军蓝底上叠蓝色到深蓝的渐变，窗口用 2px 蓝色边框加内阴影做出斜面浮雕感，标题用金色，状态栏用绿（HP）与蓝（MP），按钮靠 inset 白色高光显得凸起。菜单反馈必须硬切——75 到 120ms，模拟手柄选中项的节奏，绝不能平滑缓动。

它禁止极简扁平：无边框无阴影在这里等于没做。右边这个菜单窗口是真的：双层描边、分段血条、hover 时文字转金，全部硬切。

间距与版面

基础单位 8px，密度 compact。上限 1120px、容器内边距 16px，窗口间距 12px，形成密集的菜单排布。允许窗口层叠（主菜单上叠子菜单），每层偏移 8px 并加深阴影。所有尺寸取 4 的倍数。

组件

Bevel Window

斜面菜单窗口（核心组件）。窗口底 #132039、2px 指令蓝描边、外层再加 1px 亮蓝 20% 的环形成双层描边、8px 圆角、内边距 20px，阴影 inset 0 1px 0 白 20% 加 inset 0 -1px 0 黑 35% 做出斜面。外投影 0 8px 24px 黑 55%。标题金色 34px/700，内容窗白 16px。hero 里的菜单就是。

Command Button

指令按钮。指令蓝填充、窗白文字、2px 深蓝描边、6px 圆角、16px/700、padding 10px 24px，inset 0 1px 0 白 20% 做出凸起。hover 时填充提亮 6%、文字转金色；按下时内阴影反向（inset 0 2px 6px 黑 45%）并下沉 1px。过渡 90ms linear——硬切。

Status Bar

HP / MP 状态条。高 16px、全圆角、2px 深蓝描边，内部填充 HP 绿或亮蓝，并用 8px 宽的小格分开（每格间隔 2px），模拟分段血条。绝不用平滑渐变——分段是这个时代的标志。数值用等宽字体放在条右侧，13px 金色。

Menu List

菜单选项列表。每项高 36px、6px 圆角、左侧 8px 处一个 8px 的金色三角或方块指示选中（未选中时透明）。选中项底填金 18% 并把文字转金。切换只做颜色硬切，不做滑动，时长 90ms。

Portrait Frame

立绘与头像框。48 到 96px、8px 圆角、2px 金色描边加 1px 深蓝外环，内部填海军的深色或放立绘。四角各放一个 4px 的金色角标。用于角色、物品与队伍成员。

可为与不为

可为

  • 2px 边框加内阴影做斜面
  • 金色标题与选中项
  • 状态条必须分段
  • 菜单反馈 75 到 120ms 硬切
  • 双层描边（2px 深蓝加 1px 亮蓝）
  • 按钮用 inset 白色高光显凸起

不为

  • 不要用极简扁平（无边框无阴影）
  • 不要用平滑缓动做菜单反馈
  • 不要用连续渐变的状态条
  • 不要用扁平线稿图标
  • 不要用超过 8px 的圆角
  • 不要让金色承担正文

图像

像素立绘、道具图标、地图与技能特效。图标必须有 2px 描边与内阴影，不能是扁平线稿。允许把照片处理成 32 色调色板。不使用现代插画与扁平图标。
