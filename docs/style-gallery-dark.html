颜色

展厅黑做页面底，近黑让照片成为唯一光源；抬升面只亮一档，给卡片与侧栏；分隔线是暗场里唯一的结构手段，所有 1px 描边都用它；琥珀是唯一强调色，只给元信息、展签、链接与聚焦描边；白色做正文与标题，一律 300 细体。

  • Gallery Black页面底。近黑，让照片成为唯一光源。

    #2a2a2a--color-divider
  • Amber唯一强调色：元信息、展签、链接与聚焦描边。
    #c4956a--color-amber
  • White正文与标题，一律 300 细体。
    #ffffff--color-white

暗场里不放阴影：none — a shadow would interrupt the dark。结构只靠 1px 描边，不靠浮起。

字体

全站只有一种字体，只用 300 与 400。大标题 72px 细体紧字距，正文 14px/1.6，元信息 11px 全大写 0.15em 细体。粗字重一律不用。

组件

Full Bleed Frame

全幅作品（核心）。容器 overflow hidden、内边距 0，图片 object-fit: cover、占满、宽高 100%。零圆角零边框零阴影。上方或下方距离 48px 处放展签：10px 全大写 0.15em 的琥珀色元信息，加白色 20px 的作品名。图片绝不加遮罩或文字。hero 里那张就是。

Work Card

作品卡与缩略图格。抬升面 #1a1a1a 填充、2px 圆角、1px #2a2a2a 描边、无内边距（图片铺满）、无阴影。下方 16px 处放展签。hover 时图片整体不透明度降到 90%，不加缩放、不加阴影。

Quiet Nav

顶部导航。内边距 24px 32px、底部 1px #2a2a2a 描边、无模糊无底色变化。链接 11px 全大写 0.15em 细体白色，hover 时转琥珀。字标 20px/300。

Amber Field

搜索与订阅输入。展厅黑填充、2px 圆角、1px #2a2a2a 描边、padding 10px 14px、14px 细体。占位符白 40%。聚焦时描边转琥珀并加 1px 的琥珀 30% 外环。

Wall Label

展签元信息。固定格式「日期 · 地点 · 媒介」，10px 全大写 0.15em 细体琥珀色，行高 1.5。它是这套风格唯一有颜色的文字，也是它区别于「极简暗色」的身份标记。

可为与不为

可为

  • 近黑底，抬升面只亮一档
  • 元信息用琥珀色 10px 全大写 0.15em
  • 标题与正文都用 300 细体
  • 卡片只加 1px 描边，不加阴影
  • 照片全幅、无遮罩无文字
  • hover 只做 opacity 到 90%

不为

  • 不要用彩色阴影与渐变背景
  • 不要用亮色背景
  • 不要在照片上加文字或遮罩
  • 不要用粗字重
  • 不要给卡片加阴影
  • 不要引入第二个强调色

图像

摄影是唯一内容，必须全幅、精确裁切、无滤镜。允许不同比例，但同一系列的调色必须一致。不使用插画、图标装饰与任何非摄影图像。
