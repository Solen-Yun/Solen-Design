风格 114 · 深色版面

任务控制台风 TASK CONSOLE

近黑底、1px 白线、一支靛紫渐变：精密仪器般的工作界面。

分层只用白 3%/6%边框 1px 白 10%hover 只改不透明度动效 ≤150ms

任务控制台风是近年产品界常见的暗色系统。它的层次极薄：底色近黑，面板只提亮 3% 到 6%，边框一律 1px 白色 10%，几乎没有阴影。唯一的颜色是靛紫到紫的渐变，只出现在主按钮与品牌标记上。

交互的核心纪律是「只用不透明度」——hover 不改颜色，只把文字从 70% 提到 100%，把面板从 3% 提到 6%，过渡 150ms。

字体

全站唯一字体 Inter，字级极小（11 到 14px）并统一 -0.01em 字距。密而清晰是这套风格的语气。

组件

Gradient Button

主行动按钮。靛紫到紫的横向渐变、白字、8px 圆角、无描边。字级 14px、字重 500、padding 8px 16px。hover 不换色，只把整体不透明度降到 90%；按下降到 80%。过渡 150ms，只动 opacity。

Issue Card

卡片、列表行与看板项。白 3% 填充、1px 白 10% 描边、8px 圆角、内边距 20px，无阴影。标题 14px/500 纯白，说明 12px 白 50%，时间戳 11px 白 40%。左侧放一个 16px 的状态圆环（2px 描边、按状态取色）。hover 时填充升到 6%，过渡 150ms。hero 里两张就是。

Dark Input

表单与搜索。白 3% 填充、1px 白 10% 描边、8px 圆角、padding 8px 12px、13px 字。标签 12px 白 60%。聚焦时描边转靛紫 50%、填充升到 5%，不加外环。过渡 150ms。

Command Bar

顶部命令栏与浮层。白 4% 填充、1px 白 10% 描边、12px 圆角、12px 模糊、内边距 8px。左侧搜索图标 16px、占位文字 13px 白 50%、右侧放一个 ⌘K 提示（11px、白 30%）。展开时容器高度 360px、选项行高 36px、hover 行填充白 6%。

可为与不为

可为

  • 近黑底，不用纯黑
  • 分层只靠白 3% 与 6% 两档填充
  • 边框一律 1px 白 10%
  • hover 只改不透明度，不改颜色
  • 唯一渐变只给主按钮
  • 字级 11 到 14px，统一 -0.01em 字距

不为

  • 不要用浅色背景
  • 不要用彩色阴影或大面积阴影
  • 不要引入第二种字体
  • 不要用高饱和色，除品牌紫外
  • 不要靠阴影分层
  • 不要用超过 150ms 的动效

图像

几乎不用图像。允许头像 16px、状态圆点、极小的品牌标记。不使用摄影、插画与背景图，任何图像都会破坏这套系统的密度感。
