风格 121 · 浅色版面

论文排版风 ACADEMIC PAPER

Computer Modern 的比例、编号的层级、三线表的克制：一张纸。

全文衬线1 / 1.1 编号booktabs 三线表零圆角零阴影

摘要

本文讨论如何把学术排版的语汇搬到网页：版心收紧、正文两端对齐、表格只用三条横线，其余交给留白。

1引言

论文式版面不靠装饰建立层次，而靠编号、横线与留白。链接统一用论文蓝，交叉引用与之一致。

定理 1

纸是平的；层次只来自横线与留白，任何圆角或阴影都破坏版心的一致。

配色方案

  • Ink#111111
  • White#ffffff
  • Hyperref Blue#0b5394
  • Theorem Ground#f5f5f0
  • Muted Grey#6b6b66
  • Rule Grey#d4d4d0

颜色

印刷黑做正文、标题与三线表的粗线；纯白做纸面，不泛黄；论文蓝是链接与交叉引用，也是唯一允许出现的彩色；定理环境的浅底托住推导；灰做图注、元数据与参考文献补充信息；规则灰做表头细线与极次级分隔。

  • White纸面。纯白，不泛黄。
    #ffffff--color-white
  • Ink正文、标题、三线表的粗线。印刷黑。
    #111111--color-ink
  • Hyperref Blue链接与交叉引用，是唯一允许出现的彩色。
    #0b5394--color-hyperref-blue
  • Theorem Ground定理环境与代码块的浅底。
    #f5f5f0--color-theorem-ground
  • Muted Grey图注、元数据与参考文献的补充信息。
    #6b6b66--color-muted-grey
  • Rule Grey表头细线与极次级分隔。
    #d4d4d0--color-rule-grey

纸是平的：none — paper is flat。零圆角、零阴影，表格绝无竖线与斑马纹。

字体

全文衬线 Latin Modern Roman，标题加紧字距模拟 Computer Modern。正文行高 1.55，比常规论文略松以适应屏幕。代码、公式编号与算法块用 Latin Modern Mono——等宽只在代码处出现。

间距与版面

基础单位 4px，密度 comfortable。版心 700px、居中、文字两端对齐。区块间距 48px，标题上方留 32px。单栏，页边距对称。所有分隔用横线，绝不用底色块或阴影分区。

组件

Numbered Section

带编号的小节标题。格式为「1 引言」「1.1 背景」，编号与标题之间用 12px 空隙（不用制表符）。一级 26px/700，二级 20px/700，均为衬线并紧字距。编号不缩进，标题与编号左对齐。

Theorem Block

定理环境。浅底 #f5f5f0（或白底配 2px 墨色左线）、零圆角、内边距 12px 16px，无阴影。标签用 12px/700 正体（如「定理 1」），正文用 14px 斜体衬线、行高 1.55，标签与正文之间一个空格——hero 里那块就是。

Booktabs Table

三线表。顶部 2px 墨线、表头下 1px 墨线（或 #d4d4d0）、底部 2px 墨线，单元格 padding 4px 12px、14px 衬线，数值列右对齐。绝不允许竖线与斑马纹。表题在表上方，格式为「表 1：」。

Abstract Block

摘要。最大宽度 36rem、左右各 32px 内边距、居中放置。上方一个 12px/700 居中小标题「摘要」，正文 14px 衬线、行高 1.6、两端对齐。

Reference Entry

参考文献条目。14px 衬线、行高 1.5、悬挂缩进（padding-left: 1.5em 配 text-indent: -1.5em），条目编号用 [1] 方括号。条目之间 8px。作者与年份不加粗，保持平铺。

可为与不为

可为

  • 全文衬线，标题紧字距
  • 小节用 1 与 1.1 编号
  • 表格用 booktabs 三线
  • 链接统一 hyperref 蓝
  • 定理用浅底或左线
  • 零圆角、零阴影

不为

  • 不要给表格加竖线与斑马纹
  • 不要用彩色大按钮与渐变
  • 不要用无衬线正文
  • 不要用任何圆角
  • 不要用阴影
  • 不要用装饰图形与 emoji

图像

图形只能作为带编号图注的 Figure 出现：折线、柱状、示意图，黑白或低饱和。图注在图下方、14px 次灰、格式为「图 1：」。不使用装饰插画、emoji、彩色大图与任何无编号的图像。
