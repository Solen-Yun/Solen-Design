布局模式 06 · 编年版面

垂直时间线布局 VERTICAL TIMELINE

一条贯穿的线，把时间钉在上面：左右交替，节奏由节点控制。

连接线不断节点等大左右交替节点卡片联动

垂直时间线是把「先后」变成「上下」的布局：一条 2px 的连接线居中贯穿，节点按时间顺序排列，桌面上左右交替，移动端收成单侧。它有三条技术纪律——连接线不能断、节点尺寸必须一致、移动端必须放弃双侧交替。

视觉上连接线要足够弱（板岩 25%），让节点和卡片承担注意力；节点 hover 时圆环放大并填充主色，卡片同时抬升，两者必须联动而不是只有卡片动。下面是一条按规格跑的时间线——把指针放上去试试联动。

布局实演

上限 960px。桌面为中央线加左右交替（各 44% 宽、间隙 12%），节点在每张卡片靠近中线的一侧；移动端收成单侧左对齐，线移到最左 16px 处。节点之间至少 48px，最多不超过 96px。用按钮切换视口宽度，看双侧怎么收成单侧。

颜色

板岩承担标题、主文字与那根 25% 的连接线；雾灰是页面底，让白卡片浮起来。主蓝表示「你在这里」，完成绿给已经过去的节点，待办保持白底或琥珀点缀，警报红出现即表示时间线有断点。连接线永远足够弱，注意力属于节点与卡片。

  • Slate标题与主文字。连接线也用它，但只有 25% 不透明度。

阴影三档：卡片 0 2px 8px rgba(15,23,42,0.06)、hover 0 8px 24px rgba(15,23,42,0.10)、当前节点 0 0 0 4px rgba(59,130,246,0.20)。连接线是 2px 的板岩 25%，从第一节点画到最后一个节点，不许断裂。

字体

全站唯一字体 Inter。时间与序号用 12px 全大写加 0.06em 字距，标题 22px/600，正文 15px / 行高 1.5——时间线的内容密度不高，字要读得从容。

组件

Timeline Node

时间线上的节点圆环。20px 圆、2px 板岩 30% 描边、白底，垂直对齐连接线。当前节点填主蓝并加 4px 的主蓝 20% 外环；过去节点填完成绿；待办保持白底。hover 时圆环放大到 1.25 并填充主色，与卡片联动（卡片同时上浮 2px）。过渡 150ms。

到布局实演里悬停任意一行，节点与卡片一起动。

Timeline Card

时间节点卡片。白底、12px 圆角、1px #e2e8f0 描边、内边距 24px，阴影 0 2px 8px；卡片占单侧栏 100% 宽，与节点之间留 24px。上方 12px 全大写时间标签（灰色），下方 18px/600 标题与 13px 正文。hover 时上浮 2px、阴影扩到 24px。

Connector Line

中央连接线。2px 宽、板岩 25%、居中贯穿整个时间线，用伪元素从第一节点画到最后一个节点，不允许断裂；若两个节点间距超过 96px，说明内容过长，应拆分而不是拉长线。布局实演里那条线就是它。

Time Filter

时间筛选器。横向一排胶囊按钮，高 32px、padding 0 14px、12px/600；默认白底 1px 描边，选中态主蓝填白字。用于按年或阶段筛选节点，切换时节点列表做 200ms 的错峰淡入。

可为与不为

可为

  • 连接线不许断裂或错位
  • 节点尺寸全部一致
  • 移动端收成单侧
  • 每个节点必须有时间或序号
  • 节点与卡片交互联动
  • 节点间距 48 到 96px

不为

  • 不要让连接线断开
  • 不要用不一致的节点尺寸
  • 不要在移动端保留双侧交替
  • 不要省略时间标识
  • 不要让内容过长拉长连接线
  • 不要只让卡片动而节点不动

图像

以图标与头像为主，允许每个节点配一张 16:10 的小图。不使用全幅背景图，时间线需要干净的纵向空间。
