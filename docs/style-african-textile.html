风格 98 · 深色版面

非洲纺织 AFRICAN TEXTILE

肯特布的经纬、阿迪雷的染痕：颜色与结构一起织出来。

深木底 + 肯特橙交替条纹织纹带4px 粗边标题 0.24em 宽字距

非洲纺织来自西非的肯特布与阿迪雷扎染：深木色底传达厚重感，肯特橙与金作强调，沙作卡片与辅助底，森林绿作文字与装饰。核心图形是几何织纹——条纹、棋盘与菱形的交替重复，像布上的经纬；边框用 2 到 4px 的粗线传达织物结构；圆角保持 8px，手工但不粗糙；标题粗体全大写加宽字距，有庄重感。

右边这张织物卡是真的：顶部一条肯特织纹带，条纹宽窄交替，每三条嵌一个菱形小格。

颜色

深木色底深到让橙与金都显暖；肯特橙是第一主色，给主按钮、条纹与最抢眼的织纹带；金是第二主色，做织纹里的亮线、高光与徽标；森林绿管文字与装饰色，也是织纹的第三支；沙色做卡片与浅色区块底，平衡深木；嫩绿最亮，只在极小面积出现作点缀。

组件

Kente Band

肯特织纹带（签名）。一条 24 到 64px 高的织纹带，用 repeating-linear-gradient 交替排列四种色（橙、金、森林绿、沙）的竖条纹，条纹宽 8 到 16px 且不均匀（宽窄交替）。带内每 3 条加一个菱形或棋盘小格。它出现在页头、区块之间或卡片顶部。

Woven Card

织物卡片（核心组件）。沙色填充、8px 圆角、4px 深木描边、内边距 28px，顶部接一条 12px 的肯特织纹带。标题 36px/900 全大写森林绿、字距 0.02em，正文 16px 深木 85%。hover 时描边换肯特橙、整体上浮 2px。hero 里的卡片就是。

Weave Button

行动按钮。肯特橙填充、金色文字、6px 圆角、2px 深木描边、13px/900 全大写、字距 0.24em、padding 14px 32px，硬阴影 0 4px 0 深木 60%。hover 时填充转金、文字转深木；按下时位移 4px 4px 且阴影归零。过渡 120ms linear。

Adire Wash

扎染纹理底。用多层 radial-gradient（8 到 16px 的圆、随机错位）在底色上叠出扎染的不规则圆斑，色取金或橙、不透明度 8% 到 15%。它必须是「不均匀的重复」，规则的点阵会立刻看起来像 UI 而不是布。

Diamond Motif

菱形与棋盘装饰。24 到 48px 的实心菱形（rotate 45 度的方块）或 2×2 棋盘，填金、橙或森林绿，成组排列（2 到 4 个）。它们模拟织物上的符号纹样，放在卡片角落或分区之间，单屏 2 到 3 组。

可为与不为

可为

  • 深木底配肯特橙与金
  • 织纹带用交替条纹加小格
  • 边框 2 到 4px 传达织物结构
  • 标题全大写加宽字距
  • 圆角 8px，手工但不粗糙
  • 扎染纹理必须不均匀

不为

  • 不要用冷调摄影
  • 不要用规则点阵冒充织纹
  • 不要用细边框
  • 不要用大圆角
  • 不要用现代极简
  • 不要让织纹抢过内容

图像

织物与手工艺摄影：肯特布、扎染、编织篮、陶罐、市场场景。必须暖调、高对比、可见织纹。允许把照片裁成条带嵌入织纹结构。不使用冷调摄影、现代极简与无织纹的图像。
