风格 41 · 深色版面

Outrun 复古未来 OUTRUN

洋红与青的落日、椰树剪影、向地平线冲刺的透视网格。

双色霓虹发光网格永不静止条纹落日椰树剪影

Outrun 是 80 年代赛车与合成器美学：洋红（#ff006e）与紫（#a020f0）的霓虹、青（#00d4ff）的天空、近黑底、透视网格地面、椰树与跑车剪影。它有两条必须遵守的动效规则——第一，发光必须是双色的（洋红加青），单色发光在它看来是「不够 Outrun」。

第二，网格背景绝不能静止，必须用 background-position 的位移制造向地平线冲刺的速度幻觉，缺了它整个风格就失去核心。下面的按钮是真的——悬停它，看双霓虹一起亮。

MIDNIGHT DRIVE

油门到底。

网格永远在冲向地平线。

配色方案

  • Magenta#ff006e
  • Violet#a020f0
  • Neon Cyan#00d4ff
  • Sunset Orange#ff6b35
  • Pale Violet#9f9aff
  • Near Black#0a0a0a

颜色

洋红是第一霓虹——主按钮、地平线与关键强调；紫做层叠光晕与天空渐变；青画天空、网格线与数据，与洋红构成色散关系；近黑让霓虹有地方发光；落日橙填渐变中段；淡紫是最亮的一站，做文字反光与最高光。

  • Magenta第一霓虹色：主按钮、地平线与关键强调。

  • Violet第二霓虹色，用于层叠光晕与天空渐变。
    #a020f0--color-violet

    #00d4ff--color-cyan

    #0a0a0a--color-near-black
  • Sunset Orange落日与暖侧高光，用于渐变的中段。
    #ff6b35--color-sunset-orange
  • Pale Violet文字反光与最高光，最亮的一站。
    #9f9aff--color-pale-violet

双色霓虹是硬规则：0 0 20px #ff006e, 0 0 40px #00d4ff，加强档 0 0 28px #ff006e, 0 0 60px #00d4ff；文字发光 0 0 10px rgba(255,0,110,0.70)。

组件

Outrun Button

行动按钮。洋红填充、白字、4px 圆角、无描边、14px/700 全大写 0.22em、padding 12px 28px，静态带 0 0 12px 洋红。hover 时叠加双霓虹光晕 0 0 20px 洋红 与 0 0 40px 青（Dual Neon Glow），并上浮 2px；按下时缩到 0.97 且光晕收到 8px。过渡 200ms。

Chrome Card

内容卡。近黑 80% 填充、4px 圆角、1px 洋红 35% 描边、内边距 24px，外发光 0 0 20px 洋红 40%；标题用洋红到淡紫的横向渐变文字（background-clip: text），正文白 75%。hover 时双霓虹光晕启动，过渡 300ms。上方演示卡即此组件。

Perspective Grid + Sunset Band

透视网格地面（签名组件）：transform: perspective(320px) rotateX(62deg) 的平面，铺 40px 间隔的青 20% 网格线；必须用 background-position 的 Y 轴位移让它向观察者冲来（周期 2s、linear、无限循环），完全静止就失去了风格核心；prefers-reduced-motion 时静止。落日条带：高 160 到 240px，从近黑经紫到洋红再到落日橙，中间放一个 120px 的圆形落日并叠 8 条水平黑线切开。本页顶部的地平线即这两个组件。

Palm Silhouette

椰树与跑车剪影。纯黑剪影（单色 path），放在地平线两侧，高度 120 到 280px，边缘可以有 1px 的洋红描边作为霓虹轮廓；纯装饰，不承载交互。地平线两侧的两棵椰树就是。

可为与不为

可为

  • 洋红、紫、青三色霓虹
  • 发光必须双色（洋红加青）
  • 透视网格必须持续移动
  • 粗无衬线加宽字距标签
  • 近黑底，不用亮白
  • 落日条带带水平切纹

不为

  • 不要用明亮白色背景
  • 不要做现代简约风
  • 不要省略霓虹发光
  • 不要用柔和低饱和配色
  • 不要只用单色发光
  • 不要让网格背景完全静止
