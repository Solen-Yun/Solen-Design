风格 74 · 浅色版面

侘寂风 WABI-SABI

不完美、不恒常、不完整：让材质和时间替设计说话。

泛黄暖纸底1px 细线 30%留白近乎奢侈允许不完美

侘寂是日本美学里对「不完美」的接纳：器物的缺口、纸的泛黄、墙的斑驳都被视为价值而不是缺陷。落到界面上，它表现为暖纸底、墨色文字、衬线字体、极细的分隔线（1px 且只有 30% 不透明度），以及大量到近乎奢侈的留白。

它禁止鲜艳与高饱和、禁止厚重阴影与粗边框、禁止密集排列、禁止装饰性动画与弹跳——任何「表现欲」都是对它的冒犯。

一只缺口的碗

窑变留下的釉色，边缘的缺口在第三年被磨圆。它因此被留在窗边的位置。

颜色

中深灰而非纯黑的墨色让长时间阅读更松；泛黄的暖米色像放了很久的和纸；苔绿像石阶上的苔，做第一辅色；沙色用于不引入对比地分区；茶色是温暖的棕，管需要人气的元素与木器语义；灰青是冷侧的一笔，用于水、陶釉与安静状态。

间距与版面

基础单位 8px，密度 airy。上限 980px、容器内边距 32px，区块间距 192px。版面允许不完整与偏置：元素不必贴齐网格，留白可以不对称。禁止密集排列，一屏原则上不超过三个信息块。上方那块空白就是 Silence Block——「什么都没有」本身就是内容。

组件

Hairline Rule

极细分隔线（核心结构）。1px、色 #d4cdc5 的 30%、横跨内容宽并在两端各收进 10%。整条线必须弱到「几乎看不见但又能感觉到」，它是这套风格唯一的结构工具。

Quiet Button

行动按钮。透明底、1px 墨色 25% 描边、2px 圆角、衬线 14px、字距 0.24em、padding 14px 36px，无阴影。hover 时描边升到 45%、文字从 80% 升到 100%，元素完全不动。过渡 600ms ease-out。

Paper Card

内容卡。提亮一档的纸色填充、2px 圆角、1px 沙 30% 描边、内边距 40px，无阴影。标题 32px/400，正文 16px/300 行高 1.9。hover 时只把描边升到 50% 与填充提亮 2%，过渡 800ms。hero 里的器物卡就是。

Object Image

器物图片容器。零圆角、无边框、无阴影。图片可以是不规则的器物（陶碗、旧木、石），允许边缘不齐。图片与文字之间 36px。不叠加任何滤镜或遮罩，让材质自己呈现。

Silence Block

留白区块。一个 192px 到 320px 高的空区块，不含任何内容，作为真实元素存在。在侘寂里「什么都没有」本身就是一种内容，用来把前后的东西隔开并放大。

可为与不为

可为

  • 暖纸底，不用纯白
  • 衬线字体，行高 1.9
  • 分隔线 1px 且只有 30%
  • 留白到近乎奢侈
  • 允许不完美与不对称
  • 过渡 600 到 800ms，元素不动

不为

  • 不要用鲜艳高饱和色
  • 不要用厚重阴影或粗边框
  • 不要密集排列元素
  • 不要用装饰性动画与弹跳
  • 不要用纯白背景
  • 不要加滤镜与遮罩破坏材质

图像

器物摄影：陶器、旧木、石、枯枝、麻布。必须自然光、低饱和、有磨损痕迹。允许不对称与不完整构图。不使用高饱和、棚拍打光与装饰插画。
