风格 42 · 深色版面

暗黑学院风 DARK ACADEMIA

深棕皮革、墨绿书脊、暗金烫印：一间只在夜里开放的图书馆。

三色旧书调0.15em 烫金字距纸面内阴影光晕700–1000ms 烛光节奏

暗黑学院风来自古典校园与旧书的质感：深棕、墨绿、暗金三色构成主调，奶白作纸面，衬线字体承担全部文字，字距放开到 0.15em 像烫金。它的节奏极慢——过渡用 700 到 1000ms 的 ease-in-out，因为这套语言的参照是烛光与翻页，不是屏幕。

卡片用内阴影制造纸面凹陷的光晕（inset 0 0 35px 暗金 5%），hover 时把光晕扩到 60px。禁止霓虹、禁止现代科技感、禁止花哨动画、禁止冷灰蓝。右边这张纸页是真的——悬停它，烛光慢慢挪到右上角。

组件

Leather Button

主行动按钮。深棕填充、奶白 85% 文字、1px 暗金 45% 描边、2px 圆角、衬线 14px、字距 0.15em、padding 16px 40px，阴影 0 4px 10px 棕 20%。hover 时填充转焦棕、文字升到 100%、描边升到 80%、阴影扩到 18px；按下再暗一档。过渡 700ms ease-in-out。

Paper Card

内容卡与书页块。奶白填充、2px 圆角、1px 暗金 25% 描边、内边距 40px，内阴影 0 0 35px 暗金 5% 制造纸面光晕。hover 时描边升到 55%、内阴影扩到 60px 且加深到 14%、右上角出现一层 20% 的暖黄径向光。过渡 1000ms ease-in-out。上方演示卡即此组件。

Gilt Rule

烫金分隔线。1px 暗金 40% 的横线，两端各收进 24px，中央可放一个 8px 的菱形装饰；用于区块之间的分隔，比留白更有书页感——本页标题下方那条就是。

Study Input + Wax Seal

表单与检索输入：奶白 90% 填充、2px 圆角、1px 暗金 30% 描边、padding 14px 18px、16px 衬线；占位符焦棕 50%；聚焦时描边转暗金 80% 并加上 2px 的暗金 15% 外环。印章式标记：48px 的圆形印章，填深棕或墨绿，内嵌 24px 的衬线单字母，边缘 2px 暗金 40% 描边，外带短阴影；用于章节标记与「已读完」——演示卡右上角那枚就是。

可为与不为

可为

  • 深棕、墨绿、暗金三色主调
  • 衬线字体承担全部文字
  • 过渡 700 到 1000ms ease-in-out
  • 卡片用内阴影做纸面光晕
  • 字距放到 0.15em 像烫金
  • 奶白作纸面

不为

  • 不要用鲜艳的霓虹配色
  • 不要用现代科技感设计
  • 不要用过于花哨的动画
  • 不要用冰冷的灰蓝调
  • 不要用小圆角以外的夸张弧线
  • 不要用快于 700ms 的过渡

图像

古典静物与建筑摄影：旧书、烛台、拱窗、石廊。必须暖调、低饱和、有明显的暗部。允许把照片处理成棕褐单色。不使用现代城市、科技产品与高饱和图像。
