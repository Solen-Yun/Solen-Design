风格 29 · 浅色版面

材料设计 MATERIAL DESIGN

纸与墨的隐喻：元素有海拔，动效有物理，网格是 8dp。

海拔分层8dp 网格250ms 标准曲线按压涟漪

Material Design 的核心不是外观而是两条物理假设：第一，界面由「纸」组成，纸有海拔（elevation），层级靠阴影深度表达而不是靠边框；第二，动效必须遵循同一组曲线——cubic-bezier(0.4, 0, 0.2, 1)，250ms，减速进入。

所有尺寸落在 8dp 网格上，主色大胆（紫 #6200ee），次色作为点缀（青 #03dac6）。按钮按下必须缩到 0.98 并加深阴影——这是它认为的「触感真实性」。右边这张卡可以悬停：海拔从 1 升到 4，卡片位置不变，阴影本身就是反馈。

海拔即层级。

颜色

材料紫是整套系统的识别色——主行动、选中态与浮动按钮；青是次色，只做点缀、进度与浮动按钮上的图标；粉、琥珀、绿、锈红各管一种语义，出现在状态标记上。

  • Material Violet主行动、选中态与浮动按钮。整套系统的识别色。
    #6200ee--color-violet
  • Teal次色，用于强调、进度与浮动按钮上的图标。
    #03dac6--color-teal
  • Pink错误与删除。材料规范里的语义色之一。
    #ff0266--color-pink
  • Amber警告与需要注意的状态。
    #ffde03--color-amber
  • Green成功与完成，通常出现在对勾与进度环上。
    #00c853--color-green
  • Rust严肃警告与不可逆操作的确认态。
    #c12700--color-rust

间距与版面

基础单位 8px，密度 comfortable。上限 1200px，一切尺寸取 8 的倍数（间距 8、16、24、32）。12 栏网格、栏间距 16dp，卡片与列表用 16dp 内边距。内容左对齐，工具栏固定在顶部、浮动按钮固定在右下。

组件

Contained Button

主行动按钮。材料紫填充、白字、4px 圆角、无描边，14px/500、0.08em 字距、全大写、padding 10px 24px，海拔 2 的三层阴影。hover 时填充提亮到 #7528e5 并升到海拔 4；按下缩到 0.98、海拔降到 8 并加一道中心扩散的白色 20% 涟漪（250ms 内扩散到 2.5 倍半径）。过渡 250ms cubic-bezier(0.4, 0, 0.2, 1)。

Elevated Card

内容卡与列表容器。白底、4px 圆角、内边距 16px，海拔 1 的双层阴影，无边框；hover 时海拔升到 4（阴影加深、模糊扩大），卡片位置不变——材料规范里海拔变化本身就是反馈。上方演示卡即此组件。

Floating Action

浮动主操作按钮。56px 圆形、材料紫填充、白色 24px 图标、海拔 4，位于视口右下 16dp；hover 时海拔升到 8 并提亮；按下缩到 0.96。图标与边缘间距严格 16px。本页右下角有一颗。

Outlined Field + Snackbar

文本输入：透明底、1px #9e9e9e 描边、4px 圆角、padding 12px 16px、16px 字，标签浮动在描边上；聚焦时描边变 2px 材料紫、标签转紫、加 0 0 0 4px 的紫 12% 光环；错误态描边转粉并显示辅助文字。轻提示：深灰 #323232 填充、白字、海拔 6，出现在视口底部居中、距底 16dp，右侧放青绿色文字的动作按钮，显示 4 秒后自动消失。

可为与不为

可为

  • 层级靠海拔阴影，不靠边框
  • 一切尺寸落在 8dp 网格
  • 动效统一 250ms 与标准减速曲线
  • 按钮按下缩到 0.98 并加深阴影
  • hover 时卡片海拔必须变化
  • 主色大胆，次色只作点缀

不为

  • 不要用不一致的阴影深度
  • 不要用过于柔和的配色
  • 不要省略交互反馈
  • 不要打破 8dp 网格
  • 不要用非标准缓动曲线
  • 不要让卡片 hover 时阴影不变
