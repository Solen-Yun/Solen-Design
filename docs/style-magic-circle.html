魔法阵风 MAGIC CIRCLE

同心环、六芒星、符文沿圆周排列：一条还没启动的法阵。

3–5 层同心环hover 旋转 180°符文沿圆周排布按下缩到 0.95

魔法阵风来自奇幻作品的施法视觉：深海军黑底上叠多层次同心圆环，核心是六芒星或六边形，符文沿圆周排布，生命之花等神圣几何作暗纹，金色作唯一的暖光。它的核心动效叫 Arcane Rotation——hover 时内部虚线同心环在 3000ms 内线性旋转 180 度，像法阵被启动。

右边这条法阵是真的：hover 它，四层环会缓缓转动；按钮按下时缩到 0.95，那是施法的能量聚焦。

组件

Arcane Circle

法阵圆环组（核心组件）。由 3 到 5 层同心环组成：最外 1px 金 40% 实线、次外 1px 金 25% 虚线圈（dash 8 gap 6）、中间 2px 金 60% 实线、内部虚线环；核心放六芒星或六边形。所有环在 hover 时以 3000ms linear 旋转 180 度——绝不允许静止不动；prefers-reduced-motion 时静止。尺寸 240–480px。hero 里的法阵就是。

Rune Path

圆周符文。沿圆周均匀排列 8 到 24 个 11px 等宽字符，每个字符按其在圆上的角度旋转（transform: rotate(角度) 后反向旋转文字以保持直立或沿切线排列）。使用几何符号或拉丁大写，不用真实文字。颜色金 60%。

Sigil Button

施法按钮。阵底填充、金文字、2px 圆角、1px 金 40% 描边、16px/700、字距 0.24em、padding 12px 32px，外发光 0 0 15px 金 15%。hover 时描边升到 100%、发光扩到 30px 并加内发光；按下时缩到 0.95 且内发光加深到 60%——这是施法的能量聚焦。过渡 500ms。

Hex Card

六边形卡片。用 clip-path polygon 切出正六边形（或 8px 圆角矩形配六边形角标），阵紫填充、1px 金 30% 描边、内边距 32px，内容居中。hover 时描边升到 60% 并触发内部圆环旋转。

Sacred Geometry Bed

神圣几何暗纹。全页或区块底层叠一层生命之花或六边形网格，线宽 1px、金 6% 或靛蓝 8%，不透明度极低。它只在被注意到时才存在，绝不能压过内容。

可为与不为

可为

  • 多层同心环加六芒星核心
  • hover 时圆环 3000ms 线性旋转
  • 符文沿圆周等距排列
  • 金是唯一暖光，靛蓝为冷侧
  • 按钮按下缩到 0.95
  • 焦点环带深底色 offset

不为

  • 不要用明亮霓虹色
  • 不要让圆环在 hover 时静止
  • 不要用缺少 offset 的焦点环
  • 不要让按钮按下无缩放
  • 不要让暗纹压过内容
  • 不要用真实文字作符文

图像

符阵插画、炼金术符号、星图、魔法书页扫描。必须线稿式、金色或靛蓝、深底。不使用写实摄影、柔和插画与彩色图像。
