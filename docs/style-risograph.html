风格 44 · 浅色版面

Risograph 印刷风 RISOGRAPH

两个墨版印歪了：套印错位加网点，才是 Riso 的样子。

双向套印错位multiply 叠印100ms ease-linear网点与对位标

Risograph 是一种真实的孔版印刷：每次只上一个色版，纸走一遍印一层，所以会有套印错位、网点、以及三色以内的限制。界面上的还原靠两条硬规则——第一是 Misregistration Offset：hover 时必须用双向硬阴影模拟两个墨版错开，一个往右下（蓝版）、一个往左上（橙版），单方向阴影是错的。

第二是 Instant Print：所有过渡 100ms 且必须 ease-linear，因为是机械印刷而不是有机运动，绝不允许 ease-in-out 或用 opacity 过渡来换色。右边这张叠印卡是真的——移上去，两个墨版一起错开。

两版印歪。

粉版右下、橙版左上，multiply 出紫。

颜色

Riso 的粉墨饱和度极高，是签名色；蓝与粉叠印后产出紫——这个混合是 Riso 的核心；橙是第三个墨版与套印错位的第二个方向；纸张从来不是纯白，本身就是米白；绿与丁香是可选墨版。

套印错位公式：6px 6px 0 #2563eb, -4px -4px 0 #ff8a00、小号 4px 4px 0 #2563eb, -3px -3px 0 #ff8a00——双向才对，单方向即错。

组件

Overprint Card

叠印卡片（核心组件）。奶白纸底上叠两层墨版：第一层粉 28%，第二层蓝 22%，两层用 multiply 混合模式并各偏移 2px（一个右下、一个左上）；零圆角、1px 墨蓝 30% 描边、内边距 28px。hover 时双向硬阴影出现：6px 6px 0 蓝 与 -4px -4px 0 橙，过渡 100ms ease-linear。上方演示卡即此组件。

Riso Button

行动按钮。荧光粉填充、奶白文字、零圆角、无描边，14px/700、字距 0.14em、padding 12px 28px。hover 时出现双向硬阴影 4px 4px 0 蓝 与 -3px -3px 0 橙，同时填充硬切到橙（不做透明度过渡）；按下时位移 2px 2px 且阴影归零。全程 100ms ease-linear。

Halftone Bed + Registration Mark

网点底：用 radial-gradient 做 4px 间距、半径 1px 的网点，颜色取墨蓝 20% 或粉 20%；网点角度在不同版本间应略有不同（15 度或 45 度），避免出现摩尔纹——本页背景就是。套印对位标记：一个 16px 的圆环（1px 墨蓝）叠一个 24px 的十字（1px 橙），中心留空；放在页面四角或卡片角上——纯装饰，但它证明了这是印刷品。

Ink Counter

用色计数标记。在页面角落放一行 12px 等宽小字标注本次用了几版墨，颜色取墨黑 50%。这是 Riso 工作流的真实痕迹，也是这套风格最有说服力的细节——本页角落这行「3 INKS / PINK + BLUE + ORANGE」就是。

可为与不为

可为

  • 只用二到三支墨版色
  • hover 必须双向硬阴影
  • 过渡 100ms ease-linear
  • 阴影零模糊
  • 米白纸张底
  • 叠印用 multiply 混合

不为

  • 不要用复杂渐变
  • 不要超过四支颜色
  • 不要用写实阴影或光照
  • 不要用圆角
  • 不要用单方向阴影
  • 不要用 ease-in-out 或 opacity 过渡

图像

双色或三色网点图像：把照片分解成两到三块墨版，允许套印错位与边缘涨墨。允许手绘线稿叠印。不使用全彩摄影、写实阴影与渐变图像。
