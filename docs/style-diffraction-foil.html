颜色

全页近黑印张让变化中的银箔和光谱成为唯一的焦点。暗面板比印张亮一档，配极细白色描边分层。两种银箔面：暗箔以银灰为底，虹彩只在角度吻合处叠上去；浅箔用来印深色油墨字，不用纯白替代——因为纯白不是箔。光谱的紫、蓝、绿、黄、红是算出来的动态结果，不是固定配色，所以这里只登记三枚采样值作为参考。

组件

Foil Trading Card

收藏展示主体：深色卡框承托宽幅烫印箔面。用 #141319 卡框、白色 10% 细描边和 24px 左右圆角；中央箔面纵横比 1.8:1。标题字靠底边印在浅色位置；说明与编号用 #a9a8b6 和等宽字。边缘可以有深色投影，箔面本身不叠重阴影。

Light Foil Button

浅银箔上的主要行动，压下时材质弯曲而版面位置不动。用亮银多层银色底、screen 高光与 overlay 光谱；深色 #16151c 油墨字，12px 圆角，min-height 44px，水平 padding 24px，字体 14px/600。内侧加细白高光与深色落影；键盘操作保留 2px 的 #c9c8d4 外轮廓。

Grating Controls

让读者直接观察入射角和刻槽间距怎样改变衍射级次。深色面板内使用两条水平范围控件：灯角度 0°–70°，间距 800–2200 nm、步长 50 nm；实时显示数值和 1–3 级衍射位置。滑轨使用 #c9c8d4 作银色强调，标签 14px，数值等宽显示。

Foil Material Samples

并列展示彩虹膜、同心星芒和碎钻的刻槽差异。用统一尺寸、12px 圆角和 #141319 卡底；图形依次使用交叉光栅、圆形刻槽和随机晶面。拉丝光栅与薄膜干涉需要 WebGL2 的逐像素效果，使用明确的 WebGL 示例链接，不以假静态色块代替。

Redeem-Code Field

收藏卡或包装上用于兑换的短码。面板底 #141319，1px rgba(255,255,255,0.15) 描边，12px 圆角，padding 12px 16px；占位格式 XXXX-XXXX-XXXX，使用等宽大写字、0.2em 字距和 #6c6b78 占位文字。聚焦描边切换为 #c9c8d4，保留可见焦点环。

Collector Navigation

作为纸面边缘的一行轻导航，而非厚重应用栏。近黑底、底部 1px rgba(255,255,255,0.1) 细线、24px 水平 padding；字标可使用油墨彩箔字，普通链接保持 #a9a8b6。右侧仅放短行动按钮，桌面可提供下载 HTML 的文字链接。

可为与不为

可为

  • 用 λ = d × |dot(h, k)| / m 计算颜色，d 默认 1500 nm
  • 使用离屏 300px 的共享指针灯
  • 把光谱当作计算结果而非固定配色
  • 整页互动效果共用一个 WebGL2 上下文
  • 为不支持 WebGL 的用户提供 CSS 平替
  • 把操作反馈落在法线与光照上
  • 尊重减少动态偏好，固定灯的位置

不为

  • 不要用静态虹彩渐变冒充光栅衍射
  • 不要把彩虹铺满箔面
  • 不要让油墨文字压在高饱和光谱上
  • 不要给每个元素新建 WebGL 上下文
  • 不要靠循环 hue-rotate 改色
  • 不要为 WebGL-only 样式生成假色块预览
  • 不要交错读取布局和写入样式
  • 不要在减少动态模式下保留过冲

图像

展示真实光谱箔面、藏品或包装的宏观细节，保留能辨认金属基底的区域。静态展示用预计算光谱条加银底和方向性高光；避免照片噪点淹没细槽。WebGL-only 拉丝与幻彩需使用实际 shader 预览——本页的三块样片就是同一个上下文里的逐像素结果。
