风格 89 · 深色版面

VHS 美学 VHS AESTHETIC

一盘看了二十年的录像带：色偏、噪点、时间码在闪。

洋红青双向偏移常驻时间码扫描线 + 噪点失真是介质不是故障

VHS 美学模拟 80 到 90 年代录像带的画面缺陷：文字用洋红与青的双向偏移做 RGB 分离，全站等宽字体，深黑或深紫底，标签全大写加宽字距，画面叠扫描线与噪点，右下角常驻一个闪烁的时间码。

它与故障艺术的区别在于「这不是故障而是介质」——VHS 的失真是一贯的、温柔的、整体的，而不是突发撕裂。它禁止干净锐利的排版，因为那正是 VHS 没有的东西。

颜色

洋红是 RGB 分离的暖侧，也是主文字色；录像带的黑场做页面底；青是分离的冷侧，与洋红永远成对；黄管时间码、录制标记与高亮；绿管「PLAY」指示与状态，出现频率较低；深紫做次级底与渐变的一端，让黑不那么死。

RGB 分离固定为 2px 0 #ff00ff, -2px 0 #00ffff；文字微光 0 0 8px rgba(255,0,255,0.55)；no standard drop shadows。

间距与版面

基础单位 8px，密度 comfortable。上限 1160px、容器内边距 16px，区块间距 80px。允许画面轻微偏移与整体抖动（每 8 秒 2 到 4px）。小圆角（2 到 4px）贯穿全站。所有文字都在 OSD 层之上保持可读。

组件

Split Title

RGB 分离标题（核心）。等宽 700 全大写，主色洋红，叠两层文本副本：一层偏移 2px 用青、一层偏移 -2px 用洋红，混合模式 screen。静置时偏移 2px，每 8 秒触发一次 200ms 的步进抖动（steps(3)）让偏移跳到 4px 再回。正文绝不做分离。

Tape Panel

录像面板。深紫填充、4px 圆角、1px 洋红 25% 描边、内边距 24px。标题 22px/700 带分离，正文 13px 白 80%。左上角放「● REC」指示（绿点带 1s 闪烁），右下角放时间码（黄，如 00:12:47）。hover 时描边升到 50% 并加一条 2px 高的白 30% 横线扫过（180ms steps(3)）。hero 里的面板就是。

Scanline Bed

扫描线与噪点底。固定覆盖两层：一层 repeating-linear-gradient（每 3px 一条 1px 黑 40% 横线），一层噪点（base64 颗粒或 feTurbulence，不透明度 6%）。再叠一层极缓的垂直滚动（每 12 秒偏移 3px，linear）。pointer-events: none——本页背景就是。

Play Button

行动按钮。透明底、1px 洋红 40% 描边、2px 圆角、11px 等宽全大写 0.18em、padding 10px 24px，文字洋红带 0 0 8px 微光。hover 时描边升到 100%、文字转黄；按下时整体横向位移 2px 并做一次 60ms 的色偏。过渡 80ms linear。

OSD Label

屏幕字符标签。11px 等宽全大写 0.18em，色黄或绿，可带 1px 黑描边保证在亮画面上可读。格式固定为「SP · 00:12:47」或「PLAY」。它是录像机叠加在画面上的信息，常驻角落。

PLAY ▶

可为与不为

可为

  • 文字用洋红青双向偏移
  • 全站等宽字体
  • 深黑或深紫底
  • 叠扫描线与噪点
  • 常驻时间码与 REC 指示
  • 抖动幅度 2 到 4px、每 8 秒一次

不为

  • 不要用干净锐利的排版
  • 不要在正文做 RGB 分离
  • 不要用高清干净摄影
  • 不要用大圆角
  • 不要用标准投影
  • 不要让噪点压过文字

图像

录像带画面：家庭录像、老广告、监控、低分辨率素材。必须带扫描线、色偏与噪点。允许把现代照片做 VHS 化处理（色度位移、降采样、加噪）。不使用高清干净摄影与现代插画。
