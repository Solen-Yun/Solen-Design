风格 37 · 浅色版面

新艺术运动风 ART NOUVEAU

没有一条直线：藤蔓、长发、花茎都按植物生长的逻辑弯。

禁止直角藤蔓与花朵波浪分隔线500–700ms 慢律动

新艺术运动来自 19 世纪末：一切边缘都必须是曲线，藤蔓与花茎是主要装饰语汇，Mucha 式的海报构图把人物与植物编织进同一个框架。落到界面上，核心纪律是「禁止直角与几何形状」——按钮全圆角、卡片圆角、边框用弧线、分隔线用波浪。

字体必须是衬线或装饰性字体，现代无衬线在标题上是被禁的。节奏也要慢：过渡 500 到 700ms 的 ease-in-out，像植物的律动；150 到 200ms 的短促过渡和硬边阴影一同被排除。左边那根藤蔓是活的——悬停卡片看它慢慢转。

颜色

植物茎叶的深绿是主色——正文、主按钮与深色区块都归它；泛黄的象牙做旧海报纸面；金色勾出曲线的边缘与高光；紫藤管花朵与情绪化强调；叶绿做次级区块与藤蔓线条；亮绿只给新芽与「新增」标记，面积最小。

字体

标题用高对比装饰衬线 Playfair Display，正文用同一族更细的字重，行高拉到 1.8——让文字像藤蔓一样有呼吸的节奏。

间距与版面

基础单位 8px，密度 airy。上限 1080px、容器内边距 24px，区块间距 128px。允许非对称构图与曲线边界（区块底部可做成弧线）。元素沿植物生长的方向轻微偏移，但正文保持可读的左对齐。

组件

Vine Button

行动按钮。深绿填充、象牙文字、1px 金描边、999px 全圆角、衬线 15px、字距 0.12em、padding 16px 32px，阴影 0 4px 15px 绿 20%。hover 时填充换金、文字换深绿、阴影扩到 25px、箭头右移 4px；按下缩到 0.98。过渡 500ms ease-in-out。

Vine Card

内容卡与海报块。柔和象牙填充、32px 圆角、1px 金 35% 描边、内边距 36px，阴影 0 4px 15px 绿 20%；顶部或左侧放一条 1px 叶绿的藤蔓曲线（SVG 单条 path，带两到三片叶子）。hover 时描边升到 60%、阴影扩到 25px、藤蔓整体顺时针旋转 3 度。过渡 700ms ease-in-out。上方演示卡即此组件。

Wave Divider + Blossom Mark

波浪分隔线：一条 1px 金色波浪（SVG 单周期正弦，振幅 8px、周期 120px）横跨内容宽，中央可放一朵 16px 紫藤花；替代直线分隔——本页标题下那条就是。花朵标记：五瓣花形（SVG path 或 CSS 多圆叠加），32px 到 64px，填紫藤或金色，中心一个 6px 深色圆点；用于章节标记与「精选」，单屏不超过三处——演示卡右上的花朵即此。

Curved Frame

弧形边框与图片容器。图片容器不用矩形，用拱形（border-radius 顶端 999px 而底部 8px）或椭圆裁切；外框 1px 金描边，四角各放一个小卷草纹；不加阴影。

可为与不为

可为

  • 所有边缘都是曲线
  • 用藤蔓与花朵作装饰
  • 标题用装饰性衬线
  • 过渡 500 到 700ms ease-in-out
  • 深绿配金与象牙
  • 分隔用波浪线

不为

  • 不要用生硬直角与几何形状
  • 不要用霓虹或高饱和现代色
  • 不要用粗犷无装饰的设计
  • 不要在标题用现代无衬线
  • 不要用 150 或 200ms 的短促过渡
  • 不要用硬边阴影

图像

Mucha 式海报插画：长发、花卉、藤蔓边框、单色平涂加细线。允许把照片处理成新艺术风格的双色调后再加曲线边框。不使用几何插画、现代摄影与硬边图形。
