风格 40 · 深色版面

哥特式风 GOTHIC

尖拱、玫瑰窗、手抄本边饰：一座还没点灯的大教堂。

尖拱框架玫瑰花窗手抄本边饰首字下沉

哥特式风来自中世纪教堂建筑与手抄本装饰：深紫、血红与黑为底，金色作装饰线，形状一律是尖拱、三叶饰与玫瑰花窗，标题必须用衬线并带装饰性，页面必须有边饰与首字下沉这类手抄本语汇。

它的禁令是：不许明亮欢快的配色、不许圆润可爱的元素、不许现代无衬线做标题、不许过度简约、不许轻浮的快速抖动或弹性跳动——庄严感不容许任何轻快。右边那扇尖拱窗是真的，悬停看彩窗转起来。

尖拱之内，光线尚未点亮。

颜色

教堂夜里的深紫比黑更有层次；血红承担彩窗、印章与关键强调；金色画所有镶边；纯黑留给最深区块与阴影；中紫比底色亮一档做抬升面；铜绿是彩窗里的一抹「生」，面积最小。

  • Deep Violet页面底与主色。教堂夜里的紫，比黑更有层次。
    #2d1b4e--color-deep-violet
  • Blood Red第二主色：彩窗、印章与关键强调。
    #8b1a1a--color-blood-red
  • Gold装饰线、描边与高光。所有镶边的颜色。
    #c9a227--color-gold
  • Black最深的区块与阴影。
    #0a0a0a--color-black
  • Mid Violet抬升面与卡片，比底色亮一档。
    #4a2d6e--color-mid-violet
  • Verdigris彩窗里的一抹绿与「生」的语义，面积最小。
    #4bc542--color-verdigris

没有投影——深度来自拱形与阴影形状；唯一的「光」是金线镶边：inset 0 0 0 1px rgba(201,162,39,0.40)。

字体

标题用哥特体或高对比装饰衬线；正文用可读衬线 EB Garamond，行高 1.75，像手抄本的正文栏——哥特体只做标题，正文用它读不动。

间距与版面

组件

Pointed Arch Frame

尖拱框架（核心组件）。容器顶部用 clip-path 切出尖拱，零圆角，1px 金描边沿边勾出；内部填中紫或深紫，可嵌彩窗式色块；整块高宽比常见 1:2 到 1:2.5，像教堂的窗。上方演示窗即此组件。

Gilt Button

行动按钮。血红填充、金文字、1px 金描边、零圆角、衬线 15px、字距 0.18em、padding 14px 36px，无阴影。hover 时填充转深紫、文字转金 100%、描边升到 80%；按下时整体下沉 1px。过渡 400ms ease-out。

Rose Window

玫瑰花窗装饰。一个 96 到 240px 的圆形，内部用 conic-gradient 分成 8 或 12 个扇形，各取红、紫、绿、金之一并降到 40% 不透明度，外圈 2px 金描边加 4 个同心细环；放在区块顶部居中或角落，像教堂的窗。演示窗顶上那朵就是。

Manuscript Border + Drop Cap

手抄本边饰：页边 24 到 48px 的装饰带，1px 金线加重复的小菱形或三叶饰，四角各放一个 16px 的十字或花饰；它框住整个内容区——本页边缘的金线就是。首字下沉：段落首字母 float: left、字号为正文的 3.2 倍、行高对齐三行、颜色金或血红、字体用装饰衬线；每个内容区块只允许一次，且只在第一段。

Gothic 手抄本的第一段以一个下沉的大写字母开始，像修士在羊皮纸上落下的第一笔。它的存在本身就是仪式的一部分。

可为与不为

可为

  • 深紫、血红、黑配金线
  • 形状用尖拱、三叶与玫瑰窗
  • 标题用哥特体，正文用可读衬线
  • 页边必须有手抄本式边饰
  • 首字下沉
  • 过渡 400ms 起，动作庄重

不为

  • 不要用明亮欢快的配色
  • 不要用圆润可爱的元素
  • 不要用现代无衬线做标题
  • 不要过度简约
  • 不要用快速抖动与弹性跳动
  • 不要用哥特体排正文

图像

教堂建筑摄影、彩窗局部、手抄本插图、木刻版画。必须暗调、有明确的拱形构图。允许把照片处理成深紫与血红的双色调。不使用明亮摄影、现代插画与任何轻快的图形。
