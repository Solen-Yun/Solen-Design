风格 34 · 深色版面

合成波 SYNTHWAVE

日落渐变压在网格地平线上，霓虹从内外两侧同时发光。

双向霓虹发光条纹日落透视网格Arcade Pulse

合成波是 80 年代合成器音乐的视觉：粉紫青霓虹、橙到粉到紫的日落渐变、向地平线汇聚的透视网格、复古科技字体。它有两条标志性动效规则——第一是 Arcade Pulse，霓虹边框与发光元素在 hover 时脉冲或闪烁，像街机的 CRT 被触碰后通电。

第二是 Multidimensional Neon，按钮必须同时有内嵌青光的 inset 阴影与外侧粉光的外阴影，两根霓虹灯管从相反方向发光，hover 时一起加强——单方向发光在这里是错的。下面的按钮是真的，移上去让两根灯管一起通电。

OUTRUN 1987

双向通电。

青光向内，粉光向外，缺一半就不成立。

颜色

洋红是第一霓虹——外发光的粉侧与主按钮；青是第二霓虹——内发光的青侧与网格线；深紫底深到让两层霓虹都能被看见；日落渐变从橙经粉到紫，橙是落日与地平线的交界。

双向霓虹是硬规则：0 0 15px rgba(255,0,255,0.40), inset 0 0 10px rgba(0,255,255,0.20)，hover 加强到 30px 与 20px；文字发光 0 0 12px rgba(255,0,255,0.70)。

组件

Multidimensional Button

主行动按钮（双向霓虹）。深紫填充、白字、8px 圆角、1px 洋红 60% 描边，13px/700 全大写 0.2em、padding 12px 28px；必须同时带 0 0 15px 洋红 40% 的外发光与 inset 0 0 10px 青 20% 的内发光。hover 时两层一起加强到 30px 与 20px，并触发 Arcade Pulse（1.2s 内往复一次）。过渡 200ms。

Neon Card

内容卡。深紫 80% 填充、8px 圆角、1px 青 35% 描边、内边距 24px，双向外发光（青 12px、洋红 24px）；标题 32px/700 带 0 0 12px 洋红文字发光，正文 13px 白 80%；hover 时描边升到 70% 并触发一次脉冲。上方演示卡即此组件。

Sunset Horizon + Virtual Grid

日落与地平线（签名）：一条从橙经粉到紫的垂直渐变带，高 240 到 360px，中间一个被 8 到 12 条水平黑线切开的圆形落日；下方接透视网格，网格线青色 25%。虚拟网格（仅在接近时激活）：透视网格铺满区块下缘，默认 30% 不透明度、不位移；只有父级 hover 时才升到 70% 并开始缓慢向前位移（6s linear 循环）——静止状态下网格绝不能有动画。本页顶部的日落与地平线即此组件。

Chip Label

霓虹标签。透明底、1px 青描边、8px 圆角、13px/700 全大写 0.2em、padding 4px 10px，文字青色带 0 0 8px 青 60% 发光；hover 时描边转洋红、发光换色。演示卡左上角的标签即此组件。

可为与不为

可为

  • 粉紫青霓虹配色
  • 橙到粉到紫的日落渐变
  • 霓虹必须双向发光（inset 加 outer）
  • hover 触发 Arcade Pulse
  • 网格只在接近时激活
  • 全大写几何科技字体

不为

  • 不要用明亮白色背景
  • 不要做现代简约风
  • 不要省略霓虹发光
  • 不要用过于正式的字体
  • 不要用单向霓虹光
  • 不要让网格在静止时移动

图像

合成器视觉：落日、棕榈剪影、跑车、城市天际线、网格地面、复古科技设备。允许把照片压成粉紫双色调。不使用明亮白底、现代摄影与极简构图。
