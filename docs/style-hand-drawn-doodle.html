风格 49 · 浅色版面

手绘涂鸦风 HAND-DRAWN DOODLE

笔记本上的随手涂画：虚线、彩色马克笔、胶带与图钉。

虚线边框彩色实心阴影胶带与图钉150ms 线性

手绘涂鸦风把界面做成一页贴满便签的笔记：奶白纸底，所有边框都是 2 到 3px 的虚线，阴影不是灰的而是彩色的实心偏移（黄、红或青），标题允许 -3 度的斜切，卡片 hover 时轻微旋转。

装饰语言包括胶带条、图钉、回形针——它们是这套风格区别于「铅笔手绘」的关键：铅笔更安静，涂鸦更热闹。字体用无衬线加粗，绝不使用等宽，因为笔记里的字是随手写的。右边这张便签是真的——胶带贴着，风一吹会歪。

贴在墙上的便签！

虚线勾边，彩影垫底，胶带压角。

颜色

黑色签字笔承担虚线边框、标题与主要文字；再生纸奶白做页面与卡片底；标记红是第一强调，卡片 hover 时阴影会换成它；标记青管链接与按钮 hover 阴影；标记黄管高亮与默认阴影；橄榄是唯一的暗色强调，压在黄色上写字。

  • Ink虚线边框、标题与主要文字。像黑色签字笔。
    #2c2c2c--color-ink
  • Cream页面与卡片底色。极浅的暖黄，像再生纸。
    #fffef5--color-cream
  • Marker Red第一强调与阴影色。卡片 hover 时阴影会换成它。
    #ff6b6b--color-marker-red
  • Marker Teal链接与次级强调，按钮 hover 时的阴影色。
    #4ecdc4--color-marker-teal
  • Marker Yellow高亮与默认阴影色，用于强调一块区域。
    #ffd93d--color-marker-yellow
  • Olive唯一的暗色强调，用于压在黄色上的文字。
    #a98d16--color-olive

阴影全是彩色实心偏移：便签 5px 5px 0 #ffd93d、hover 8px 8px 0 #ff6b6b、按钮 4px 4px 0 #ff6b6b；按下归零。没有灰色模糊。

字体

标题与按钮用 Baloo 2，字重 800 并允许 -3 度斜切——圆润的无衬线是涂鸦的语气；正文与说明用 Nunito，保持可读但仍有手写气质。绝不使用等宽。

间距与版面

基础单位 8px，密度 comfortable。上限 1080px、容器内边距 24px，区块间距 96px。卡片允许 ±2 度旋转，同屏最多三张带旋转。元素可略微错位，像贴在墙上的便签。整体保持可读的网格，不追求整齐。

组件

Doodle Button

行动按钮。奶白底、2px 虚线墨黑描边、2px 圆角、18px/800 全大写 0.12em 字距、padding 12px 24px，阴影 4px 4px 0 标记红。hover 时填充硬切墨黑、文字转奶白、上浮 4px、右移 1px、旋转 1 度、阴影换成标记青并扩到 6px；按下时位移 3px 3px、缩放 0.98、旋转归零、阴影去除。过渡 150ms 线性。

Note Card + Tape Strip

便签卡与内容卡：奶白底、3px 虚线墨黑描边、2px 圆角、内边距 32px，阴影 5px 5px 0 标记黄；标题 32px/800 默认 -3 度斜切，hover 归零；hover 卡片上浮 4px、旋转 -1 度、阴影换标记红并扩到 8px。装饰胶带：宽 96px、高 24px、旋转 -4 度、半透明标记黄 80%、两端各一个 2px 锯齿，压住边框 4px——上方便签角上那条就是。

Scribble Input

表单与笔记输入。奶白底、2px 虚线墨黑描边、2px 圆角、padding 12px 16px、16px 无衬线；占位符墨黑 30%；聚焦时描边转标记红并加 2px 2px 0 标记黄的硬阴影，不改变盒子尺寸。过渡 200ms。

Doodle Underline

手绘下划线与圈注。用单周期 SVG 波浪线（stroke 2px、颜色取标记色之一）压在文字下方 4px，长度比文字宽 6%；圈注用椭圆、倾斜 6 度、不闭合（留 12px 缺口），只用一次以保持强调的稀缺。

被圈注的关键词只有一处

可为与不为

可为

  • 所有边框用虚线，2 到 3px
  • 阴影用彩色实心偏移
  • 卡片允许 ±2 度旋转
  • 用胶带、图钉等实物装饰
  • 标题加粗并允许 -3 度斜切
  • 动效 150ms 线性

不为

  • 不要用实线边框
  • 不要用灰色模糊阴影
  • 不要用等宽字体
  • 不要用渐变
  • 不要用精确的直角与几何
  • 不要用大圆角

图像

涂鸦插画、便签照片、手写步骤图。允许把照片贴成「拍立得」并加胶带。不使用写实摄影、渐变与精确矢量插画。
