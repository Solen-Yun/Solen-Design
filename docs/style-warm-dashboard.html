暖色仪表盘 WARM DASHBOARD

陶土色底配奶油白卡片：数据界面也可以有体温。

陶土底 + 奶油卡漫射阴影四色图表序列边框 ≤1px

暖色仪表盘要解决一个矛盾：仪表盘通常冷、硬、蓝，但团队每天要盯八小时。解法是把底色换成陶土，卡片用奶油白，阴影是柔和漫射的而不是硬边，圆角放大到 24px。数据本身用青绿与金黄两条序列，避免蓝红这种「系统告警」配色。

层次靠卡片提亮与漫射阴影，绝不靠边框加粗——这套风格禁止 2px 以上的边框。右边这张指标卡是真的：hover 时阴影扩散、卡片上浮，出现 1px 极浅描边。

颜色

陶土是页面底色，整套风格的体温来源，比任何强调色都重要；奶油白比陶土亮很多，靠明度差把内容托起来；青绿是暖底上唯一冷静的锚，管主行动与图表第一序列；金黄与陶土同色系但更亮，管第二序列与高亮；砖红比纯红温和，仍能传达下降；灰青管次要数据与说明，用于不需要被主动读的序列。

组件

Warm Button

主行动按钮。青绿填充、白字、12px 圆角、无描边，15px/500、padding 12px 24px，阴影 0 4px 12px 青绿 20%。hover 时填充加深到 #3d8380、阴影扩到 20px、上浮 2px；按下缩放 0.98 并收阴影。过渡 200ms ease-out。

Cream Card

指标卡与图表容器。奶油白填充、24px 圆角、无描边、内边距 32px，阴影 0 8px 24px 黑 4%。hover 时阴影扩到 40px、上浮 4px、出现 1px 极浅描边。数值 32px/700 用等宽数字，变化率右侧带一个 12px 的青绿圆点（正向）或砖红圆点（负向）。hero 里的指标卡就是。

Warm Input

筛选与搜索。白 80% 填充、12px 圆角、1px 陶土 25% 描边、padding 10px 16px、13px 字。聚焦时描边转青绿并加 3px 青绿 20% 外环，不改变尺寸。

Glass Sidebar

侧边导航。白 80% 填充、12px 模糊、右侧 1px 陶土 20% 描边、宽 240px。项目高 40px、12px 圆角、13px 字；选中项用青绿 12% 底配青绿文字，hover 用白 60% 底。

Series Palette

图表配色规则。第一序列青绿 #4a9d9a、第二金黄 #e8b86d、第三砖红 #c17767、第四灰青 #6b8e8e。只允许这四色，且必须按此顺序使用。网格线用陶土 15%，坐标轴文字用灰青。禁止蓝紫红三原色组合。

可为与不为

可为

  • 陶土底、奶油白卡
  • 阴影柔和漫射，不用硬边
  • 圆角 12 到 24px
  • 图表只用四色序列且按序使用
  • 数值用等宽数字并对齐
  • 边框不超过 1px

不为

  • 不要用冷色背景（蓝、紫）
  • 不要用纯黑文字
  • 不要用硬边阴影
  • 不要用高饱和霓虹色
  • 不要用 2px 及以上的边框
  • 不要在图表里用蓝紫红三原色

图像

以图表与图标为主，几乎不用照片。允许头像与产品缩略图。图表本身是主要视觉，配色必须取自四色序列。
