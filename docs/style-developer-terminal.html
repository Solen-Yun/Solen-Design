颜色

荧光绿是主文字与光标，整套风格唯一的识别色，像老 CRT 的磷光；极深的蓝黑让绿色看起来在发光而不是在反光；青是第一强调，管路径、链接与关键词；品红是第二强调，管函数名与命令；琥珀是第三强调，管警告与参数，终端里最多用到这一档；蓝灰管注释、元数据与禁用状态，永远比正文暗一档。

  • Terminal Black页面底。极深的蓝黑，让绿色看起来在发光而不是在反光。
    #0a0e12--color-terminal-black
  • Phosphor Green主文字与光标。整套风格唯一的识别色，像老 CRT 的磷光。
    #4af626--color-phosphor
  • Cyan第一强调：路径、链接与关键词。语法高亮里的字符串色。
    #8be9fd--color-cyan
  • Magenta第二强调：函数名与命令。
    #ff79c6--color-magenta
  • Amber第三强调：警告与参数。终端里最多用到这一档。
    #ffb86c--color-amber
  • Comment Grey注释、元数据与禁用状态。永远比正文暗一档。
    #6272a4--color-comment-grey

终端是平的：none — the terminal is flat；唯一的光效是焦点环 0 0 0 1px #4af626。绝不用渐变与玻璃态。

间距与版面

基础单位 4px，密度 compact。上限 1100px、容器内边距 16px，区块间距 32px。整页像一次滚动的会话记录：从 $ 命令开始，向下是输出、注释、下一组命令。行宽控制在 100 字符以内，保持终端阅读习惯。

组件

Command Block

命令与输出的成对结构（核心组件）。命令行以 $ 开头，$ 与命令之间 8px，命令用白色或荧光绿；输出行缩进 16px、颜色稍暗。命令与输出之间无空行，两组之间空 16px。整块用 13px 等宽、行高 1.6，无需边框与背景——hero 里那块就是。

Terminal Panel

面板与分区块。#0f141a 填充、2px 圆角、1px #1f2937 描边、内边距 16px，无阴影。面板顶部可放一行 12px 蓝灰的路径标头（如 ~/projects）。面板之间 16px。

Cursor Block

闪烁光标。8px × 16px 的荧光绿实体块，跟在标题末尾或输入位的文字之后，每 1 秒以 steps(1) 硬切显示与隐藏（不做淡入淡出）。同一屏最多出现一个。

Status Bar

tmux 式状态栏。固定在视口底部、高 24px、荧光绿 15% 底、顶部 1px #1f2937 描边。左侧显示会话名与分支（12px 全大写 0.08em），右侧显示时间与 CPU 占位。整条不加圆角。

Aligned List

ls 式对齐列表与表格。列表用等宽对齐成三到四列（权限/大小/时间/名称），列间用 8px 稳定间隔，不靠 tab 而是靠固定列宽。表头用蓝灰全大写 12px，下方一条 1px #1f2937 分隔线。行高 24px。

可为与不为

可为

  • 全站等宽字体，无例外
  • 近黑底配荧光绿文字
  • 内容是命令加输出的成对结构
  • 注释以 # 开头并用蓝灰
  • 列表按列宽对齐
  • 光标用 steps(1) 硬切闪烁

不为

  • 不要用无衬线或衬线字体
  • 不要用白色或浅色背景
  • 不要用渐变与玻璃态
  • 不要用摄影与插画
  • 不要超过四种强调色
  • 不要用厚阴影

图像

没有图像。只有字符、ASCII 图形与块字符进度条。允许把进度条做成 ███░░ 式的字符画。不使用图标（会破坏纯字符假设），需要指示时用 → 与 » 这类字符。
