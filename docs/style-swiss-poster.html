瑞士海报风 SWISS POSTER

字大到成为图形，区块紧贴不留缝，层级靠尺寸与色块。

120–180px 海报字gap-0 紧贴网格2px 黑线分隔极端非对称

瑞士海报风是国际主义风格的海报分支：与常规瑞士风格的区别在于它把字推到海报尺度——字大到成为图形本身，行宽与栏宽由内容决定，允许单字占半屏。它的版面规则极其硬：黑白为主，原色只作色块强调；区域之间用 2px 黑线分隔而不是留白，元素之间 gap-0 紧贴。

圆角不超过 2px。禁止装饰性字体与等宽字体、禁止渐变、禁止虚线边框。下面这张「海报」是真的——每个区块紧贴，缝隙全靠 2px 黑线。

颜色

黑承担文字、分隔线与最大色块——海报的骨架全靠它；白是画布与反白文字，与黑成对不做灰阶；红标记最重要的信息，面积不超过一屏 20%；蓝常与红形成对角关系；黄是高亮条，给需要跳出的细节；赭是唯一暗暖色，压在黄色块上写字。

组件

Poster Headline

海报主标题（核心）。120 到 180px、900 字重、行高 0.85、字距 -0.045em，字块左对齐或贴顶部，允许单行占满 1440px 宽；可与色块重叠（文字永远在上），与相邻区块之间不加空隙而是用 2px 黑线分割。上方海报区的大字即此组件。

Flush Grid + Color Field

紧贴网格：12 栏网格、gap 为 0，区域之间只用 2px 黑线分隔；每个区域填纯色，区域内边距 24px；禁止用间距做分隔——在瑞士海报里线就是间距。色块区域：整块填一支原色或纯黑，零圆角、无描边，块内文字按对比取黑或白、最小 24px，一块只用一色。上方整块海报区就是这两个组件。

Block Button

行动按钮。纯黑填充、白字、零圆角、无描边、无阴影，14px/700、字距 0.04em、padding 16px 40px。hover 时填充硬切到原红；按下时填充换原蓝并位移 2px 2px（模拟套印偏移）。过渡 120ms linear。

Rule Divider

2px 分隔线。2px 纯黑实线，横跨或纵贯，用于切割区域；绝不用虚线（这在瑞士语言里等于软弱），也绝不用留白代替线。

可为与不为

可为

  • 字大到成为图形（120 到 180px）
  • 黑白为主，原色只作色块
  • 区域用 2px 黑线分隔，gap 为 0
  • 行高压到 0.85 到 0.92
  • 允许极端非对称
  • 圆角不超过 2px

不为

  • 不要用装饰性字体或等宽字体
  • 不要用超过 2px 的圆角
  • 不要用渐变
  • 不要用虚线边框
  • 不要用间距代替分隔线
  • 不要做居中的对称排版

图像

黑白摄影、几何构成、单色图形。图像必须能被裁剪成严格的矩形并贴齐网格，允许高对比双色调叠加一支原色。不使用柔和摄影、插画与装饰图形。
