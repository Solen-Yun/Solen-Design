风格 108 · 浅色版面

开发者平台风 DEV PLATFORM

灰度做结构，蓝只做交互，颜色永远带语义。

五档灰阶承担结构蓝只给可点击元素圆角统一 6px动效 80ms 内

开发者平台风是开发者工具的默认语言：绝大部分界面由灰阶组成（白、#f6f8fa、#d0d7de、#656d76、#1f2328 五档），蓝色 #0969da 只用于可点击的东西，绿黄红三色只有语义（通过、警告、失败）。圆角统一 6px，边框统一 1px #d0d7de，阴影几乎为零。

代码块用等宽字体加浅灰底，是它最重要的识别元素。

颜色

蓝是唯一的主色，只用于链接、主按钮与选中状态；白是卡片与内容区底，与浅灰底形成唯一的分层手段；浅灰画布是页面底与代码块底，整套界面的地基；边框灰统一所有 1px 边框与分隔线，只用这一个值；次灰管元数据、时间戳与说明文字；带一点蓝的深灰做标题与正文，比纯黑柔和。绿黄红三色是语义专用：绿通过、黄待处理、红失败。

字体

界面文字用 Inter，字级偏小（12 到 16px 为主），极少超过 24px；代码块、分支名、commit hash 与命令行用 JetBrains Mono——等宽是这套风格的识别核心。

组件

Primary Button

主行动按钮。通过绿 #1f883d 填充、白字、6px 圆角、1px rgba(31,35,40,0.15) 描边、无阴影，14px/500、padding 5px 16px。hover 时填充加深到 #1a7f37；按下内阴影 inset 0 1px 0 rgba(31,35,40,0.10)。过渡 80ms。注意主按钮是绿色而链接是蓝色，两者分工不混。

Repo Card

仓库卡与内容卡。白底、6px 圆角、1px #d0d7de 描边、内边距 16px、无阴影。标题 16px/600 用交互蓝（可点击），描述 14px 主文字，底部一行 12px 次灰放语言色点、star 数与更新时间。hover 时描边颜色不变，只让标题加下划线——hero 那张就是。

Code Block

代码块（识别核心）。浅灰 #f6f8fa 底、6px 圆角、1px #d0d7de 描边、内边距 16px，字体 JetBrains Mono 13px、行高 1.5、可横向滚动。语法高亮只用五到六种色，且不改变字重。右上角可放一个复制按钮（12px、次灰）。

State Label

状态标签与徽标。999px 全圆角、语义色 10% 底、语义色文字、1px 同色 25% 描边、12px/500、padding 2px 10px。通过用绿、待处理用黄、失败用红、信息用蓝。每个标签必须带文字，颜色只是辅助。

PASSED

Side Nav

侧边导航与筛选。白底或透明、宽 240px、无右边框。项目高 32px、6px 圆角、14px 字，选中项用 #f6f8fa 底加 2px 交互蓝左边条。分组标题 12px/600 次灰，上方间距 16px。

可为与不为

可为

  • 五档灰阶承担结构
  • 蓝色只用于可点击元素
  • 绿黄红只表达语义
  • 圆角统一 6px，边框统一 #d0d7de
  • 代码块用等宽加浅灰底
  • 动效 80ms 以内，无弹跳

不为

  • 不要用渐变背景或彩色装饰
  • 不要用重阴影
  • 不要用非语义的装饰色
  • 不要用衬线字体
  • 不要用过大字号或过宽间距
  • 不要用动感十足的动画

图像

几乎没有图像。允许头像 20 到 40px、图标 16px、语言色点 8px。不使用插画、摄影与背景图，界面本身就是内容。
