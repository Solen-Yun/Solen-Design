风格 81 · 深色版面

黑色电影 FILM NOIR

一束斜光切开黑房间：其余全部藏在阴影里。

斜光渐变深灰阶分层猩红只一处衬线斜体标题

黑色电影来自 1940 到 50 年代的黑色片：极端明暗对比、深灰阶分层、斜向光影、以及只在必要时出现的一抹猩红。它不用颜色造层次而用亮度——卡片之间靠极微妙的灰差区分，光影用线性渐变模拟，hover 只改亮度不改色相。

标题用衬线斜体，像片头字幕。禁令是：不许彩色背景、不许高饱和色（猩红只作点缀）、不许大圆角。右边这张斜光卡是真的：一道 115 度的光从左上打进来，hover 时只提亮 8%。

颜色

近纯黑的影黑让光看起来是打上去的；幕灰只比底色亮一档，做第一层抬升面；次灰是第二层抬升面与卡片内部；烟白略带暖，像旧拷贝，管标题与主要文字；猩红是唯一的彩色，只作点缀——一个标记、一条线、一次警告；黄铜极少量出现，暗示「贵」，如奖项与年份。

  • Film Black页面底与最深的阴影。近纯黑，让光看起来是打上去的。

  • Second Grey第二层抬升面与卡片内部。
    #262626--color-second-grey
  • Smoke White标题与主要文字。略带暖的灰白，像旧拷贝。
    #f5f5f0--color-smoke-white
  • Crimson唯一的彩色，只作点缀：一个标记、一条线、一次警告。

  • Brass极少量用于「贵」的暗示，如奖项与年份。
    #d4af37--color-brass

层次靠渐变假光：none — light is faked with gradients；卡片影 0 24px 60px rgba(0,0,0,0.70)。斜光固定 linear-gradient(115deg, rgba(255,255,255,0.08), transparent 45%)。

字体

标题用衬线斜体 Playfair Display，像 1940 年代的片头字幕；正文用同族正体，行高 1.7。

间距与版面

基础单位 8px，密度 comfortable。上限 1120px、容器内边距 24px，区块间距 128px。允许斜向构图与元素错位。整页以黑为主，靠不同层的暗灰区分区域，几乎不用留白做分隔。

组件

Shaft Card

斜光卡片（核心组件）。#1a1a1a 填充、4px 圆角、1px #2e2e2e 描边、内边距 32px。关键是用一层线性渐变模拟斜光：linear-gradient(115deg, rgba(255,255,255,0.08) 0%, transparent 45%)，从左上打入。标题 38px 衬线斜体烟白，正文 20px 烟白 70%。hover 时整体亮度升 8%（filter: brightness），绝不改色相。hero 里的卡片就是。

Noir Button

行动按钮。透明底、1px 烟白 30% 描边、2px 圆角、20px/700、字距 0.14em、padding 12px 32px。hover 时描边升到 70%、文字从 85% 升到 100%、背景加烟白 4%；按下时亮度降 10%。过渡 400ms ease-out。

Crimson Mark

猩红标记。一条 2px、长 32 到 64px 的猩红横线，或一个 8px 的猩红圆点，或一行猩红文字。全页只允许出现一到两处，它是画面的「出血点」。绝不铺成色块——hero 卡左下那条线就是本页的第一处。

Diagonal Shadow

斜向阴影带。一个绝对定位的斜向条带（rotate(-18deg)）、宽 200 到 400px、填黑 60% 并加 120px 模糊，压在内容上但 pointer-events: none。它模拟百叶窗或门框投下的影，单屏最多两处。

Smoke Field

暗场输入。#1a1a1a 填充、2px 圆角、1px #2e2e2e 描边、padding 12px 16px、20px 衬线。占位符烟白 35%。聚焦时描边转烟白 50% 并加 1px 外环。

可为与不为

可为

  • 极端明暗对比，深灰阶分层
  • 用线性渐变模拟斜光
  • hover 只改亮度不改色相
  • 标题用衬线斜体
  • 猩红只作点缀，一到两处
  • 圆角不超过 4px

不为

  • 不要用彩色背景
  • 不要用高饱和色（猩红除外）
  • 不要用大圆角
  • 不要把猩红铺成色块
  • 不要用平光摄影
  • 不要用彩色图像

图像

黑白摄影：人物侧影、百叶窗光、雨夜街道、烟雾、烟头特写。必须有强方向光与深阴影。允许把彩色照片转成高对比黑白。不使用彩色图像、平光摄影与柔和插画。
