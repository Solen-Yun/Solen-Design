太阳朋克 SOLARPUNK

乐观的生态未来：植物与技术不是对立，而是长在一起。

叶绿配金黄绿到金暖渐变24px 大圆角深赭代替黑

太阳朋克是对赛博朋克的正面回答：不要霓虹废土，要阳光、植物与共居的技术。视觉上它靠三件事——温暖浅色的底、叶绿与金黄这对主色、以及大圆角与有机曲线（没有一条边是完全直的）。渐变在这里是合法的，而且必须是从绿到金的暖向渐变。

它禁止纯黑背景、尖锐直角、冷工业元素与霓虹发光，也禁止任何废土或反乌托邦的暗示。右边这张有机卡是真的：hover 时上浮 4px，阴影带着绿调扩散。

颜色

叶绿是主色，管生长、行动与植物元素，整套风格的乐观感来自它；金黄是阳光与能量，几乎总与叶绿同现，形成暖向渐变；奶油浅底让绿与蓝都显得温和；天蓝管水与清洁能源；深赭代替黑，避免任何冷硬感；薰衣草紫管科技与社区语义，出现频率最低。

组件

Sun Button

主行动按钮。叶绿到金黄的 135 度渐变填充、白字、999px 全圆角、无描边，15px/700、padding 12px 28px，阴影 0 8px 20px 金黄 30%。hover 时渐变角度转 180 度（模拟光线移动）、阴影扩到 28px、上浮 2px；按下缩放 0.98。过渡 300ms ease-out。

Organic Card

内容卡与项目卡。薄荷白填充、24px 圆角、1px 叶绿 15% 描边、内边距 28px，阴影 0 12px 32px 叶绿 18%。左上角配一个 48px 的圆形图标底（叶绿 12%）。hover 时上浮 4px、阴影扩到 48px。圆角不对称也是允许的（如 24px 与 32px 混用），但同一卡片内保持一致。hero 里的卡片就是。

Soft Input

表单输入。薄荷白填充、16px 圆角、1px 叶绿 20% 描边、padding 12px 18px、15px 字，聚焦时描边转叶绿并加 4px 的叶绿 20% 外环。占位符赭石 45%。

Plant Motif

植物与有机装饰。单线条植物图形（藤蔓、叶片、太阳能板叶片混合），stroke 2px、颜色叶绿或赭石、尺寸 64px 到 160px。可沿卡片边缘或区块之间蜿蜒，允许超出容器 16px。单屏不超过三处——图标底里那株就是。

Warm Gradient Band

渐变区块与分隔。从叶绿到金黄的 120 度渐变，高度 120px 到 200px，圆角 32px 或全宽无圆角。用于区块之间的过渡，替代留白。渐变上可叠一层 8% 的叶脉纹理。

可为与不为

可为

  • 暖浅底，不用黑或深色
  • 叶绿与金黄成对，用暖向渐变
  • 大圆角与有机曲线
  • 植物元素与技术并置
  • 文字用深赭代替黑
  • 阴影带绿调而不是灰调

不为

  • 不要用纯黑或暗色主题
  • 不要用尖锐直角
  • 不要用冷工业风元素
  • 不要用高对比霓虹发光
  • 不要出现废土或反乌托邦元素
  • 不要用灰暗压抑的配色

图像

植物与技术的混合插画：太阳能板长成叶片形状、楼顶有花园、藤蔓绕着结构。允许自然光摄影并加暖色调。不使用冷工业摄影、废土场景与霓虹灯效。
