颜色

暖纸白是页面底与输入框填充，它不是泛黄滤镜——所有正文都要在这里保持清楚。墨色承担正文、标题、主要操作与焦点轮廓。石墨做次级正文、图表线与元数据，但仍须有足够对比度。规则灰只做卡片边框、分隔线与非关键网格，绝不用它写正文。阅读面是列表分组与表格行的底。

  • Ink正文、标题、主要操作和焦点轮廓。
    #20211e--e-ink-text
  • Warm Paper页面底色和输入框填充。
    #f5f3ea--e-ink-paper
  • Graphite次级正文、图表线、元数据和简短标签。
    #555750--e-ink-muted
  • Rule Gray卡片边框、分隔线和非关键网格。
    #bab9b0--e-ink-rule
  • Reading Surface列表分组、表格行或选中的阅读卡片。
    #e6e4da--e-ink-panel

不做浮起：none; use a single divider or offset hatch. 选中态用 2px ink outline 配文字标记，不用阴影。

字体

正文用系统里已有的无衬线，保持常规字重，标题最多到 700，不引入专有屏幕字体。日期、时间、数值、单位与简短状态用等宽，因为这些字段需要对齐。

组件

Ink Action

页面的单一主要行动。纸底上的墨色填充，零圆角，12–16px 内边距。标签用 14px/600；键盘焦点用 2px 墨色轮廓并与边缘保留 2px 间隔。不要加入图标当作唯一提示。

Reading Row

书目、列表和摘要项。每行用一条 1px 细线分隔，序号与数字用等宽字体；次级描述换行，不缩到 12px 以下。选中行同时显示「当前」标签和左侧墨色条。

Paper Field

搜索、筛选和短文本输入。暖纸填充、1px 中性边框、最小高度 44px；占位文字仍用可读灰度，不能把提示做成近乎消失的浅灰。提供可见 label 和 2px 键盘焦点轮廓。

Halftone Mark

示例背景纹理或有限灰阶图表填充。只把小点阵用于装饰性图块或图表区域，点距至少 5px；文字与可交互元素保持纯色，避免灰点破坏字符边缘。需要深浅层次时，应同时保留标注和图例。

Status Marker

进度、在线状态与提醒。灰阶色块与实心/空心几何标记配合，旁边有「完成」「离线」等文字。圆点不是唯一状态载体，错误或警告不借用未定义的颜色。

可为与不为

可为

  • 先写屏幕目的，再选最少的卡片与状态
  • 数字列、单位和日期保持对齐
  • 每个状态同时给出形状或文字
  • 用细规则和局部点阵分组
  • 交互控件保留 44px 触控高度与焦点
  • 窄屏按阅读顺序合并列
  • 示例数据明确标注来源或示例状态

不为

  • 不要把演示内容说成实时硬件数据
  • 不要把重要文字放进点阵或低对比灰
  • 不要只用灰阶深浅表示状态
  • 不要使用发光、玻璃模糊与连续闪烁
  • 不要假定 1-bit 量化或屏幕刷新已完成
  • 不要引入未确认许可的像素字体或品牌图

图像

优先使用留白、可读数据表与少量线性图形。点阵只用于局部图表，不复制他人品牌标识、字体、设备外壳或宣传图像。需要预览真实图像时，先确认许可并保留原始来源。
