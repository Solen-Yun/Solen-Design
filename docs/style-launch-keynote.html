颜色

舞台是纯黑无纹理，让产品图的边缘消失，形成无限深的舞台。主要文字用比纯白柔的 #f5f5f7，长时间看不刺眼；中灰做次级说明与规格，永远是第三层级；卡面深灰只比舞台亮一点，用来在不破坏纯黑的前提下分区。电蓝是全页唯一强调色，只给链接、主 CTA 与关键数字——全页不得出现第二种彩色。

  • Stage Black页面底。纯黑无纹理。
    #000000--color-stage-black
  • Near White主要文字与高对比元素。
    #f5f5f7--color-near-white
  • Mid Grey次级文字、说明与规格。
    #86868b--color-mid-grey
  • Electric Blue唯一强调色：链接、主 CTA 与关键数字。
    #2997ff--color-electric-blue
  • Card Graphite卡片与信息块。
    #1d1d1f--color-card-graphite

舞台没有深度线索：none — the stage has no depth cues。卡片可用 0 24px 60px rgba(0,0,0,0.6)，其余一律不加。

字体

全站一种字体。两种极端并置是这套风格的声音：大标题 56 到 80px 配 -0.035em 的紧字距，小标签 12px 全大写 0.2em 宽字距。

间距与版面

基础单位 8px，密度 airy。上限 1120px，区块间距 240px——大到近乎奢侈，几乎全部居中。文字块宽度不超过 20 个汉字或 40 个字符，因为短句才配得上这么大的留白。帧序列区块占 3 到 4 屏滚动高度。

组件

Buy Button

主行动按钮。电蓝填充、白字、999px 全圆角、无描边，17px/500、紧字距、padding 12px 24px。hover 时填充转 #0071e3；按下缩到 0.98。过渡 300ms。全页只有一个这样的按钮——hero 里那个就是。

Spec Card

规格与特性卡。卡面深灰填充、24px 圆角、无描边、内边距 32px。上方 12px 全大写 0.2em 的电蓝标签，中间 28px/600 白标题，下方 17px 中灰说明。卡片本身不加边框与阴影——纯黑舞台上加边框会毁掉无限深。

Scrub Stage

滚动擦洗帧序列（签名组件）。外层高度为视口的 3 到 4 倍，内层 sticky top-0、高 100vh，内含一个 canvas。帧以 WebP 存放，用 IntersectionObserver 在区块接近视口时才加载（绝不首次渲染就预载全部帧），画布尺寸按 devicePixelRatio 封顶 2 倍。滚动进度用 requestAnimationFrame 读取 window.scrollY 一次并缓存，绝不在处理器里读 getBoundingClientRect 或 offsetTop。prefers-reduced-motion 时只画关键帧。所有关键文字必须叠在 canvas 之外的 DOM 里。

Glass Nav

顶部导航。固定顶部、高 48px、黑 70% 底加 24px 模糊、底部 1px 白 10% 描边。左侧 17px/600 近白字标，右侧链接 14px 近白 80%，购买链接用电蓝。hover 时链接转纯白。

Dark Field

邮箱与表单输入。卡面深灰填充、1px 白 10% 描边、12px 圆角、padding 12px 20px、17px 字。占位符中灰。聚焦时描边转电蓝，不加外环、不加光晕。

可为与不为

可为

  • 纯黑舞台，无边框无纹理
  • 只用一支电蓝强调色
  • 帧用 IntersectionObserver 懒加载
  • 滚动进度在 rAF 里读一次并缓存
  • 关键文字放在 DOM，不放帧图
  • 尊重 reduced-motion，给 DPR 封顶

不为

  • 不要用多彩渐变或第二个强调色
  • 不要在滚动处理器里读布局属性
  • 不要在首屏预载全部帧
  • 不要把关键信息烘焙进帧图
  • 不要堆砌边框与圆角装饰
  • 不要忽略 reduced-motion 与 DPR 封顶

图像

产品渲染图是唯一图像，且必须自带光源、边缘融入纯黑。允许产品特写、内部结构剖视与帧序列动画。不使用人物摄影、多彩渐变与背景纹理。
