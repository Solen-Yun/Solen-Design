风格 77 · 浅色版面

可爱极简 KAWAII MINIMAL

圆、粉彩、大留白、一点点弹跳：可爱但不吵。

暖白底粉彩点缀999px 全圆角hover 1.05 弹跳留白过半

可爱极简把日本 kawaii 文化里的「柔软」与极简主义的「克制」缝在一起：暖白底、粉彩强调、全圆角或 24px 大圆角、柔和阴影、圆润无衬线、极多留白。它允许弹跳——hover 放大到 1.05、按下缩到 0.95，这是它唯一被允许的夸张。

禁止深色背景、禁止发光与霓虹、禁止高饱和荧光色、禁止粗黑边框、禁止信息过密。可爱在这里靠比例与温度，不靠堆装饰。右边这张软卡是真的：hover 会轻轻上浮，按钮会弹。

今天也要好好吃饭

圆润的插画、柔和的粉色、足够的留白。

颜色

粉是主色，管主按钮、选中态与图标底，整套风格的可爱感由它承担；带橙调的暖白比纯白更有体温；薰衣草紫管次级行动与分类标记；天蓝是唯一偏冷的粉彩，管信息与「新」标记；奶油黄管高亮与庆祝状态，面积最小；深粉是粉的加深版，用于需要更高对比的文字与图标。

组件

Bouncy Button

行动按钮。粉色填充、白色文字、999px 全圆角、无描边、17px/700、padding 14px 28px，阴影 0 4px 12px 粉 18%。hover 时放大到 1.05、阴影扩到 24px；按下缩到 0.95。过渡 200ms cubic-bezier(0.34, 1.56, 0.64, 1)，这条带回弹的曲线是这套风格的签名。

Soft Card

内容卡。白底、24px 圆角、1px 粉 200（#fbcfe8）描边或无描边、内边距 32px，阴影 0 4px 12px 粉 18%。左上角可放一个 40px 的粉彩图标底（999px 圆角）。hover 时上浮 4px、阴影扩到 24px。hero 里的卡片就是。

Pill Input

输入框。白底、999px 全圆角、1px 粉 200 描边、padding 12px 20px、15px 字。占位符粉 400（#f9a8d4）的 60%。聚焦时描边转粉 400 并加 3px 的粉 20% 外环。

Pastel Chip

分类与状态标签。999px 全圆角、粉彩 15% 底（粉、薰衣草、天蓝或奶油黄）、无描边、13px/500、padding 6px 14px，文字用深粉或深灰而不是白。

新 · NEW

Gentle Avatar

头像与图标容器。999px 全圆、尺寸 32 到 64px、粉彩底加 1px 白 60% 描边，内放 16 到 24px 的白色或深粉图标。hover 时旋转 6 度并放大 1.08。

可为与不为

可为

  • 暖白底，不用深色
  • 全圆角或 24px 大圆角
  • 粉彩强调，每屏不超过两种
  • hover 1.05、active 0.95 的弹跳
  • 阴影柔和且带粉色
  • 留白占五成以上

不为

  • 不要用深色或黑色背景
  • 不要用发光与霓虹
  • 不要用高饱和荧光色
  • 不要用粗黑边框
  • 不要信息过密
  • 不要用锐利直角

图像

圆润的插画：动物、食物、植物，线条粗而圆、平涂粉彩。允许真实摄影但必须柔和、暖调、高留白。不使用冷硬几何、暗调摄影与写实图标墙。
