可为与不为

可为

  • 白或浅灰底，保证产品图准确
  • 图片固定 1:1 或 3:4 比例
  • 价格是页面对比最高的元素
  • 主按钮只用品牌绿且足够饱和
  • 原价划线放在现价旁
  • 信任标识用小图标配 12px 文字

不为

  • 不要用深色主背景
  • 不要在列表页加大面积装饰
  • 不要用低对比价格色
  • 不要让 CTA 低饱和
  • 不要给产品图加滤镜或色彩叠加
  • 不要用不规则图片比例

图像

产品摄影是唯一图像，必须白底或极浅底、无滤镜无色彩叠加、统一比例。允许同一商品的多角度图与细节特写。不使用场景图作主图、装饰插画与图标墙。
