风格 02 · 浅色版面

新野兽派 NEO-BRUTALIST

黑框、硬阴影、零圆角：界面由一块块压不扁的实体组成。

硬阴影零圆角等宽标签物理交互高饱和强调色

新野兽派从建筑取来态度：结构外露，材料不加装饰。网页上的做法是给每个元素一个 2px 到 4px 的纯黑外框、一层无模糊的偏移阴影、以及零圆角，让平面产生真实厚度。

交互也必须是物理的——hover 时阴影变大、元素向左上抬起（Brutal Snap）；active 时元素位移量正好等于阴影偏移量，阴影归零，像被手掌压平（Physical Crushing）。颜色只有黑白打底，加四支高饱和强调色，每支承担一个固定职能，不做渐变、不做半透明。右边这张卡可以悬停和按压，试试它。

FEATURED

压不扁。

结构外露，材料不加装饰。

颜色

黑白打底，加四支高饱和强调色，每支承担一个固定职能。Ink 承担结构的全部重量，不允许换成深灰；Tangerine 使用频率最低，全站不超过三处同时出现。

  • Ink所有边框、文字、硬阴影与反色区块。结构的全部重量都由它承担，不允许换成深灰。

  • Paper页面画布与卡片填充。纯白是为了让黑框与阴影的对比拉到最大。

    #ccff00--color-acid-lime
  • Electric Cyan数据、状态与次级面板的强调。和粉、绿同时出现时只占小面积。
    #00d9ff--color-electric-cyan

表面层级：0 Paper #ffffff，1 Slab #f4f4f4（次级面板与分区底）。阴影只有硬偏移三档：4px 4px 0 0 #000000、8px 8px 0 0 #000000、hover 抬起 10px 10px 0 0 #000000；按下时归零。

字体

两套字各司其职：标题的力量来自 900 字重与紧缩字距，不来自字号堆叠；等宽字体让界面读起来像终端输出，是这套风格的第二识别点。

间距与版面

基础单位 8px，密度 compact。12 栏、上限 1280px，容器内边距 16px 到 32px，区块间距 80px，卡片间距 32px。允许元素相对网格偏移 4px 到 8px 制造碰撞感，但同一区块内偏移方向保持一致；标题与正文硬对齐，不做居中柔化。

组件

Block Button

主行动按钮。白底、2px 墨黑描边、直角、4px 硬阴影。字号 12px、字重 700、全大写、字距 0.12em、等宽；padding 12px 24px。hover 时阴影增到 10px、元素向左上位移 4px，背景转为酸柠绿，按 150ms ease-out 过渡。按下时元素右下位移 6px，阴影归零。

Brutal Card

内容卡片与商品卡。白底、2px 墨黑描边、直角、8px 硬阴影，内边距 24px，卡片间距 32px。hover 时元素上移 4px、阴影增到 10px，阴影色可切到荧光粉，过渡 150ms ease-out。上方演示卡即此组件。

Mono Label

分类标签与状态徽标。墨黑填充、白字、直角、无描边。12px 等宽、字重 700、全大写、字距 0.12em；padding 4px 8px。反色用途时改为白底黑框。

CATEGORY INVERTED

Hard Input

表单输入。白底、2px 墨黑描边、直角、无阴影。14px 等宽、padding 12px 16px。聚焦时出现 4px 硬阴影并保持描边宽度不变，不改变尺寸以避免布局抖动。

Marquee Bar

页面顶部或底部的滚动条。墨黑底、白字、直角、无阴影。16px 等宽、全大写、字距 0.12em、上下 padding 8px，内容横向匀速滚动，间隔用 4px 实心方块分隔。页面末尾这条即此组件。

可为与不为

可为

  • 所有元素使用 2px 到 4px 纯黑边框，绝不用灰色边框
  • 阴影必须是零模糊的硬偏移，4px 与 8px 两档
  • 保持直角，任何圆角都会削弱实体感
  • hover 增大阴影，active 位移等于阴影偏移并把阴影归零
  • 标题固定 900 字重，正文用等宽字体
  • 共享过渡 token 为 transition-all duration-200；本页具名 showcase 组件示例采用 150ms ease-out

不为

  • 不要使用任何圆角（rounded-lg、rounded-full 等）
  • 不要用模糊阴影（shadow-lg、shadow-xl），它们会毁掉物理感
  • 不要用渐变，包括按钮与背景
  • 不要用灰色或半透明边框
  • 不要用 opacity 淡入淡出；区分共享 token 的 200ms 与具名 showcase 组件的 150ms 覆盖
  • 不要在 active 时只位移不归零阴影

图像

不用摄影。用粗描边的几何图形、点阵与棋盘格、像素化的图标，全部单色或四支强调色之一。任何图像都必须能画成 2px 线条与实心块，出现渐变或柔光就破坏风格。
