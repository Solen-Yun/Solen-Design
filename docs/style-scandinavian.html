北欧极简风 SCANDINAVIAN

暖灰白、细线条、极慢的过渡：把「安静」做成可测量的参数。

字重只有 200/3002px 圆角700ms ease-in-out饱和度 <30%

北欧极简风来自 Hygge 的生活观：少、慢、暖。它的所有参数都比常规更收敛——字重只用 200 与 300，圆角只有 2px，边框是 1px 的 30% 透明度，过渡长达 700ms 且必须 ease-in-out。交互刻意做得极轻：hover 只让边框从 30% 变到 80%，按下只改明暗，绝不位移、绝不弹跳。

留白不是装饰而是结构，元素之间至少 40px。配色是暖灰白加木色、苔绿与灰蓝，饱和度全部压在 30% 以下。右边这张 Hygge 卡是真的：hover 时描边缓缓升起，标题慢慢转苔绿。

晨间的一盏灯

木质家具、亚麻织物、一株绿植。房间安静下来之后，光才显出形状。

颜色

炭灰深而不黑，长看柔和，管标题与主按钮底；暖白是带木质暖调的米白，比冷白更接近室内墙色；木色像浅橡木，是这套风格的温度来源，管次级文字与装饰；苔绿取自室内植物，管 hover 高亮与成功状态；灰蓝管链接与冷色平衡，用在需要后退的信息上；沙色管分隔线与图块底，在不引入对比的前提下分区。

组件

Quiet Button

主行动按钮。炭灰填充、暖白文字、2px 圆角、无描边、无阴影。14px/300、0.12em 字距、padding 14px 40px。hover 时填充转苔绿并把亮度降 5%；按下只把填充再压暗一档，绝无缩放与位移。过渡 700ms ease-in-out，这是整套风格的节奏基准。

Hygge Card

内容卡与图块。白 60% 填充、2px 圆角、1px 沙 30% 描边、内边距 40px，无阴影。标题 26px/300 炭灰，正文 14px/300 木色。hover 时描边升到 80%、底色微亮、标题转苔绿，全部在 700ms 内完成。hero 里的卡片就是。

Line Input

表单输入。透明底、仅底部 1px 沙 40% 描边、无左右边框、2px 圆角、padding 8px 0、14px/300 字。聚焦时底线转苔绿、宽度不变，不加外环。

Breathing Section

区块容器。区块之间 160px 间距，标题与内容之间 40px，内容最大行宽 34em。区块间只用 1px 沙 30% 的分隔线，或干脆靠留白分隔。禁止把两个高对比元素并排——本页每个 section 之间就是这样。

可为与不为

可为

  • 字重只用 200 与 300
  • 过渡 700ms ease-in-out
  • 圆角 2px，近乎直角
  • hover 只改边框与底色
  • 元素间距至少 40px
  • 饱和度全部压在 30% 以下

不为

  • 不要用高饱和鲜艳色
  • 不要用粗边框与强阴影
  • 不要密集排列元素
  • 不要用装饰字体或超大字号
  • 不要用弹跳或快速缩放
  • 不要给按下加强烈反馈

图像

自然光下的室内摄影：木质家具、亚麻织物、绿植、陶器。低饱和、暖调、大量留白。不使用高对比、冷光与装饰插画。
