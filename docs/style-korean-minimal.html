风格 99 · 浅色版面

韩式极简 KOREAN MINIMAL

暖白、粉彩、大圆角：克制但不冷，像一间光线很好的房间。

暖白底不用纯白低饱和粉彩圆角 16–24px永不全大写

韩式极简来自 K-beauty 与韩国建筑的双重影响：留白要大（内边距 32 到 64px），底色是暖白而不是纯白，主文字用石板蓝而不是黑，强调色全部是低饱和的粉彩（藕粉、鼠尾草绿、米沙）。圆角偏大，边框极细，阴影几乎不可见。

它有两条很容易被忽略的禁令——不许全大写、不许宽字距，因为这两者在这套语言里被视为强势。右边这张呼吸卡是真的：hover 时阴影缓缓扩散、卡片上浮 2px。

颜色

石板蓝比黑柔，长时间阅读不压迫，做主文字与标题；带一点米调的暖白是整套风格的地基，做页面画布；藕粉是第一强调，用于标签、情感语义与细节描边；鼠尾草绿是第二强调与成功状态，常以 10% 底出现；米沙做暖色区块与图片衬底，制造温度差；橄榄是最暗的一支粉彩，用于边框与次级标记。

阴影几乎不可见：0 2px 8px rgba(61,74,92,0.04)，hover 0 6px 20px rgba(61,74,92,0.07)。边框永远 1px 的 10%。

字体

组件

Soft Button

主行动按钮。石板蓝填充、暖白文字、16px 圆角、无描边、无阴影，15px/400、padding 14px 32px。hover 时填充提亮 6%；按下时填充压暗一档并轻微缩到 0.99。过渡 400ms ease-out，慢但不拖。

Breathing Card

内容卡与作品卡。白底、24px 圆角、1px 石板蓝 10% 描边、内边距 32px，阴影 0 2px 8px 石板蓝 4%。标题 26px/400，正文 14px/400 行高 1.75，色为石板蓝 70%。hover 时阴影扩到 20px、上浮 2px。hero 里的卡片就是。

Gentle Input

表单输入。白底、16px 圆角、1px 石板蓝 12% 描边、padding 12px 18px、15px 字。占位符石板蓝 35%。聚焦时描边转石板蓝 40% 并加 3px 的藕粉 15% 外环，不改变尺寸。

Pastel Chip

分类与筛选标记。999px 全圆角、12% 粉彩底（藕粉、鼠尾草绿或米沙）、无描边、13px/500、padding 6px 14px，文字用石板蓝而非彩色。选中态底升到 22%。

笔记

Photo Bed

图片容器。20px 圆角、衬底用米沙或藕粉 12%、内边距 0、overflow hidden。图片本身不加边框，允许 4:5 或 1:1 比例。hover 时图片放大 1.03，容器阴影加深。

可为与不为

可为

  • 暖白底，不用纯白
  • 主文字用石板蓝
  • 强调只用低饱和粉彩
  • 圆角 16 到 24px
  • 边框 1px 的 10%
  • 永不全大写、永不宽字距

不为

  • 不要用高饱和纯色
  • 不要用 2px 以上边框
  • 不要用全大写与宽字距
  • 不要用深色或黑色背景
  • 不要过度装饰与堆叠元素
  • 不要用霓虹或荧光色

图像

自然光下的静物与人像，色调偏暖，饱和度低。允许粉彩衬底。不使用高对比摄影、冷光与 UI 插画。
