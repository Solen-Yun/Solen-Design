风格 76 · 深色版面

科幻 HUD SCI-FI HUD

深空底上的一层发光数据：面板半透明，角标是 L 形，灯一直在脉冲。

L 形四角角标等宽大写 0.16em状态灯脉冲交互必发光

科幻 HUD 模拟星舰驾驶舱与战术指挥台的显示层。它的构成是固定的：深空底，面板以 85% 不透明叠上去并带 20px 发光边，四角用 L 形 2px 边框做框选标记，文字用等宽大写加宽字距，状态灯持续脉冲，进度条用渐变加一道扫描光。

它的关键不是装饰而是「系统活着」的感觉——所有交互都必须让某个部件发光或脉冲，普通阴影加深在这里不够用。

颜色

间距与版面

基础单位 4px，密度 compact。上限 1600px、容器内边距 16px，面板间距 8px，形成密集的仪表盘排布。允许面板以 1px 青线拼接成更大的显示区。四角常驻 L 形角标，页面边缘保留 16px 安全区。

组件

HUD Panel

主面板与数据块。深板岩 85% 填充、20px 模糊、4px 圆角、1px 主青 30% 描边、内边距 20px，外发光 0 0 20px 青 50%。四角各用两个伪元素画 L 形角标（2px 主青、长 16px）。hover 时描边升到 60%、外发光扩到 32px——这就是「系统激活」。hero 里的面板就是。

Glow Button

主行动按钮。透明底、2px 主青描边、2px 圆角、无填充，12px/700 全大写 0.16em、padding 8px 20px，文字亮青。静态时已有 0 0 12px 的发光。hover 时填充青 12%、发光扩到 24px；按下时发光收到 6px 并把填充升到 20%。过渡 120ms。

Status Light

状态指示灯。8px 圆点，正常绿、预警紫、告警橙。必须持续脉冲：0 到 100% 之间把外发光从 4px 扩到 12px 再收回，周期 2 秒，缓动用 ease-in-out。灯旁边永远配 11px 的等宽状态文字，不只靠颜色。

在线

Scan Bar

进度条与扫描指示。高 6px、2px 圆角，底槽为主青 15%。填充用主青到亮青的横向渐变，并在填充上叠一道 24px 宽的白色 40% 高光，以 3 秒周期从左扫到右。数值以等宽字体放在右侧，单位与数字分开。

Radar Ring

雷达与环形仪表。直径 160px 到 240px 的圆环，2px 主青 30% 描边，内部十字准线 1px 主青 20%，扫描扇区用 conic-gradient 从主青 40% 渐隐到透明，旋转一周 4 秒、线性。中心显示 18px 等宽读数。

可为与不为

可为

  • 面板半透明加深模糊加外发光
  • 四角必须有 L 形角标
  • 等宽大写，字距 0.08 到 0.16em
  • 状态灯持续脉冲
  • 交互必须让某处发光变化
  • 暖色只用于警告

不为

  • 不要用浅色或白色背景
  • 不要用暖色调（警告除外）
  • 不要用衬线字体
  • 不要用圆润可爱的语言
  • 不要用 8px 以上的圆角
  • 不要让状态灯静止

图像

以网格、雷达、波形与星图为图像语言，不用摄影。允许深空摄影作为面板底层并压到 20% 不透明度。不使用插画、人物与任何暖色图像。
