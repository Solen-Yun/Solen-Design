枯山水 ZEN GARDEN

白砂、苔石、耙纹：留白不是空的，是被梳理过的。

白砂底 + 苔绿1px 边框 30%留白 240px 起步过渡 1000ms

枯山水用白砂、苔藓与石头三种材料构成一个没有水的庭园：界面上就是沙白底、苔绿点缀、纤细到几乎看不见的边框（1px 的 30%），以及大量被「梳理过」的留白——留白在这里是核心结构而不是余量。它的时间感极慢：过渡 1000ms ease-in-out，因为耙纹与苔藓的变化以年为单位。

禁令是：不许明亮鲜艳的色彩、不许厚重边框与粗线条、不许快速动画与弹跳、不许密集排列。本页背景叠着 24px 间隔的耙纹。

三石一组

主石立，客石伏，从石斜倚。它们没有对齐任何网格。

颜色

带绿的深灰是庭园里唯一的重量，管文字与石头；沙白是白砂的颜色，所有内容铺在它上面；苔绿是唯一强调色，管 hover 态、选中与「生长」语义；砂砾色永远只以 1px 的 30% 出现，管边框与分隔；岩色管次级文字与元数据；池青是冷侧的一笔，暗示「水」，出现频率极低。

间距与版面

基础单位 8px，密度 airy。上限 960px、容器内边距 32px，区块间距 240px。构图像庭园：内容偏一侧、另一侧留白，元素不必对齐网格。禁止密集排列，一屏最多三个元素。上方的空白区块就是 Silence Gap——没有它，庭园只是几堆石头。

组件

Quiet Button

行动按钮。透明底、无描边（默认 border-color: transparent）、零圆角、衬线 15px、字距 0.28em、padding 12px 32px，文字为石色 70%。hover 时描边转苔绿 30%、文字升到 100%、背景加苔绿 5%、并加一层几乎看不见的苔绿光晕（0 0 20px 苔 5%）。过渡 1000ms ease-in-out。

Stone Card

内容卡与石组。沙色填充（与底同色，靠边框区分）、零圆角、1px 砂砾 30% 描边、内边距 40px，无阴影。hover 时描边升到 55%，其余完全不变。卡片之间可错位 16 到 48px，像石头不按网格摆放。hero 里的石组卡就是（它偏置在右）。

Raked Line

耙纹装饰。用 repeating-linear-gradient 画 24px 间隔的 1px 沙色 40% 或砂砾 25% 的平行线，覆盖在一个区块上（不透明度 50%），模拟砂纹。线必须是等距的同心弧或直线，绝不杂乱——本页背景即是。

Moss Cluster

苔与石的点缀。由两到三个不同尺寸的圆或不规则块组成（16 到 64px），苔绿或岩色，不透明度 60% 到 80%，紧挨着放在卡片角落或标题旁，像一组石头旁长了苔。单屏最多两处——hero 卡左上那两颗就是。

Silence Gap

留白区块。240px 到 320px 高的空区块，作为真实元素存在。枯山水的核心就是它——没有这块空白，庭园只是几堆石头。

可为与不为

可为

  • 沙白底，苔绿点缀
  • 边框 1px 且只有 30%
  • 留白到 240px，它是核心
  • 过渡 1000ms，元素不动
  • 行高 1.9、字距 0.28em
  • 用耙纹做装饰

不为

  • 不要用明亮鲜艳色彩
  • 不要用厚重边框与粗线条
  • 不要用快速动画与弹跳
  • 不要密集排列元素
  • 不要用阴影
  • 不要把耙纹画得杂乱
