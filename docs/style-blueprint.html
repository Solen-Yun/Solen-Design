工程蓝图 BLUEPRINT

蓝底白线：网格、坐标、标注、尺寸线，一张还没施工的图。

8px + 80px 双层网格全站等宽标注用橙色零圆角纯色填充

工程蓝图模仿技术制图：蓝图蓝底上铺 1px 的白色或浅蓝网格，所有线条与文字都是白色或浅蓝，标注和尺寸线用橙色高亮，字体必须是等宽以维持制图感。元素的边框都是 1px 半透明白，辅助线用虚线，卡片是半透明的同色蓝加轻微模糊（像描图纸叠在图上）。

它禁止暖色背景、禁止圆润柔和元素、禁止渐变填充——线条与色块必须纯色。

颜色

蓝图蓝是页面底，所有白线与网格铺在它上面；白是主线条与主要文字，制图的白线；浅蓝比白弱一档，管次级线条、网格与辅助文字；中蓝是链接与选中态，画面里最饱和的蓝；橙是唯一暖色，只用于标注、尺寸线与需要被指出的问题；修订紫管修订标记与版本注记，出现频率最低。

  • Blueprint Blue页面底。制图纸的蓝，所有白线与网格铺在它上面。
    #1e3a5f--color-blueprint-blue
  • White主线条与主要文字。制图的白线。
    #ffffff--color-white
  • Pale Blue次级线条、网格与辅助文字，比白色弱一档。
    #a0c4e8--color-pale-blue
  • Mid Blue链接与选中态，是画面里最饱和的蓝。
    #4a90d9--color-mid-blue
  • Callout Orange唯一暖色，只用于标注、尺寸线与需要被指出的问题。
    #ff6b35--color-callout-orange
  • Revision Violet修订标记与版本注记，出现频率最低。
    #b071e4--color-revision-violet

图纸是平的：none — the drawing is flat；唯一的焦点环是 0 0 0 1px rgba(255,255,255,0.30)。绝不出现渐变填充。

基础单位 4px，密度 comfortable。上限 1280px、容器内边距 16px，图块间距 12px，形成图纸式的密集排布。允许图块以 1px 白线拼接成大图。所有尺寸取 4 的倍数，与网格对齐。

组件

Grid Bed

网格底（核心结构）。两层 repeating-linear-gradient 叠出 8px 小格与 80px 大格的白色网格：小格 1px 白 5%，大格 1px 白 10%。全页固定覆盖，pointer-events: none。它让整页读起来像一张图纸——本页背景就是。

Drafting Card

内容卡与图块。蓝图蓝 60% 填充、12px 模糊、零圆角、1px 白 30% 描边、内边距 20px。左上角放 12px 等宽全大写的图块编号（如 FIG. 01），右上角放尺寸标记。hover 时描边升到 60%。hero 里那块就是。

Dimension Line

尺寸线与标注。一条 1px 白 50% 的直线，两端各一个 4px 的短垂线作为端点标记，中间放 10px 等宽标注文字（如 2400）。关键标注用橙色 #ff6b35。用于说明间距与尺寸——hero 卡里那条就是。

Draft Button

行动按钮。透明底、1px 白 40% 描边、零圆角、11px 等宽全大写 0.16em、padding 10px 20px。hover 时填充白 12%、描边转白、文字保持白；按下时填充升到 20%。过渡 120ms linear。

Auxiliary Rule

辅助虚线。1px 虚线（dash 4px、gap 4px），颜色白 25% 或浅蓝 40%，用于引出标注、连接图块与说明。它绝不用于装饰，只用于表示「这条线与那个对象有关」。

可为与不为

可为

  • 蓝底白线，铺 8px 与 80px 双层网格
  • 全站等宽字体
  • 标注用橙色高亮
  • 辅助线用虚线
  • 零圆角、纯色填充
  • 图块带编号与尺寸标记

不为

  • 不要用暖色背景
  • 不要用圆润柔和元素
  • 不要用渐变填充
  • 不要用彩色摄影
  • 不要用衬线或无衬线字体
  • 不要让辅助线变成装饰

图像

技术插图：剖面图、平面图、爆炸图、流程图与结构示意，全部白线绘制。允许把照片处理成蓝底白线的线稿。不使用彩色摄影、柔和插画与装饰图形。
