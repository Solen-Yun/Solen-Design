风格 94 · 浅色版面

构成主义 CONSTRUCTIVISM

红与黑切进纸里：一切都在斜着喊。

严格三色只有 900 字重4px 黑边硬阴影角度只用三档

构成主义来自苏联宣传海报：只用红（#cc0000）、黑（#1a1a1a）与泛黄纸（#f2e8d5）三色，色块以对角线切入画面，元素整体旋转 -6 到 3 度并斜切，字是超粗全大写，边框 4px 黑，阴影是 4px 的硬偏移模拟版画。

它的纪律是「三色、直角、硬边」——禁止圆角、禁止渐变、禁止任何超出这三色的颜色。混乱是表面的，构成是精确的。

ПЛАКАТ № 4

БУДУЩЕЕ

斜切的色块切进纸里，标题压在最上层。

配色方案

  • Poster Red#cc0000
  • Ink#1a1a1a
  • Aged Paper#f2e8d5
  • Gold#d4a843
  • Ochre#8b4513

颜色

海报红是主色，给色块、强调与需要立刻被看到的一切；墨色管文字、4px 边框与硬阴影，结构与冲击都靠它；泛黄的旧纸色做页面底，像 1920 年代的印刷纸；金是唯一允许的第三色，只作小面积高亮；赭石是压在红色上的文字色，避免红上红。

  • Aged Paper页面底。泛黄，像 1920 年代的印刷纸。
    #f2e8d5--color-aged-paper
  • Poster Red主色：色块、强调与需要立刻被看到的一切。
    #cc0000--color-poster-red
  • Ink文字、4px 边框与硬阴影。结构与冲击都靠它。
    #1a1a1a--color-ink
  • Gold唯一允许的第三色，只作小面积高亮。
    #d4a843--color-gold
  • Ochre压在红色上的文字色，避免红上红。
    #8b4513--color-ochre

硬偏移只有墨：4px 4px 0 #1a1a1a，hover 扩到 8px 8px 0，按下归零。全页只用红、黑、旧纸三色。

字体

只有 900 一个字重，全大写。标题 80 到 112px、行高 0.88，字块本身是一块斜切的版面。

间距与版面

基础单位 8px，密度 compact。上限 1200px，允许元素溢出容器与页面边缘。整页以对角线为主要构图手段，区块之间用 8 到 16px 粗条分隔。角度只用三档：-6、0、+3 度，混用更多角度会让版面失序。

组件

Diagonal Plane

斜切色块（核心组件）。一个填红或黑的矩形，用 transform: rotate(-6deg) skewX(3deg) 倾斜，或直接用 clip-path 切出斜边。零圆角，可选 4px 黑色描边。它不被容器裁切，允许溢出页面边缘，产生「切进纸里」的感觉。hero 左上那块红的就是。

Agitprop Headline

标语式标题。80 到 112px、900 字重、全大写、行高 0.88、字距 -0.03em，本身旋转 -3 度。允许分三行堆叠并与色块重叠，但文字必须在最上层。部分词可反白（在红色块上）或转红。

Block Button

行动按钮。红填充、旧纸色文字、4px 黑边、零圆角、16px/900 全大写、padding 12px 28px，硬阴影 4px 4px 0 墨。hover 时填充转黑、文字转旧纸、阴影扩到 8px；按下时位移 4px 4px 且阴影归零。过渡 100ms linear。

Bar Divider

粗横条分隔。高 8px 或 16px 的纯黑或纯红横条，横跨全宽，可倾斜 -2 度。它替代留白来分隔区块——构成主义不用空，用块。

Number Stamp

大号数字标记。80 到 160px 的 900 字重数字，颜色红或黑，可半透明（30%）压在色块上作为背景标记。用于章节编号与数据强调，一屏最多两处。

可为与不为

可为

  • 严格三色：红、黑、旧纸
  • 对角线与斜切色块
  • 只有 900 一个字重，全大写
  • 4px 黑边加 4px 硬阴影
  • 角度只用 -6、0、+3 三档
  • 用粗条分隔区块而不是留白

不为

  • 不要用柔和圆角
  • 不要用渐变
  • 不要超出三色体系
  • 不要用超过三档角度
  • 不要用细边框
  • 不要用柔和插画

图像

构成主义海报式图形：几何色块、粗黑剪影、工厂与齿轮、工人剪影、放射线。允许把照片处理成红黑双色调并加粗黑描边。不使用彩色摄影、柔和插画与渐变。
