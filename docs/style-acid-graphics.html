风格 48 · 深色版面

酸性平面设计

荧光绿压在纯黑上，字被拉扯变形，一切都在高频振动。

平面荧光色skew 扭曲字100ms 内反馈硬边偏移阴影

酸性平面设计来自锐舞文化与地下俱乐部视觉：纯黑底上铺荧光绿、荧光黄、紫与粉，颜色必须是纯平面的荧光色而不是渐变，字体用等宽并做 skew 与 rotate 的扭曲，阴影是硬边偏移。

它的动效语言反抛光——禁止 ease-in-out 与缓慢微交互，一切反馈都在 100ms 内完成，像设备在跳帧。禁令还有：不许柔和粉彩与低饱和、不许圆角、不许衬线、不许白色或浅色背景。下面的按钮是真的——移上去，颜色是硬切的。

SIGNAL // 0X1F

跳帧、扭曲、高频率。没有柔光。

颜色

荧光绿在纯黑上几乎在振动，是整套风格的标志；荧光黄与绿形成最近的频率冲突；电紫拉开冷暖；热粉管情绪化强调与故障感；电青频率最低，管数据与刻度。颜色必须平面，渐变即违规。

  • Hot Pink第四荧光色，用于情绪化强调与故障感。
    #ff6ec7--color-hot-pink
  • Electric Cyan第五荧光色，出现频率最低，用于数据与刻度。

硬边偏移阴影：6px 6px 0 #39ff14 与 6px 6px 0 #a020f0；按下归零。没有模糊，没有渐变。

组件

Skewed Headline

扭曲标题（核心组件）。等宽 700、行高 0.95、字距 -0.02em，整块 skewX(-8deg) 并 rotate(-2deg)，颜色用荧光绿或黄；允许与色块重叠、允许超出容器边缘。hover 时 skew 量硬切到 -14 度（抖一下），transition-none 或 80ms linear。本页 H1 就是它——移上去抖一下。

Acid Button + Acid Card

行动按钮：荧光绿填充、黑字、零圆角、2px 黑描边、14px/700、字距 0.08em、padding 10px 24px，硬阴影 6px 6px 0 电紫；hover 时填充硬切到荧光黄、阴影换色；按下时位移 6px 6px 且阴影归零。内容卡：纯黑 90% 填充、零圆角、2px 荧光绿描边、内边距 20px，硬阴影 6px 6px 0 电紫；标题 26px/700 荧光绿，正文白 80%；hover 时描边硬切到荧光黄、阴影转绿。上方演示卡即后者。

Liquid Form

液态流动形状。用 SVG 的 feTurbulence 加 feDisplacementMap（baseFrequency 0.015、scale 30）让一个纯色块或粗描边图形的边缘流动；填充用一支荧光色，每秒或每帧位移噪声种子形成蠕动；只作用于装饰块，绝不作用于文字。

Tick Rail

刻度与数据条。高 32px 的一段，用 repeating-linear-gradient 每 8px 画一条 2px 的荧光青或荧光绿竖线，模拟音频电平表；数值用等宽荧光色叠加在右侧；用于装饰与数据可视化，单屏不超过三处——演示卡里那排就是。

可为与不为

可为

  • 纯黑底配荧光色
  • 颜色必须是平面荧光，不用渐变
  • 用 skew 与 rotate 扭曲字
  • 硬边偏移阴影
  • 反馈在 100ms 内完成
  • 等宽字体

不为

  • 不要用柔和粉彩与低饱和色
  • 不要用圆角
  • 不要用衬线字体
  • 不要用白色或浅色背景
  • 不要用渐变
  • 不要用 ease-in-out 与缓慢微交互

图像

锐舞传单式图像：扭曲的金属质感图形、液态色块、故障条纹、ASCII 与栅格化照片。允许把照片压成 8 色荧光调色板。不使用精致摄影、柔和插画与低饱和图像。
