米色纸面上的一篇文档，界面退到看不见，只剩内容。

米色纸面hover 只变底色拖拽手柄708px 窄栏

文档工作台风是为长时间阅读与写作服务的界面。它用一层米色纸面代替纯白，把文字压到柔和的墨黑。

交互的信噪比被刻意压到最低：hover 只让背景变暗一点，150ms 内完成，没有位移、没有缩放、没有阴影跳变。

标志性的细节是拖拽手柄：hover 时从透明变为可见，提示「这块可以移动」。

i

允许一种柔和强调底色，但同一页面只用一种。

配色方案

  • Ink#37352f
  • Paper#f7f6f3
  • Hover Grey#efedea
  • Hairline#e9e7e4
  • Link Blue#2eaadc
  • Marker Red#eb5757

颜色

墨色偏暖，纯黑会让纸面显得脏；米色纸面既是画布也是 hover 前后的基准色；hover 灰只比纸面暗一点，做到「能感觉到但不打扰」；发丝线永远 1px、永远这么浅；链接蓝是整套系统里唯一明确跳出来的颜色，红出现即表示内容有风险。

  • Ink正文、标题与图标。这套风格的墨色偏暖，纯黑会让纸面显得脏。
    #37352f--color-ink
  • Paper页面画布。整站默认背景，也是 hover 前后的基准色。
    #f7f6f3--color-paper
  • Hover Greyhover 与选中底色。只比纸面暗一点，做到「能感觉到但不打扰」。
    #efedea--color-hover-grey
  • Hairline表格线、分隔线与输入框描边。永远 1px，永远这么浅。
    #e9e7e4--color-hairline
  • Link Blue链接与可点击引用。是整套系统里唯一明确跳出来的颜色。
    #2eaadc--color-link-blue
  • Marker Red删除与错误提示。出现即表示内容有风险。
    #eb5757--color-marker-red

除弹层外一律无阴影；弹层也只有一层 0 8px 24px rgba(15,15,15,0.12)。纸面上没有任何漂浮感。

字体

全站唯一字体，系统栈优先——文档工具最重要的指标是渲染稳定。层级由字号（12 到 32px）与 400/500/600 三档字重承担，正文字号 14 到 16px、行高 1.6。

间距与版面

组件

Block Row

文档块、页面树与设置项。透明底、无边框、4px 圆角、padding 4px 8px、行高 1.6、14px 字；hover 时背景变 #efedea，150ms 颜色过渡，不做任何位移；左侧拖拽手柄宽 16px，默认透明，hover 与聚焦时可见。上方那页文档的每一行都是它。

悬停任意一行：底色微暗，手柄现身。

Ghost Button

工具栏按钮与次级行动。透明底、无描边、4px 圆角、13px/500 字、padding 4px 8px、图标 16px 线性、与文字间距 6px；hover 背景 #efedea，按下 #e3e1db。禁止上浮与缩放，只变颜色，150ms。

Inline Input

行内编辑与搜索。透明底、无描边、padding 4px 8px、正文同字号；聚焦时只加一层 1px #e9e7e4 的底边线，不加外环、不改背景；占位符用 60% 墨色。

Callout Block

提示、引用与说明块。浅灰底 #efedea、4px 圆角、padding 12px 16px、左侧留 8px 图标位、文字 14px/1.6；允许一种柔和强调底色（蓝、黄、红任选其一），但同一页面只用一种。上方文档末尾的提示块即此组件。

可为与不为

可为

  • 用米纸 #f7f6f3 做画布，正文墨色 #37352f
  • hover 只变背景色，150ms，无位移无缩放
  • 拖拽手柄 hover 时从透明变可见
  • 分隔线一律 1px #e9e7e4
  • 正文宽度 708px 上限，行长不超过 80 字符
  • 圆角不超过 4px，除胶囊标签外

不为

  • 不要用渐变背景
  • 不要用重阴影，除弹层外一律无阴影
  • 不要用任何 translate 或 scale 动画
  • 不要用 hover 边框或阴影跳变
  • 不要用 8px 以上的圆角
  • 不要给按钮加上浮效果，文档没有漂浮感

图像

几乎不用装饰性图像。允许内容截图、图表与嵌入的媒体块，且必须与文档同宽、直角或 4px 圆角。不使用背景图、插画与图标墙，它们会把纸面变成海报。
