颜色

深青是整套系统里唯一的高对比色，承担主行动、标题、进度条与选中态；正文用比它更深的墨青，长段落才读得动。雾绿白做页面与卡片底。剩下四支全是低饱和柔色，只用于分类与状态，不承担正文——薄荷代表生活与完成，杏色代表提醒与截止，藕粉代表个人，淡蓝代表信息与日程。

卡片不靠阴影浮起：none — 1px border carries it。只有按钮与底部弹层带阴影。

字体

全站一种字体。字级偏移动端：正文 13 到 17px，标题 22 到 28px，标签 12px。字重不超过 600——再重就会压过柔色。

组件

Primary Action

主行动按钮（例：完成任务）。深青填充、白字、16px 圆角、无描边，字级 17px、字重 600、padding 12px 20px，阴影 0 6px 16px 主色 20%。hover 时填充加深到 #234b52；按下缩放 0.98。过渡只改颜色，200ms。

Task Card

任务卡与进度块。雾绿白填充、1px 主色 15% 描边、16px 圆角、内边距 20px，无阴影。左上 40px 薄荷图标块（12px 圆角），标题 17px/600 墨青，说明 12px 灰。底部进度条高 8px、全圆角、底槽 #d9e8e3、填充深青。

Soft Input

添加任务与搜索。白底、1px 主色 20% 描边、16px 圆角、padding 12px 16px、15px 字。占位符用灰 60%。聚焦时加 4px 的薄荷 50% 外环，不改变描边宽度。

Category Chip

分类与筛选标记。全圆角、padding 6px 12px、12px/500。四个分类各用一支柔色作 20% 底配主色文字：薄荷=生活、杏=截止、藕粉=个人、淡蓝=日程。选中态底色升到 100% 并保持深色文字。

Bottom Sheet

移动端底部弹层。白底、顶部 20px 圆角、顶部 1px 主色 10% 描边、阴影 0 -12px 40px 墨青 12%。顶部中央放一个 36px × 4px 的灰色抓手。内边距 20px，内容区可滚动，最大高度 88vh。

可为与不为

可为

  • 主色深青，只用它承担行动与正文
  • 圆角 12 到 16px
  • 柔色只用于分类与状态
  • 字重不超过 600
  • 动效 200ms，只改颜色
  • 移动端单栏，上限 480px

不为

  • 不要用弹跳或夸张动效
  • 不要让柔色承担正文
  • 不要用超过 20px 的圆角
  • 不要用重阴影
  • 不要在同一屏用超过三种分类色
  • 不要在移动端上多栏

图像

以图标与少量插画为主。允许柔色几何图形作为分类标识。不使用摄影与背景图，移动工具里图像会挤掉信息。
