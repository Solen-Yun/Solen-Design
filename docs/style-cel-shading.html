风格 72 · 浅色版面

赛璐璐动画风 CEL SHADING

粗墨线、平涂、硬阴影：手绘动画的每一帧都只有两种颜色。

3px 墨线描边平涂不渐变按下挤压变形过渡 75ms linear

赛璐璐来自传统动画的赛璐璐片上色法：每个色块都是平的，阴影只有一层并且是硬的，边缘用 3px 墨线勾出来。落到界面上有一条独特的时间规则——过渡只有 75ms，因为动画是抽帧的，不是流体缓动的；缓动必须用 linear 或 ease-in，绝不使用 ease-in-out。

按下时元素做挤压变形（横向 110%、纵向 90%）并下沉，这是卡通物理而不是材料物理。试试下面这颗按钮：hover 有高光掠过，按下会被「压扁」。

ACTION!

3px 墨线 + 4px 硬阴影，卡通里的一帧。

颜色

墨线是这套风格的骨架——所有 3px 描边、硬阴影与文字都是它；赛璐璐白略带暖调，像动画用的赛璐璐片；赤色管主行动与高能状态，平涂、不渐变；水蓝是画面里的冷色块，管信息与次级行动；草绿管成功与生命值，卡通语义里的正向；日落黄管高亮与能量，用于强调条与徽标。

间距与版面

基础单位 8px，密度 comfortable。上限 1120px、容器内边距 24px，区块间距 80px。元素可以轻微重叠与错位，像分镜排列。所有区块用 3px 墨线分隔，留白比其它硬边风格略少，因为线条本身承担了分隔。

组件

Cel Button

主行动按钮。赤色平涂、白字、3px 墨线描边、零圆角、4px 硬阴影，14px/900 全大写、padding 12px 24px。hover 时填充提亮到 #ff4d5a、上浮 4px、阴影扩到 6px，并有一道斜切白色 30% 的高光从左掠到右（300ms linear）。按下时横向缩放 1.1、纵向 0.9、位移 4px 8px、阴影归零——这是挤压变形，不是位移。过渡 75ms linear。

Cel Card

内容卡与分镜卡。纸白平涂、3px 墨线描边、零圆角、内边距 24px、4px 硬阴影。标题 28px/900 全大写，正文 14px/700，字色 60% 墨。hover 时上浮并左移各 2px、阴影扩到 6px。过渡 75ms linear。hero 里的卡片就是。

Ink Divider

分区与描边线。3px 纯墨线，横跨内容宽或全宽。用于分隔区块而不是留白——这套风格更依赖线条分区。允许 8px 的短粗线作为强调标记。

Impact Badge

状态与能量徽标。橙黄或草绿平涂、3px 墨线、999px 全圆角、14px/900 全大写、padding 4px 12px，可带 3px 硬阴影。用于「新」「完成」「关键」等一次性标记。

NEW!

Speed Lines

速度线与动势装饰。3 到 5 条 3px 墨线，长度 24px 到 64px 不等，以 15 度斜向排列在元素一侧，间距 8px。用于暗示运动方向，只出现在交互元素上，静态区块不加——hero 卡右侧那组就是。

可为与不为

可为

  • 3px 墨线包住每个元素
  • 平涂填充，不用渐变
  • 阴影只有一层且无模糊
  • 过渡 75ms，缓动 linear 或 ease-in
  • 按下做挤压变形（110%/90%）
  • 零圆角，徽标除外

不为

  • 不要用渐变色
  • 不要用细边框
  • 不要用低饱和或灰色调
  • 不要用 300ms 以上的丝滑过渡
  • 不要用 ease-in-out
  • 不要用模糊阴影

图像

平涂插画与赛璐璐上色：两种明度、硬边阴影、3px 描边。允许角色与道具插画。不使用摄影、渐变与柔和阴影。
