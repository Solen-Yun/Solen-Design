风格 05 · 浅色版面

企业简洁风 CORPORATE CLEAN

克制的商务蓝，一切为可读性与信任感让路。

商务蓝浅描边微交互信任感克制动效

企业简洁风是一套被大量 B2B 产品验证过的默认解：浅灰蓝底、一个主蓝、白色卡片配极浅描边、12px 圆角。它不追求记忆点，追求的是零风险——任何人打开都不会觉得奇怪。

层次靠 1px 边框与两级阴影（sm 与 md）建立，交互只做两件事：hover 时元素上浮半像素级并加深阴影，active 时缩小 2% 给出按压反馈。焦点环必须带 offset，这是无障碍底线。所有动效不超过 200ms，超过就开始显得轻浮。右边是一张真的会动的功能卡。

模块化的一切

白卡、细描边与两级阴影，让每一块功能都能独立成立。

颜色

只用一种蓝——主色与链接色同源，避免同一页面出现两种蓝。Action Blue 只做焦点环、选中态与数据高亮，不用于大面积填充；Confirm Green 仅在状态语义明确时出现。

字体

全站唯一字体，层级靠 400/500/600/700 四档字重与字号建立；正文 16px 起、行高 1.65、行长控制在 70 字符内。

组件

Primary Button

主行动按钮。企业蓝填充、白字、8px 圆角、无描边；字级 14px、字重 500、padding 8px 16px，rest 阴影 0 1px 2px。hover 换更深的蓝并上浮 2px、阴影升到 0 4px 12px；active 缩放 0.98 且去掉上浮，过渡 150ms ease-out。页头与下面的样本都是它。

Feature Card

功能卡与内容容器。白底、1px #e5e7eb 描边、12px 圆角、1px 高度阴影、内边距 24px。hover 时阴影升到 0 4px 12px 并上浮 2px；图标容器 40px 见方、浅蓝底，hover 填充企业蓝、图标转白、放大 1.1。首屏右侧即此组件。

Form Input

表单输入与搜索。白底、1px #d1d5db 描边、8px 圆角、16px 字级、padding 8px 12px；标签 14px/500 深灰，帮助文字 12px 石板灰。聚焦时描边转企业蓝并加 2px 焦点环（2px offset），不改变盒子尺寸。

Top Navigation

全站顶部导航。高 64px，白底、底部 1px 浅灰描边、无阴影；字标 18px/600 深灰，链接 14px/500 石板灰、间距 24px、hover 转深灰并上浮 1px，右侧一个主按钮。

Status Badge

状态与分类标签。全圆角、12px 字号、500 字重、padding 4px 10px。默认浅蓝底配企业蓝字；成功用浅绿底配确认绿；提示用 1px 描边而不用填充。永远带一枚小圆点，不只靠颜色传达状态。

IN PROGRESS ACTIVE BETA

可为与不为

可为

  • 只用一种蓝，主色与链接色同源
  • 卡片用 1px 描边加一级浅阴影，不要用重阴影
  • 焦点态必须带 2px offset 的焦点环
  • hover 上浮不超过 2px，active 缩放不小于 0.98
  • 动效不超过 200ms，用 ease-out
  • 正文 16px 起，行高 1.65，行长控制在 70 字符内

不为

  • 不要在同一页面出现两种主色蓝
  • 不要用渐变按钮
  • 不要用直角或大于 16px 的圆角
  • 不要用重阴影（shadow-2xl 一类）
  • 不要省略 focus 环的 offset
  • 不要让按钮缺少 active 反馈，否则按钮像装饰

图像

产品截图与界面局部为主，白底或浅灰底、干净的设备外框、无人物特写。允许灰度图标与线稿示意。不使用抽象渐变、夸张插画或高饱和摄影。
