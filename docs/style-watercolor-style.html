风格 33 · 浅色版面

水彩画风 WATERCOLOR STYLE

纸上的三层晕染：颜色从不描边，只在边缘化开。

没有硬边晕染圆斑衬线斜体标题纸白底

水彩画风的关键是「没有硬边」。所有色块都是半径极大的模糊圆，彼此叠压形成晕染；卡片的渐变从对角淡入淡出，边缘再叠一层 1px 的极淡描边暗示纸张。底色是暖纸白（#faf8f5），主色是偏灰的蓝（#4a6fa5）。

标题用衬线斜体，正文行高拉到 1.7。它不使用投影来分层，而是靠「颜色在纸上扩散的面积」——hover 时卡片内部的色斑放大并加深，像水在湿纸上继续晕开。右边这张卡是真的，移上去看水继续化开。

颜色在纸上化开。

三层晕染叠出中间色，从不描边。

配色方案

  • Watercolor Blue#4a6fa5
  • Paper White#faf8f5
  • Peach#e8a87c
  • Water Teal#85cdca
  • Rose#c38d94
  • Ochre#d4a373

颜色

偏灰的蓝像颜料被水稀释过一次，承担主行动、标题与文字；暖纸白模拟水彩纸的底色；蜜桃是暖色晕染的第一层，出现在标题区与卡片一角；水青是冷色晕染，与蜜桃叠压成中间色；玫瑰透明度最低，只用来加深中心；赭石多用于纸边的细线。

阴影只有柔光两档：卡片 0 10px 30px rgba(74,111,165,0.10)、hover 0 12px 40px rgba(74,111,165,0.18)——分层主要靠晕染面积。

字体

标题、引文与导航字标用 Cormorant Garamond，多用斜体——衬线斜体是水彩最自然的文字表情；正文与说明用 Inter 保持中性，避免与衬线标题抢戏。

组件

Wash Button

主行动按钮。蓝到水青的横向渐变（80% 不透明）、白字、999px 全圆角、无描边；字级 17px、衬线、padding 16px 32px，阴影 0 10px 30px 蓝 20%。hover 时渐变升到 90%、阴影扩到 40px、上浮 2px；按下缩放 0.98 并让阴影收回到 10px。过渡 500ms ease-in-out。

Wash Card

作品卡与内容卡。蜜桃 20% 到白到水青 20% 的三段对角渐变、24px 圆角、1px 蓝 10% 描边、内边距 32px、10px 模糊，内部右上角放一块 96px 的水青 30% 模糊圆。hover 时两端渐变升到 30%、圆斑放大 1.5 倍并加深到 40%、阴影扩到 40px。过渡 500ms，圆斑 700ms。上方演示卡即此组件。

Wash Input

表单与写作输入。白 60% 填充、1px 蓝 20% 描边、16px 圆角、padding 16px 20px、15px 衬线；占位符用蓝 40%。聚焦时描边升到 40%、填充升到 80%、加一层 0 10px 30px 蓝 10% 的柔光。过渡 300ms。

Color Wash

背景晕染层。二到三块直径 256px 到 384px 的圆，填充蜜桃、水青或玫瑰的 20% 到 30%，模糊 64px，随意分布在页面两角与中心，彼此可叠压；不使用动画；整页不超过三块。本页两角的两块就是它。

可为与不为

可为

  • 所有色块都是大半径模糊圆，没有硬边
  • 标题用衬线斜体
  • hover 让色斑放大与加深
  • 纸白底，不用冷白
  • 每页晕染圆不超过三块
  • 动效 500ms，色斑 700ms

不为

  • 不要用硬边描边或锐利几何
  • 不要用高饱和原色
  • 不要用投影作为主要分层手段
  • 不要在正文用衬线加粗
  • 不要让晕染遮住文字
  • 不要用三块以上的晕染叠在一起

图像

水彩原作、晕染质感、纸质纹理。允许在照片上叠一层纸纹并降低饱和度。不使用锐利摄影、硬边图形、3D 渲染与霓虹色。
