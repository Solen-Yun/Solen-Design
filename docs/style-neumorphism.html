风格 04 · 浅色版面

新拟物派 NEUMORPHISM

元素和背景同色，只有两个方向的阴影在说明它凸起还是凹陷。

双向阴影同色基底固定光源凹凸物理柔和圆角

新拟物派用一束固定的光塑造所有界面：光源在左上，所以每个元素都有左上白色高光与右下冷灰暗影。元素本身与背景同色，一旦换了深浅就立刻失去材质感。

凸起用外阴影对，凹陷用 inset 阴影对，按下就是把凸起翻成凹陷。这套系统里没有边框、没有实色填充、没有强烈对比，全部层次由两段模糊值承担，字号与字重必须比常规更保守，否则内容会压过材质。右边是一块可交互的材质面板：按钮、开关和输入框都是真的。

字体

全站唯一字体，字重克制——材质已经是主角，字体再加戏会显得廉价。深色文字只出现在内容层，界面层用中灰。

组件

Raised Button

主行动按钮。与背景同色填充、无描边、16px 圆角、双阴影凸起。字级 14px、字重 500、深灰字。hover 时两段模糊减半到 4px，模拟手指靠近遮光；按下时整对翻成 inset，位移为 0。过渡 200ms ease-out。首屏面板里那枚即此组件。

Recessed Input

输入框与搜索。与背景同色填充、inset 双阴影、16px 圆角、padding 12px 16px，占位符用中灰。聚焦时保持凹陷，只把阴影色相转向紫罗兰 30% 透明度，不移动元素。

Soft Card

内容卡片与统计块。凸起双阴影、24px 圆角、内边距 32px、无描边无换色。卡片之间至少留 32px，否则两套阴影会互相污染。hover 时阴影模糊减半并整体上浮 2px，表示可点击。首屏面板即此组件。

Soft Toggle

开关与分段控件。轨道凹陷（inset 对、16px 圆角、高 32px），旋钮凸起（外阴影对、直径 24px、与轨道同色）。开启时旋钮填紫罗兰，关闭时与基底同色。切换过渡 200ms，只动阴影与位置，不用缩放。首屏面板里有一枚可点的。

可为与不为

可为

  • 所有元素与背景同色，深浅差异只由阴影承担
  • 固定单一光源：左上高光、右下暗影，全站一致
  • 凸起用外阴影对，凹陷用 inset 对，不混用
  • 圆角 16px 起，卡片用 24px
  • hover 时减小阴影模糊，模拟手靠近遮光
  • 字重不超过 600，让材质当主角

不为

  • 不要用纯黑阴影，会立刻变成脏灰
  • 不要在深色背景上做新拟物，没有可用光
  • 不要加实色边框，材质不再连续
  • 不要让元素换底色来区分层级
  • 不要用锐利描边图标或高对比插画
  • 不要把两套阴影的元素放得比阴影模糊半径更近

图像

不用摄影。材质本身是内容：可用同色系的柔和图形、极浅的线性图标，或与基底同色的产品渲染。任何强对比、深色背景、纯白图标都会破坏统一光源的假设。
