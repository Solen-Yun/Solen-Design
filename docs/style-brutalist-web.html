风格 85 · 浅色版面

网页粗野主义 BRUTALIST WEB

回到 1993 年的 HTML：系统字体、蓝下划线链接、纯白底、零装饰。

纯白底蓝下划线链接1px 边框分区零圆角零阴影

网页粗野主义不是「难看」，而是拒绝被设计：纯白底（#ffffff）、系统字体栈（无衬线正文配 Times New Roman 标题）、蓝色 #0000ff 下划线链接作为唯一交互语言、1px 实线边框做结构、零圆角、零阴影、零渐变与背景图、间距压到最小。它的价值判断是内容优先于形式——任何为了好看而增加的东西都被视为负担。

这也是它与新野兽派的区别：新野兽派靠粗边与硬阴影造风格，网页粗野主义连风格都不要。

配色方案

  • Black#000000
  • White#ffffff
  • Link Blue#0000ff
  • Red#ff0000
  • Green#008000
  • Magenta#d60099

颜色

纯黑做正文与标题，不做灰度修饰；所有区块的底都是纯白，绝不用米色或灰白；链接蓝是唯一的主交互色，未访问用它，访问后转 #551a8b；红管警告与错误，来自浏览器默认语义；绿管成功与「OK」，同样来自浏览器默认；品红是已访问链接的变体与特殊标记，出现频率极低。

  • White所有区块的底。纯白，绝不用米色或灰白。
    #ffffff--color-white
  • Black正文与标题。纯黑，不做灰度修饰。
    #000000--color-black
  • Link Blue唯一的主交互色。未访问链接用它，访问后转 #551a8b。
    #0000ff--color-link-blue
  • Red警告与错误，浏览器默认语义。
    #ff0000--color-red
  • Green成功与「OK」，同样来自浏览器默认。
    #008000--color-green
  • Magenta已访问链接的变体与特殊标记，出现频率极低。
    #d60099--color-magenta

层次为零：none — shadows are forbidden。没有第二层表面——分区靠 1px 边框。

字体

标题用衬线 Times New Roman（浏览器默认），不加字距、不做字重处理，因为 1993 年没有这些；正文用系统无衬线栈或等宽，默认、无修饰、随系统变化。

间距与版面

基础单位 4px，密度 compact。上限 720px、容器内边距 16px，区块间距 24px。单栏、紧排、不用网格系统。元素之间用 1px 边框分隔而不是留白。整页读起来应该像一个排版良好的纯文本文件。

组件

Bare Link

链接（唯一交互语言）。内联文本、色 #0000ff、带下划线（text-decoration: underline）、无背景无边框无过渡。hover 时保持同样样式（浏览器默认行为即可），不加上划线、不改透明、不做位移。已访问转 #551a8b。

这只是一个链接。

Bare Button

提交按钮。浏览器默认按钮外观（或 1px 实线黑边加白底）、零圆角、14px 系统字体、padding 4px 12px。不加悬停动画、不加阴影。它的「朴素」是刻意的。

Rule Block

1px 边框分区。用 1px 实线黑边（#000000 或 50% 灰）画出区块边界，内边距 12px。整页可以有多层嵌套边框，像早期 HTML 的 table 布局。绝不用阴影或底色分区。hero 里的框就是。

Default List

列表与表格。使用浏览器默认的 ul / ol 缩进与项目符号，表格用 1px 实线边框（border-collapse: collapse）、单元格 padding 4px 8px、无斑马纹无圆角。

  • 内容优先于形式
  • 链接是唯一交互
  • 边框承担结构

Dense Text Column

正文栏。最大宽度 720px、行高 1.5（不放大）、段间距 12px、段首不缩进。左对齐，不使用首字下沉或任何排版装饰。密度接近纯文本文件。

可为与不为

可为

  • 纯白底，不用米色或灰白
  • 系统字体栈，不做字体设计
  • 蓝下划线链接作为主交互
  • 1px 实线边框分区
  • 零圆角、零阴影、零渐变
  • 间距压到最小

不为

  • 不要用任何圆角
  • 不要用投影或文字阴影
  • 不要用渐变或背景图
  • 不要给链接加过渡动画
  • 不要用装饰性字体
  • 不要为了好看而加元素

图像

几乎不用图像。允许未优化的原生图片（不做圆角、不加遮罩、不加滤镜），alt 文字必须完整。不使用装饰插画、全幅背景图与任何经过艺术处理的图像。
