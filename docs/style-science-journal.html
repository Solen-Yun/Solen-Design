一条窄衬线栏讲论证，边注放旁白，图表突破版心放证据。

注意力如何分配

一段长文的说服力取决于读者的注意力落在哪里。窄栏把行长压到可扫读的范围，让每一次换行都成为一个决策点。1

1边注在小屏折叠为浅灰内联块。

而图表可以突破版心，占据两倍宽度，把证据推到读者眼前。2

颜色

深灰蓝比纯黑更适合长文，做正文与标题；纯白无纹理做页面底，论文不需要气氛；学术蓝只给链接、上标引用与关键强调三处；图表橙管数据强调与图表主序列，绝不用于界面装饰；灰做图注、边注与元信息，永远是第三层级；浅灰块是小屏边注折叠块与代码块底。

层次靠发丝线与留白：none — hairlines and whitespace do the work，最高只允许 0 1px 2px rgba(31,41,51,0.05)。禁用任何渐变。

字体

正文与标题必须衬线 Source Serif，行高 1.75 是长文可读性的下限，不可压缩；Inter 仅用于 UI 控件标签与元信息，正文绝不使用无衬线。

组件

Reading Column

正文窄栏（核心结构）。max-width 42rem（672px）、左右各 24px 内边距、居中。正文 17px 衬线、行高 1.75、段间距 24px、段首不缩进。绝不允许正文全宽铺满——全宽只属于图表。

Sidenote

边注（旁白）。大屏（1280px 以上）绝对定位到正文右缘外侧 24px、宽 200px、12px 灰字、行高 1.5；小屏折叠为正文内的浅灰块（#f3f4f6）、4px 圆角、内边距 12px、12px 灰字。锚点用上标数字。

Evidence Figure

图表（突破版心）。max-width 64rem（1024px）、居中，比正文宽出一倍。图注 13px 灰、以「图 N：」开头，与图之间 12px。图表区域零圆角、无边框。这是唯一允许突破版心的元素——hero 里那张就是。

Booktabs Table

booktabs 风格表格。顶部 2px 墨色横线、表头下 1px 墨色横线、底部 2px 墨色横线，中间绝无竖线与斑马纹。单元格内边距 8px 12px、14px 衬线，数值列右对齐并用等宽数字。

Citation Sup

上标引用。正文后跟 12px 上标数字（学术蓝、不换行、与正文间距 2px），文末参考文献列按编号排列，每条 13px、含标题与出处。点击上标跳转到条目并高亮 2 秒。

可为与不为

可为

  • 正文窄栏 42rem、行高 1.75
  • 正文必须衬线，无衬线只给 UI
  • 边注在大屏浮到右缘、小屏折叠
  • 图表突破版心到 64rem
  • 表格用 booktabs，无竖线无斑马纹
  • 分割只用 1px hairline

不为

  • 不要用任何渐变
  • 不要用重阴影
  • 不要用大圆角
  • 不要让正文全宽铺满
  • 不要用多彩装饰与大色块
  • 不要给表格加竖线与斑马纹

图像

图表即图像：散点、折线、网络、注意力热图，必须带坐标轴与图注。允许作者照片。不使用装饰摄影、插画与背景图，气氛在这套语言里没有位置。

把这个效果带走

一份 Markdown 文档说明这套风格的窄栏、边注与图表突破规则。复制后可直接交给编程助手。


        
复现这套风格时，42rem 窄栏、64rem 图表与 booktabs 表格必须原样保留；正文铺满全宽或表格加竖线一出现即违规。
