风格 19 · 深色版面

桌面毛玻璃 DESKTOP VIBRANCY

三层深灰、系统级模糊、几乎没有装饰——像一台安静的桌面应用。

三层深灰80% 通透侧栏1px 细分隔线只动颜色

这套风格模仿桌面系统的原生材质：窗口是三层深浅不同的深灰（#1c1c1e 最深、#2c2c2e 中间、#3a3a3c 最浅），侧边栏用 80% 不透明的深灰配大半径 backdrop-blur 做出通透感，所有分隔线都是 1px 白色 8% 到 12%，绝不加粗。

标题用衬线体（Georgia）与正文的无衬线形成对话，这是它与普通暗色仪表盘的区别。动效只允许变颜色，200ms ease-out；任何位移或缩放都会让人意识到这是网页而不是系统。右边这扇窗口是真的——行可以悬停，按钮可以按。

颜色

窗口底与侧边栏用最深灰，内容区亮一档做区分，工具栏与浮层再亮一档靠近观者。系统蓝只给选中项、链接与主按钮——等同于桌面系统的强调色，只此一支；绿、橙、红各管一种状态，小面积出现。

  • Deepest Grey窗口底与侧边栏基色。整页最深的一层，其他灰都压在它上面。
    #1c1c1e--color-deepest
  • Mid Grey内容区与列表行。与最深灰差一档，用来区分侧边栏与主区。
    #2c2c2e--color-mid
  • Light Grey工具栏、悬浮面板与需要再靠近观者一层的表面。
    #3a3a3c--color-light-grey
  • System Blue选中项、链接与主按钮。等同于桌面系统的强调色，只此一支。
    #0a84ff--color-system-blue
  • System Green成功、在线、已完成。与系统蓝同屏时只做小面积标记。
    #30d158--color-system-green
  • System Orange警告与待处理。表示「需要你看一眼」，不表示失败。
    #ff9f0a--color-system-orange
  • System Red删除与不可逆操作。出现即意味着有代价。
    #ff453a--color-system-red

面板阴影：inset 0 1px 0 rgba(255,255,255,0.08), 0 20px 48px rgba(0,0,0,0.5)；浮层 0 12px 32px rgba(0,0,0,0.55)。分隔线一律 1px 白色 8% 到 12%。

字体

三套字各司其职：窗口标题与大标题用衬线 Georgia，是这套暗色界面唯一的「人味」；正文与控件用系统无衬线，字级偏小（11 到 17px），这是桌面应用的密度；代码与数值用 SF Mono，不做装饰用途。

组件

Vibrancy Sidebar

侧边栏与浮层背景。深灰 80% 不透明填充、backdrop-blur 40px、仅右侧 1px 白色 10% 描边；宽 240px、内边距 12px。选中项用系统蓝 18% 底、圆角 6px；hover 用白色 8% 底。不做位移与缩放。上方演示窗口的侧栏即此组件。

悬停左侧列表行，只有颜色在变。

System Button

主按钮与工具栏按钮。系统蓝填充、白字、6px 圆角、无描边、字级 13px/500、padding 6px 14px；hover 只把填充亮度提高 8%，按下降低 10%，过渡 200ms 且只动颜色。禁用态用白色 12% 填充配 40% 文字。

List Row

设置项、文件列表与消息列表。高 44px、水平内边距 12px、圆角 6px、无背景；行与行之间用 1px 白色 8% 分隔线。hover 填充白色 6%，选中填充系统蓝 18%；左侧图标 16px、右侧说明文字 13px 白色 60%。

列表分栏画廊

可为与不为

可为

  • 只用三层深灰，层级靠明度差而不是描边
  • 侧边栏与浮层用 80% 不透明加深模糊做通透
  • 所有分隔线都是 1px 白色 8% 到 12%
  • 标题用衬线，正文用系统无衬线
  • 动效 200ms，只改颜色
  • 密度按桌面应用设定：行高 44px、字级 11 到 17px

不为

  • 不要用超过 1px 的描边
  • 不要在动效里加位移或缩放
  • 不要用玻璃拟态那种高饱和光斑，这里是系统材质不是装饰
  • 不要把强调色用于大面积填充
  • 不要用网页级的大字号破坏桌面密度
  • 不要给面板加圆角超过 14px
