风格 54 · 浅色版面

拼贴艺术风 COLLAGE ART

剪下来、撕开口、歪着贴上去：一页手工拼贴的杂志内页。

撕纸毛边三种字体交替胶带与标签条±3 度拼贴

拼贴艺术风模拟手工拼贴：纸片被剪下、撕出毛边、用胶粘在旧纸上，边缘对不齐，角度也不统一。技术上靠四件事——clip-path polygon 做撕纸边、任意角度旋转（避免与 hover 冲突）、硬偏移阴影模拟纸片厚度、以及混合字体交替（衬线、无衬线、等宽在同一页轮流出现）。

它禁止平滑渐变、禁止 8px 以上的圆角、禁止毛玻璃，因为手工拼贴的每一块都是实体纸。右边这张撕纸卡是真的——胶带压角，hover 时它会摆正。

剪下来，贴上去。

MAGAZINE PAGE · 1987

纸片厚度靠硬偏移阴影：6px 6px 0 rgba(45,45,45,0.28)、小号 3px 3px 0 rgba(45,45,45,0.22)；按下归零。撕边用 8–12 顶点的 clip-path 多边形，绝不能规律。

字体

大标题用衬线 Playfair Display，模拟从杂志上剪下来的标题块；正文与标签用无衬线 Inter；编号、坐标与注释标签用等宽 JetBrains Mono，像打字机打的标签条——字体在页面中交替出现是本风格的语法。

间距与版面

基础单位 8px，密度 comfortable。上限 1200px、容器内边距 24px，区块间距 96px。元素允许互相覆盖与错位，旋转范围 -3 到 3 度。整体保持一条隐形的中轴让拼贴不至于失控，但每块都偏离它一点。

组件

Torn Paper Card

撕纸卡片（核心组件）。旧纸色或撞色填充、零圆角，用 clip-path 的多边形（8 到 12 个顶点，各点上下随机偏移 2 到 6px）做出撕开的毛边；硬偏移阴影 6px 6px 0 墨色 28%；默认旋转 -2 到 -1 度。hover 时旋转归零并上浮 2px，阴影扩到 8px。过渡 200ms。上方演示卡即此组件。

Cutout Tag + Tape Strip

剪下来的标签条：高 28px、内边距 0 12px、零圆角，左右两端用 clip-path 切成斜角（各 8px），填撞色之一，文字用等宽 13px 全大写 0.12em；整体旋转 1 到 3 度，硬阴影 3px 3px 0 墨 22%——演示卡右上那条就是。胶带：96 到 160px 长、20px 高、旋转 -6 到 6 度，填半透明撞色（60%）或半透明白，两端切锯齿；压在纸片的角上，跨过边缘 8px；无边框无阴影。

Mixed Type Stack

混合字体排版组。同一区块内故意混用三种字体：标题衬线 900、副标题无衬线 900、标签等宽；三者各自带不同的旋转（-2、0、+2 度）与不同的底色条，形成「分别剪下来再拼」的效果。演示卡内部就是按这个组排的。

Cut Mark Border

剪切痕迹边框。2px 虚线或实线边框，颜色取墨 40%，配合一个小剪刀图标或沿边的短刻度线，暗示「这块是沿着这条线剪下来的」；只用于强调某一个元素，不滥用。

可为与不为

可为

  • 用 clip-path 做撕纸与斜角
  • 旋转用 rotate 工具类不用 inline transform
  • 硬偏移阴影模拟纸片厚度
  • 三种字体在同页交替
  • 旧纸底，纸片贴在上面
  • 每块旋转 -3 到 3 度

不为

  • 不要用平滑渐变
  • 不要用 8px 以上圆角
  • 不要用毛玻璃
  • 不要让所有块角度一致
  • 不要用统一字体
  • 不要让撕边完全规律

图像

剪报照片、杂志碎片、手绘涂鸦、标签与印花。图像必须有清晰剪裁边缘（可带白边），允许叠两层不同来源的碎片。不使用平滑渐变、圆形裁切与统一风格的摄影。
