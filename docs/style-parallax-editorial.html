布局模式 13 · 翻页版面

视差杂志 PARALLAX EDITORIAL

暖纸上的长文，前后景以不同速度移动，翻页被拉成一段旅程。

砖红首字下沉视差只用 transformsticky 图文交叠行宽 ≤75 字符

视差杂志把编辑排版与物理景深缝起来：暖纸底配近黑墨正文，首字下沉 3 到 4 行高并用砖红，章节号与引文也用同一支砖红，其余全是墨。视差只用 transform 做——绝不能在 scroll 事件里改 top、margin 或 height，那会触发重排并卡顿。景深层级最多三级，因为再多景深就浑浊。正文永远不做视差主体，行宽不超过 75 字符；移动端必须削弱或关闭视差，否则性能和眩晕都会出问题。

布局实演

左边一块 sticky 图（60vh 高、不缩放不淡出），右边正文逐段覆盖它——「翻页」的错觉全靠位置关系。

第一章

雨季从三月开始，沿着河岸一路向北。纸页翻动时，前景的河与远景的山以不同的速度后退。

「翻页不该是一次跳变，而是一段旅程。」

—— 卷首语

正文只随正常滚动前进，行宽压在七十五个字符之内；砖红只出现在首字、章节号与引文上，其余全是墨。

颜色

带暖调的近黑像印刷油墨，管正文与标题；偏黄的纸色做页面底，绝不能用纯白或冷白；砖红是唯一强调色，只用于首字、章节号、引文与链接，绝不能铺成大色块；深褐是墨的暖化版本，做深色区块与引文底；沙色管次级区块与图片衬底，在不破坏纸感的前提下分区。

字体

正文与标题都用衬线 Source Serif。行高 1.75，行长控制在 75 字符以内——这是视差不干扰阅读的前提。

组件

Drop Cap

首字下沉（识别核心）。段落首字母 float: left、字号约为正文的 3.4 倍（行高对齐三到四行）、颜色砖红、右与下各留 8px、字体同正文衬线。每个长文区块只允许一次，且仅用于第一个段落。实演里那个「雨」字就是。

Parallax Layer

视差层。滚动时只用 transform: translate3d(0, Ypx, 0) 移动，Y 由滚动进度乘速率得出（背景 0.15，中景 0.30，前景 1.0）。绝不能在 scroll 处理器里读或写布局属性（offsetTop、getBoundingClientRect、top、margin、height）。一屏最多三个速率层级。prefers-reduced-motion 时所有层归零。

Sticky Interlock

图文锁定（sticky 交叠）。图片容器 sticky top-24，高度 60vh；右侧正文正常滚动并逐段覆盖图片。图片不缩放、不淡出，只靠位置关系产生「翻页」的错觉。移动端取消 sticky，改为图文上下排列。实演的左图右文就是。

Chapter Number

章节号。砖红色、14px/600、字距 0.14em、全大写、位于标题上方 16px，格式为「第一章」或「01」。可配一条 24px 的砖红短线在左侧。

第二章 · 02

Pull Quote

引文。左侧 3px 砖红竖线、内边距 24px 32px、引文 26px/400 衬线斜体、行高 1.5、墨色，下方 14px 的署名。它随正文一起滚动，不参与视差。

可为与不为

可为

  • 视差只用 transform
  • 一屏最多三级视差速率
  • 正文不做视差主体，行宽不超 75 字符
  • 砖红只给首字、章节号、引文、链接
  • 暖纸底，绝不用纯白
  • prefers-reduced-motion 时全部归零

不为

  • 不要在 scroll 里改 top/margin/height
  • 不要超过三级视差
  • 不要让视差压过可读性
  • 不要在移动端保留强视差
  • 不要用多个强调色或大面积砖红
  • 不要省略 reduced-motion 降级

图像

编辑类摄影：人物、场所、物件，暖调、有纸感、可做轻微颗粒。图片以 4:5 或 3:2 出现，配 sticky 交叠。不使用冷光摄影、纯白背景图与插画。
