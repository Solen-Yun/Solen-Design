钢笔线描的枝叶、旧纸、暗绿与金：一页自然史图鉴。

1px 不填充线描边框 1px 30% 暗绿hover 描边转金圆角 8px

维多利亚植物模仿 19 世纪的自然史图鉴与植物学插图：仿旧纸底、暗绿主色、金作强调、绛红作花的点缀。核心图形是钢笔线描的植物——1px 的细线与不规则的自然曲线，绝不填充成色块。

边框是 30% 暗绿的细线呼应线描，圆角克制在 8px，阴影是极淡的暖绿。交互状态把描边换成金色。

组件

Plant Plate

植物线描图版（核心组件）。一个 1:1 或 3:4 的区域，内部用 1px 的暗绿线描出植物（茎、叶、花），线条必须自然弯曲、粗细一致、绝不填充。叶脉用中绿 1px。下方放 13px 等宽的学名（斜体衬线）与编号（如「图版 XII」）。整块零背景、零边框——hero 左边那块就是。

Fine Card

细线卡片。旧纸填充、8px 圆角、1px 暗绿 30% 描边、内边距 32px，阴影 0 2px 8px 暗绿 10%。标题 34px/600 暗绿，正文 16px 行高 1.8。hover 时描边转金 60%、阴影扩到 18px——交互状态的主要变化是那根线换色。

Gold Button

行动按钮。暗绿填充、旧纸文字、6px 圆角、1px 金 40% 描边、13px/600、字距 0.18em、padding 12px 28px，阴影 0 2px 8px 暗绿 10%。hover 时描边升到 100%、文字转金；按下时位移 1px 2px。过渡 250ms ease-out。

Sprig Rule

枝叶分隔线。一条 1px 暗绿 30% 的横线，中央嵌入一段 32px 的枝叶线描（两片叶加一截茎），两端延伸出细的卷须。它替代普通分隔线，也是版面上最典型的装饰。

Index Label

图鉴编号。13px/600、字距 0.18em、暗绿或金。格式固定为「图版 XII · 1836」或「PL. XII」。它是页面上唯一的装饰性文字，模仿图鉴的标注——hero 卡右上那行就是。

可为与不为

可为

  • 旧纸底配暗绿与金
  • 线描必须 1px 且不填充
  • 边框 1px 的 30% 暗绿
  • hover 把描边换成金
  • 圆角克制在 8px
  • 标注用图版编号

不为

  • 不要给线描填色
  • 不要用粗边框
  • 不要用高饱和图像
  • 不要用全圆角
  • 不要用现代无衬线
  • 不要用冷灰阴影

图像

植物学线描、标本摄影、图鉴页面扫描。线描必须 1px 且不填充；照片必须柔和、暖调、去饱和。不使用彩色插画、现代排版与高饱和图像。
