指标先行：先给数字，再给图，最后才给细节。

KPI 三件事tabular-nums2:1 图表区44px 行高

仪表盘布局解决的是「一眼看懂」：顶部一排 KPI 卡（3 到 4 张），下面是图表区与明细表。每张 KPI 卡只放三个元素——指标名、数字、变化率，变化率用绿色与红色的 10% 底色块表示，不靠箭头。左侧深色侧栏与浅灰内容区形成固定分区，卡片用 12px 圆角、1px 描边、一级阴影。

密度比企业站更高：图表内边距 16px、表格行高 44px、数字用等宽字体对齐。下面就是一张按规格跑的仪表盘。

颜色

仪表盘需要比企业站更强的对比：近黑承担侧栏、标题与主要数字，雾灰是内容画布，卡片白浮在其上。靛蓝是唯一强调色——主行动与图表主序列都用它，全屏只允许一个蓝紫色系；增长与下降分别用绿与红的 10% 底芯片，两者保持同等面积与字重。

组件

KPI Card

顶部指标卡。白底、12px 圆角、1px #f3f4f6 描边、内边距 20px、阴影 0 1px 2px。第一行 13px 灰字指标名加右侧变化率芯片；第二行 36px/700 数字用 tabular-nums；第三行 11px 灰字对比说明。hover 时底色转 #f9fafb、阴影升到 0 4px 12px。布局实演顶部那排就是它。

一排四张，每张只有三件事。

Chart Panel

折线、柱状与面积图容器。白底、12px 圆角、1px 描边、内边距 16px；标题 20px/600 与图例同行，图例 11px、色点 8px 圆角。图表本身不留网格竖线，只留水平虚线 1px #f3f4f6；高度固定 280px 或 320px，避免容器抖动。

Data Table

明细表与活动流。白底、12px 圆角、1px 描边；表头 11px/500 全大写 0.04em、灰底 #f9fafb、高 36px；行高 44px、行间 1px #f3f4f6 分隔、hover 行底色 #f9fafb；数值列右对齐并用等宽字体，状态列用 10% 底芯片。

Sidebar Rail

左侧导航。宽 240px、近黑填充、白字 70%、固定；项目高 40px、8px 圆角、图标 18px；选中项白 10% 底配纯白，hover 白 6%；分组之间 24px 间距加 1px 白 8% 分隔线。布局实演左侧那条深色导轨就是它。

可为与不为

可为

  • KPI 卡只放名称、数字、变化率三件事
  • 数字用 tabular-nums 保证列对齐
  • 变化率用 10% 底色芯片，不用箭头与强调色块
  • 图表只留水平虚线，不放竖网格
  • 表格行高 44px，数值右对齐
  • 图表高度固定，避免布局抖动

不为

  • 不要在一张 KPI 卡里塞图表或按钮
  • 不要用彩虹配色区分数据系列
  • 不要用超过 12px 的卡片圆角
  • 不要用重阴影或发光
  • 不要让表格行高低于 40px
  • 不要把筛选器藏在二级菜单里

图像

图表是主要视觉元素，不用摄影。允许头像、产品缩略图与图标。图表配色必须与强调色同源，不用离线彩虹色。
