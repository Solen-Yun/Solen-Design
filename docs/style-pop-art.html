波普艺术 POP ART

粗黑轮廓、Ben-Day 网点、喊出来的对话框：漫画印在画布上。

4px 粗黑边框45° Ben-Day 网点900 字重全大写硬阴影 4px 4px 0

波普艺术来自沃霍尔与利希滕斯坦：4px 粗黑边框包住一切，背景铺 Ben-Day 网点（等距圆点），颜色是高饱和的平涂黄、粉、蓝，文字用 900 字重全大写像漫画标题，按钮与卡片带 4px 4px 0 黑的硬阴影。它禁止渐变（一切必须平涂）、禁止低饱和与灰调、禁止 2px 以下细边框、禁止全圆角。

右边这张网点卡是真的：45 度 Ben-Day 网点，hover 时网点换色、阴影扩到 6px；气泡是全站唯一允许圆角的元素。

颜色

波普黄是主底色与最大色块，整套风格的亮度来源；粉是第二主色，常与黄直接相撞；蓝是第三撞色与对话气泡底；黑勾出一切形状——4px 轮廓、硬阴影与文字都由它承担；白是画布与网点底色，也用于反白文字；浅紫是第四撞色，出现频率最低，用来打破黄粉蓝的固定组合。

硬阴影只有黑：4px 4px 0 #000000，hover 扩到 6px 6px 0，按下归零。网点必须清晰——模糊网点等于丢掉风格。

组件

Comic Headline

漫画式标题（核心）。56 到 80px、900 字重、全大写、行高 0.95、字距 -0.02em，颜色黑或白。可叠 2px 的文字描边（-webkit-text-stroke）与 4px 4px 0 黑的偏移阴影，形成漫画标题的立体感。允许旋转 -2 到 2 度。

Pop Button

行动按钮。波普黄或粉填充、黑字、4px 黑边、2px 圆角、16px/900 全大写、padding 12px 28px，硬阴影 4px 4px 0 黑。hover 时填充硬切到另一撞色、阴影扩到 6px；按下时位移 4px 4px 且阴影归零。过渡 100ms linear。

Ben-Day Bed

Ben-Day 网点底（签名）。用 radial-gradient 做 6px 间距、1.5px 半径的圆点，颜色取撞色之一（黄、粉或蓝）的 100%，铺在白底上。网格角度 45 度（避免摩尔纹）。它必须清晰可见——网点是利希滕斯坦的签名，模糊它就等于丢掉风格。本页背景与演示卡都是。

Speech Bubble

对话气泡。白或黄填充、4px 黑边、24px 圆角（气泡是唯一允许圆角的元素）、内边距 20px，硬阴影 4px 4px 0 黑。尾巴用两个伪元素画：一个 4px 黑边三角、一个覆盖描边的白三角。文字 20px/900 全大写。hero 右下那个就是。

Dot Card

网点内容卡。白底叠 45 度 Ben-Day 网点、4px 黑边、2px 圆角、内边距 24px，硬阴影 4px 4px 0 黑。标题 40px/900，正文 16px/900。hover 时网点颜色换到另一撞色、阴影扩到 6px。

可为与不为

可为

  • 4px 粗黑边框包住一切
  • Ben-Day 网点作背景纹理
  • 高饱和平涂，绝不用渐变
  • 900 字重全大写标题
  • 硬阴影 4px 4px 0 黑
  • 对话气泡承载引语

不为

  • 不要用渐变
  • 不要用低饱和或灰色系
  • 不要用 2px 以下边框
  • 不要用全圆角（气泡除外）
  • 不要做极简无装饰的页面
  • 不要把网点做糊

图像

波普化图像：把照片压成 4 到 6 个平涂色块加黑轮廓（像丝网印刷），或处理成网点单色。允许重复排列同一张图（沃霍尔式）。不使用渐变图像、写实摄影与极简构图。
