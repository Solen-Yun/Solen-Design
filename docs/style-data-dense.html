风格 118 · 浅色版面

数据密集 DATA DENSE

每像素都用来放数据：字号 10 到 12px，间距 4px 一跳，没有装饰。

字号 10–12px行高固定 28px数字等宽右对齐交替行色分层

数据密集是为操作台服务的，所有美学指标被压到最小：字号 10 到 12px、行高 28px、间距以 4px 递增、圆角 4px、无阴影无渐变。它的层次靠三件事建立——交替行底色、1px 分隔线、以及状态标签的色块。

数字、ID 与代码一律等宽并右对齐，保证纵向可比。这套风格的价值在密度本身：一屏能看到 40 行记录，而不是 12 行。任何增加留白的改动都是退步。

颜色

白是表格与面板底，与交替行色形成最轻的一层区分；极浅蓝灰只差一档，靠重复面积被感知；深板岩做主要文字与数字，在密集排版里仍保持锐利；灰管表头、次要列与说明，永远与 10px 全大写同时出现；主蓝是主操作、选中行与焦点，表格里唯一允许的饱和色块；红只出现在删除与错误的文字与 10% 底标签上；绿与危险红同等面积同等字重。

字体

全站唯一字体 Inter，最大只到 18px。表头 10px 全大写是这套风格的识别标记；数字、ID、时间戳与代码用 JetBrains Mono——等宽让纵向对比成为可能。

间距与版面

基础单位 4px，密度 compact。上限 1600px、容器内边距 16px，区块间距 16px，卡片内边距 12px，元素间距 4px。左侧 192px 导航加右侧内容区，顶部指标条 12px 间距，下方表格占满剩余高度。所有间距是 4 的倍数，表格行高固定 28px，一屏目标 35 行以上。

组件

Data Table

主数据表。外框 1px #e2e8f0、4px 圆角、无阴影。表头高 32px、底色 #f8fafc、10px 全大写 0.06em 灰字 500 字重。行高 28px、内边距 8px 12px、交替行底色 #f8fafc。数值列等宽右对齐，状态列放色标签。hover 整行为 #eff6ff。过渡 120ms——hero 里那张就是。

Action Button

行内操作与工具栏按钮。高 24px、padding 4px 10px、4px 圆角、11px/500，无阴影。主操作用蓝填充白字；次要操作白底配 1px #e2e8f0 描边；删除操作用红字透明底。hover 只变底色，过渡 120ms。

Stat Card

顶部指标条。白底、1px #e2e8f0 描边、4px 圆角、内边距 10px 12px、无阴影。第一行 10px 全大写灰字标签，第二行 18px/600 等宽数字，第三行 10px 的涨跌（绿或红）。三张卡以上等宽横排，间距 12px。

Status Tag

状态与分类标记。10px/500、4px 圆角、padding 2px 6px、无描边。进行中用蓝 10% 底配蓝 700 字，成功用绿 10% 配绿 700，失败用红 10% 配红 700。颜色必须与文字标签同时出现，不单靠色相。

RUN

Admin Rail

左侧导航。宽 192px、#f8fafc 底、右侧 1px #e2e8f0 描边、垂直内边距 12px。项目高 26px、4px 圆角、12px 字、图标 14px。选中项蓝填充白字，hover 白底加墨字。分组标签 10px 全大写灰字，上间距 12px。

可为与不为

可为

  • 字号 10 到 12px，最大 18px
  • 间距以 4px 递增
  • 行高固定 28px
  • 数字与 ID 用等宽右对齐
  • 用交替行色与 1px 线分层
  • 状态色必须配文字标签

不为

  • 不要用 16px 以上的内边距
  • 不要用 8px 以上的圆角
  • 不要给表格加阴影
  • 不要用装饰性渐变
  • 不要为了美观而加留白
  • 不要用色相单独传达状态

图像

几乎没有图像。允许头像 20px、图标 14px 与迷你趋势图（高度不超过 24px）。不使用大图、插画与背景纹理，它们会直接减少可显示的行数。
