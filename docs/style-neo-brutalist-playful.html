风格 36 · 浅色版面

俏皮野兽派 NEO-BRUTALIST PLAYFUL

黑框硬影的骨架不变，但换上五支糖果色，还允许歪一点。

彩色硬阴影hover 换色-2 到 3 度歪斜300ms 弹簧

俏皮野兽派是新野兽派的年轻版本，骨架完全一致：4px 纯黑边框、零圆角、零模糊的偏移阴影。区别在三点——第一，阴影可以是彩色的，而且 hover 时会换色；第二，元素允许 -2 到 3 度的旋转，hover 时继续转；第三，强调色从四支扩到五支，允许同屏出现三种。

动效用带回弹的弹簧曲线（300ms），按下时位移等于阴影偏移并归零。所有装饰必须用图标而不是 emoji，这是它区别于「随便玩」的地方。右边这张卡是真的——悬停它，阴影会从薄荷换成珊瑚红。

歪一点更开心。

薄荷影 hover 换珊瑚红，转过去 2 度。

颜色

4px 描边不可协商——纯黑承担所有边框、阴影基准与文字；珊瑚红是频率最高的强调，也是第一阴影色；薄荷与珊瑚形成冷暖对位；阳光黄管 hover 高亮与角标；海泡浅于薄荷管分类色；蜜桃管收藏与喜欢的情绪化角标。

间距与版面

基础单位 8px，密度 comfortable。上限 1200px、容器内边距 24px，区块间距 80px。元素允许 -2 到 3 度旋转，同屏最多四个带旋转的元素。卡片垂直错落 8px。所有内容对齐 8px 网格的倍数，旋转不改变落点。

组件

Playful Button

主行动按钮。珊瑚红填充、白字、4px 黑边、零圆角、6px 珊瑚或薄荷硬阴影，默认 -2 度旋转；16px/900、padding 12px 24px。hover 时上浮 4px、右移 1px、旋转到 3 度、阴影换成阳光黄并扩到 8px；按下时位移 6px 6px、缩放 0.95、旋转归零、阴影去除。过渡 300ms 弹簧曲线。右上角可放一个 12px 黄色角标。

Tilted Card

内容卡与功能卡。白底、4px 黑边、零圆角、8px 薄荷硬阴影，默认 -1 度旋转，内边距 28px；顶部放一排 16px 彩色方块（各 2px 黑边）作装饰序列。hover 时上浮 8px、旋转 2 度、阴影换成珊瑚红并扩到 12px。过渡 300ms 弹簧。上方演示卡即此组件。

Square Input + Icon Tag

表单输入：白底、4px 黑边、零圆角、padding 12px 16px、16px/700 字；聚焦时加 4px 薄荷硬阴影且不改变尺寸；错误态把边框与阴影都换成珊瑚红。带图标的标签：彩色填充、2px 黑边、零圆角、12px/700、padding 4px 10px，左侧配 14px 线性图标；禁止 emoji 替代。

收藏 进行中 分类

Sticker Cluster

装饰性贴纸组合。由 3 到 5 个 12px 到 24px 的小方块、圆点或星形组成，各自 2px 黑边，分别用不同强调色，整体旋转 -3 度；只用于卡片角落，不承载信息，单屏不超过两组。上方演示卡的角上贴着一组。

可为与不为

可为

  • 4px 黑边、零圆角、硬阴影
  • 阴影可用彩色并在 hover 换色
  • 旋转控制在 -2 到 3 度
  • 装饰只用图标，不用 emoji
  • 动效 300ms 带回弹
  • 同屏最多三种强调色

不为

  • 不要用任何圆角
  • 不要用模糊阴影
  • 不要用渐变
  • 不要旋转超过 3 度
  • 不要用 emoji 或符号字符
  • 不要用柔和灰色

图像

粗描边图形、几何贴纸、单色图标。允许把照片处理成高对比双色调后加黑框。不使用柔和摄影、渐变与 emoji 装饰。
