风格 27 · 浅色版面

拟物设计 SKEUOMORPHISM

每个控件都是一件实物：皮革、木头、金属，有厚度也有高光。

双内阴影加渐变皮革与木纹黄铜扣件凹陷与凸起分明

拟物设计把界面做成实物：面板像皮革或木纹，按钮像金属片，纸张像米色信纸。它的技术核心是「双内阴影加一段渐变」——顶部 inset 0 1px 0 白色 70% 是受光面，底部 inset 0 -1px 0 黑色 12% 是转折暗线，外阴影提供离地高度，再叠一层 3% 的纹理点阵作为材质。

它在新拟物与扁平之间走了第三条路：不靠单色，而靠光与材质。代价是每个组件都需要精细调光，粗糙实现会立刻显得廉价。右边这块面板是真的——按钮可以按下去，旋钮可以转。

颜色

做旧皮革承担深色面板与主按钮，带细微颗粒纹理；浅木与纸板比皮革亮两档，做卡片；金属面必须有纵向渐变才有反射感；米色信纸做页面底；黄铜管扣件、刻度与选中状态；深棕是文字与压印凹槽，像烧灼与刻痕；森林绿是老式仪表的绿色刻度，管成功与「已启用」。

凸与凹是两套阴影：凸起面板 0 8px 16px rgba(0,0,0,0.2) 加顶高光与底暗线；凹陷 inset 0 2px 6px rgba(0,0,0,0.25) 加底部反光。混用即穿帮。

字体

标题与带刻度的标签用 Georgia——衬线让文字像被印在材质上而不是浮在屏幕上；界面文字与数值用 Verdana，略带方正的无衬线像老设备的面板字。

间距与版面

基础单位 8px，密度 comfortable。上限 1080px、容器内边距 24px，区块间距 64px。整体像一台设备的面板：分区用凹槽与凸起代替留白，工具栏可带皮革底，内容区像纸张。控件之间至少 12px，保证阴影不互相污染。

组件

Metal Button

主行动按钮。纵向金属渐变（#d8d8d8 到 #a8a8a8）、深棕文字、8px 圆角、1px #7a7a7a 描边，阴影 0 3px 6px 黑 25% 加 inset 0 1px 0 白 85%；字级 14px/700、字距 0.1em、padding 10px 24px。hover 时渐变整体提亮 6%、外阴影加深；按下时渐变反向（上暗下亮）并换成内阴影。过渡 150ms。

Leather Panel

深色面板与工具栏。皮革色填充配 3% 点阵纹理、12px 圆角、内边距 24px，阴影 0 8px 16px 黑 20% 加顶边白 70% 高光与底边黑 12% 暗线；面板内文字用米色，标签 12px/700、0.1em 字距，像刻上去的。上方演示面板即此组件。

Inset Well

输入框与凹槽区域。木色填充、6px 圆角、1px #b8a88c 描边，阴影全部朝内：inset 0 2px 6px 黑 25% 加 inset 0 -1px 0 白 45%，形成凹陷；padding 8px 12px、14px 字。聚焦时内阴影加深到 8px 并加 2px 黄铜外环。

Brass Knob + Ribbon Header

滑块与旋钮控件：24px 圆形、镜像径变（135deg，#e8d48a 到 #9a7a1e）、1px #7a5f14 描边，阴影带内高光与内暗缘；hover 时旋转 8 度，按下时内阴影加深——右侧面板角落那颗就是。页头与分区标题条：深棕填充、底部 3px 黄铜边线、无圆角、内边距 12px 24px，顶部 1px 白 15% 高光；标题 22px 衬线、米色、字距 0.1em，左对齐并带 24px 图标位——本页每个 h2 前的深棕条即此。

可为与不为

可为

  • 每个控件都要有顶高光与底暗线
  • 用材质纹理，但不超过 8% 不透明度
  • 凸起用外阴影，凹陷用内阴影
  • 金属面必须有纵向渐变
  • 文字用衬线，像刻进材质
  • 控件间距至少 12px

不为

  • 不要用纯扁平色块
  • 不要省略阴影与高光
  • 不要用过简的线条图标
  • 不要用现代渐变与玻璃态
  • 不要让纹理超过 8%
  • 不要把凹陷与凸起的阴影混用

图像

真实材质照片：皮革纹理、木纹、金属拉丝、装订线。允许把纹理以 3% 到 8% 的不透明度叠在面板上。不使用扁平插画与现代渐变，它们会毁掉材质假设。
