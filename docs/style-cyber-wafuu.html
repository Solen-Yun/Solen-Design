赛博和风 CYBER WAFUU

青海波与电路同源，金缮的裂纹成了发光的边框。

障子格栅卡片金缮裂纹发光青海波叠电路hover 只浮 1–2px

赛博和风让传统日本纹样被技术「黑」进来：青海波与电路走线合流，麻叶纹作网格，障子格栅作卡片边框，鸟居作导航框架，金缮的金色裂纹作描边与强调。底是深靛，主色藏青，辅以朱红、金与电路青。交互极克制——hover 只上浮 1 到 2px 并让光晕增强，绝不夸张。

右边这张障子卡是真的：格栅线穿过内容但不干扰阅读，右下有一条 2px 的金缮裂纹；hover 时上浮 2px，光晕转青金双色。

组件

Shoji Card

障子格栅卡片（核心组件）。深靛填充、零圆角、1px 藏青 30% 描边、内边距 32px；内部用 1px 藏青 20% 的线画出障子格栅（横 2 条、竖 2 到 3 条，等分），格栅线穿过内容但 opacity 低到不干扰阅读；左上或右下叠一条 2px 的金缮裂纹（折线 path，带 0 0 12px 金 40% 发光）。hover 时上浮 2px、光晕转电路青加金双色。hero 里的面板就是。

Torii Nav

鸟居导航框。页面顶部一条横梁（高 12px、朱红填充、两端各外伸 24px）加两根立柱（各 8px 宽、从横梁垂到内容区顶部），形成鸟居的轮廓；导航项放在横梁下方。鸟居本身就是容器边界，绝不与其它边框重复。

Kintsugi Border

金缮裂纹边框。用 SVG 折线沿着容器的一边（或四边）画一条不规则的裂纹，2px 金描边、带 0 0 12px 金 40% 发光，转折处角度 100 到 140 度。它替代普通描边，并暗示这件东西是被修好的。同一屏最多三处——演示卡右下那条就是。

Seigaiha Ground

青海波底纹。用重复的同心半圆（radial-gradient 或 SVG pattern）画青海波，单元 32px、线宽 1px、色电路青 10% 或金 8%。它可与电路走线叠加（走线用直线折角 90 度），形成「传统纹样被电路穿过」的效果。

Execute Button

行动按钮。藏青填充、银灰文字、零圆角、1px 藏青 60% 描边、13px/600、字距 0.18em、padding 12px 24px，外发光 0 0 12px 藏青 40%。hover 时上浮 1px、描边转电路青 60%、光晕转电路青加金；按下时下沉 1px 且光晕收回。过渡 250ms ease-out。

可为与不为

可为

  • 青海波与电路合流
  • 障子格栅作卡片结构
  • 金缮裂纹作边框与强调
  • 鸟居作导航框架，只一次
  • hover 只上浮 1 到 2px
  • 零圆角，全站直角

不为

  • 不要用明亮或高饱和图像
  • 不要用圆角
  • 不要让纹样抢过内容
  • 不要重复鸟居框架
  • 不要用夸张的位移动效
  • 不要在一屏放三处以上金缮

图像

和风影像与纹样：障子门、鸟居、枯山水、金缮陶器、青海波织物。必须暗调、可叠电路纹理。允许把照片处理成靛蓝双色调。不使用明亮摄影、卡通插画与高饱和图像。
