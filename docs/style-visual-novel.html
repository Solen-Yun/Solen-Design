风格 56 · 深色版面

视觉小说风 VISUAL NOVEL

半透明的对话框浮在场景上，一切为「读下去」让路。

85% 对话框渐变名牌高光扫过选项行高 1.8 长读

视觉小说风来自 ADV 游戏界面：场景是一张插画，对话框是压在下方的一块 85% 不透明的深色面板，角色名在面板左上角用渐变名牌标出，选项是纵向排列的分支按钮，hover 时有一道高光从左扫过。

它的排版纪律很清楚——叙事文本用衬线、UI 标签用无衬线，正文行高拉到 1.8，因为玩家要连续读几百字。装饰要克制：只在面板角落放 L 形线，绝不用粗边框、RGB 分离与像素字体。下方那个对话框是真的——选项 hover 时高光会扫过去。

字体

叙事与对话正文用衬线 Lora——衬线让长文本读起来像小说，行高 1.8 是硬指标；UI 标签、按钮与数值用 Inter，永远与衬线叙事文本分工明确。

组件

Dialogue Panel

对话框（核心组件）。夜板岩 85% 填充、20px 模糊、12px 圆角、1px 叙事靛 20% 描边、内边距 32px（顶部 40px 留给名牌），阴影 0 8px 32px 黑 50%；叙事文字 16px 衬线、行高 1.8、白色；左上角用两条 1px 叙事靛 40% 的线做 L 形装饰（各 24px）。hover 时描边升到 40%、面板上浮 2px。上方演示框即此组件。

Nameplate

角色名牌。压在对话框左上角、向上偏移 16px，横向内边距 24px、纵向 6px，叙事靛到深靛的横向渐变填充，圆角只有上两角与右下角（模拟标签），白字 13px/700、字距 0.08em，阴影 0 4px 10px 靛蓝 30%；名牌宽度随名字自适应，不留空。

Choice Button

分支选项按钮。夜板岩 60% 填充、8px 模糊、8px 圆角、1px 叙事靛 30% 描边，左对齐、18px 无衬线、padding 16px 32px，全宽；hover 时填充转靛 20%、描边到 60%、上浮 2px，同时一道白色 5% 的高光从左扫到右（700ms）；按下时整体右移 8px 并回落。上方对话框里那三个选项就是。

Save Slot + Scene Stage

存档与章节列表：雾白 70% 填充、12px 圆角、内边距 16px，左侧 16:9 截图缩略图，右侧 15px 章节名与 12px 时间戳；hover 时填充升到 85%、缩略图放大 1.03；空档位用虚线边框并显示「空」。场景区域：占视口 85% 高度，背景渐变插画，角色以底部对齐的半透明剪影出现（160px 宽、120% 高度、8% 不透明度）；对话框叠在底部 24px 处，不遮挡中心视觉——本页顶部那两个剪影就是。

可为与不为

可为

  • 叙事用衬线、UI 用无衬线
  • 对话框 85% 不透明加深模糊
  • 正文行高 1.8
  • 名牌只圆三角，做成标签形
  • 选项 hover 用高光扫过
  • 装饰只用角落的 L 形线

不为

  • 不要用 4px 以上的粗边框
  • 不要用 RGB 分离的重影
  • 不要用像素风或等宽字体做正文
  • 不要用纯黑背景
  • 不要用全大写宽字距的终端风文本
  • 不要让对话框遮住场景中心

图像
