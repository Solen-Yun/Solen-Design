动力学排印 KINETIC TYPOGRAPHY

字就是界面：它逐个到场、字重会呼吸、宽度跟着滚动速度伸展。

字母遮罩上升可变字重呼吸只动 transform/opacity一屏一个主效

动力学排印把可变字体当成动画本体：近黑舞台配暖骨白文字，字母逐个入场、字重呼吸、宽度随滚动速度伸展，唯一的强调色是信号橙，只落在主 CTA、关键词与 hover 态。它的技术纪律比视觉更硬——只许动 transform、opacity 与 font-variation-settings，绝不动 top、left、width、height（那会重排卡顿）。

离散入场用 expo-out 0.7 到 0.9 秒，超过 1.2 秒或对一次性过渡用 linear 都算错；一屏只能有一个主导动效（一次一个主角）。

组件

Letter Stagger

字母逐个入场（核心动效）。标题按字符拆成 span，每个字符初始 translateY(110%) 加 opacity 0，进入视口时按 30 到 40ms 间隔依次回到 0 与 1，缓动 cubic-bezier(0.22, 1, 0.36, 1)（expo-out），单字符时长 0.7 到 0.9 秒。父容器加 overflow hidden 形成遮罩上升，绝不用纯 opacity 淡入代替。prefers-reduced-motion 时直接显示终态。hero 里的 KINETIC 就是。

Variable Breath

字重与字宽呼吸。用 font-variation-settings 在 2.4 秒内循环改变 wght（300 到 900）与 wdth（85 到 100），缓动 ease-in-out。连续装饰循环不受一次性过渡的 1.2 秒上限约束。单屏最多一个元素在做呼吸，否则会互相打架。

BREATHE

Scroll Marquee

跑马灯。内容复制两份、容器 overflow hidden，用 translateX 从 0 到 -50% 的 24 秒 linear 无缝循环。hover 时暂停。自动播放超过 5 秒且与其他内容并列时，必须提供可持续使用的暂停／停止／隐藏控制，不能只靠 hover。hero 下面那条就是。

Signal CTA

主行动按钮。信号橙填充、墨黑文字、2px 圆角、无描边，18px/700、padding 14px 32px。hover 时填充提亮 8% 并把文字变成可变字重的 900（0.4 秒 expo-out）；按下缩放 0.98。过渡只动 opacity、transform 与 font-variation-settings。

Velocity Widen

随滚动速度改变字宽。读取滚动速度（在 rAF 内计算两帧 scrollY 差值并缓存），映射到 font-variation-settings 的 wdth（85 到 100）与 letter-spacing（-0.04em 到 -0.02em）。速度衰减用 0.3 秒的阻尼，静止时回到默认值。禁止在 scroll 事件里读布局属性。

可为与不为

可为

  • 只动 transform、opacity、font-variation-settings
  • 入场用 expo-out 0.7 到 0.9 秒
  • 一屏只有一个主导动效
  • 跑马灯用 24 秒 linear 无缝循环
  • 自动播放超过 5 秒必须提供暂停控制
  • 信号橙只给 CTA、关键词与 hover

不为

  • 不要动布局属性（top/left/width/height）
  • 不要一屏跑多个主效
  • 不要让图像抢戏
  • 不要超过一个强调色
  • 不要用纯 opacity 淡入代替遮罩上升
  • 不要让一次性过渡超过 1.2 秒或用 linear

图像

几乎没有图像——文字就是图像。允许极低不透明度的噪点或网格作为舞台纹理。不使用插画与摄影，任何有形象的图像都会抢走字的戏。
