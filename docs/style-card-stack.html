布局模式 15 · 层叠版面

卡片堆叠布局 CARD STACK

三张卡片前后错开叠在一起，用 Z 轴而不是排布说明顺序。

Z 轴层级12px 偏移缩放分层位置指示器400ms 缓出

卡片堆叠是一个 3D 排布策略：一张主卡在最前，后面两张各向上偏移 12px 与 24px、缩小到 0.96 与 0.92、并降低不透明度。它把「顺序」变成空间关系而不是列表。

视觉上必须克制——卡片本身只是白底、16px 圆角、一级阴影，所有表现力都放在层级变换上：切换时前后卡片沿着 Z 轴重新排列，用 400ms 的缓出完成。卡片之间的偏移不能超过 24px，否则会读成散落的纸片而不是一副牌。

布局实演

左右两个圆形按钮切换卡片，下面的指示器告诉你现在看到第几张。切换时只过渡 transform 与 opacity，卡片本身不换颜色——所有层级感都来自那三步变换。

颜色

所有卡片同色，层级只靠变换区分——这是这套布局最重要的纪律。午夜蓝是标题与主按钮，也是后置卡片阴影的基准；雾灰是页面底色，带一点蓝的浅灰让白卡片的边缘清晰；靛蓝只做主强调与指示器激活态，用来告诉用户当前看到第几张。

  • Midnight标题、主按钮与深色卡片。堆叠需要一支足够深的颜色来区分主卡。
    #1a1a2e--color-midnight
  • Fog页面底色。带一点蓝的浅灰，让白卡片的边缘清晰。
    #f0f0f5--color-fog
  • Card White主卡与后置卡片的填充。所有卡片同色，只靠变换区分层级。
    #ffffff--color-card-white
  • Indigo主强调与指示器激活态，用于告诉用户当前看到第几张。
    #6c5ce7--color-indigo
  • Cyan成功与「已完成」步骤，用于进度语义。
    #00cec9--color-cyan
  • Pink情感化强调，用于收藏与推荐。
    #fd79a8--color-pink
  • Butter高亮与「新」标记，只在小面积出现。
    #ffeaa7--color-butter

组件

Stack Card

堆叠中的任意一张卡片。白底、16px 圆角、无描边、内边距 32px。前置卡片阴影 0 18px 40px 午夜 12%；后置卡片每层上移 12px、缩放 0.96、不透明度降到 70%，第二层再上移 12px、缩放 0.92、不透明度 40%。切换时用 transform 过渡，400ms cubic-bezier(0.22, 1, 0.36, 1)。

Deck Controls

切换按钮。圆形按钮 40px、白底、1px #e4e4ec 描边、无阴影，箭头图标 16px。hover 时描边转午夜并加 0 4px 12px 8% 阴影；按下缩放 0.94。左右两个按钮分列卡片两侧，垂直居中。上面布局实演里的左右两枚就是它。

Step Indicator

当前进度指示。一排 8px 圆点，间距 8px。当前项填充靛并拉长成 24px 的胶囊，其余为 30% 午夜圆点。切换时宽度与颜色一起过渡，300ms ease-out。

Stack Container

堆叠容器。最大宽度 640px，高度固定为卡片最高内容的高度加 48px（为后置层留出空间）。用 transform 与 z-index 实现层级，禁止用绝对定位偏移来模拟。容器需支持触摸左右滑动，滑动阈值 80px；移动端取消重叠，改单卡滑动。

可为与不为

可为

  • 偏移不超过 24px，缩放不低于 0.92
  • 所有卡片同色，只靠变换分层
  • 切换时沿 Z 轴重排，400ms 缓出
  • 用指示器告诉用户位置
  • 移动端取消重叠，改单卡滑动
  • 容器为后置层预留 48px 空间

不为

  • 不要让偏移超过 24px
  • 不要给后置卡片换颜色
  • 不要用绝对定位模拟层级
  • 不要在卡片里放第二个堆叠
  • 不要用超过 500ms 的切换
  • 不要在移动端保留重叠

图像

卡片内以插图与产品截图为主，每张卡片最多一张图且宽度铺满内容区。不使用全幅摄影与背景纹理，堆叠本身已经足够有存在感。
