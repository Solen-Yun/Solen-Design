风格 52 · 浅色版面

油画印象派风 IMPRESSIONIST OIL

厚涂的颜料与斑驳的光：界面像一张还没干的画布。

厚涂双层阴影笔触纹理点彩光斑按下下沉 3px

油画印象派风借鉴莫奈与雷诺阿：暖画布底、粗笔触纹理、斑驳的光影、点彩式的杂色、以及厚涂的体积感。技术上靠三件事——按钮用线性渐变模拟颜料从管里挤出的走向，卡片用 repeating-linear-gradient 做出笔触方向的纹理，阴影用「实色底加模糊扩散」的双层组合模拟厚涂堆起的高度。

它禁止纯平色块、禁止霓虹荧光、禁止等宽字体、禁止全大写，而且按钮按下必须下沉 3px，因为实色阴影不做陷入感就会失真。右边这张笔触卡是真的——按一下按钮，颜料会被压进画布里。

画布还没干。

笔触的方向就是纹理的方向。

配色方案

  • Warm Ochre#e8a87c
  • Vermilion#c0392b
  • Teal#1abc9c
  • Sunlight#f5d88a
  • Deep Blue#2c3e50
  • Canvas#f5f0e1

颜色

亚麻画布的暖米色是底，所有笔触画在它上面；暖赭是印象派最常用的暖调——日落、肤色与主按钮；朱红出现在小面积但极醒目；印象派从不用纯黑，深蓝承担文字与阴影；青绿是水与叶的冷侧，与朱红形成点彩对比；日黄是画面里最亮的笔触。

厚涂阴影是双层：0 4px 0 rgba(44,62,80,0.18) 实色底 + 0 12px 28px rgba(44,62,80,0.14) 模糊扩散；hover 加厚到 0 6px 0 / 0 18px 36px；按下收到 0 1px 0。

字体

粗衬线 Lora，字重 700 用于标题。绝不用等宽，也绝不用全大写——印象派是柔的。

间距与版面

基础单位 8px，密度 comfortable。上限 1080px、容器内边距 24px，区块间距 112px。允许元素重叠与柔化边缘。整页保留画布纹理，色块像薄涂一样半透明。

组件

Paint Button

行动按钮。暖赭上下渐变（#f0b98f 到 #d99a6d）、画布色文字或深蓝文字、8px 圆角、无描边、18px/700、padding 14px 32px，厚涂阴影 0 4px 0 深蓝 18% 加 0 12px 28px 深蓝 14%。hover 时渐变提亮、阴影扩到 36px；按下时 translateY(3px) 且阴影收到 1px——这是颜料被压下去的感觉。焦点环必须带画布色 offset。

Brushstroke Card

笔触卡片（核心组件）。画布色填充并叠一层 repeating-linear-gradient 笔触纹理（8px 间隔、深蓝 3%、角度 -12 度，模拟笔刷方向），10px 圆角、1px 深蓝 12% 描边、内边距 32px，厚涂阴影；标题 40px/700 深蓝，正文 18px 深蓝 75%。hover 时阴影加深加厚。上方演示卡即此组件。

Dab Light

光斑与点彩。一组 6 到 14 个半径 12 到 32px 的圆形，颜色取日黄、青绿或朱红并降到 20% 到 35%，绝对定位在区块上，允许互相重叠、互相柔化；它们模拟穿过树叶的光斑，单屏 2 到 3 组——本页左上那组就是。

Mixed Hue Edge + Canvas Field

混色边缘：边框不用单一颜色，而用两层错开的描边——底层朱红 25%、上层青绿 20%，各偏移 1px，读起来像颜料在边界处混在了一起；它替代纯色描边。暗场输入：画布色填充、8px 圆角、1px 深蓝 20% 描边、padding 12px 16px、18px 衬线；聚焦时描边转暖赭并加 2px 的暖赭 25% 外环，外环 offset 取画布色。

可为与不为

可为

  • 暖画布底加亚麻纹理
  • 按钮用渐变模拟颜料挤出
  • 卡片叠笔触方向的纹理
  • 阴影用实色底加模糊扩散
  • 按下必须下沉 3px
  • 焦点环带画布色 offset

不为

  • 不要用纯平色块
  • 不要用霓虹或荧光色
  • 不要用等宽字体
  • 不要用全大写文字
  • 不要让按钮按下不下沉
  • 不要让焦点环贴住元素

图像

印象派油画：风景、花园、水面、人物小景。必须可见笔触与混色，暖调、柔光。允许把照片处理成油画笔触。不使用纯平色块、霓虹图像与高清写实摄影。
