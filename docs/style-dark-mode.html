风格 11 · 深色版面

暗黑模式 DARK MODE

深板岩底上的一支蓝，靠内发光而不是投影说明层次。

三级明度描边分层顶边内高光状态色克制

暗黑模式不是把白色反过来，而是重建一套明度秩序：最深的一层是 #0f172a，绝不用纯黑——纯黑会让阴影失效。往上每一级只提亮 4% 到 6%，最多三级；边框用 1px 的白色 6% 到 10%，靠它切分区块而不是靠阴影。

所有发光都朝内：按钮顶边一层 inset 白色高光，模拟屏幕自下而上的光，这才是暗色界面里真实的物理。强调色只有一支蓝，绿、橙、红仅作为状态。右边这张卡可以悬停：填充升到完全不透明，描边转亮，上浮 2px——暗色里的层次感来自这三件事同时发生。

颜色

明度只有三级：深板岩做底，石板 800 承载，石板 700 给浮层与 hover，不再往上加。蓝是唯一强调色，主行动、链接与选中态都用它；绿、橙、红各管一种状态，用 15% 底配实色文字，出现即传达信息，不做装饰。

  • Deep Slate页面底，全站最深的一层。用它替代纯黑，阴影才有落点。

层次由 1px 描边承担：rgba(255,255,255,0.08) 常态、0.16 hover。发光只有一个方向：inset 0 1px 0 rgba(255,255,255,0.15) 顶边内高光；hover 外发光 0 0 10px rgba(59,130,246,0.30) 只给主按钮。

字体

全站唯一字体 Inter。暗底上需要比亮色版更宽松的行高（1.6）与略低的最大字重，避免光晕；正文用 90% 到 95% 的白而不是纯白。

间距与版面

组件

Primary Button

主行动按钮。主蓝填充、白字、8px 圆角、无描边；核心是顶边内高光 inset 0 1px 0 白 15%，模拟屏幕自身的光。hover 时填充提亮并叠一层蓝 30% 外发光；按下缩放 0.98，内阴影换成下压。过渡 200ms ease-out。

Surface Card

内容卡与列表容器。石板 800 的 50% 填充、1px 石板 700 描边、12px 圆角、24px 内边距、无阴影——暗色里阴影几乎不可见，靠描边分层。hover 时填充升到完全不透明、描边转亮、上浮 2px、加 0 8px 30px 黑 50%。上方演示卡即此组件。

悬停上面那张卡试试描边与填充的变化。

Dark Input

表单与搜索。石板 800 填充、1px 石板 700 描边、8px 圆角、padding 8px 12px、14px 字，占位符用石板 400。聚焦时描边转主蓝并加 2px 主蓝 30% 外环，焦点环 offset 用深板岩本色以免出现白边。

Status Chip

状态与分类标记。全圆角、12px 字、500 字重、padding 2px 10px；成功绿 15% 配绿 400，警告橙 15% 配橙 400，错误红 15% 配红 400。必须带一个小圆点，不只靠色相传达状态。

PASSED PENDING FAILED

可为与不为

可为

  • 用深板岩 #0f172a 而不是纯黑做底
  • 明度分三级，每级只差 4% 到 6%
  • 用 1px 白色 6% 到 10% 的描边分层
  • 按钮带顶边内高光
  • 正文行高 1.6，字重不超过 700
  • 焦点环的 offset 用底色而不是白色

不为

  • 不要用纯黑 #000000 做底
  • 不要靠投影分层，暗色里看不见
  • 不要把状态色当装饰色
  • 不要用低于 4.5:1 的正文对比
  • 不要用纯白文字，用 90% 到 95%
  • 不要在暗底上使用亮色大色块
