伊斯兰几何 ISLAMIC GEOMETRIC

无限延展的镶嵌图案、金与深蓝、严格的对称：装饰即秩序。

深蓝金象牙三色镶嵌无缝重复2px 金线边框严格对称居中

伊斯兰几何来自清真寺与经书的装饰传统：用精确的镶嵌图案（八芒星、六边形、几何交织）构成无限延展的边框与底纹，配色是深蓝、金与象牙白的经典组合，辅以墨绿与绛红。布局严格对称并居中，边框用 2px 金线，阴影是极淡的金色扩散。

它禁止荧光与霓虹、禁止不对称的混乱布局、禁止极简无装饰（适度装饰才是核心）、禁止手写与卡通字体。

八芒星与卷草

图案严格重复且无缝衔接，装饰本身就是秩序。

颜色

深蓝是瓷砖的蓝，管深色区块与图案底；象牙白是页面底与图文纸色；金承担所有描边、图案线与强调，是装饰的主要载体；墨绿做第二辅色，用于植物纹样与次级区块；绛红做第三辅色，用于强调与需要跳出的细节；亮绿最亮，只在图案的小面积出现。

组件

Tessellation Border

镶嵌边框（核心组件）。用 SVG pattern 或重复的 conic-gradient 做出八芒星与六边形的交织图案，线宽 1px、色金 70%，单元尺寸 48px。作为区块边框（宽 24 到 48px）或底纹（不透明度降到 8%）。图案必须严格重复、无缝衔接。

Arch Frame

拱形框。卡片顶部用 border-radius: 50% 50% 0 0 做出尖拱或半圆拱、2px 金描边、内部填深蓝或象牙、内边距 32px。四角各加一个 12px 的几何角饰（四分之一星）。hero 里的卡片就是。

Gold Button

行动按钮。金填充、深蓝文字、8px 圆角、1px 深蓝 30% 描边、15px/600、字距 0.2em、padding 14px 32px，阴影 0 4px 12px 金 20%。hover 时填充提亮 6%、阴影扩到 24px；按下缩放 0.98。四角可加 4px 的几何切角。

Arabesque Divider

植物纹分隔。一条 1px 金线的横线，中央嵌入一个 32px 的对称卷草纹（用 SVG path 画），左右各延伸一段交织的藤蔓。它替代普通分隔线，是版面上最典型的装饰语汇。

Star Medallion

星形徽章。48 到 120px 的八芒星或十六芒星（两个正方形叠转 45 度），1px 金描边填深蓝或绛红，中心一个 8px 的亮绿或金圆点。放在区块中央或标题上方，单屏 1 到 2 处。hero 卡顶部那颗就是。

可为与不为

可为

  • 深蓝、金、象牙的经典三色
  • 镶嵌图案必须无缝且精确重复
  • 布局严格对称并居中
  • 边框 2px 金线加几何角饰
  • 阴影是极淡的金色扩散
  • 植物纹用对称卷草

不为

  • 不要用荧光或霓虹色
  • 不要用不对称的混乱布局
  • 不要极简无装饰
  • 不要用手写或卡通字体
  • 不要让图案失准
  • 不要在一屏放两处以上镶嵌边框

图像

建筑与装饰摄影：清真寺瓷砖、穹顶、木雕、经书页。必须有图案细节与对称构图。允许把照片处理成深蓝金双色调。不使用写实人物摄影、霓虹图像与不对称构图。
