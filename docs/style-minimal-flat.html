风格 06 · 浅色版面

极简扁平风 MINIMAL FLAT

黑白两色、零阴影、大量留白，一切装饰都被删掉。

黑白两色零阴影色块层级反转交互大留白

极简扁平风靠删减工作：不用阴影、不用渐变、不混用圆角，层次只由色块与留白建立。黑白是主结构，四支高饱和强调色各自承担一类动作——主色粉用于按下态，青用于数据，黄用于高亮，赭用于次级。

交互同样不用阴影，hover 时直接反转前景与背景，200ms 内完成；按下态换成强调色，给出明确的一次性反馈。圆角必须统一——要么全部直角，要么全部全圆角，混用会立刻散掉。右边这张卡悬停就会整体反色，试试。

HIGHLIGHT

删掉一切装饰。

没有阴影，没有渐变，没有圆角——黑与白就是全部结构。

颜色

黑白是主结构，四支高饱和强调色各自承担一类动作，不互相替代。粉只出现在一次交互的瞬间；黄的高亮面积不超过一行；青只给需要被读出来的数字。

  • Black文字、描边与深色区块。允许纯黑，因为这套风格就是要最高的对比。
    #000000--color-black
  • White页面画布与反转区块的填充。与纯黑成对使用，没有中间灰。
    #ffffff--color-white
  • Signal Pink按下态与主强调。全站最强的视觉信号，只出现在一次交互的瞬间。
    #ff3366--color-signal-pink
  • Mint数据、成功与图表。用于需要被读出来的数字，不做背景。
    #00d4aa--color-mint
  • Bright Yellow高亮与标记。用于强调一段文字或一个标签，面积不超过一行。
    #ffcc00--color-yellow
  • Ochre次级强调与警示。出现频率最低，用于需要区分于信号粉的场合。
    #b45700--color-ochre

表面层级：0 White #ffffff，1 Black Block #000000（反转区块与页脚）。没有阴影，唯一的「立体」规则是 2px solid #000000 描边；一页反转区块不超过两次。

字体

全站唯一字体。标题用 900 与紧字距制造版面张力，正文 400 保持中性——没有灰色层级，字重就是层级。

间距与版面

基础单位 8px，密度 airy。12 栏、上限 1280px、容器内边距 24px。区块间距 128px 到 192px——比常规大得多，留白本身就是版面的主要材料；区块全部左对齐或贴边，标题不居中；整块反转为黑底白字一页不超过两次。

组件

Filled Button

主行动按钮。纯黑填充、白字、2px 纯黑描边、直角、无阴影；字级 16px、字重 700、padding 16px 32px。hover 时填充与文字互换（白底黑字、保留描边）；按下时填充换成信号粉、文字白、描边同色。过渡只变颜色，200ms，无位移。

Outlined Button

次级行动。白底、纯黑文字、2px 纯黑描边、直角；padding 16px 32px、16px/700。hover 反转为黑底白字；按下换成信号粉，与主按钮保持同一套状态逻辑。

Flat Card

内容块与作品卡。白底、2px 纯黑描边、直角、无阴影、无圆角，内边距 32px。hover 时背景整体转黑、文字转白，不做位移。图像必须与卡片同宽、直角裁切。首屏右侧即此组件。

Accent Label

分类、标签与状态。无描边、直角、无圆角，12px 字、700 字重、0.12em 字距、padding 4px 8px。默认黑底白字；高亮换亮黄底黑字；数据用薄荷青底白字。三种变体不混用。

DEFAULT HIGHLIGHT DATA

可为与不为

可为

  • 只用纯黑白做主结构，强调色各自承担一类动作
  • 零阴影，层级靠色块与留白
  • 圆角必须统一，要么全直角要么全圆角
  • hover 反转前景与背景，不用阴影
  • 按下态换强调色，一次性明确反馈
  • 区块间距 128px 起，宁可减少模块

不为

  • 不要使用任何阴影
  • 不要使用渐变
  • 不要混用直角与小圆角
  • 不要用低于 50% 透明度的元素
  • 不要用灰色文字替代黑色层级
  • 不要用图案或纹理背景

图像

两色摄影、几何构图、大面积纯色块。图像必须是直角裁切、强对比、无柔和过渡。允许把照片压成单色作为区块背景。不使用阴影、渐变、柔光与装饰性插画。
