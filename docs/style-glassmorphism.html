风格 10 · 深色版面

玻璃拟态 GLASSMORPHISM

夜色里的光学：玻璃没有自己的颜色，它只借用、弯曲、柔化背后的光。

夜景光斑8% 玻璃填充40px 模糊三层阴影香槟金唯一强调

玻璃拟态的本质是光学，不是配色。真实玻璃是无色的，它从内容层取色、保持自身中性。整套系统由三件事构成：深墨夜景底加两到三个大半径柔光斑，玻璃必须有东西可模糊；面板本身只用 5% 到 12% 的白，配 40px 到 60px 的 backdrop-blur 与 180% 的 backdrop-saturate；光必须有方向——顶边 1px 白色内高光、底边 1px 深色内暗缘、外层深阴影，三层同时存在才有厚度。

唯一允许的颜色是香槟金，只给主 CTA 与关键数字。右边这张玻璃面板可以悬停：填充从 8% 升到 14%，描边提亮，阴影升档，面板上浮 2px——玻璃的每一个状态都走 500ms 的慢过渡。

FEATURED

浮在夜色上。

模糊、描边、填充，三层缺一不可。

组件

Glass Panel

所有内容容器：卡片、面板、弹层。白色 8% 填充、40px backdrop-blur、180% backdrop-saturate、1px 白色 15% 描边、24px 圆角，阴影三层同时存在。hover 时填充升到 14%、描边到 30%、阴影升到 64px 档、面板上浮 2px，过渡 500ms cubic-bezier(0.16, 1, 0.3, 1)。上方演示卡即此组件。

Champagne CTA

主行动按钮，全页只允许一个。香槟金填充、深墨文字、999px 全圆角、无描边；16px 字体、500 字重、padding 14px 28px。hover 时填充提到 92% 不透明度、上浮 1px、加一层金色 25% 的光晕。

Glass Input

表单输入与搜索框。透明底、1px 白色 15% 描边、14px 圆角、无外阴影；内边距 12px 16px、14px 字体、占位符用月光钢。聚焦时描边升到 40%，并加一圈白色 8% 的外环，不改变尺寸。

Stat Tile

关键数字与仪表盘指标。玻璃面板的轻量版：白色 5% 填充、24px 模糊、16px 圆角、内边距 24px。上方 12px 全大写标签用月光钢，下方 40px 数字用 600 字重白色；数字本身不允许用香槟金，除非它是页面上唯一的强调。

可为与不为

可为

  • 背景必须先有光：深墨底加两到三个大半径柔光斑
  • 玻璃面板只用 5% 到 12% 的白，绝不超 15%
  • 模糊 40px 起，并始终叠加 180% 饱和度增强
  • 阴影必须三层：外层深阴影、顶边白色内高光、底边深色内暗缘
  • 唯一强调色香槟金只给主 CTA 与关键数字
  • 过渡统一 500ms 与 cubic-bezier(0.16, 1, 0.3, 1)

不为

  • 不要用紫粉 AI 渐变背景（#667eea、#764ba2、#f093fb 一类）
  • 不要在纯色平面背景上用玻璃，没有可模糊的东西
  • 不要给玻璃面板本身上色，颜色属于背景
  • 不要用低于 40px 的模糊，也不要省略 backdrop-saturate
  • 不要用不透明填充或直角，圆角 16px 起
  • 不要用 100ms 到 150ms 的快过渡，玻璃需要慢

图像

必须有光源。用夜景摄影、暗场产品照，或纯 CSS 的两到三个大半径径向光斑。图像低饱和、深色、带明显的高光区域，因为玻璃要靠这些高光才能读出折射。不使用插画、图标墙与纯色平面背景。
