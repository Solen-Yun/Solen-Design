风格 104 · 浅色版面

大理石奢华 MARBLE LUXURY

大理石白、古金细线、极细衬线：一切都在说「不急」。

古金只作 1px 线衬线仅 300/400字距 ≥0.2em零圆角零阴影

大理石奢华是高端酒店与地产的语言：大理石白底、纯黑文字、古金只作 1px 分隔线与细边框、衬线字体保持细字重、字距放到 0.2em 以上。它的奢侈感来自「少而精」——没有阴影、没有渐变、没有装饰图形，只有比例、留白与那一根金线。

石材纹理作为极淡的底纹（不透明度 5% 到 8%）出现，绝不做成抢眼的大理石贴图。

颜色

带一丝暖的大理石白像抛光石材，做页面底；纯黑不掺灰，承担全部文字；古金是唯一强调色，只作 1px 分隔线、细边框与小标记；石纹灰管次级文字与纹理的暗线；浅石只比底色深一档，做次级区块与卡片衬底；玉绿极少量用于「自然」「园林」语义，出现频率最低。

组件

Gold Rule

古金分隔线（核心结构）。1px、色古金 30%，横跨内容宽并在两端各收进 5%。它替代所有其它分隔手段——不用阴影、不用底色块、不用留白条。奢华感的全部重量在这根线上。

Marble Card

内容卡。大理石白或浅石填充、零圆角、1px 古金 20% 描边、内边距 48px，无阴影。标题 34px/300 黑、字距 0.04em；正文 15px/300 行高 1.85。hover 时只把描边升到 40%，其余不变。hero 里的卡片就是。

Quiet Button

行动按钮。透明底、1px 黑 40% 描边、零圆角、13px/400、字距 0.28em、padding 18px 40px，无阴影。hover 时描边转古金 100%、文字转古金；按下时描边升到 2px 但位置不变。过渡 500ms ease-out。

Stone Vein

石纹底。用 SVG 的 feTurbulence 加 feDisplacementMap（极低频、细线）生成几缕不规则石纹，颜色石纹灰、不透明度 5% 到 8%，只出现在大区块的背景。它的存在应该几乎察觉不到——察觉到了就太重。

Index Mark

序号与小标记。13px/400、字距 0.28em、古金或石纹灰。格式为「01 — 04」或「EST. 1987」。它是页面上除标题外唯一的「小字」，也是唯一允许的装饰性文字——hero 卡左上那行就是。

可为与不为

可为

  • 大理石白底配纯黑文字
  • 古金只作 1px 线与细边框
  • 衬线只用 300 与 400 字重
  • 字距 0.2em 以上
  • 零圆角零阴影
  • 留白占六成以上

不为

  • 不要用阴影
  • 不要用渐变
  • 不要把金铺成面
  • 不要用粗边框
  • 不要用装饰图形
  • 不要让石纹抢眼

图像

建筑与室内摄影：石材、金属、玻璃、比例精确的空间。必须自然光、低饱和、构图克制。允许把照片处理成暖灰单色。不使用高饱和摄影、装饰插画与人像特写。
