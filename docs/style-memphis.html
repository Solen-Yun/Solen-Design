风格 26 · 浅色版面

孟菲斯风格 MEMPHIS

撞色、粗边、几何乱飞：把 1981 年米兰那群人的玩笑做成界面。

4px 纯黑描边hover 各自乱动颜色硬切锯齿分隔

孟菲斯是 1981 年米兰设计团体对现代主义的反驳：不要克制，要撞色；不要网格，要不规则。落到界面上有两条硬规则——第一，几何装饰必须存在，而且 hover 时要各自朝不同方向移动或旋转（Playful Chaos）；第二，标题与文字允许在 hover 时瞬间反转成高饱和撞色（Pop Swap），150ms 硬切。

边框一律 4px 纯黑，阴影是硬偏移且按下时归零。它禁止单调配色、禁止过于对称的布局、也禁止几何装饰在 hover 时保持静止。下面这张卡可以悬停——每个装饰会朝自己的方向跑。

颜色

撞色必须成对使用，不与同色系相邻：珊瑚红是起点，永远与蜜黄、电蓝对撞；泡泡糖粉专给几何装饰；薄荷绿管成功、面积最小；葡萄紫是深色撞色，压在浅底上做形状或次要按钮。

  • Coral第一撞色与主行动。孟菲斯的起点，永远与黄、蓝对撞使用。
    #ff6b6b--color-coral
  • Honey第二撞色与高亮底。常作为 Coral 的直接对手。
    #feca57--color-honey
  • Electric Blue第三撞色与链接，用于打破红黄的暖调。
    #48dbfb--color-electric-blue
  • Bubblegum几何装饰专用，几乎不用于文字。
    #ff9ff3--color-bubblegum
  • Mint成功状态与第四撞色，面积最小。
    #1dd1a1--color-mint
  • Grape深色撞色，用于压在浅底上做形状或次要按钮。
    #5f27cd--color-grape

阴影只有硬偏移两档：6px 6px 0 #000000 与 10px 10px 0 #000000；按下时归零。没有模糊，没有柔和。

间距与版面

组件

Pop Button

主行动按钮。珊瑚填充、白字、4px 纯黑描边、零圆角、6px 硬偏移阴影；14px/700、0.06em 字距、padding 12px 24px。hover 时填充硬切到蜜黄、文字转黑、阴影扩到 10px，绝不向阴影方向位移；按下时位移 6px 6px 且阴影归零。过渡 150ms。

Playground Card

内容卡与作品卡。暖白填充、4px 纯黑描边、零圆角、内边距 28px，6px 硬阴影；卡内放 3 到 4 个几何装饰（圆、三角、波浪线），各自不同色。hover 时每个装饰朝不同方向移动 6 到 10px 并各自旋转 8 到 20 度（Playful Chaos），标题文字硬切到撞色（Pop Swap），卡片本身不动。首屏那张卡就是它。

悬停首屏的卡——装饰会各自乱跑。

Geometric Ornament

几何装饰元素。只用圆、三角、波浪线与锯齿四种，填撞色之一，可带 3px 黑描边；尺寸 24px 到 96px，绝对定位在卡片或区块的边角并允许溢出边界 8 到 16px；hover 时按各自方向位移与旋转，绝不同步。

Memphis Input + Zigzag Divider

表单输入：白填充、4px 纯黑描边、零圆角、padding 10px 14px、14px/700；聚焦时描边硬切到电蓝并加 4px 蜜黄硬阴影，不改变尺寸。区块分隔：高 16px 的锯齿折线（clip-path 或 SVG），填撞色之一，横跨内容宽；用于替代直线分隔，同一页面不超过三条——下方这条就是。

可为与不为

可为

  • 撞色成对使用，不与同色系相邻
  • 4px 纯黑描边，零圆角
  • 几何装饰必须有，且 hover 时各自移动
  • hover 颜色硬切，150ms
  • 按下位移等于阴影偏移并归零
  • 标题 900 字重、行高 1.0

不为

  • 不要用单调或低饱和配色
  • 不要用对称规整的布局
  • 不要用细边框
  • 不要省略几何装饰
  • 不要让装饰在 hover 时静止
  • 不要在 hover 时向阴影方向位移

图像

几何图形即是图像，不用摄影。允许 80 年代风格的抽象插画与粗描边线稿。不使用写实摄影、渐变与柔和阴影。
