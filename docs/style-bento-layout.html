布局模式 01 · 网格版面

便当盒布局 BENTO GRID

大小不一的卡片在同一张网格里，用尺寸而不是颜色分出主次。

尺寸层级4 栏网格24px 圆角单一间隙一张锚点卡

便当盒布局把页面当成一张 4 栏网格，卡片跨 1 列、2 列或 2 行，尺寸本身就是信息层级：最大的格子放主功能，最小的格子放补充说明。

所有间隙必须一致（16px 或 24px），否则整张网格会散。卡片统一 24px 圆角、极浅描边、一层几乎看不见的阴影；hover 时上浮 4px、放大 1% 并把阴影扩到 0 8px 30px，像把一个真实的盒子往上提了一下。允许在少数卡片用渐变做视觉锚点，但整屏不超过两张。下面就是一张按规格跑的便当盒网格。

布局实演

锚点卡跨 2x2，跨列与跨行成对出现（有 2x2 就至少配两个 1x1），没有一行只剩一张卡。用上方按钮切换视口宽度，看它怎么退化：桌面 4 栏、平板 2 栏、手机 1 列，间隙与内边距保持不变。

主功能在此

最大的格子放主功能，尺寸先说话，颜色只负责锚点。

数据位

全屏最多一处的橘色留给它：+18%

补充说明

最小的格子放补充说明，不参与层级竞争。

功能组

跨 2 列的格子承接一组相关功能，与锚点卡保持比例上的呼应。

图标网格

一组相关入口平铺在跨 2 列的格子里，节奏与整张网格一致。

状态

小格子放一条随时可换的状态。

快捷入口

一个按钮就能完成的动作放最小格。

颜色

层级只由尺寸与内容决定，颜色不参与排序：卡片全是白底，靠与雪白画布的一档明度差浮起。天蓝做主要强调与图标底；紫罗兰只与天蓝一起出现在渐变锚点卡上；橘色是数据与提醒，全屏最多一处，用在小格子里。

  • Ink标题、主按钮与深色锚点卡。也是整张网格的对比基准。
    #18181b--color-ink
  • Snow页面画布。卡片比它亮一档，靠明度差浮起。
    #fafafa--color-snow
  • Card White所有卡片填充。不使用灰卡，层级只由尺寸与内容决定。
    #ffffff--color-card
  • Sky主要强调与图标底。用于一张锚点卡片或一组图标。
    #3b82f6--color-sky
  • Violet第二强调，只与天蓝搭配出现在渐变锚点卡上。
    #8b5cf6--color-violet
  • Tangerine数据与提醒。全屏最多一处，用在小格子里。
    #f97316--color-tangerine

表面层级：0 Snow #fafafa，1 Card White #ffffff，2 Ink Anchor #18181b。阴影三级：0 2px 10px rgba(0,0,0,0.02)、0 8px 30px rgba(0,0,0,0.08)、锚点卡 hover 0 12px 40px rgba(59,130,246,0.30)。

间距与版面

基础单位 8px，密度 comfortable。页面级网格上限 1152px：移动端 1 列、平板 2 列、桌面 4 栏；间隙统一 16px（紧凑）或 24px（宽松），全页只选一种。行高用 grid-auto-rows 固定为 180px 的倍数，保证跨行卡片的比例稳定。跨列与跨行必须成对出现：有 2x2 就至少配两个 1x1，避免整行只剩一张卡。

组件

Bento Cell

网格中的任意一张卡片。白底、24px 圆角、1px #f4f4f5 描边、内边距 24px（大格 32px）、阴影 0 2px 10px 2%。默认跨 1 列，可按需跨 2 列或 2 行。hover 上浮 4px、缩放 1.01、阴影扩到 0 8px 30px 8%，过渡 300ms ease-out。上面布局实演里的格子都是它。

悬停任意格子试试那一下「往上提」。

Anchor Card

主功能卡，通常是 2x2 大格。墨黑填充或天蓝到紫的 135 度渐变、白字、32px 内边距；标题 24px/600，正文 14px 白 80%；图标 48px 见方、16px 圆角、白色 12% 底。hover 时阴影带主色（天蓝 30%）并上浮 4px。整屏只允许一张。

墨黑锚点卡

渐变或墨黑二选一，一张页面只放一张。

Bento Grid Container

页面级网格容器。移动端 1 列、平板 2 列、桌面 4 栏；间隙统一 16px（紧凑）或 24px（宽松），全页只选一种；行高用 grid-auto-rows 固定为 180px 的倍数，保证跨行卡片的比例稳定。布局实演用的就是它，切换视口按钮能看到三个断点的样子。

Bento Tile Action

卡片内的按钮与链接。墨黑填充、白字、12px 圆角、字级 14px/500、padding 8px 18px，阴影一级。hover 换成墨黑 80% 并上浮 2px；按下缩放 0.95。深色卡内改用白底墨黑字。

可为与不为

可为

  • 卡片尺寸必须有差异，尺寸就是层级
  • 全页只用一个间隙值
  • 圆角统一 24px，不混用 12px 与 32px
  • hover 上浮 4px、放大 1%，300ms 内完成
  • 锚点卡（渐变或墨黑）全屏不超过一张
  • 移动端退化为单列，保留原有顺序

不为

  • 不要让所有卡片同样大小
  • 不要在页面里混用两种间隙
  • 不要用直角
  • 不要用硬偏移阴影（新野兽派那一套）
  • 不要在一张卡片里塞三段以上内容
  • 不要让某一行只剩一张卡

图像

卡片里以产品截图、数据图表、图标网格和小段动效为主。允许在一张锚点卡上使用渐变作为图像替代。不使用大幅人物摄影或装饰性插画，它们会撑破网格。
