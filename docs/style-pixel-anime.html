风格 59 · 深色版面

像素动漫风 PIXEL ANIME

一屏 GBA 时代的 JRPG：对话框有角块，动画只有 15 帧。

4px 边框四角方块分段状态条Framerate Drop 75ms零模糊零圆角

像素动漫风把经典 JRPG 的界面语法搬进网页：RPG 对话框用 4px 勇者蓝边框加四角实心方块，状态条分段成 8px 小格，全站等宽像素字。它的时间规则叫 Framerate Drop——所有过渡 75ms、缓动只用 linear，因为 2000 年代初的掌机只有 15 帧，动画是跳的不是滑的。

禁令同样硬：禁止平滑渐变、禁止圆角、禁止任何模糊——像素的发光必须是零模糊的硬边。右边这块对话框是真的：四角有 8px 方块，按钮 hover 时直接调色板替换，不做渐变。

颜色

勇者蓝是 JRPG 的界面蓝，管对话框边框、主按钮与选中项；夜紫做深底与对话框内部，像战斗时的暗场；警报红管危险、伤害与「敌人」标记；金币黄是画面里唯一「亮」的东西，给经验、金币与高亮；治疗绿管生命值与成功；橄榄绿最暗，专门压在金色上做文字。

字体

全站唯一字体 Press Start 2P，等宽像素字。行高必须放大到 1.8，否则像素字会粘在一起。替代栈用 'Courier New'、ui-monospace。display 加 0.05em 字距，全大写标签放宽到 0.12em。

间距与版面

基础单位 4px，密度 compact。上限 960px、容器内边距 16px，区块间距 64px。布局像游戏画面：中央是主内容区，底部可固定一条对话框，右上角挂状态。所有尺寸取 4 的倍数并落在 4px 网格上。

组件

Dialog Box

RPG 对话框（核心组件）。深紫 #1a1038 填充、4px 勇者蓝边框、零圆角、内边距 20px；四角各放一个 8px × 8px 实心方块（勇者蓝），位于边框内侧 4px。文字 14px 等宽、行高 1.8、白色。框外可选 4px 零模糊硬阴影。上方演示面板即此组件。

Command Button

指令按钮。勇者蓝填充、白色等宽字、4px 夜紫边框、零圆角、14px、字距 0.12em、padding 12px 24px，硬阴影 4px 4px 0 夜紫。hover 时填充硬切到金币黄、文字转夜紫——调色板替换，不做渐变；按下时位移 4px 4px 且阴影归零。全程 transition-none 或 75ms linear。

Status Bar

状态条（HP / EXP）。高 12px、零圆角、4px 夜紫边框，内部填充用治疗绿（HP）或金币黄（EXP），分成 8px 宽的小格、格间 2px 空隙，模拟分段血条。绝不使用平滑渐变。数值以等宽字体放在条右侧——演示卡里的 HP 与 EXP 条就是。

Corner Block Decoration

角块与像素装饰。8px 或 12px 的实心方块，取调色板四色之一，放在面板四角、标题两侧或作为分隔符。可组成 2×2 的小簇作为「星光」效果，但每个方块必须有硬边、零模糊、零圆角。

Menu List

菜单与选项列表。每项高 32px、零圆角，左侧 8px 处一个 8px 的箭头方块指示选中（未选中时透明）。选中项填充勇者蓝 20%、文字转金币黄。切选项时只做颜色硬切，不做滑动。

可为与不为

可为

  • 4px 边框加四角方块装饰
  • 全站等宽像素字体
  • 只用 NES 调色板的四支色
  • 过渡 75ms 或 transition-none
  • 缓动只用 linear
  • 发光必须是零模糊硬边

不为

  • 不要用平滑渐变
  • 不要用任何圆角
  • 不要用模糊（含 backdrop-blur）
  • 不要用衬线字体
  • 不要用 ease-in-out 或 ease
  • 不要用柔和阴影

图像

像素画：16×16 到 64×64 的角色、道具与地形，必须放大整数倍（2× 或 3×）并用 image-rendering: pixelated 保持硬边。允许把照片降采样成像素图。不使用矢量插画、平滑渐变与模糊。
