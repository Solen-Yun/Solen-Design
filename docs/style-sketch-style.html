铅笔手绘风 SKETCH STYLE

线不是画直的：虚线、波浪、轻微歪斜，像在纸上随手勾出来的。

虚线与波浪边±1 度歪斜排线阴影150ms 短促

铅笔手绘风的关键是「拒绝完美」。所有边框都是虚线或波浪线，卡片允许 -1 度倾斜，hover 时回到 0 度，阴影用交叉排线而不是实色模糊。纸底是暖米（#f5f0e8），主色是铅笔灰（#2c2c2c），强调色像彩色铅笔一样只有四支且不饱和。

动效必须短促（150 到 200ms），因为铅笔的反馈是「画下去」，不是「飘起来」。这条风格最容易被做坏的地方是——把不规则做得太规律，反而变成装饰图案。下面这张便签是真的，拿正它试试。

随手一勾。

便签歪了 1 度，hover 时会被摆正。

颜色

铅笔灰承担全部线条、文字与描边——带一点暖，模拟 2B 铅笔；米黄纸底比纯白更像速写本；朱红像红笔批注，管重点标记与提醒；湖蓝是最冷静的一支彩色铅笔，管链接；草绿管完成与勾选；琥珀做荧光笔式的强调底色。

阴影是硬偏移不是模糊：便签 5px 5px 0 rgba(44,44,44,0.15)、hover 8px 8px 0 rgba(44,44,44,0.20)；需要体积的插图用 45°/-45°、间距 6px 的交叉排线填充。

字体

标题与手写标注用 Caveat——笔迹感是这套风格的人格，缺了就只剩虚线边框；正文用 Georgia——衬线正文比手写体更耐读，形成手写标题与印刷正文的对照。

组件

Sketch Button

行动按钮。透明底、2px 虚线铅笔灰描边、2px 圆角、衬线斜体加粗、0.1em 字距、padding 12px 32px，阴影 4px 4px 0 铅笔灰 15%。hover 时填充硬切为铅笔灰、文字转纸色、阴影扩到 6px 并上浮 4px、旋转 1 度；按下时位移 4px 4px、旋转 -2 度、阴影归零。过渡 150ms。

Sketch Card

内容卡与便签。纸底、2px 实线铅笔灰描边（卡片允许实线，按钮用虚线）、2px 圆角、内边距 32px，默认倾斜 -1 度，阴影 5px 5px 0 铅笔灰 15%；hover 时旋转回到 0 度、上浮 4px、阴影扩到 8px，过渡 200ms；右上角可放 32px 的手绘圈，hover 时出现并放大到 1.25。上方便签即此组件。

Sketch Input

表单与写作输入。透明底、仅底部 2px 波浪线（用 repeating-linear-gradient 模拟）、无左右描边、padding 8px 4px、16px 衬线；聚焦时波浪线转湖蓝并加粗到 3px，不改变盒子尺寸，不加外环。

Hand Underline + Cross Hatched Shadow

手绘下划线：一条 2px 的虚线或单周期 SVG 波浪线，长度比文字宽出 8%、下沉 2px、允许 1 度倾斜；hover 时从长度 0 展开到 100%，时长 200ms，用 steps 或线性缓动而不是弹簧——下方标题下那条就是。排线阴影：一层 45 度与 -45 度的 1px 线条重复图案（间距 6px、铅笔灰 15%），不加模糊；仅用于需要「体积」的插图，界面元素用硬偏移即可。

被手绘下划线标记的一句话

可为与不为

可为

  • 边框用虚线或波浪，不用完美直线
  • 卡片允许 ±1 度倾斜
  • 阴影用硬偏移或排线，不用模糊
  • 纸色底，不用纯白
  • 动效 150 到 200ms，短促直接
  • 标题用手写体，正文用衬线

不为

  • 不要用完美直线与对称圆角
  • 不要用纯白背景
  • 不要用渐变与玻璃模糊
  • 不要用高饱和色
  • 不要用超过 200ms 的平滑动画
  • 不要让不规则变得有规律
