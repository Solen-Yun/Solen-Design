霓虹复古 NEON RETRO

粉紫青三色渐变、扫描线、故障位移：一个坏掉的 1987 年系统。

粉青双色重影扫描线网格0.24em 宽字距600ms 慢漂浮

霓虹复古是 80 到 90 年代未来想象的回收：粉、紫、青三色渐变铺底，霓虹发光必须是双色重影（粉与青各偏移 1 到 2px），扫描线与网格背景暗示 CRT 与透视地面。它的交互语汇也来自旧系统——点击时元素做 2px 的错位抖动，像错误弹窗。

动效刻意慢：hover 用长时间漂浮而不是快速响应。禁止单调灰、禁止现代极简、禁止单色发光。右边的卡片可以悬停，按钮可以按下去——感受那个 2px 的错位。

颜色

粉是第一主色与发光重影的暖侧，青是冷侧——两者成对出现，不可单独使用；带紫的近黑底让两支霓虹都能浮起来；紫罗兰是渐变的中间站；薄荷绿管成功与在线；柠檬黄只给需要立刻被看到的关键数值，面积最小。

字体

标题用方形无衬线 Space Grotesk；小标签用等宽全大写加 0.24em 的宽字距——宽字距是这套风格最强的年代信号。正文、标签与数据用 JetBrains Mono，让整页像一份从旧系统导出的日志。

组件

Neon Button

主行动按钮。透明底、1px 荧光粉描边、4px 圆角，12px 等宽全大写 0.24em、padding 12px 24px，文字荧光粉带双色文字发光。hover 时填充粉 12%、上浮 4px、发光扩到 24px，过渡 600ms ease-out（慢漂浮，不能快）；按下时元素做 2px 的 glitch 错位并在 120ms 内复位。

Glitch Card

内容卡与面板。粉 6% 填充、4px 圆角、1px 青 30% 描边、内边距 24px，1px 粉 20% 的偏移重影（2px 2px 0）；标题 24px/500 带双色文字发光，正文 13px 等宽、粉白 75%。hover 时描边转粉 60%、重影换成青、上浮 2px，过渡 600ms。上方演示卡即此组件。

Grid Floor + Chrome Text

透视网格与扫描线背景：底层 4px 间隔的青色 6% 横线（扫描线），再叠 40px 间隔的品红 8% 竖线构成网格；透视用 perspective(400px) rotateX(60deg) 做出地平线；整层 pointer-events none——本页每一寸都叠着它。铬金属标题：background-clip: text 填粉→紫→青三段渐变，叠 2px 深色描边与双色重影；仅用于首屏主标题，单页最多一处，正文绝不使用。本页 H1 即铬字，移上去试试。

Status Strip

底部状态条。固定在视口底部、高 32px、深夜底、顶部 1px 青 20% 描边；左侧 12px 等宽薄荷绿文字显示「在线」，右侧显示时间与坐标——像旧系统的状态栏。本页底部这条即此组件。

可为与不为

可为

  • 粉紫青三色渐变
  • 发光必须是粉青双色重影
  • 叠扫描线与透视网格
  • 标签全大写、字距 0.24em
  • hover 用 600ms 慢漂浮
  • 点击做 2px 的 glitch 错位

不为

  • 不要用单调灰配色
  • 不要做现代简约风
  • 不要省略霓虹发光
  • 不要用正式字体
  • 不要只用单色发光
  • 不要让交互过快
