风格 35 · 浅色版面

柔和野兽派 NEO-BRUTALIST SOFT

骨架仍是硬阴影与零圆角，但换成灰边、灰影与粉彩色。

2px 灰描边20% 灰硬阴影粉彩强调零圆角保留

柔和野兽派保留了野兽派的骨架：零圆角、硬偏移阴影、按下时位移等于偏移并归零。但它把三个最刺眼的参数降了一档——边框从 4px 纯黑降到 2px gray-800，阴影从纯黑降到 20% 的黑，配色从霓虹换成粉彩（pink-400 而非 #ff006e）。

结果是一套可以放进企业产品里的野兽派：仍然有物理感，但不再喊叫。底色也从纯白退到浅灰。右边这张卡是真的——hover 看描边变柔粉，按下去阴影照旧归零。

颜色

深灰替代纯黑做文字、边框与阴影基准——长时间阅读更舒服；浅灰底让白卡有依托；柔粉是 pink-400 的柔和版，管主强调与选中态但不做大面积填充；青柠管 hover 高亮与成功，天蓝管链接，与柔粉形成冷暖对位；琥珀频率最低。

组件

Soft Block Button

主行动按钮。白底、深灰文字、2px gray-800 描边、零圆角、4px 灰色硬阴影（黑 20%），15px/700、padding 12px 24px。hover 时填充换成柔粉、文字转白、阴影扩到 6px，不上浮也不过量位移；按下时位移 4px 4px 且阴影归零。过渡 150ms ease-out。

Soft Brutal Card

内容卡与功能卡。白底、2px gray-800 描边、零圆角、内边距 24px、4px 灰色硬阴影；标题 24px/700 深灰，正文 15px/500 灰 60%。hover 时上浮 2px、阴影扩到 6px、描边转柔粉。过渡 150ms。上方演示卡即此组件。

Quiet Input

表单输入。白底、2px gray-800 描边、零圆角、padding 10px 14px、15px 字；聚焦时描边转天蓝并加 4px 的灰硬阴影，不改变盒子尺寸。

Pastel Tag

标签与状态。粉彩填充（柔粉、青柠、天蓝或琥珀之一，取 15% 透明度作底）、零圆角、2px gray-800 描边、13px/700、padding 2px 8px；文字用深灰，不用白色。演示卡左上角与下面这排都是它。

可为与不为

可为

  • 2px gray-800 边框，不用纯黑
  • 阴影用 20% 黑而不是实色
  • 粉彩强调，每屏不超过两种
  • 保持零圆角与硬偏移阴影
  • 浅灰底，不用纯白
  • 过渡 150ms，短促

不为

  • 不要用圆角
  • 不要用纯黑边框
  • 不要用高饱和纯色
  • 不要用纯黑背景
  • 不要用渐变
  • 不要用模糊阴影
