蒸汽朋克 STEAMPUNK

黄铜、铜管、铆钉与齿轮：一台还在冒气的维多利亚机器。

铆钉面板黄铜渐变按钮齿轮 20s 慢转压力表盘读数

蒸汽朋克来自维多利亚时代的工业机械：深棕底上装黄铜与铜的金属件，文字用奶油色，衬线字体承担全部排版，边框是铜色半透明细线并配铆钉圆点，按钮用黄铜上下渐变模拟受光的金属面，黄铜光泽靠 0 0 15px 的暖色外发光表现。它禁止纯白背景、禁止现代极简、禁止霓虹与荧光、禁止扁平无质感。

右边这台仪表是真的：表盘 12 个刻度、铜色指针按压力偏转；下方黄铜按钮 hover 时发光扩到 30px，渐变整体提亮。

颜色

黄铜是主金属色，管按钮、描边与文字高光；深棕是皮革与旧木的颜色，做页面底与面板；铜是第二金属色，管管道、铆钉与边框；奶油色管主要文字与标签纸色；铁灰管次级金属件与压印槽；铜绿是铜氧化的绿，用于「已使用」的痕迹与状态。

组件

Brass Button

行动按钮。黄铜上下渐变（#c9b84e 到 #8a7d32）、深棕文字、4px 圆角、1px 铜色 50% 描边、18px/700、字距 0.08em、padding 14px 32px，外发光 0 0 15px 黄铜 30% 加 inset 0 1px 0 白 30% 的顶部高光。hover 时发光扩到 30px、渐变整体提亮；按下时渐变反向并加深内阴影。过渡 200ms。

Riveted Panel

铆钉面板（核心组件）。深棕填充、4px 圆角、1px 铜色 50% 描边、内边距 32px，边缘每隔 24px 放一个 6px 的铜色圆点（铆钉），四角各一个 8px 的铆钉。外发光 0 0 15px 黄铜 30%。耳钉必须等距——手工感不等于随意。

Gear Ornament

齿轮装饰。一个 48 到 120px 的齿轮（12 到 20 个齿，用 clip-path polygon 或 SVG），填黄铜或铜，中心挖一个 20% 直径的孔，缓慢旋转（20s linear 无限）。可两三个咬合排列。单屏不超过三处，旋转必须慢，快转会变成游乐场。

Pressure Gauge

压力表盘读数。96 到 160px 的圆形表盘：黄铜描边 3px、奶油色盘面、12 个刻度（每 30 度一个，长 8px）、一根铜色指针按数值旋转、中心一个 8px 铆钉。数值用衬线 18px 放在表盘下方——hero 里那台就是。

Pipe Divider

管道分隔。一条 8px 高的铜色横条，两端各一个 12px 的圆形法兰（带 4 个铆钉），中间可加一个 90 度弯头。它替代普通分隔线，用来表达「这是同一套管路」。

可为与不为

可为

  • 深棕底配黄铜与铜
  • 衬线字体，宽字距像铭牌
  • 面板边缘必须有铆钉
  • 按钮用黄铜渐变显受光
  • 黄铜光泽用暖色外发光
  • 齿轮转动 20s 起，很慢

不为

  • 不要用纯白背景
  • 不要做现代极简
  • 不要用霓虹或荧光色
  • 不要用扁平无质感的设计
  • 不要让整屏都是黄铜
  • 不要让齿轮转快

图像

工业摄影与机械插画：齿轮、管道、压力表、飞艇、怀表。必须有金属反光与暖调。允许把照片处理成棕褐单色。不使用现代城市、极简产品与冷调摄影。
