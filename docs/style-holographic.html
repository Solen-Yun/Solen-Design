风格 86 · 深色版面

全息渐变 HOLOGRAPHIC

彩虹色谱在深空底上随角度流动：像镭射膜在光里翻转。

三色以上渐变Spectrum Shift深空底光球禁纯色块

全息渐变模拟镭射全息膜的棱镜折射：底色是深紫或深海军，所有元素都带三色以上的渐变，而且渐变会随交互横向流动——这是它独有的规则叫 Spectrum Shift，用 background-size: 200% 加 hover 时 background-position 从左侧移到右侧来实现，模拟箔片随视角变色。

它禁止纯色元素（没有渐变的实心块在这套语言里等于失去材质）、禁止浅色背景（会直接杀掉全息感）、禁止低饱和色、也禁止没有光晕的锐角。

棱镜之内

渐变随视角流动，纯色块在这套语言里等于失去材质。

配色方案

  • Deep Space#0a0a1f
  • Deep Violet#1a0b2e
  • Hologram Violet#a855f7
  • Magenta#ff0080
  • Cyan#00d4ff
  • Gold#ffd700

颜色

深空底深到让所有虹彩都能浮起来；深紫做次级面板底；全息紫是渐变的主站与品牌色，最常用于按钮起点；品红是光谱的暖端，让渐变跨过紫与青；青是光谱的冷端，渐变里最亮的一站；金是高光与「箔片反光」，只在渐变中出现，不做填充；霓虹绿是光谱的第五站，让渐变多一层不规则。

  • Deep Space页面底。深到让所有虹彩都能浮起来。
    #0a0a1f--color-deep-space
  • Deep Violet次级面板底，比深空偏紫。
    #1a0b2e--color-deep-violet
  • Hologram Violet渐变的主站与品牌色，最常用于按钮起点。
    #a855f7--color-hologram-violet
  • Magenta光谱的暖端，用于让渐变跨过紫与青。
    #ff0080--color-magenta
  • Cyan光谱的冷端，是渐变里最亮的一站。
    #00d4ff--color-cyan
  • Gold高光与「箔片反光」，只在渐变中出现，不做填充。
    #ffd700--color-gold

虹彩光晕 0 0 40px rgba(168,85,247,0.35)、品红光晕 0 0 32px rgba(255,0,128,0.30)。相邻元素不得连续出现两个无渐变的纯色块。

组件

Spectrum Button

主行动按钮。紫到品红到青的三色线性渐变填充（每站约 1/3）、白色文字、999px 全圆角、无描边，15px/700、padding 12px 28px，外发光 0 0 32px 品红 30%。渐变设 background-size: 200% auto，hover 时 background-position 从 left 移到 right（1.2s ease），这就是 Spectrum Shift。按下缩放 0.98。

Prism Card

内容卡。白 6% 填充、20px 圆角、1px 白 12% 描边、内边距 24px，外加一层紫到青的柔光晕（0 0 40px 紫 35%）。顶部放一条 2px 的三色渐变横线（紫→品红→青）作为「箔片边缘」。hover 时渐变横线的 background-position 反向流动，卡片外发光转品红。hero 里的卡片就是。

Spectrum Text

渐变标题。用 background: linear-gradient(90deg, 紫, 品红, 青, 金) 配 background-clip: text 与 color: transparent，background-size 200%，hover 时位置移动。仅用于首屏与章节标题，正文绝不使用（可读性会崩）。

Glass Field

输入框。白 6% 填充、16px 圆角、1px 白 15% 描边、padding 12px 18px、15px 字。聚焦时描边换 1px 渐变（用 border-image 或伪元素），并加 0 0 0 3px 的紫 25% 环——焦点环必须带 offset 到深空色，否则在暗底上看不见。

Iridescent Orb

装饰光球。96px 到 240px 的圆，径向渐变从紫中心渐隐到品红与青，无边框，外发光 0 0 60px 紫 30%。放在卡片背后或区块角落，允许溢出容器。单屏最多两个——hero 里那两颗就是。

可为与不为

可为

  • 所有元素带三色以上渐变
  • 深紫或深海军底
  • 用 Spectrum Shift 让渐变横向流动
  • 锐角必须配光晕
  • 焦点环带深空色 offset
  • 高饱和色，保持虹彩强度

不为

  • 不要用无渐变的纯色块
  • 不要用浅色或白色背景
  • 不要用低饱和或灰调色
  • 不要给锐角不加光晕
  • 不要连续两个以上的非渐变元素
  • 不要让焦点环在暗底上消失

图像

镭射材质、棱镜、箔片、流体与晶体。所有图像必须带多色虹彩。允许把照片叠一层 30% 的彩虹渐变后用 overlay 混合。不使用单色摄影、纯白背景与灰调插画。
