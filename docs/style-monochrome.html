风格 91 · 浅色版面

单色极简 MONOCHROME

没有颜色：层次全靠五档灰、字重与负空间。

五档灰无色相字重 ≤500700ms 只改颜色1px #e5e5e5 结构

单色极简是最严格的减法：整个页面只有黑、白与三档灰（#111111、#444444、#666666、#999999、#cccccc、#e5e5e5）。层级靠三件事建立——字重对比（300 对 500）、灰度深浅、以及负空间。

它禁止任何带色相的颜色、禁止全圆角、禁止重阴影、禁止渐变。节奏刻意放慢：过渡 700ms 的 ease-in-out，而且只改颜色不改位置，因为在这套语言里位移本身就是噪音。

APPROACH / 04

灰度的五档

墨、纸、三档灰。层级由字重与留白共同完成，颜色不在场。

配色方案

  • Ink#111111
  • Deep Grey#444444
  • Mid Grey#666666
  • Light Grey#999999
  • Soft Grey#cccccc
  • Border Grey#e5e5e5

颜色

墨色是主文字、主按钮与最深区块，整套风格的唯一「强调」；极浅灰白做页面底，让卡片能靠 #f5f5f5 分层；深灰比 #666666 再深一档，做 hover 后的次级文字；中灰管正文与说明文字；浅灰管元数据与占位符；边界灰承担所有 1px 分隔线——几乎不可见，但缺了结构会散。

  • Paper页面底。极浅的灰白，让卡片能靠 #f5f5f5 分层。

层次靠边框：none — a 1px #e5e5e5 border does the work；最高只允许 0 1px 2px rgba(17,17,17,0.04)。

组件

Mono Button

主行动按钮。墨色填充、纸色文字、2px 圆角、无描边、无阴影，11px/500、全大写、字距 0.2em、padding 16px 32px。hover 时填充转 #2a2a2a；按下再暗一档。过渡 700ms ease-in-out，只改颜色。

Grey Card

内容卡。#f5f5f5 填充、2px 圆角、1px #e5e5e5 描边、内边距 40px，无阴影。标题 32px/300 墨色、字距微开；正文 13px/300 中灰、行高 1.8。hover 时填充转 #ebebeb、描边转 #cccccc、正文转 #444444，全部在 700ms 内完成，元素不动。hero 里的卡片就是。

Hairline Divider

极细分隔线。1px #e5e5e5 横线，横跨内容宽，不做渐变淡出。它是这套风格唯一的结构工具，比留白更明确、比阴影更安静。

Ghost Field

输入框。纸色填充、2px 圆角、1px #e5e5e5 描边、padding 14px 16px、13px 字。占位符 #999999。聚焦时描边转墨色并保持 1px，不加外环、不改背景。

Weight Ladder

字重层级规则。标题只用 300，正文只用 300，标签与按钮用 500，元数据用 400。禁止出现 600 以上字重——一旦出现，灰度的细腻感会被压死。层级靠字号、灰度与留白三重叠加。

可为与不为

可为

  • 只用五到六档灰，无色相
  • 层级靠字重与灰度
  • 字重不超过 500
  • 过渡 700ms，只改颜色
  • 边框 1px #e5e5e5
  • 留白作为主要构图手段

不为

  • 不要用任何带色相的颜色
  • 不要用全圆角
  • 不要用重阴影
  • 不要用渐变
  • 不要在 hover 时位移元素
  • 不要用 600 以上的字重
