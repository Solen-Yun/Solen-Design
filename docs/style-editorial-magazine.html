风格 03 · 浅色版面

编辑杂志风 EDITORIAL MAGAZINE

暖米纸上的衬线杂志版面，秩序来自留白与一条发丝线，而不是分栏装饰。

衬线标题发丝线留白单一暖色点缀直角

编辑部风格来自印刷媒体：高端杂志与报纸的版面语言。它把全部表现力放在字号级差、衬线标题与留白的呼吸感上，颜色退到只剩一个柔和的墨黑与一层暖米底。

层次靠透明度（文字 /60、/40，边框 /10）和字距（标题收紧，标签放开）建立；深度靠留白与 1px 细线，不用阴影、不用圆角、不用渐变。整套系统只有一个暖色点缀，出现面积控制在一屏的 2% 以内，用于引文标记与选中态。

秩序来自留白与一条发丝线。

配色方案

  • Ink#1c1c1c
  • Paper#f9f8f6
  • Graphite#6b7280
  • Mauve#816d70

颜色

颜色退到只剩一个柔和的墨黑与一层暖米底。层次靠透明度建立：文字 /60 与 /40，边框 /10，而不是引入新颜色；唯一暖色是莫夫色，只出现在引文标记与选中态。

  • Ink正文、标题、1px 边框与反色区块的底色。全站唯一的深色，替代纯黑以免印刷感过硬。
    #1c1c1c--color-ink
  • Paper页面画布。所有默认背景都用它，比冷白更接近纸张，也避免长时间阅读的刺目感。
    #f9f8f6--color-paper
  • Graphite次要文字、题注、日期与辅助说明。层级需要后退时用它，而不是缩小字号。
    #6b7280--color-graphite
  • Mauve全站唯一暖色点缀。只出现在引文标记与选中态，面积不得超过一屏的 2%。
    #816d70--color-mauve

表面层级：0 Paper #f9f8f6，1 Ink Band #1c1c1c（反色区块：页脚、CTA 条、引文段）。层级表达只有一条发丝线：1px solid rgba(28,28,28,0.1)，不用阴影。

字体

衬线是这套风格的识别核心，缺了它就只剩一页灰底文字；无衬线始终与衬线标题成对出现，承担所有功能性文本。

间距与版面

基础单位 8px，密度 airy。单栏 1200px 上限，内部 8 栏网格；hero 为 45/55 左右分栏，正文区块单栏或 2 栏，栏间距 48px。区块间距 96 至 128px，阅读宽度控制在 34em 以内；标题与正文硬对齐，不做三栏以上的密集排版。

组件

Contrast Lockup Button

主行动按钮。墨黑填充、暖米纸色文字、1px 墨黑描边、直角。字级 12px、字重 500、全大写、字距 0.2em；padding 16px 32px。hover 时填充与文字互换，过渡 200ms。页头与下面两个样本即此组件。

Underline Text Link

次级行动与导航。无填充无边框，12px 全大写 0.2em 字距。下划线是一条 1px 当前色线，从右向左以 scale-x 0 起步，hover 时从左展开到 1，时长 500ms，缓动 cubic-bezier(0.16, 1, 0.3, 1)。

VIEW ALL

Hairline Card

文章卡片与列表项。顶部 1px 墨黑 /10 边线，padding-top 24px，无圆角无阴影无背景。hover 时边线加深到 /40，过渡 500ms；行内左侧石墨色日期，右侧衬线标题与石墨摘要。

Section Label

区块分类与栏目名。12px 全大写、0.2em 字距、石墨色；前面接一条 24px 长、1px 宽的墨黑横线，线与文字间距 12px。不加大写以外任何装饰。

SECTION LABEL

Pull Quote

段落中的引文强调。28 至 36px 衬线斜体、行高 1.3、左右各缩进 24px、左侧 2px 墨黑竖线、上下留白 32px。引号用莫夫色，字号为正文的 1.5 倍。首屏右侧即此组件。

可为与不为

可为

  • 标题用衬线、正文用无衬线，两者始终成对出现
  • 用透明度构建灰度：文字 /60 与 /40，边框 /10，而不是引入新颜色
  • 区块间距至少 96px，容器内边距 24px 到 48px
  • 标签统一 12px 全大写 0.2em 字距，不加粗
  • 斜体只用于副标题与引文，不用于正文强调
  • 交互只用下划线展开与颜色反转，时长 500ms 上下

不为

  • 不要引入其它彩色强调，只允许莫夫色用于引文标记和选中态
  • 不要用阴影表达层次，深度只来自留白与 1px 线
  • 不要用纯黑 #0a0a0a 或冷白 #fafafa 做主色
  • 标题不得使用无衬线字体
  • 不要用任何圆角，包括卡片、按钮与输入框
  • 不要用渐变、背景图案或装饰性几何

图像

以摄影为主，低饱和、暖调、full-bleed 满幅裁切，人物与静物都可以，但必须能读成杂志跨页。不使用插画、图形纹样与图标系统；需要图示时用 1px 墨黑线框代替，保持纸面感。
