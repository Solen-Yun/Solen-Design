风格 45 · 深色版面

机甲风 MECHA

驾驶舱面板：切角金属、粗边框、警告黄与军绿。

clip-path 切角4px 警告黄边条等宽大写铭牌字零模糊硬阴影

机甲风来自高达与 EVA 的机设语言：军绿与深蓝海军作底，警告黄与危险红作强调，界面像一块被切角、铆接、贴了警示标的面板。它的技术特征是切角（clip-path polygon 切掉一角或两角）、粗边框（2px 起，左侧常加一条 4px 的强调边）、以及零模糊的硬阴影。

字体必须等宽大写并放宽字距，因为这是设备铭牌。禁止柔和圆角、禁止粉色与浅色调、禁止花哨渐变与毛玻璃、禁止手写体。右边这块装甲面板是真的——左侧的黄条会增宽，角标会亮起来。

颜色

海军蓝是机体涂装的主色；装甲板的哑光军绿做次级面板与边框；警告黄是工业警示色——左侧边条、按钮文字与关键读数都用它；危险红出现即表示状态异常；信号绿是仪表上的指示灯，管「系统在线」；深绿是绿色的暗部，压在亮绿上写字。

  • Navy主底与深色面板。机体涂装的主色。
    #1a2744--color-navy
  • Military Green次级面板与边框。装甲板的哑光绿。
    #4a5c3a--color-military-green
  • Hazard Yellow主强调：左侧边条、按钮文字与关键读数。工业警示色。
    #fbbf24--color-hazard-yellow
  • Danger Red警报、过载与删除。出现即表示状态异常。
    #ef4444--color-danger-red
  • Signal Green正常运转与「系统在线」，像仪表上的指示灯。
    #56ed40--color-signal-green
  • Deep Green绿色的暗部，用于压在亮绿上的文字与图表第二序列。
    #069006--color-deep-green

硬阴影零模糊：4px 4px 0 #1a2744、黄色档 4px 4px 0 rgba(251,191,36,0.30)；按下 2px 2px 0 #1a2744。切角统一 14px 或 20px。

组件

Armor Button

主行动按钮。深灰填充、警告黄文字、2px 警告黄 60% 描边、零圆角、4px 4px 0 海军蓝硬阴影，等宽 11px/700、全大写、字距 0.16em、padding 12px 32px；clip-path 切掉左上与右下各 14px。hover 时填充硬切到警告黄、文字转海军蓝；按下位移 2px 2px 且阴影缩到 2px。过渡 100ms linear。

Armor Panel

卡片与仪表面板。海军蓝填充、2px 军绿描边、左侧 4px 警告黄边条、零圆角、内边距 24px，硬阴影 4px 4px 0 警告黄 30%；右下角切掉 20px；右上角一个 32px 的 L 形角标，hover 时角标向内侧移动 2px 并升到 100%；hover 时左边条从 4px 增宽到 10px，过渡 150ms linear。上方演示面板即此组件。

Hazard Stripe + Readout Gauge

警示条纹：高 8px 的斜条纹带，45 度重复的警告黄与海军蓝（各 12px 宽），用于面板顶部或区块之间；纯平面的工业标记，不带圆角与阴影——本页标题下那条就是。读数仪表：12px 高的分段条，分成 10 格、每格间隔 2px、零圆角，底槽为军绿 30%；填充按状态取荧光绿、警告黄或危险红；左侧 10px 全大写标签，右侧等宽数值。

Cockpit Frame

页头与座舱框架。高 64px、海军蓝底、底部 2px 军绿描边、顶部 8px 警示条纹；左侧 20px 等宽大写字标，中部放三到四个系统的状态灯（8px 圆点加 10px 标签），右侧一个 Armor Button；整体零圆角。

可为与不为

可为

  • 切角用 clip-path，不用圆角
  • 面板左侧 4px 警告黄边条
  • 等宽大写、字距 0.08 到 0.16em
  • 硬阴影零模糊
  • 军绿配海军蓝，警告黄作强调
  • 所有尺寸取 4 的倍数

不为

  • 不要用柔和的圆角
  • 不要用粉色或浅色调
  • 不要用花哨渐变与毛玻璃
  • 不要用手写体或花体字
  • 不要用模糊阴影
  • 不要在同一屏混两种切角尺寸
