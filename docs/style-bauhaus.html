风格 14 · 浅色版面

包豪斯风格 BAUHAUS

形式追随功能：圆、方、三角与三原色，其余一律删掉。

基本几何三原色零阴影全部左对齐

包豪斯是一套功能主义的设计纪律，不是一种装饰。它的规则极简到近乎苛刻：只用基本几何（圆、方、三角）、只用三原色加黑白、不用阴影、不用渐变、不用装饰性插图。层次通过尺度与色块面积建立，文字主导版面且一律左对齐。

与几何大胆风的区别在于克制——包豪斯不允许为了动势而旋转与重叠，每个元素都必须有功能位置。右边是一个按规格搭的区块：黄色实心色块承载文字，黑白摄影裁成圆形，一个蓝色半圆只负责构图，不遮挡任何东西。

FORM / FUNCTION

圆、方、三角。

每个元素都有一个功能位置。

配色方案

  • Black#000000
  • White#ffffff
  • Red#ff0000
  • Yellow#ffcc00
  • Blue#0000ff

颜色

只有三原色加黑白，五支一组的封闭系统。黑承担文字与描边，白是画布与反白；红是警示与主强调、全屏面积不超过 20%；黄承载深色文字做区块底；蓝给链接与信息区块，是三原色里最冷静的一支。

  • Black文字、描边与最深色块。功能主义需要绝对的对比。
    #000000--color-black
  • White画布与反白文字。不做灰阶过渡。
    #ffffff--color-white
  • Red警示与主强调。全屏面积不超过 20%。
    #ff0000--color-red
  • Yellow高亮与区块底色，用于承载深色文字。
    #ffcc00--color-yellow
  • Blue链接与信息区块，是三原色里最冷静的一支。
    #0000ff--color-blue

一套没有阴影的系统：elevation: none。层次全部来自字号与色块面积；一个色块只允许一种颜色，禁止在同一块内混两种。

字体

全站唯一字体 Futura，几何无衬线，只用 400 与 700。标题左对齐、字距收紧；标签全大写、字距放开 0.14em。

组件

Function Button

行动按钮。纯黑填充、白字、零圆角、无阴影、无描边；14px/700、全大写、0.14em 字距、padding 14px 28px。hover 时填充换成红并保持白字；按下时整体位移到 1px 描边状态（无位移动画）。过渡 120ms。

Primary Block

色块分区与信息卡。整块填三原色之一，零圆角、无描边、无阴影、内边距 32px；块内文字用黑或白按对比度选择，字号至少 18px。一个区块只用一种颜色，禁止混两种。上方演示里的黄色块即此组件。

Geometric Frame

图片与内容框架。容器零圆角、1px 黑描边（或无描边），内部图像可为圆形或半圆裁切；允许在区块角落放一个 96px 到 160px 的实心圆或三角作为构图元素，但不得遮挡文字。上方演示的蓝半圆即此用法。

Type Stack

标题与正文排版组。一律左对齐：48 到 72px 标题，上方 12px 全大写 0.14em 标签，两者间距 16px；正文单栏、行长不超过 70 字符。禁止居中与右对齐。本页每一节的排版都按这个组执行。

可为与不为

可为

  • 只用圆、方、三角三种形状
  • 只用三原色加黑白
  • 一切左对齐
  • 零圆角、零阴影、零渐变
  • 层次靠字号与色块面积
  • 标签 12px 全大写 0.14em

不为

  • 不要旋转或重叠元素
  • 不要用渐变与阴影
  • 不要混用两套圆角
  • 不要引入三原色之外的颜色
  • 不要用装饰性插画
  • 不要居中排版

图像

几何构成与黑白摄影。允许把照片裁成圆形或半圆嵌入色块。不使用彩色摄影、装饰插画与任何非基本几何的形状。
