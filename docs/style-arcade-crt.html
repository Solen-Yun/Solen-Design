街机 CRT ARCADE CRT

一块还亮着的街机显示器：扫描线、曲面、荧光与色散。

全屏扫描线高饱和荧光色霓虹光晕阴影RGB 色散边缘

街机 CRT 模拟 80 到 90 年代的街机显示器：全屏扫描线覆盖层、桶形曲面（用轻微 scale 与圆角模拟）、高饱和荧光色、以及 RGB 色散造成的边缘彩边。它的技术配方是固定的——所有内容区都必须叠扫描线、字体必须是等宽或像素、只用高饱和荧光色、阴影只能是霓虹光晕、渐变只能是霓虹到暗。

禁令同样固定：不许柔和低饱和、不许衬线或常规无衬线正文、不许超过 4px 的圆角、不许细微阴影。右边这块面板是真的：标题带文字发光，hover 时描边与光晕都会涨。

颜色

老式绿磷屏的荧光绿管主文字与荧光；近纯黑的屏黑让荧光层看起来在自发光；品红是 RGB 色散的暖侧与「加分」状态；青是色散的冷侧与数据；警报红管生命值与失败，是屏幕上最刺的颜色；金币黄管分数、金币与高亮，用于「闪一下」的地方。

发光只用霓虹：0 0 20px rgba(57,255,20,0.60)、0 0 20px rgba(255,0,255,0.55) 与文字 0 0 8px rgba(57,255,20,0.70)。细微阴影不存在。

组件

Scanline Overlay

扫描线覆盖层（签名）。全页固定覆盖一层 repeating-linear-gradient，每 3px 一条 1px 的黑色 45% 横线，pointer-events: none。可选再加一条每 3 秒从上到下扫过的亮带（亮 8%、周期 3s、linear）。这层必须覆盖所有内容区，缺了它就不是 CRT——本页背景就是。

Tube Frame

显像管外框。页面最外层容器：24px 圆角、2px 深灰边框、inset 0 0 80px 黑 60%（模拟显像管暗角）加外层 0 0 120px 荧光绿 8% 的溢出光。内部再套一层 scale(0.995) 的轻微桶形错觉。

Neon Panel

内容面板。屏黑 90% 填充、4px 圆角、1px 荧光绿 40% 描边、内边距 20px，外发光 0 0 20px 荧光绿 60%。标题 26px 带 0 0 8px 文字发光，正文 12px 荧光绿 85%。hover 时描边升到 80%、发光扩到 32px。hero 里的面板就是。

Arcade Button

行动按钮。品红或荧光绿填充、屏黑文字、2px 圆角、12px 全大写 0.12em、padding 10px 20px，外发光 0 0 16px 同色 60%。hover 时发光扩到 28px 并加一道 60ms 的 RGB 色散抖动；按下时位移 1px 且发光收到 8px。过渡 80ms linear。

Score Readout

分数与状态读数。10px 等宽全大写 0.12em，荧光绿或金币黄，带 0 0 8px 文字发光。格式为「SCORE 0012400 / HI 0098000」，数值部分用金币黄。它可以在区块角落常驻，像街机的计分条。

Chromatic Edge

色散边缘。给标题或按钮叠两层文本副本：一层偏移 -2px 用品红、一层 +2px 用青，混合模式 screen，不透明度 60%。静置时偏移 2px，hover 时硬切到 3px 并抖动一次。

GAME OVER

可为与不为

可为

  • 全屏叠扫描线
  • 等宽或像素字体
  • 只用高饱和荧光色
  • 阴影只能是霓虹光晕
  • 渐变只能霓虹到暗
  • 圆角不超过 4px（显像管除外）

不为

  • 不要用柔和低饱和色
  • 不要用衬线或常规无衬线正文
  • 不要用超过 4px 的圆角
  • 不要用细微阴影
  • 不要用非霓虹到暗的渐变
  • 不要漏掉扫描线

图像

街机与复古游戏的像素图、屏幕截图、低分辨率渲染。图像必须带扫描线与轻微色散。不使用现代高清摄影与平滑插画。
