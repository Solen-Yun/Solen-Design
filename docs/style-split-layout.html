布局模式 03 · 对照版面

分屏布局 SPLIT LAYOUT

两块内容各占一半，靠对比产生张力，靠平衡避免刺眼。

两半对照反色按钮留白中缝非对称允许移动堆叠

分屏布局用一条中缝把视口切成两半，两侧放互相映照的内容：图与文、旧与新、问题与答案。它的规则全是平衡问题——两侧内容绝不能完全相同（那是无意义分屏），视觉重量不能严重失衡（一边满页面一边空白），阅读顺序不能被中缝切断，分割线不能突兀到抢戏。

移动端必须放弃分屏转为上下堆叠，否则每侧只有 180px 宽。允许非对称分屏（如 40:60）来表达主次。下面是一个按规格跑的分屏面板。

布局实演

两侧构成对照而不是重复：一暗一亮、一问题一答案，标签取蓝与红，两侧标题同字号；按钮与所在侧反色，hover 只改亮度不做位移。用上方按钮切换：对称 1:1、非对称 2:3（40:60 表达主次），以及手机堆叠——堆叠后标签保留、顺序与阅读一致。

Before

改版之前

旧版把所有功能塞进同一条导航，找东西靠记忆，第一次来的用户要在页面里迷路三次。

After

改版之后

新版按任务重组导航，任何功能三步内到达；首次访问的用户在测试里全部一次找对入口。

颜色

整页的基本张力来自墨白成对：深色一侧负责吸住视线，浅色一侧负责呼吸。红与蓝是一对结构性对立——「之后」取红、「之前」取蓝，永远成对出现；绿色只说正向结果；琥珀标注需要注意的差异项。

  • Ink深色一侧的底与文字。用于制造两侧的最大对比。
    #0f0f0f--color-ink
  • White浅色一侧的底。与墨成对，构成整页的基本张力。
    #ffffff--color-white
  • Red「之后」「新」这一侧的强调，与蓝形成对立。
    #ff4757--color-red
  • Green正向结果与成功对比项。
    #2ed573--color-green
  • Blue「之前」「旧」这一侧的强调，与红形成对立。
    #1e90ff--color-blue
  • Amber需要注意的差异项与高亮。
    #ffa502--color-amber

表面层级：0 Ink Half #0f0f0f，1 White Half #ffffff，2 Image Half（整幅照片）。阴影两级：面板 0 12px 32px rgba(15,15,15,0.10)，按钮 0 4px 12px rgba(15,15,15,0.15)；中缝优先用留白，需要线时用 1px 深色 10% 且不贯穿全高。

字体

全站唯一字体 Inter。两侧标题必须同级同字号，否则视觉重量会失衡——这条比任何字号选择都重要。

间距与版面

基础单位 8px，密度 comfortable。上限 1440px，首屏 100vh 分两半；内容区可用 40:60 非对称表达主次。每侧内边距 48px（移动端 24px）、内容垂直居中、单列、行宽不超过 34em；中缝对齐整页网格。移动端（小于 768px）放弃分屏转单列堆叠。

组件

Split Panel

分屏容器。grid-template-columns 取 1fr 1fr（对称）或 0.8fr 1.2fr（非对称），最小高度 100vh（首屏）或 600px（内容区）。每侧内边距 48px、内容垂直居中、单列、行宽不超过 34em。上面布局实演用的就是它，切换按钮可以看对称、非对称与堆叠三种形态。

Contrast Pair

两侧的成对内容。两侧必须构成对照而不是重复：一图一文、一暗一亮、一问题一答案。标签用 12px 全大写 0.08em，分别取蓝与红；两侧标题字号必须相同。实演里的「改版之前 / 改版之后」即此结构。

Split CTA

每侧的独立行动。8px 圆角、16px/500、padding 12px 24px。深色侧用白底墨字，浅色侧用墨底白字——按钮必须与所在侧反色，否则会失去分离感。hover 时只改亮度，不做位移。

Seam Divider

中缝分隔。优先用留白（48px 间隙）而不是线。需要线时用 1px 深色 10%，不贯穿全高（上下各留 15%），避免把版面切成两块互不相关的图。

Compare Row

对比行——移动端保留的对照结构。堆叠后每项上方用 12px 标签标明「之前」「之后」，颜色对应（蓝对红），堆叠顺序与阅读顺序一致。

After

可为与不为

可为

  • 两侧内容必须构成对照
  • 两侧标题同字号
  • 允许 40:60 非对称分屏
  • 中缝优先用留白
  • 按钮与所在侧反色
  • 移动端转单列堆叠并保留标签

不为

  • 不要让两侧内容完全相同
  • 不要在移动端保持分屏
  • 不要让视觉重量严重失衡
  • 不要切断阅读顺序
  • 不要让分割线突兀
  • 不要在 hover 时位移按钮

图像

一张对比性强的照片或截图占一侧，另一侧是文字或纯色块。图像比例固定（1:1 或 4:5），允许裁切但不允许拉伸。不使用两侧都放图像的对称布局，除非两张图构成明确对照。
