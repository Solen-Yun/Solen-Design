风格 55 · 深色版面

故障艺术风

画面在出错：RGB 分离、屏幕撕裂、丢帧，全都刻意保留。

RGB 双向分离transition-noneskew 撕裂按压粗左边框卡片

故障艺术风把数字错误当成美学：等宽字体全大写加宽字距，文字用 3px 的洋红与青双向 text-shadow 做 RGB 色彩分离，所有状态切换用 transition-none（帧丢失的断裂感），按钮按下时用 skew-x 加 scale-y 制造屏幕撕裂，卡片靠 4 到 8px 的粗左边框标记、hover 时换色。

它的禁令同样绝对：不许圆角、不许平滑过渡动画、不许毛玻璃与柔和渐变、不许 CMY 三色以外的装饰色、不许衬线或常规无衬线——只有等宽，阴影只能是纯色块。右边这张卡是真的——左边框会硬切颜色。

SIGNAL LOST

FRAME_DROP // 0x0A4F — 左边框 hover 硬切。

颜色

纯黑让青与洋红的分离显出重影；青是 RGB 分离的左侧通道与主文字色；洋红是右侧通道与警告色；黄是 CMY 的第三支，管高亮与丢帧标记；白只用于文字与实心色块；警报红管崩溃，频率最低。

组件

RGB Split Text

RGB 分离文字（核心组件）。等宽 900 字重全大写，正常文字为白或青，叠两层伪元素副本：一层偏移 -3px 用洋红、一层偏移 +3px 用青，不透明度 80%；静置时分离量 3px；hover 时分离量硬切到 6px 并加 1px 的垂直抖动（steps(1) 两帧）。绝不用模糊或平滑过渡。本页 H1 就是它——移上去抖一下。

Tear Button

撕裂按钮。青或洋红填充、黑字、零圆角、2px 同色描边、14px/900 全大写 0.16em、padding 10px 24px，硬阴影 4px 4px 0 对色；hover 时填充硬切到另一色（transition-none）；按下时 skewX(-6deg) 加 scaleY(0.9) 制造屏幕撕裂并位移 2px 2px。所有状态切换 transition-none。

Marked Card

粗左边框卡片。深灰 #111 填充、零圆角、4 到 8px 的左边框（青或洋红）、内边距 20px，无阴影；hover 时左边框换色从青到洋红（硬切），标题文字同步换色；边框宽度不变——变化只在颜色。上方演示卡即此组件。

Scanline Bed + Error Readout

扫描线与噪点底：全页固定覆盖两层——一层 repeating-linear-gradient 画 3px 间隔的白色 4% 横线，另一层用噪点图做 2% 的错位噪点；pointer-events: none；可选每 4 秒一次 60ms 的整体位移抖动——本页每一寸都叠着它。错误读数：12px 等宽全大写 0.16em，青色或警报红，格式固定为「ERR // 0x0A4F // FRAME DROP」；放在区块角落作环境信息；真正的错误提示必须同时给出可读的自然语言。

可为与不为

可为

  • 等宽字体，全大写加宽字距
  • 用双向 text-shadow 做 RGB 分离
  • 所有状态切换 transition-none
  • 按下用 skew-x 加 scale-y 撕裂
  • 阴影只能是纯色块
  • 装饰色只用 CMY

不为

  • 不要用任何圆角
  • 不要用平滑过渡动画
  • 不要用毛玻璃或柔和渐变
  • 不要用 CMY 之外的装饰色
  • 不要用衬线或常规无衬线
  • 不要用柔和模糊阴影

图像

故障图像：像素化的截图、错位的色带、压缩伪影、扫描线。允许把照片做 RGB 通道位移与块状压缩。不使用写实摄影、柔和插画与自然图像。
