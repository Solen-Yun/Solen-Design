风格 87 · 深色版面

生成艺术 GENERATIVE ART

一切由函数画出来：噪声、参数与缓动生成一个不重复的界面。

种子可复现HSL 旋转派生全站等宽数学缓动驱动

生成艺术用算法而非手绘来构图：近黑底上，SVG 或 canvas 用数学函数绘出圆、线与曲网格，色板由 HSL 旋转从基准紫派生，文字一律等宽，动效由数学缓动函数（而非固定 cubic-bezier）驱动，卡片是暗色玻璃，交互元素带 0 0 20px 的紫光。

它的核心原则是「参数可复现」——同一个种子必须画出同一张图，随机不等于不可控。

组件

Plotted Field

算法绘图区（核心组件）。一个 canvas 或 SVG，用数学函数绘制：圆族（半径按 sin 序列）、曲网格（参数方程）、或噪声场（simplex noise 转等高线）。线宽 1px、颜色从 HSL 派生（每次递增 30 度）、不透明度按层递减。所有参数由种子生成，同种子必须重现同一图。hero 里的曲网格就是。

Glass Card

玻璃面板。neutral-900 80% 填充、12px 圆角、1px 白 10% 描边、内边距 24px、20px 背景模糊，外发光 0 0 20px 紫 40%。标题 22px/700 紫白，正文 13px 白 75%。hover 时发光扩到 36px 并让绘图区重新生成一次（新种子）。hero 的参数卡就是。

Parameter Input

参数输入。近黑填充、8px 圆角、1px 白 15% 描边、padding 10px 14px、13px 等宽。左侧放 11px 全大写的参数名（如 SEED / FREQ），右侧可放一个 4px 宽的紫滑块。聚焦时描边转紫并加 0 0 0 2px 紫 25% 环。

Easing Preview

缓动可视化。一条小的曲线图（120×80px），画出当前缓动函数的形状（如 cubic-bezier 或指数衰减），线宽 2px 紫色，网格 1px 白 8%。旁边用等宽小字显示函数名与参数。动效由该曲线实际驱动，预览即真实。

Glow Node

发光节点。8px 实心圆（紫或派生色）带 0 0 20px 同色 60% 光晕，放在标签左端或绘图区的数据点上。hover 时光晕扩到 36px 并弹出 11px 的等宽数值提示。hero 曲网格中央那颗就是。

可为与不为

可为

  • 一切由函数与种子生成
  • 同种子必须复现同图
  • 色板由 HSL 旋转从基准紫派生
  • 全站等宽字体
  • 动效由数学缓动函数驱动
  • 卡片是暗色玻璃加紫光

不为

  • 不要用不可复现的纯随机
  • 不要用非等宽字体作正文
  • 不要用亮底
  • 不要用固定 cubic-bezier 敷衍缓动
  • 不要让绘图区压过文字
  • 不要用柔和阴影

图像

图像即算法输出：噪声场、参数曲线、点阵、网格、粒子轨迹。允许把照片按像素采样后重绘为几何图元。不使用摄影原图、柔和插画与手工装饰。
