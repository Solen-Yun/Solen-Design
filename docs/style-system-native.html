风格 23 · 浅色版面

系统原生风 SYSTEM NATIVE

大量留白、一颗系统蓝、慢到刚好的动效：让产品自己说话。

留白优先一颗系统蓝500ms 缓动产品图主角

系统原生风的核心不是元素，而是比例：内容占的面积远小于留白，产品图是唯一的主角。底色用偏冷的浅灰（#f5f5f7）代替纯白，卡片比它白一档浮起来。颜色只允许一支系统蓝（#0071e3）用于行动，其余全是灰阶。

圆角克制而统一，按钮全圆角、卡片 24px、输入框 12px。动效是这套风格的签名：500ms 与一段缓入缓出的曲线，hover 时轻微上浮、阴影扩散，快一点就变成普通网页，慢一点就拖沓。右边这张产品卡是真的——悬停它，感受那个节奏。

颜色

灰阶承担一切结构：原生灰做画布让白卡有依托，纯黑留给深色满屏区块，把产品图推到最前。系统蓝是唯一强调色，一屏只允许一处；绿与红只做小面积状态标记。

组件

Pill Button

主行动——Buy、Learn more。系统蓝填充、白字、999px 全圆角、无描边；字级 17px、500 字重、padding 12px 24px，阴影 0 4px 14px 蓝 30%。hover 时填充提亮到 #0077ed、上浮 2px、阴影扩到 20px 40%；按下缩放 0.96。过渡 500ms，缓动 cubic-bezier(0.25, 0.1, 0.25, 1)。

Product Card

产品卡与功能卡。白底、24px 圆角、内边距 32px、阴影 0 4px 12px 4%；内容居中：上方 192px 见方的产品图（18px 圆角、原生灰底），下面 24px/600 标题与 14px 灰字。hover 时上浮 4px、阴影扩到 0 20px 40px 8%、产品图放大 1.05，过渡 500ms。上方演示卡即此组件。

Search Field

搜索与输入。原生灰底、12px 圆角、无描边、padding 12px 16px、17px 字；聚焦时加 2px 系统蓝焦点环，不改变尺寸。

Vibrancy Nav

顶部导航。高 48px、白色 80% 不透明、backdrop-blur 20px、底部 1px 灰 50% 描边；链接 12px、字重 400、间距 32px，hover 转 50% 灰；右侧最多一个纯文字 CTA。

SOLEN 概述规格购买

可为与不为

可为

  • 留白优先，元素稀疏到近乎空
  • 只用一支系统蓝，#0071e3
  • 动效 500ms，缓入缓出
  • 按钮全圆角、卡片 24px、输入 12px
  • 标题 600 字重配紧字距
  • 背景用原生灰而不是纯白

不为

  • 不要用多个强调色
  • 不要用渐变背景
  • 不要用重阴影
  • 不要把内容挤在一起
  • 不要用装饰性插画或图标墙
  • 不要让圆角混用超过三档

图像

产品渲染与实拍是唯一的主角：满屏、居中、背景纯净（黑、白或原生灰）。允许缓慢的视差与缩放。不使用插画、图标墙、渐变背景或人物特写。
