Z 型布局 Z-PATTERN LAYOUT

视线走 Z 字形：左上到右上，斜穿到左下，再落到右下。

三段固定结构CTA 在路径终点页头中间留空高对比牵引

Z 型布局把营销页的注意力路径画出来：第一笔是页头（左 logo、右 CTA），第二笔是斜穿首屏的对角线，第三笔是底部区域的横向扫过并落在右侧 CTA。所以规则很硬——Z 路径上只能放必须被看到的内容，CTA 必须在路径的终点，任何打断流动的元素都不允许。

视觉上它需要高对比与强主色，因为路径靠对比被牵引。下面就是一张按 Z 轨迹搭的页面。

布局实演

组件

Path CTA

路径终点的主行动。靛蓝填充、白字、12px 圆角、无描边，18px/700、padding 16px 40px，阴影 0 4px 14px 靛蓝 30%。hover 时阴影扩到 25px、上浮 4px、放大 1.02；按下缩放 0.95 并下移 2px。过渡 200ms ease-out。全页最多两处，且都在 Z 路径上。

Diagonal Lead + Header Bar

首屏对角区的主视觉块：标题左对齐置于左上，使视线扫向右上；右侧放视觉块（截图、产品图或抽象图形），高度不超过视口 60%；两者之间不加分隔线；副标题最多两行，紧贴标题下方 16px。路径起点的页头：高 72px、白底、无边框；左侧 20px/700 字标，右侧一个 Path CTA 与最多三个链接；中间留空——中间放导航会打断第一笔横线。上方实演顶部即此。

Trust Row

信任条（logo 或数据）。紧贴首屏下方的一条横带，高 80px，放 4 到 6 个灰度 logo 或三个关键数字；文字 12px 全大写 0.06em，透明度 60%；它是 Z 第二笔的支撑，不打断路径。上方实演的灰字横带即此组件。

Bottom Band

路径终点区域。深板岩底或白底，横向排列：左侧一句话结论，右侧一个 CTA 与一个邮箱输入框；整块高度不超过 240px，不放卡片网格。上方实演的深色横带即此组件。

可为与不为

可为

  • Z 路径上只放必须被看到的内容
  • CTA 放在路径终点（右下）
  • 标题左对齐，视觉块右置
  • 首屏一个主张，不堆信息
  • 保持高对比与单一主色
  • 页头中间留空

不为

  • 不要在路径上放次要内容
  • 不要打断 Z 的流动
  • 不要堆过多内容干扰路径
  • 不要把 CTA 放在路径之外
  • 不要让页面过于复杂
  • 不要在中段放双列卡片墙

图像

右对齐的产品截图或抽象图形，用于承接对角线。允许设备的干净外框。不使用大幅人物摄影与背景图，它们会把视线拉离路径。
