陶土与土坡之间

一间做手工陶的工作室。作品本身先于任何修饰语，所以标题用衬线，正文交给细无衬线，两者都不抢戏。

颜色

所有中性色必须偏暖：正文上限是深褐 #2d2a24 而不是纯黑，页面底是像纹理纸的暖白 #f5f0eb，卡片底比页面底暖一档。陶土红是唯一主强调，橄榄绿是第二强调兼自然元素。暖沙色专管 hairline 分隔与装饰形状——它模拟的不是线条，而是两张纸叠在一起时的那道阴影。

  • Warm Umber正文与标题的上限色。绝不用纯黑。
    #2d2a24--color-warm-umber
  • Warm Paper页面底。像纹理纸的暖白。
    #f5f0eb--color-warm-paper
  • Terracotta唯一主强调：链接、CTA 与按钮。
    #c86a4a--color-terracotta
  • Olive第二强调与自然元素，用于标签与点缀。
    #7a8b5e--color-olive
  • Warm Sandhairline 分隔线、装饰圆与卡片衬底。
    #d4bfa5--color-warm-sand
  • Pale Clay卡片与面板底，比页面底暖一档。
    #e8ded1--color-pale-clay

阴影也要暖：0 6px 20px rgba(45,42,36,0.06)，hover 扩到 0 12px 32px rgba(45,42,36,0.10)。用过冷或过亮的阴影即违规。

字体

正文用 Inter 细体、行高 1.75；标题可用衬线（Lora 400 到 500），它提供手作感的一侧，与细无衬线正文形成对照。字距可以放宽，不用紧压。

间距与版面

基础单位 8px，密度 comfortable。上限 1120px、容器内边距 24px，区块间距 112px。留白宽松但不空旷，密度中低。圆角统一 8px，绝不出现大小混用。允许非对称双栏（5:7）。

组件

Terracotta Button

主行动按钮。陶土红填充、暖白文字、8px 圆角、无描边，15px/500、padding 12px 28px，阴影 0 6px 20px 深褐 6%。hover 时填充加深到 #b25c3e、阴影扩到 32px；按下缩放 0.98。过渡 300ms ease-out。hero 里那个就是。

Clay Card

内容卡与作品卡。浅陶填充、8px 圆角、无描边（靠暖色分层）、内边距 28px，阴影 0 6px 20px 深褐 6%。标题用衬线 30px/500 深褐，正文 15px/400 行高 1.75。hover 时阴影扩到 32px、上浮 2px。

Warm Hairline

暖分隔线与叠纸阴影。1px、色 #d4bfa5 的 60%，横跨内容宽。它模拟的不是线条而是「两张纸叠在一起时的那道阴影」，所以颜色必须偏暖且半透明。

Organic Pebble

有机形状装饰。48px 的圆或椭圆（border-radius 取 60% 40% 55% 45% 这类四值），填暖沙 30%，中心放一个 4px 的橄榄绿细点。放在卡片角落或区块之间作为节奏点，单屏最多三处。

Clay Field

表单输入。浅陶 40% 填充、8px 圆角、1px 暖沙描边、padding 12px 16px、15px 字。聚焦时描边转陶土红并加 1px 的陶土红 20% 外环，不改背景。

可为与不为

可为

  • 所有中性色必须偏暖
  • 陶土红与橄榄绿是唯二强调色
  • 圆角统一 8px，像磨圆的石头
  • 分割用暖 hairline
  • 正文上限深褐 #2d2a24
  • 装饰用圆与有机形状

不为

  • 不要用冷灰作中性色
  • 不要用高饱和霓虹或冷蓝
  • 不要用玻璃拟态
  • 不要用纯黑正文
  • 不要混用不同圆角
  • 不要用过冷或过亮的阴影

图像

手作与建筑摄影：陶器、木作、亚麻、水泥墙、自然光下的室内。允许纸质纹理叠加。不使用冷调摄影、玻璃与金属高光、霓虹色图像。
