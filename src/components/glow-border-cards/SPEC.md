# 光标辉光卡边 — GlowBorderCards

制作「光标辉光卡边」场景：一张 340×340 的深色四卡特性组。光标在场景内移动时，一枚以光标为圆心的柔和辉光同时照亮四张卡——紫色核心、蓝色外沿沿卡片 1.5px 厚的边框层扩散，卡面内侧也泛起 14% 强度的紫色晕；光标离开后辉光以更缓的节奏渐隐。整个效果由指针驱动，无自动播放、无任何位图素材。

## 布局与材质

- 340×340px 场景卡，圆角 30px，溢出裁切。背景固定为 #0A0B10（浅色与深色主题下同为深色），文字基色 #E9ECF5，内边距 18px，外圈 1px 线色描边、下方 0 30px 60px -36px 强阴影。窄容器时整景按 min(1, 可用宽/340) 等比缩放。
- 卡片组为 2×2 网格：行列各 1fr、间距 10px、占满场景内容高度。
- 每张卡两层嵌套。外层描边层圆角 18px、内边距 1.5px（这 1.5px 就是光环的厚度），背景是「径向辉光叠白色基底」：radial-gradient(160px circle at var(--cx) var(--cy), rgba(132,94,247, 强度×1), rgba(77,171,247, 强度×0.5) 40%, transparent 70%)，其下再垫一层 rgba(255,255,255,.08) 作为常态细边；内层卡面圆角 16.5px（与外层 18px 配合保证环厚恒定），背景 #12141C 上叠 radial-gradient(220px circle at var(--cx) var(--cy), rgba(132,94,247, 强度×0.14), transparent 60%)，内边距 14px，纵向 flex、间距 6px、溢出裁切防止晕光出卡。
- 辉光由三枚 CSS 变量驱动：--cx/--cy 是以每张卡自身左上角为原点的光标坐标（px），--o 是 0–1 的强度系数；场景根初始 --x:-500px、--y:-500px、--o:0，光点停在场景外、强度为 0，即无光状态。描边层与卡面层的辉光同心同位，透明度都乘以全局 --o，形成「亮边 + 内晕」的双层光效；强度为 0 时卡上只留下 rgba(255,255,255,.08) 的常态细边。
- 卡内图标片 30×30px、圆角 10px，背景 rgba(255,255,255,.06)、内描边 1px rgba(255,255,255,.08)，内嵌 16×16px 的 24 网格 SVG 图标。标题 13.5px/字重 800、通过 margin-top:auto 推到卡底；说明 11px/600、色 #8A90A6、word-break: keep-all。
- 场景令牌含浅色与深色两套变量（light-dark() 切换：浅色表面 #FFFFFF、surface-2 #F5F3EF、surface-3 #EAE7E1、墨色 #16151B、次级墨 #57535F、三级墨 #8E8A97、accent #6A57F2，深色表面 #13141C、surface-2 #1A1B25、surface-3 #252632、墨色 #F4F0E8、accent #B7A4FF），但本场景卡底与卡面写死为深色，不随主题翻转；字体栈继承页面（font:inherit）。

## 操作和动效

- pointermove 监听在场景根上：先把光标换算成场景逻辑坐标（场景被等比缩小时按 offsetWidth/实际渲染宽 的补偿系数还原），再对每张卡计算以卡自身左上角为原点的光标坐标，写入该卡的 --cx/--cy（内层卡面再各减 1.5px 对齐描边层内侧），同时把全局强度目标置 1。逐卡定位里再次用到同一补偿系数，缩放场景下光点与指针不错位。四张卡共享同一坐标，也就是一枚光源同时照亮相邻卡片。
- 每次指针移动除更新强度目标外，还立即执行一次逐卡定位（光点位置零延迟跟随）；其后的 requestAnimationFrame 循环只负责透明度缓动，位置不再插值。帧句柄以 0 作哨兵防止重复起帧，循环结束时句柄归零，下次指针事件重新拉起。
- 挂载与缩放：初次挂载即无条件执行一次定位，后续因容器宽度变化引起的缩放由移动事件内的补偿系数自然覆盖。
- 强度 --o 由 requestAnimationFrame 缓动逼近目标：按帧间隔 dt 计算，进入时速率 8/s、离开时 2.5/s（单帧 dt 上限 0.05s），|目标-当前|≤0.005 时停帧；pointerleave 只把目标置 0，位置变量保留最后一次的值，余晖在原地渐隐而不是移走；再次进入把目标置回 1，没有冷却期。
- 初次挂载即执行一次定位，保证缩放场景下坐标正确；每帧同步更新描边层与卡面两层渐变。整个场景没有自动播放、没有计时器，唯一的帧循环由指针事件拉起、透明度到位即停。
- prefers-reduced-motion 下：透明度缓动关闭（缓动系数取 1，强度一步到位后按同一停帧条件结束循环），位置仍随指针实时移动（这是直接状态映射而非过渡动画）。
- 无障碍：卡片组 role="list"、aria-label "Four feature cards"，卡片 role="listitem"，图标 SVG aria-hidden。组件为纯指针装饰效果，不承载键盘操作，也无自身可聚焦元素。
- options.height 调整场景高度（默认 340），options.reducedMotion 覆盖系统偏好。支持同页多实例；卸载时取消未完成的帧回调与监听器。
