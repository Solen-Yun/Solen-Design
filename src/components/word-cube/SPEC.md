# 滚动词立方 — WordCube

340×282 的标题型场景：上方一行小字 "What we do"，下面是一座 3D 立方体，正面压着一个大号英文关键词——Plan、Design、Build、Run 四个字轮流出现。立方体永远朝同一个方向滚：每换一个词就整体旋转 90°，滚到位后旧面沉到背面、新的面亮起来，其余三面保持压暗。右侧是上下两个箭头按钮可以手动翻面，底部一排小圆点指示当前是第几个词、一条细进度条走完 2.6 秒就自动翻到下一个词；鼠标悬停在立方体上时进度条与自动翻页一起暂停，移开后继续。关键词下方还有一句解释文案，翻页时旧句向上推出、新句从下方推入。

## 布局与材质

- 340×282px 场景卡，圆角 28px，溢出裁切，内边距 22px 20px 18px，纵向 flex 布局，表面色底，外圈 1px 线色描边，下方 0 30px 60px -36px 强阴影。容器变窄时整景按 `min(1, 可用宽 / 340)` 等比缩小，不重排。
- 眉题 "What we do" 12px/750、三级墨色；它与主行之间留 22px 上边距。
- 主行为 flex 居中、间距 12px：左侧是舞台区，flex 占满剩余宽度、高 72px、透视 520px；右侧是箭头列，纵向排列、间距 6px。
- 立方体占满舞台区、高 72px，`preserve-3d`，整体沿 Z 轴后移 36px 并绕 X 轴旋转当前角度，0.9s `cubic-bezier(.5,-.25,.3,1.3)` 过渡（带轻微过冲）。四个面都是绝对定位铺满、flex 垂直居中、内边距 0 18px、圆角 16px、背面隐藏，字号 42px、字重 880、字距 -0.05em；文字色为页面色（表面色的反色）。第 1 面与第 3 面为墨色底，第 2 面与第 4 面为强调色底并配强调字色；四个面依次绕 X 轴 0°、-90°、-180°、-270° 再沿 Z 轴外移 36px 摆位。非当前的面统一压暗到 55% 亮度，0.9s 过渡。
- 箭头按钮 36×33、圆角 11px、次级表面底、墨色图形，按下时缩到 0.9 倍（0.35s 弹跳缓动）；图标为 16×16 的线性上下箭头，描边 2.2px、圆角端点。
- 解释文案区高 48px、上边距 18px、溢出隐藏，16px/1.5/650、次级墨色；每次换词插入一个新的整行 span，新句初始下移一整行并透明，落到位置上后旧句上移一整行并淡出，旧句 700ms 后移除。
- 底部条贴住场景底边，flex 居中、间距 10px：左侧是四个 26×26 的圆形指示点按钮（透明底、居中排布、彼此间距 6px），每个点内画一枚 8×8 的小圆点，未选中时是线色、选中时是墨色并放大到 1.3 倍（0.3s 变色、0.4s 弹跳缩放）；右侧是进度条，flex 占满剩余宽度、高 3px、圆角 3px、线色槽，内填一条强调色条（缩放 X 轴从 0 走到 1）。
- 场景令牌浅色与深色两套（`prefers-color-scheme` 切换）：页面色 #FFFFFF / #0B0C12，表面 #FFFFFF / #13141C，次级表面 #F5F3EF / #1A1B25，墨色 #16151B / #F4F0E8，次级墨 #57535F / rgba(244,240,232,.68)，三级墨 #8E8A97 / rgba(244,240,232,.42)，线色 rgba(22,21,27,.09) / rgba(255,255,255,.08)，强调色 #6A57F2 / #B7A4FF，强调字色 #FFFFFF / #0B0C12，强阴影 rgba(40,30,80,.3) / rgba(0,0,0,.72)。弹跳缓动为 `cubic-bezier(.34,1.56,.64,1)`；正文使用系统无衬线栈。

## 数据

- 写死四个词与四句解释，一一对应：Plan — "We break the problem down and set the order"；Design — "We draw screens you want to touch"；Build — "We build it fast and solid"；Run — "We stay with you after launch"。
- 底部四个指示点与这四个词一一对应，可访问名就是这个词本身；默认选中第 1 个词。
- 无网络数据、无外部图片；立方体与箭头图形全部用 DOM 与 CSS 3D 绘制。

## 操作和动效

- 自动翻页：每 2.6 秒前进一个词。进度条同时以 2.6 秒线性动画从 0 走到 100% 并保持满格；计时到期后立刻翻到下一个词并重置进度条。
- 悬停暂停：指针进入立方体即暂停自动翻页（进度条动画同时暂停），移出后恢复；暂停期间计时器每 300ms 自检一次，一旦离开就继续计时。
- 手动翻页：点下箭头翻到上/下一个词，点底部指示点直接跳到对应词。翻页时立方体始终沿同一方向多转 90°（不回退），当前面被点亮为高亮面、其余面压暗，同时指示点更新、解释文案换新。
- 文案切换：新解释句从下方推入、上方旧句推出，两句各带 0.7s 位移与 0.4s 透明度过渡。
- 键盘操作：箭头按钮与指示点都是原生按钮，可用 Tab 与 Enter/Space 操作；按钮本身没有额外的方向键绑定。
- 无障碍：立方体容器为 `aria-live="polite"` 区域；非当前面设 `aria-hidden="true"`，当前面可读；指示点用 `aria-pressed` 标记选中态并以词名作为可访问名；箭头按钮的可访问名分别是 "Previous word" 与 "Next word"。
- 减少动态：命中 `prefers-reduced-motion` 时不启动自动翻页与进度条动画，立方体旋转的 CSS 过渡也被关闭（宿主在减少动态下会关闭所有过渡与动画），只剩瞬时换词与文案替换；手动翻页按钮与指示点照常可用。
