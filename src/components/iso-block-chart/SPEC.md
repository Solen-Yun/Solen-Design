# 等距数据方块图 — IsoBlockChart

制作「等距数据方块图」：一张 340×340 的等距投影方块城图卡，展示四个地区六个月的数据。方块从斜视角按行列排布、高度编码数值；首次进入视口时从前排向后逐排升起，切换指标芯片时全部方块以波浪错峰重新调平。悬停任一方块时只有它所在的行和列保持彩色、其余变灰，同时一枚数值气泡从方块顶端浮起。

## 布局与材质

- 340×340px 场景卡，圆角 30px，溢出裁切。场景根是 340×340 的无底色包装层（水平居中），卡片视觉放在其内部的绝对填充层上——文档演示舞台会剥离场景根的背景，卡片底色必须在嵌套层上才能保留。底色为 160° 线性渐变 #F5F7FF → #E9EEFB，外圈 1px 线色描边加 0 30px 60px -36px 强阴影，全局墨色 #1E2440。
- 头部在卡片内左 16px、右 16px、上 14px：左侧标题 13.5px/字重 800；右侧指标芯片组是一个 3px 内边距的 999px 胶囊，底色 #1E2440 的 7% 透明度，两枚芯片内边距 5px 11px、11px/750、色 #525A7A；选中芯片底 #1E2440 白字。role="group" 带 "Choose a metric" 标签，芯片用 aria-pressed 表达选中。焦点圈 2px #3D8BFF。
- 方块城是一张铺满卡片的 SVG（viewBox 0 0 340 340，role="img" 带英文描述）。等距投影参数：原点 OX=149、OY=160，列进深 DX=21、行进深 DY=12.2，方块半宽 FW=0.72，投影函数 x=OX+(c−r)·DX、y=OY+(c+r)·DY。4 行（地区 Seoul/Busan/Daegu/Gwangju）×6 列（月份 Jan–Jun）共 24 块，按 (r+c) 升序、同值按列升序的绘制顺序保证遮挡正确。每块由顶/左/右三个面拼成，行配色三段：紫 #7C8CFF/#5A69E6/#4352C4、青 #4FD1C5/#2FB3A8/#22948A、橙 #FFB86B/#F2994A/#D97F2E、粉 #F78FB3/#E26D98/#C4537D。地面用一条 (-0.6,-0.6)→(5.6,3.6) 的菱形路径，5% 墨色填充加 10% 描边。
- 悬停提示气泡：#1E2440 实底、白字、圆角 10px、内边距 6px 9px，标题 11px/700（地区 · 月份），数值 13px/800 tabular-nums；以 translate(-50%,-120%) 悬浮在方块顶点上方，0.15s 透明度加 0.22s cubic-bezier(.34,1.45,.64,1) 弹性缩放入场。
- 底部图例居中排四个地区名，10.5px/700、色 #525A7A，前置 8×8px 圆角 2px 的行首色块。aria-hidden 装饰（气泡、图例）不进无障碍树。
- 场景令牌含浅色与深色两套（`prefers-color-scheme: dark` 切换）：深色下描边与阴影加深；方块、芯片、气泡与渐变底色为固定色不随主题翻转。

## 操作和动效

- 数值到高度的映射：方块逻辑高度 = 数值 × 1.25。数据表两套指标——Orders 四行六列 [[42,55,61,58,74,88],[30,34,41,47,45,52],[22,25,24,31,36,40],[15,19,23,21,27,33]]，Visits [[66,70,64,80,85,92],[48,44,57,60,66,63],[35,41,38,46,44,55],[28,26,34,38,41,47]]；气泡数值 = 数值 × 37 四舍五入并千分位，单位 " orders"/" visits"。
- 首次进入视口（IntersectionObserver 触发一次）时从前排升起：每块延迟 (8−r−c)×70ms；切换指标时波浪重平：延迟 (r+c)×45ms。每块 650ms 走弹性缓动 `1−(1−t)³·cos(t·4.2)·(1−t·0.2)`，rAF 逐帧重画三面路径，全部落定后停止。重复触发以最后一次为准。
- 悬停方块：所在行与列的方块保持原色（is-line），悬停块加白色 1.2px 描边（is-on），其余方块三面依次变 #E4E7F1/#D2D7E5/#C0C6D9（外层加 ibc-dim 类），面色 0.2s 过渡；气泡跟随实时高度。移开即整体复原。
- `prefers-reduced-motion` 下跳过升起动画与 IntersectionObserver，直接以最终高度呈现；悬停照常工作，过渡关闭。
- 无障碍：SVG role="img" 带英文 aria-label；芯片组 role="group" + aria-pressed；焦点圈清晰；气泡与图例 aria-hidden。
- options.heading 覆盖标题；options.metric 为初始/受控指标（0=Orders、1=Visits），外部更新触发重平但不回调；onMetricChange 仅在用户点击芯片时回调一次；options.height 调整场景高度，options.reducedMotion 覆盖系统偏好。支持多实例，更新不重挂载；卸载时释放帧回调、观察器及监听器。
