# 通讯录索引刷选 — IndexScrubber

一张 300×480 的通讯录场景。左侧是按首字母分组的联系人列表（每个字母一个浅蓝分组头，下面是带头像圆片的联系人行），右侧是一列 14 个字母的竖排索引。手指或鼠标在索引列上上下刷动时，右侧弹出蓝色水滴形气泡显示当前字母，列表平滑平移到对应分组，同时字母列上离指尖越近的字母越向左倾出并放大；松手后气泡淡出、字母回位。直接点某个字母也能跳转，列表顶部会浮出一条半透明的当前分组条。

## 布局与材质

- 场景根 300×480px，圆角 32px，溢出裁切；外圈 1px 线色描边（`box-shadow: 0 0 0 1px`），下方 `0 30px 60px -36px` 强阴影。
- 场景底色与正文色是写死的浅色值：底 `#FFFFFF`、正文 `#1F2330`。令牌变量仍以 `light-dark()` 写在根上（表面 `#FFFFFF` / `#13141C`；次级表面 `#F5F3EF` / `#1A1B25`；三级表面 `#EAE7E1` / `#252632`；墨色 `#16151B` / `#F4F0E8`；次级墨色 `#57535F` / `rgba(244,240,232,.68)`；三级墨色 `#8E8A97` / `rgba(244,240,232,.42)`；线色 `rgba(22,21,27,.09)` / `rgba(255,255,255,.08)`；强线色 `rgba(22,21,27,.17)` / `rgba(255,255,255,.16)`；强调色 `#6A57F2` / `#B7A4FF`；次强调 `#2F8FE0` / `#7DB4FF`；强调淡色 `rgba(106,87,242,.12)` / `rgba(183,164,255,.15)`；强调字色 `#FFFFFF` / `#0B0C12`；薄荷 `#119C72` / `#7EE8C0`；警示 `#D6731E` / `#FFB26B`；危险 `#D93A55` / `#FF7D8C`；玻璃面 `rgba(255,255,255,.58)` / `rgba(255,255,255,.07)`；玻璃线 `rgba(255,255,255,.85)` / `rgba(255,255,255,.18)`；阴影 `rgba(40,30,80,.14)` / `rgba(0,0,0,.45)`；强阴影 `rgba(40,30,80,.3)` / `rgba(0,0,0,.72)`），但组件自身的可见面板一律用固定浅色，所以深色模式下场景仍是浅底、只有描边与阴影切到深色值。
- 组件 CSS 未声明 `font-family`，字体沿用宿主页继承。
- 面板层次（自下而上 z-index）：列表视窗 0、当前分组条 2、标题栏 3、索引列 4、气泡 5。
- 标题栏：绝对定位 left 0 / right 0 / top 0，高 56px，内边距 `22px 20px 0`，文字 `Contacts`，字号 20px、字重 850、字距 -0.02em，底色 `#fff`。
- 列表视窗：绝对定位 left 0 / right 30px / top 56px / bottom 0，溢出裁切——右侧留出 30px 给索引列。内层列表容器绝对定位在视口左上，靠 `transform: translateY(...)` 平移，不是真的滚动。
- 列表位移过渡 0.28s `cubic-bezier(.3,.9,.3,1)`；刷动过程中会临时加上 `is-fast` 类，把过渡换成 0.12s `ease-out`，让列表跟手。
- 分组头：高 26px，内边距 `6px 20px 0`，字号 11px、字重 850，文字色 `#5C7CFA`，底色 `#F4F6FB`。
- 联系人行：高 46px，flex 居中、间距 12px，内边距 `0 20px`，下沿 1px `#F1F3F5` 分隔线，文字 14px/650。行首头像圆片 30×30px、圆形，底色按固定色板循环，中心是姓名首字母，字号 12px、字重 800、白色。
- 当前分组条：绝对定位 left 0 / right 30px / top 56px，高 26px，内边距 `6px 20px 0`，与分组头同色系（文字 `#5C7CFA`、底 `rgba(244,246,251,.96)`），阴影 `0 4px 8px -6px rgba(31,35,48,.3)`，它浮在列表上方，列表平移时始终显示当前字母。
- 索引列：绝对定位 right 4px / top 64px / bottom 14px，宽 26px，纵向 flex、字母在列内均匀分布、水平居中；`touch-action:none`（手指在索引上拖动不会带动页面滚动），光标为 `ns-resize`。整列标记 `role="group"`、`aria-label="Index"`。
- 索引字母：22×22px 的按钮，圆形，无边框无底色，10.5px/800、字色 `#5C7CFA`，行高 22px 居中；靠 `transform: translateX(var(--dx,0)) scale(var(--sc,1))` 做倾出与放大；当前分组对应的字母加 `.is-on`，底色 `#5C7CFA`、字色 `#FFFFFF`；`focus-visible` 为 2px `#1F2330` 描边。
- 气泡：绝对定位 right 66px、top 由脚本写入，62×62px，外边距 top -31px 让圆心对准指尖，圆角 `50% 50% 8px 50%` 的水滴形，整体旋转 -45°，底色 `#5C7CFA`、白字，阴影 `0 10px 24px -8px rgba(92,124,250,.6)`；内部字母反向旋转 45°，字号 28px、字重 900。静息时透明度 0 且缩放 0.4，展开时透明度 1、缩放 1，透明度过渡 0.2s、缩放过渡 0.3s `cubic-bezier(.3,1.6,.5,1)`；不接收指针事件。
- 场景固定 300px 宽，没有媒体查询断点；容器窄于 300px 时由运行时整体等比缩小（缩放比 = min(1, 容器宽 / 300)），320px 以下的窄容器也不会横向溢出。

## 操作和动效

- 组件挂载即定位到 A 组：列表位移为 0、A 字母高亮、当前分组条写 `A`、气泡内预置 `A`。
- 在索引列上按下（pointerdown）即进入刷选：捕获指针，用指针纵坐标换算出所在的字母区间——先把指针位置按场景缩放比例还原到布局坐标，再取 `floor(比例 × 14)` 并夹在 0 到 13 之间；随即跳到该分组（走 0.12s 快速过渡），气泡显示该字母并淡入展开，气泡纵向位置跟随指针。
- 按住并移动（pointermove）持续更新：字母跟着手指换、列表跟着换组、气泡跟着手指上下走。
- 刷动时索引列上的字母会朝指尖方向"弯"：字母中心与指针的布局距离 d 小于 70px 时才开始响应，权重 `w = 1 - d / 70`，再取 `sin(w × π/2)` 得到平滑衰减；字母据此左移最多 26px（`--dx`）并放大最多到 1.6 倍（`--sc`）。
- 松手（pointerup）或指针被取消（pointercancel）后复位：气泡淡出并收回 0.4 倍，所有字母的 `--dx` 归 0、`--sc` 归 1。指针在未按下的情况下移出索引列也会复位。
- 点击索引上的某个字母直接跳转该分组（走 0.28s 的慢过渡），当前字母高亮、当前分组条更新为该字母；重复点击当前分组不做任何事。
- 跳转的位移量取 `min(最大平移量 1642, 该组起始偏移)`，所以最后几组到底时列表停在列表末尾而不是留白。
- 无障碍：索引列 `role="group"`、`aria-label="Index"`，每个字母按钮的 `aria-label` 形如 `S group, jump`；当前分组条与气泡都是视觉辅助，均对读屏隐藏（`aria-hidden="true"`），避免重复播报字母；字母是原生按钮，可 Tab 聚焦并回车激活。
- 键盘操作：Tab 到字母按钮后按 Enter / Space 触发点击，走与点击相同的慢速跳转路径。
- 无自动播放，也没有循环动画；所有动效都由指针或点击触发。
- `prefers-reduced-motion` 下列表的平移过渡关闭（瞬时到位），并把索引字母的 transition 置为 none；`options.reducedMotion` 覆盖同一偏好，只影响过渡时长，不改变任何跳转逻辑与最终位置。
