# 专辑封面隧道 — AlbumCoverTunnel

制作「专辑封面隧道」交互组件。一整面专辑封面在三维空间里排成无尽隧道：悬停抬起、点击飞入镜头中央、滚轮或上下拖动穿行，空闲数秒后隧道自行向前推进。

## 画面与素材

- 组件没有固定尺寸：画面是一块 16:9 的宽银幕，宽度跟满容器，高度由比例算出，容器变窄时画面等比收窄而不是溢出，最小高度 240px。深色主题底 #05060f，浅色主题底 #f4f4f4；文字用 system-ui、-apple-system、PingFang SC、Microsoft YaHei 回退栈。浅色主题把画面收进四周 3% 的内缩框，加 20px 圆角与 0 14px 35px #0002 投影，并隐藏底部提示。舞台底部居中有一行 12px、#ffffffa0 的提示文案：滚轮 / 上下拖动：穿过封面隧道 · 悬停吸起 · 点击飞入中央 · 方向键切换 · 空格暂停，9 秒后淡出。
- 封面是 2.9 见方的薄盒，厚度 0.348。盒体正面贴着封面图，带外沿倒角、左上亮右下暗的斜向覆膜流光与纸纹颗粒；四条厚度侧面是半透明壳，透出封面的边缘印刷，壳沿有两条亮棱；背面是近黑的深色背板。封面下方另有一层比本体大 1.6 倍的软阴影，落在下一层上。
- 十张封面依次为霓虹雨夜都市、星海孤崖、樱花黄昏神社、深海巨鲸、冰与火之界、天空浮岛、雨夜末班车、极光镜湖、苍绿巨神、焰羽之舞。取 3:4 竖幅插画壁纸的居中方形裁切，缩到 512×512，以 base64 JPEG data URI 内嵌在引擎里，离线可用；`images` 可整组替换，最多 96 张，字符串与 { src, alt } 两种写法都接受，非正方形图片同样居中裁切。
- 背景是着色器绘制的深紫夜空：中心 38% 是隧道深处的光晕，四周压暗；前景另有 1400 粒加法混合的尘埃，随镜头缓慢旋转。
- 后期处理：半分辨率 UnrealBloom（强度 0.5、半径 0.35、阈值 0.9）、一道从隧道尽头光源向外放射的体积光束分级、轻微色差、暗角与胶片颗粒。

## 隧道与封面阵

- 14 层，层间距 5.5，网格间距 4.4，每层按奇偶隔格取点，合计 700 个封面实例，一次实例化绘制。镜头焦点固定在相机前方 14 个单位；相机沿 z 轴前进，落到身后的层回卷到最前方，隧道因此无尽延伸。
- 封面用 three 的 InstancedMesh 绘制：一张 512×512 的层叠纹理数组（DataArrayTexture）装下所有封面，实例属性 aTex 选层、aLook 带亮度与透明度、aPh 走覆膜扫描、aFog 混进背景色，材质是自定义 ShaderMaterial。
- 每张封面记录所在层、格点、静止目标位置与当前偏移。悬停的那张抬起 2 个单位并放大 14%，同层邻居被沿半径推开；悬停封面还会随指针轻微侧倾。
- 层与层之间按距离做深度雾，远处的封面溶进同一张背景色，而不是半透明叠加。

## 手势与键盘

- 滚轮累计 deltaY、上下拖动累计指针位移，两者转成前进速度；速度按 0.06^dt 衰减。空闲超过 0.45 秒时缓慢吸附到最近一层的中心；空闲超过 5 秒且没有悬停时，`autoTravel` 让隧道自动向前推进。
- 点击某张封面：它沿弧线飞入镜头中央成为主封面，原本占据中央的封面被挤到一侧，镜头补足位移。`onSelect` 回报被选中封面的序号。
- 方向键在当前层里挑选同方向上最近的一张封面并切换主封面；空格暂停或继续。被选中的封面序号可用 `active` 指定。
- 画布本身是 tabIndex 0 的 region，aria-label 说明滚轮、拖动、点击、方向键与空格的用法；当前主封面名称写入 aria-live 的状态文本。

## 自动切换与交付

- `autoTravel` 默认 true，`paused` 默认 false，`theme` 默认 "dark"。没有高度参数：画面尺寸永远跟展示框走。
- `paused` 或系统开启减少动态时，所有插值立即到位，动画停在当前状态而不是继续缓动；交互仍然完整可用。
- 环境不支持 WebGL2 时显示「当前环境不支持 WebGL2」；封面加载失败时显示「封面图片加载失败，请检查图片地址」。
- 连续两次采样低于 45fps 时自动下调像素比（最低 0.75），场景随容器尺寸重建。
- 组件在阴影 DOM 内运行，同页多个实例互不干扰；卸载时释放几何体、材质、纹理、后期通道与 WebGL 上下文，取消所有帧、监听器与观察器。

- 仅凭本文从零生成可运行的实现。尺寸、颜色、文案、图形和运动算法均以上述文字为准；封面素材以 base64 内嵌，不加载远程图片、字体、视频或素材。
- 当前交付重点为 Vanilla，组件名称 AlbumCoverTunnel。从零创建四个文件：AlbumCoverTunnel.ts、AlbumCoverTunnelEngine.js、motion-runtime.ts、AlbumCoverTunnelEngine.d.ts；分别实现框架入口、完整交互核心、实例生命周期和类型声明。文件名是需要生成的产物，不假定接收者已经拥有任何文件。
- 同时提供 React、Vue、Svelte、Solid、Preact、Vanilla 原生生命周期入口，共享框架无关核心。DOM 仅在挂载后访问，支持同页多实例；更新时保持状态，销毁时清理动画、计时器、观察器及监听器。不要用 iframe 代替组件实现。
- 依赖安装说明：npm install three@0.185.1。若使用依赖，只使用其公开 API；场景、材质、着色器、后期与交互必须在本次生成的文件中完整实现，不引用现成效果组件。
- 不提供场景高度参数：画面比例固定 16:9，宽度跟满容器，高度由比例算出；options.reducedMotion 覆盖系统偏好，减少动态效果仍保留完整交互状态。

- 验收：375 / 768 / 1440px 无横向溢出；悬停抬起、点击飞入、滚轮与拖动穿行、方向键切换、空格暂停都可用；无 WebGL2 或图片加载失败时给出明确提示；帧率过低时自动降像素比；多实例互不干扰，卸载后停止所有任务并释放 GPU 资源。
