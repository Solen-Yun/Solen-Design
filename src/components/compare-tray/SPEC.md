# 商品对比托盘 — CompareTray

一张 340×340 的笔记本电脑对比场景。画面上半部是 2×2 的四台笔电卡片，每张卡有渐变缩略图、机型名、价格和右上角一枚 Compare 勾选胶囊；勾选后底部墨色托盘从下方滑起，右侧三个虚线空槽按选择顺序填入对应机型的迷你笔记本，Compare 按钮在选满两件后点亮，按下它整张场景被一张 "Comparison" 对比表覆盖，列出 Weight / Battery / Price 三行规格并给每行的最优值挂一枚绿色 Best 徽标。第四件再勾选时托盘左右抖动拒绝，Escape 或关闭按钮退回列表。

## 布局与材质

- 场景根 340×340px，圆角 30px，溢出裁切，背景取表面色；外圈 1px 线色描边（`box-shadow: 0 0 0 1px`），下方 `0 30px 60px -36px` 强阴影。场景内容全部由内联 SVG 与 CSS 绘制，不加载远程图片、字体或素材。
- 令牌全部用 CSS `light-dark()` 写在场景根上，浅色 / 深色两套：表面 `#FFFFFF` / `#13141C`；次级表面 `#F5F3EF` / `#1A1B25`；三级表面 `#EAE7E1` / `#252632`；墨色 `#16151B` / `#F4F0E8`；次级墨色 `#57535F` / `rgba(244,240,232,.68)`；三级墨色 `#8E8A97` / `rgba(244,240,232,.42)`；线色 `rgba(22,21,27,.09)` / `rgba(255,255,255,.08)`；强线色 `rgba(22,21,27,.17)` / `rgba(255,255,255,.16)`；强调色 `#6A57F2` / `#B7A4FF`；次强调 `#2F8FE0` / `#7DB4FF`；强调淡色 `rgba(106,87,242,.12)` / `rgba(183,164,255,.15)`；强调字色 `#FFFFFF` / `#0B0C12`；薄荷 `#119C72` / `#7EE8C0`；警示 `#D6731E` / `#FFB26B`；危险 `#D93A55` / `#FF7D8C`；玻璃面 `rgba(255,255,255,.58)` / `rgba(255,255,255,.07)`；玻璃线 `rgba(255,255,255,.85)` / `rgba(255,255,255,.18)`；阴影 `rgba(40,30,80,.14)` / `rgba(0,0,0,.45)`；强阴影 `rgba(40,30,80,.3)` / `rgba(0,0,0,.72)`；渐变 `linear-gradient(120deg,#7B61FF,#3D8BFF 55%,#1FB89A)` / `linear-gradient(120deg,#B7A4FF,#7DB4FF 55%,#A5F2D3)`。组件自身不声明 `color-scheme`，`light-dark()` 跟随宿主的 `color-scheme` 取值。
- 组件 CSS 未声明 `font-family`，字体沿用宿主页继承；数字处统一 `font-variant-numeric: tabular-nums`。
- 标题「Laptops」绝对定位在左 20px、上 18px，字号 16px、字重 900、字距 -0.03em。卡片网格绝对定位左 14px、右 14px、上 52px，两列均分 `1fr 1fr`，行列间距 8px。
- 卡片 padding 8px、圆角 14px、背景次级表面、内嵌 1px 线色描边（`inset 0 0 0 1px`），`box-shadow` 过渡 0.2s；被选中时内嵌描边加粗为 2px 强调色。缩略图区高 50px、圆角 10px、居中放置，底色是内联的 `linear-gradient(150deg, 机型色, color-mix(in srgb, 机型色 60%, #fff))`。
- 缩略图里的笔记本符号：屏幕 50×30px，圆角 `5px 5px 2px 2px`，填充 `#1E293B`，外圈 `0 0 0 3px rgba(255,255,255,.75)`；伪元素是键面，左右各外扩 10px、下沉 7px、高 5px，圆角 `0 0 4px 4px`，填充 `rgba(255,255,255,.85)`。
- 机型名在缩略图下方 6px，字号 11.5px、字重 850；价格紧随其下，字号 10px、字重 750、三级墨色、等宽数字。
- Compare 胶囊绝对定位在卡片右上（right 6px、top 6px）：高 22px，内边距 `0 7px 0 5px`，圆角 999px，背景 `rgba(255,255,255,.85)`，文字色 `#334155`，字号 9.5px、字重 850，阴影 `0 1px 3px rgba(0,0,0,.12)`；左侧 12×12px 方块圆角 4px，默认内嵌 1.5px `#94A3B8` 描边，勾选后填强调色并换成 3×6px 的白色对勾（右边与下边框 1.6px、旋转 45°）。
- 底部托盘绝对定位左 10px、右 10px、下 10px，高 58px，内边距 `0 8px`，圆角 18px，背景墨色、文字取表面色；静息时 `translateY(120%)` 藏在场景外，出现时 0.45s `cubic-bezier(.3,1.3,.5,1)` 滑入。托盘内从左到右是：三个空槽（各 40×40px，圆角 11px，1.5px 虚线描边色 `color-mix(in srgb, 表面色 35%, transparent)`，内含 28×17px 圆角 3px 的深色迷你笔记本与 `0 0 0 2px rgba(255,255,255,.8)` 白边）、一行状态文字（flex 撑开，10px/750、70% 不透明、单行省略）、Compare 按钮（高 38px、内边距 `0 13px`、圆角 11px、强调色实底白字 11.5px/850）。
- 空槽被填上时虚线边转为实线且边框透明，槽底色设为对应机型色；迷你笔记本从 `scale(.2)`、`opacity 0` 以 0.4s `cubic-bezier(.3,1.7,.5,1)` 与 0.2s 透明度双通道弹入。
- 对比表是一层覆盖整个场景的抽屉：绝对定位 inset 0，内边距 `18px 16px`，背景表面色，静息 `translateY(102%)`，展开时 0.5s `cubic-bezier(.3,1,.3,1)` 上滑。表头一行 15px/900 写「Comparison」，右侧 30×30px 圆形关闭钮（次级表面底、次级墨色图标，11×11px 的对角叉线，线宽 1.8px、圆头）。
- 表格网格自表头下方 14px 开始，行间无空隙。列宽为 `62px repeat(选中数, 1fr)`。每行最小高 46px，下沿 1px 线色分隔，字号 11.5px、字重 800、居中、等宽数字；行首格左对齐，字号 10.5px、三级墨色。表头行放大到 12px/900。
- Best 徽标是值格子的伪元素：内容取 `data-b`（写死 "Best"），块级、宽自适应、外边距 `3px auto 0`，内边距 `1px 6px`，圆角 999px，背景 `#10B981`、白字 8.5px/850，静息 `scale(0)`，对比表展开后 0.5s 延迟、0.4s `cubic-bezier(.3,1.7,.5,1)` 弹出。
- 场景固定 340px 宽，没有媒体查询断点；容器窄于 340px 时由运行时整体等比缩放（缩放比 = min(1, 容器宽 / 340)），320px 以下的窄容器因此仍完整可见且不产生横向溢出。

## 数据

- 机型表写死 4 条，字段依次为机型名、重量 kg、电池小时、价格、主题色：`Air 13` / 1.24 / 18 / 1390 / `#CBD5E1`；`Pro 14` / 1.55 / 22 / 2390 / `#94A3B8`；`Slim 15` / 1.48 / 15 / 1190 / `#A5B4FC`；`Ultra 16` / 1.92 / 24 / 2990 / `#FBCFE8`。
- 规格行写死 3 条，字段为行名、单位、取值列下标：Weight / `kg` / 重量列；Battery / `h` / 电池列；Price / 空 / 价格列。取值列下标为电池列时取最大值最优，其余（重量、价格）取最小值最优。
- 价格格式化为 `$` 加千分位数字；格式化函数在数值 ≥ 10000 时改用除以 10000 后的数字字符串。本场景四个价格均低于 10000，分别渲染成 `$1,390`、`$2,390`、`$1,190`、`$2,990`。
- 最多同时选中 3 台；托盘空槽固定 3 个，第 k 个槽显示第 k 个被选机型的缩略图形与主题色。
- 其余文案写死：标题 `Laptops`、抽屉标题 `Comparison`、勾选胶囊文字 `Compare`、按钮文字 `Compare`、状态文字 `N selected` 与 `You can compare up to 3`、徽标文字 `Best`、无数据来源，全部为组件内置常量。

## 操作和动效

- 点击任意卡片的 Compare 胶囊即切换该机型的选中状态：卡片加粗强调色内描边，胶囊方块填强调色并显示对勾，`aria-pressed` 同步为 true/false。已选机型再次点击即取消。
- 选中集合变化后立刻重算：前 N 个空槽被填上并按选择顺序显示对应机型色，未用的槽恢复虚线空槽；托盘在选中数大于 0 时滑入，否则滑回场景外；Compare 按钮在选中数少于 2 时禁用（透明度 0.35、指针禁用样式），状态文字写成 `N selected`。托盘带 `aria-live="polite"`，选择变化会被读屏播报。
- 想选第 4 件时（已选 3 件）不改动任何状态：状态文字改为 `You can compare up to 3`，托盘触发 0.45s 抖动——关键帧在 20% 与 60% 处 `translateX(-6px)`、40% 与 80% 处 `translateX(6px)`，每次重触发先移除抖动类、强制回流再重新加上，保证连点会重新播放。
- 点击 Compare 按钮时先按当前选择重建表格（表头写入机型名，三行数据每行算最优值并给最优格挂 Best 徽标），随后在下一帧把抽屉滑入并聚焦关闭按钮；行入场有 0.12s、0.20s、0.28s 的错峰延迟（按行序 0.12 + 0.08n 秒），每行 0.35s 淡入与 0.45s `cubic-bezier(.3,1.3,.5,1)` 上浮。
- 抽屉以 `role="dialog"` 标记，关闭时 `aria-hidden` 置为 true。点击关闭按钮或按 Escape（监听挂在场景根上）关闭抽屉，抽屉滑回场景下方，焦点交还 Compare 按钮，调用时带 `preventScroll` 避免页面跳动。
- 键盘：所有按钮为原生 `button`，可 Tab 聚焦；`focus-visible` 为 2px 强调色描边、偏移 2px。抽屉打开时焦点移入关闭按钮，关闭后回到 Compare 按钮，形成焦点闭环。
- 无自动播放，也没有循环动画；所有动效都由用户操作触发。`prefers-reduced-motion` 下托盘、抽屉、行、空槽与徽标的过渡全部置为 `none`（瞬间到位），抖动动画取消；`options.reducedMotion` 可覆盖该偏好，覆盖后同样由运行时的属性把整场过渡时长清零。
