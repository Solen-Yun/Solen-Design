制作“品牌海报三联卡片”，以大面积留白和三张竖向卡片展示同一品牌，使用真实DOM图片、品牌图形和文字，组件可复制并替换图片、字标、角标及介绍文案。

精确版式
- 基准场景1200×675，纯白#fff，无标题、按钮、导航或额外装饰。三张卡片在场景中央水平排列，总宽800px，间距60px，每张约226.667×383.2，宽高比.5915。整组水平、垂直居中。卡片直角，无描边、圆角、悬浮阴影；背景照片铺满并裁切。
- 三张照片依次为：霓虹雨夜的未来赛博朋克都市街景，撑透明圆伞的黑衣少女背影，品红粉紫与青蓝双色霓虹，湿漉漉的柏油路面映出破碎倒影；樱花黄昏的山坡神社，长石阶通向朱红鸟居，樱花盛放、花瓣横飞，橙金夕阳；极光下的静水与冬日山峰，绿色极光在水面流动。三张素材都随包内嵌为data URI，不依赖本机路径。保留原图的噪点和颗粒，不增加滤镜或磨皮。默认图片使用object-fit:cover、object-position:center。调用方可传入自己的图片地址。
- 卡片左上角放白色小标志，外接框16×16，距左、上约6px；中央放白色完整字标，宽154px，几何中心位于卡片宽度50%、高度50%。字标与左上角标使用独立图片节点；装饰标志不重复朗读，不把小角标与中央完整字标混为同一尺寸。
- 默认品牌为Solen。角标与中央完整字标都是随包内嵌的白色SVG矢量（data URI）：角标是Solen标志——差一点闭合的环，笔划由粗30px渐细到6px，外侧一条回声细弧，缺口里一道橙色短条，两条不等弧把中心负空间挤成S形通道，viewBox=0 0 200 200；中央完整字标把标志放在左侧、右侧排白色Solen（Helvetica Neue/Helvetica/Arial/system-ui，500字重），viewBox=0 0 520 180。两个矢量都保持各自viewBox与比例，不重新近似品牌路径，不加载外部字体或图片。若调用方给出完整logo图片则保持原宽高比直接显示，不重绘字标。
- 底部正文距左右11px、距底11px，字号10px、行高12.8px、字重400，白色，字体Arial, Helvetica, sans-serif，左对齐，约三行。保留英文，不改成中文。三个卡片使用同一句正文：A personal box of UI ideas, interaction details, and components worth keeping. Curated by Solen Design.
- 仅在底部正文后添加极弱透明黑渐变，从卡片高度68%的透明过渡到底部黑色.18，以提高白字可读性；中央字标仅可用很淡的0 1px 7px黑色.12投影。保持照片的原本色调和构图。Logo和正文固定在前景，任何图片运动都不改变其坐标。

可操作状态与运动
- 初始同时展示三张完整卡片，不轮播，不自动换图。图片完成解码后才发出ready状态，避免加载空白。
- 鼠标进入或键盘聚焦一张卡片，仅将该卡片背景图片从scale1平滑放大到1.035，GSAP 650ms、power2.out；离开及失焦后以550ms返回1。卡片外框、角标、中央字标和正文一律固定，不上浮、不偏移、不改文字排版。此轻缓缩放是静态版式的交互补充。
- 触屏轻触或键盘Enter/Space切换当前卡片的固定聚焦态，再次触发取消；只保留一个选中项。ArrowLeft/Right在三张之间移动焦点，Home/End到首末，Escape取消选中。选择只影响本地缩放状态，不打开页面、不上传数据。快速进出覆盖原动画，从当前缩放继续，不能跳回起点。
- 减少动态效果时立即回到scale1，但保留焦点、选中和键盘操作。焦点采用卡片内侧1px白描边与外侧1px深色细环，不能改变尺寸或推动布局。
- 图片失败保留卡片尺寸、品牌字标和正文，以墨绿黑底显示；所有图片加载结束或失败后都应解除loading状态，不无限等待。对多个实例分别管理选择、动画和图片加载，卸载时清理GSAP、事件、计时器和观察器，迟到的decode不能修改已销毁实例。
