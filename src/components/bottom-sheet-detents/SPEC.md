# 三档底部抽屉 — BottomSheetDetents

300×500 的地图咖啡场景：上方是浅绿底的城市地图，交叉的白色路网之间卧着一块湖面和一块绿地，地图上钉着 5 枚水滴形定位针；下方是浮在地图上的底部抽屉，抽屉头是一行标题 "Cafés nearby"、右侧标注 "8 places"，头部上方是一枚抓手。拖动抽屉头，抽屉跟手上下移动，向上推时地图轻微缩远、压上一层薄黑；松手时按手势速度投影到最近的一档，抽屉用弹簧落定。抽屉有三档：收起（只露出头部与搜索框）、半开（露出更多列表）、全开（整份 8 条咖啡馆列表）。点列表里的任意一家，对应的定位针会变红并弹一下，抽屉同时跳到半开档。

## 布局与材质

- 300×500px 场景卡，圆角 36px，溢出裁切，底色 #0B0C10（写死的深色，不随深浅色切换），外圈 1px 线色描边，下方 0 30px 60px -36px 强阴影。容器变窄时整景按 `min(1, 可用宽 / 300)` 等比缩小，不重排。
- 地图层铺满场景，圆角 36px，底色是次级表面色与 #8CE99A 按 82% 混合的结果（浅绿）；随着抽屉打开进度增加，地图整体以顶部为中心缩小（比例 1 减 0.07×进度）。地图内容是一张 `viewBox 0 0 300 500`、拉伸铺满的内联 SVG：四条白色路网——一条 16px 宽的横弯主路、一条 12px 宽的纵路、一条 10px 宽的横向次路、一条 8px 宽的纵弯小路；下方一块用次级表面色与 #74C0FC 按 40% 混合的湖面区域，一块用次级表面色与 #51CF66 按 50% 混合的 60×60、圆角 14 的绿地。
- 5 枚定位针：26×26，水滴形（上方半圆、下方收成尖角并旋转 -45°），accent 底色、0 4px 8px -2px 黑色投影，中心一枚白色圆点；写死坐标为 (70,150)、(180,110)、(130,260)、(240,220)、(60,340)。被选中的那枚换成 #F03E3E，并以 0.7s `cubic-bezier(.3,1.6,.5,1)` 弹一下（35% 处上抬 16px 后回落）。
- 抽屉层铺满宽度、高 500px（比场景还高，靠位移藏在画面外），圆角 26px 26px 0 0，表面色底，顶部投影 0 -8px 30px -10px rgba(0,0,0,.35)。抽屉头内边距 22px 20px 10px，flex 基准线对齐、间距 8px、禁用文本选择、鼠标为抓取、触屏禁用滚动手势：标题 "Cafés nearby" 19px/880、字距 -0.03em、墨色；右侧 "8 places" 12.5px/700、三级墨色。
- 抓手：绝对居中于抽屉头内左 50%、上 4px，60×18 的透明按钮，内部一条左右各缩进 12px、高 5px、圆角 3px 的线色粗横杠；焦点样式为 2px accent 外圈。
- 搜索框：左右各留 16px，高 40px、圆角 12px、次级表面底色，flex 居中、间距 8px、内边距 0 14px，三级墨色 13.5px/600，前置一枚 16×16 的线性放大镜（圆形 r=5 在 (7,7)，加一段 3px 长柄），占位文案 "Search by name or menu"。
- 列表：上边距 10px、左右各 8px、无序样式。每行是一枚占满宽度的原生按钮，flex 居中、间距 12px、内边距 9px 10px、圆角 14px、透明底、悬停时铺次级表面色；左侧 42×42、圆角 12px 的色块，右侧为店名 14px/780 与步行时长 12px/三级墨色，最右是橙色的 "★ 4.8" 评分（12.5px/800，色 #E8590C）。
- 抽屉上方另有一层覆盖全场景的黑幕，不透明度等于 0.4 乘以打开进度，不拦截指针。
- 场景令牌浅色与深色两套（`prefers-color-scheme` 切换）：表面 #FFFFFF / #13141C，次级表面 #F5F3EF / #1A1B25，墨色 #16151B / #F4F0E8，三级墨 #8E8A97 / rgba(244,240,232,.42)，线色 rgba(22,21,27,.09) / rgba(255,255,255,.08)，强调色 #6A57F2 / #B7A4FF，强阴影 rgba(40,30,80,.3) / rgba(0,0,0,.72)。地图配色与列表色块是写死值；正文使用系统无衬线栈。

## 数据

- 写死 8 条咖啡馆记录，每条是店名、步行时长、评分三项；对应色块依次为 #FFA94D、#69DB7C、#FFD43B、#B197FC、#74C0FC、#F783AC、#63E6BE、#FF8787。逐条为：Corner Roastery / 3 min walk / 4.8；Green Garden Café / 5 min walk / 4.6；Dawn Bakery / 6 min walk / 4.9；Slow Afternoon / 8 min walk / 4.5；Bookshop Coffee / 9 min walk / 4.7；Hilltop Tea House / 12 min walk / 4.4；Ocean Latte / 14 min walk / 4.3；Little Station / 15 min walk / 4.6。
- 写死 5 个定位针坐标；列表条目与定位针之间按下标循环对应（第 i 条对应第 i mod 5 枚针）。
- 三档高度写死为：收起档抽屉上沿在 384、半开档 250、全开档 56；三档名称分别是 collapsed、half、full。初始状态为收起档。
- 无网络数据、无外部图片；地图与定位针由内联 SVG、CSS 渐变与 DOM 绘制。

## 操作和动效

- 拖动：按住抽屉头上下拖，抽屉位置实时跟手，位移按场景缩放比换算；向下拖会被"橡皮筋"挡住——超出全开档（56）以上时只按 0.25 倍跟随，向上超出收起档（384）以下同理只按 0.25 倍跟随。拖动中抽屉不跑弹簧。
- 松手吸附：记录最近 6 次（时刻, 位置）采样，算出手势速度（采样时长不足 1 毫秒时视为 0），再把当前位置按速度外推 0.2 秒得到投影位置，选三个档位里离投影最近的一个作为目标，用弹簧落定。没拖动（位移不超过 4px）则回到当前档位。
- 弹簧：积分式为 `速度 += (-320×(位置 - 目标) - 25×速度)×dt`，`位置 += 速度×dt`，每帧 dt 取 0.032 秒上限；位置与目标差小于 0.3 且速度小于 6 时吸附到目标并停止帧循环。阻尼偏弱，落定时会略微过冲再回来。
- 抓手点击：在收起与半开之间循环推进，到全开后再点回到收起；刚结束一次拖拽后的 350 毫秒内点击不生效，避免拖拽收尾误触。
- 键盘：抓手获得焦点后，方向键上推进一档、方向键下退一档，均阻止默认行为。抓手的可访问名随当前档位更新，形如 "Change sheet height, now half"。
- 点击列表项：命中的定位针变红并弹跳，其余恢复常态，同时抽屉跳到半开档。
- 联动：抽屉打开进度按"半开档到全开档之间的插值"计算，驱动地图缩小（最多缩到 0.93）与黑幕变暗（最多 0.4 不透明度）。
- 无障碍：抽屉容器 `aria-label` 为 "Cafés nearby"；列表行是原生按钮；地图与黑幕对读屏隐藏；抓手是原生按钮并带动态可访问名。
- 减少动态：命中 `prefers-reduced-motion` 时所有档位变化直接吸附（不做弹簧、不做惯性外推），宿主同时关闭 CSS 过渡与动画；地图缩放与黑幕联动仍照常更新。
