Implement the "GlassSurface" component from zero: a liquid-glass panel that bends whatever sits behind it — chromatic-aberration refraction through an edge displacement map, in one of three rendering tiers (WebGL2 sampling an explicit backdrop element, an SVG `backdrop-filter` displacement filter, or a frosted fallback), plus an arbitrary-shape mode where a traced logo/image mask turns the panel into glass shaped like the image, complete with a distance-field outline and soft glow. Full specification follows; it must not depend on external pages, videos, or font files; the backdrop and the shape image come only through props (data URIs and same-origin elements are fine).

## Structure & rendering

- Pure React + CSS + WebGL2 + SVG filters: GlassSurface.jsx and GlassSurface.css. React >= 18; no runtime dependencies.
- Root is a `<div class="glass-surface">` plus a tier class — `glass-surface--webgl`, `--svg` or `--fallback` — and any className. Sized by width/height (px or CSS length), radius = borderRadius px, flex centring, overflow hidden.
- Tier selection: WebGL runs only when `refraction` is on, a `backdrop` element is provided, context creation and shader compilation succeed, and `renderer` is "webgl" — or "auto" with SVG filters unsupported. The SVG tier runs when `refraction` is on and the browser passes a capability probe that creates a div with `backdrop-filter: url(#filter)` and verifies the style sticks (WebKit and Firefox are excluded up front). Everything else is the frosted fallback. The probe runs once on mount.
- Every tier renders a hidden inline `<svg>` holding the filter definition: `feImage` (the displacement map) feeding three `feDisplacementMap`s — one per colour channel with scale `distortionScale + offset` and the configured x/y channel selectors — each isolated by a colour matrix, screen-blended back together, then a final `feGaussianBlur` of `displace`. When the SVG tier is active the root's `backdrop-filter` is `url(#filter) saturate(saturation)` over an optional `backgroundOpacity` tint, with layered inset/outer shadows.
- Displacement map (panel mode): an SVG data URI sized to the live box — a black base, a right-to-left red linear gradient and a top-to-bottom blue linear gradient combined with `mix-blend-mode: mixBlendMode`, and an inner rounded rect inset by `min(w,h) × borderWidth × 0.5` filled `hsl(0 0% brightness% / opacity)` and gaussian-blurred by `blur`. The centre stays flat (0.5 grey = no shift); only the blurred rim pushes pixels. Regenerated whenever the box resizes (ResizeObserver), producing IDs namespaced by React useId.
- Frosted fallback: `backdrop-filter: blur(12px) saturate(saturation × 1.4) brightness(1.04)` plus a diagonal white sheen gradient and a masked 3px rim; browsers without any backdrop-filter get a solid 72% panel instead.
- WebGL tier: a full-bleed canvas samples the backdrop element (image, video or canvas, passed directly or as a ref) and the displacement map as textures. The fragment shader displaces each channel separately (`scale = distortionScale + red/green/blueOffset`), samples with 5×5 gaussian spread when `displace > 0`, and applies a saturation matrix. Per-frame uploads are gated by a signature of box position/size, content box (computed with the source's object-fit and object-position), source state (currentSrc/currentTime/dimensions), map URL and the displacement settings — nothing redraws unless something changed. Images mip-map with an LOD chosen from texels-per-pixel and spread; video re-uploads per frame while playing. Upload failures and context loss flip to the failed state (frosted); visibility gates the loop; unmount deletes all GL objects.
- Shape mode: `shape` is an image URL. Its alpha channel is traced into a signed distance field (2-pass exact euclidean distance transform over a DPR- and area-capped raster), which yields (a) a displacement map whose gradient bends the backdrop only near the silhouette edge — the interior stays optically flat with a slight level shift from brightness/opacity — and (b) two outline canvases: a crisp 1px-class `line` and a wider soft `glow`, both generated by pasting the SDF through a smoothstep of distance and used as CSS mask images over theme-tinted backgrounds. The panel itself is masked by the shape image (placed with the trace's contain-fit box), radius and box-shadow cleared; while the shape loads the panel is transparent; a failed trace renders nothing rather than a broken shape. Works in both the SVG and WebGL tiers (the WebGL path uses the same map URL), and in the frosted tier only as outline + mask.

## Interaction & layout

- `children` render centred inside `__content` (full size, padded 0.5rem, radius inherit, z-index 1). The panel is purely visual — pointer events pass through to children normally.
- `:focus-visible` shows a 2px system-blue outline offset 2px. light-dark() rules adapt the chrome to the document colour scheme.
- Unmount disconnects the ResizeObserver, cancels the GL loop, removes listeners and deletes textures/programs/buffers. Same-page instances are independent (namespaced filter IDs, own GL state).

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| children | ReactNode | - | Panel content, centred. |
| width | number \| string | 200 | Panel width (px or CSS length). |
| height | number \| string | 80 | Panel height (px or CSS length). |
| borderRadius | number | 20 | Corner radius in px (panel mode). |
| borderWidth | number | 0.07 | Fraction of the shorter side that the refracting rim occupies. |
| brightness | number | 50 | Brightness of the inner plate that shapes the map's level shift (0–100). |
| opacity | number | 0.93 | Opacity of the inner plate in the displacement map. |
| blur | number | 11 | Blur (px) of the plate inside the map — how softly the rim distortion fades inward. |
| displace | number | 0 | Extra gaussian smoothing of the refraction result (the final feGaussianBlur). |
| backgroundOpacity | number | 0 | Tint opacity layered under the glass. |
| saturation | number | 1 | Saturation multiplier applied to the refracted backdrop. |
| distortionScale | number | -180 | Base displacement magnitude (negative bends inward). |
| redOffset | number | 0 | Extra scale for the red channel (chromatic aberration). |
| greenOffset | number | 10 | Extra scale for the green channel. |
| blueOffset | number | 20 | Extra scale for the blue channel. |
| xChannel | "R" \| "G" \| "B" \| "A" | "R" | Map channel driving horizontal displacement. |
| yChannel | "R" \| "G" \| "B" \| "A" | "G" | Map channel driving vertical displacement. |
| mixBlendMode | string | "difference" | Blend mode combining the map's two gradients. |
| refraction | boolean | true | Enables refraction (falls back to frost when unavailable). |
| renderer | "auto" \| "webgl" | "auto" | Force the WebGL tier, or pick automatically. |
| backdrop | HTMLElement \| Ref | - | Image/video/canvas element (or ref) the WebGL tier refracts. |
| shape | string | - | Image URL whose silhouette becomes the glass shape. |
| className | string | "" | Extra class names for the root. |
| style | CSSProperties | {} | Inline styles for the root. |
