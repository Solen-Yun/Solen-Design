# 停靠迷你播放器 — DockingMiniPlayer

一张 300×480 的播客页面场景：顶部是一块深紫到玫红的渐变大播放器卡（132px 封面、节目标签「Maker Talk · Ep. 42」、标题「How small teams build big」、一条由 18 根小柱组成的声波、进度条与时间 5:12 / 38:20、白色圆形播放按钮），下面是简介段落、另外三集列表与四个章节。点播放后声波跟着起舞、进度条与时间一起推进；一旦大播放按钮被滚出可视区，底部就滑出一条深靛色的迷你播放条（封面、标题、圆形播放键与一条底部粉色进度线），点它可以平滑滚回大播放器。

- 场景卡为 300×480px 的 div，圆角 32px，overflow 裁切，底色表面色，外圈 1px 线色描边（0 0 0 1px），下方 0 30px 60px -36px 强阴影。

## 数据

- 大播放器写死：封面话筒 SVG、节目标签「Maker Talk · Ep. 42」、标题「How small teams build big」、总时长「38:20」。
- 声波固定 18 根柱，初始播放位置是时间轴的第 312 单位（显示为 5:12），时间轴全长 2300 单位，播放时按每真实秒 6 个单位推进。

- 迷你条里的标题与副题不是另写的，而是运行时从大播放器的标题与节目标签复制过来，保证两处一致。

## 操作和动效

- 点大播放器的圆形按钮：开始/暂停。播放时大封面放大到 1.04 倍，18 根声波柱起起伏落，进度条按每真实秒 6 个单位推进，计时器把当前时间写成「分:秒」（不足两位补零），大进度条与迷你条底部的粉色进度线同时按同一比例走；播放到 2300 单位后停在终点。暂停时声波与进度都停住，封面回到原大小。再点一次即暂停。
- 播放/暂停图标在大按钮和迷你条按钮上同步切换，两处的 aria-label 同步写成 Play 或 Pause。
- 滚动监听用 IntersectionObserver 观察大播放按钮（以滚动区为根，阈值 0）：按钮滚出可视区时给根节点加上停靠类，迷你条从底部滑入并可 Tab 到达；滚回来时迷你条收回并移出焦点序列。
- 点迷你条：从当前滚动位置平滑滚回顶部，600ms 内用三次缓出（1 - (1-k)^3）把滚动值推到 0；结束后把焦点交回大播放按钮（阻止滚动）。迷你条本身带 aria-label「Back to full player」。
- `prefers-reduced-motion` 下：迷你条的滑入滑出与封面缩放过渡关闭；声波不再起伏，柱高固定在 14px；点迷你条时不做滚动动画，直接跳回顶部；播放与暂停的逻辑、进度推进与文案都不变。
- 无障碍：滚动区可聚焦并带 aria-label「Podcast page」；两个播放按钮都是原生按钮并带 aria-label（Play / Pause），焦点可见样式为 2px 强调色外框、偏移 2px；迷你条只有停靠时才进入 Tab 序列。
