# 点阵地球 — DotGlobe

制作「点阵地球」场景：一张 340×340 的深夜蓝渐变卡片，中间是一颗 Canvas 绘制的点阵地球——6400 个斐波那契球面采样点里落在大陆轮廓内的点被画成蓝色方点，随深度改变亮度与大小，球体缓慢自转；12 座城市以薄荷绿亮点加小旗杆标注，每 0.35s 随机一座城市荡出扩散涟漪，访客数随之微调，左上角「Live visitors」行汇总总数（带脉冲呼吸的绿点）。抓住球体左右拖动可直接转动地球（按位移实时改角度并测量甩出速度），松手后带惯性旋转、阻尼回到 0.18 rad/s 的常态自转；悬停城市弹出米白气泡显示城市名与「Now N visiting」。

## 布局与材质

- 场景 340×340px，圆角 30px，溢出裁切；底色固定为深夜径向渐变 radial-gradient(80% 80% at 50% 48%, #0F1A33, #060912 72%)，文字基色 #E8F0FF，不随浅色/深色主题变化；外圈 1px 线色描边加 0 30px 60px -36px 强阴影。场景根是无底色包装层，视觉卡片放在其内部的绝对填充层上。
- Canvas 绝对填充整卡，backing store 按 min(2, devicePixelRatio) 缩放；touch-action: none，cursor: grab、按下 grabbing；role="img"，aria-label「Dotted globe, drag to spin」。
- 地球几何：球心画布坐标 (170, 184)、半径 132px、倾角 TILT −0.32 rad（正交投影，z>0 为正面）。球体先画一层辉光底（半径 R+30 的径向渐变，内圈 rgba(70,120,255,.22)、0.8 处 rgba(40,70,160,.08)、边缘透明，中心向左上偏移 40/50px），再画 1px rgba(120,160,255,.18) 的球轮廓圈。
- 陆地点：斐波那契球面均匀撒 6400 个采样点，用 12 组写死的经纬度多边形轮廓做点内判定（纬度低于 −68° 的南极圈整片算陆地），命中的点进入绘制列表；每点画为小方块，尺寸 0.6+z×1.2 px，颜色随深度插值 rgba(120+k·80, 170+k·60, 255, 0.12+k·0.78)（k=(z+0.15)/1.15），z 低于 −0.15 的背面点直接跳过。
- 城市：12 座写死坐标（纬度,经度）——Seoul (37.6,127)、Tokyo (35.7,139.7)、New York (40.7,−74)、San Francisco (37.8,−122.4)、London (51.5,−0.1)、Berlin (52.5,13.4)、São Paulo (−23.5,−46.6)、Lagos (6.5,3.4)、Mumbai (19.1,72.9)、Sydney (−33.9,151.2)、Singapore (1.35,103.8)、Dubai (25.2,55.3)。每城初始访客数 40 + random×260 取整（40–300）。正面城市（z ≥ 0.05）画 #5CF2B5 实心圆点（半径 2.6+z，悬停时变白色 4.2）与一根 8×z px 高的旗杆线（rgba(92,242,181,.35)、1px）。
- 涟漪：绿色圆环 stroke rgba(92,242,181, 0.9×(1−t))、线宽 1.4、半径 3 + t×18，寿命 1.4s，只画正面城市（z ≥ 0.05）。
- 计数行：绝对定位 left 16px、top 14px、pointer-events none——小标「Live visitors」10.5px/字重 700、rgba(232,240,255,.55)、字距 .02em；数字 20px/字重 800、tabular-nums、字距 -.02em，前置一枚 7px #5CF2B5 圆点跑 1.6s 无限脉冲（box-shadow 从 0 扩到 7px 再消散）；数值为 12 城访客数之和，toLocaleString 千分位格式。
- 悬停气泡：绝对定位，padding 6px 9px、圆角 10px、底 rgba(232,240,255,.95)、文字 #0F1A33、11px/字重 750、不换行、pointer-events none；副行为 10px/650、色 #4A5878；默认 opacity 0、translate(-50%,-140%) scale(.9)，显示时过渡 opacity .18s、transform .25s 弹性曲线。
- 组件固定 340px 逻辑宽度：容器更窄时整景按 min(1, 容器宽/340) 等比缩放，指针坐标按缩放比换算。

## 数据

- 陆地点阵完全确定性生成：6400 个斐波那契采样点 + 写死的 12 组大陆轮廓多边形，无随机种子参与。
- 运行时随机数据：12 城初始访客数 40–300 随机；每 0.35s 随机选一座城市生成涟漪，同时该城访客数按 round((random−0.35)×9) 漂移、下限 20（轻微净流出倾向）。城市名与坐标写死如上。无外部数据来源。

## 操作和动效

- 自转：常态角速度 0.18 rad/s，rot 初始 −2.1 rad；rAF 逐帧推进（帧步长 clamp 0.05s），非拖动时速度按每秒 1.2 倍指数速率向 0.18 回归（带惯性的阻尼回落），rot += vel×dt。
- 拖动：pointerdown 记录起点（setPointerCapture），位移除以半径 132 直接换算为旋转角（拖 132px 转 1 rad）；每次 pointermove 用增量测瞬时角速度，松手时速度 clamp 到 ±6 rad/s 作为甩出惯性，随后阻尼回常态。
- 悬停：pointermove 对正面城市做命中检测（半径 11px），命中显示气泡（城市名 + 「Now N visiting」，数值为该城当前访客数）；pointerleave 清除。
- 涟漪与计数：每 0.35s 随机一城起一圈涟漪并微调访客数，计数行每帧重算总和；涟漪 1.4s 荡开后移除。
- `prefers-reduced-motion: reduce`（或 options.reducedMotion）下：不启动 rAF 循环，挂载时画单帧静止地球（初始 rot −2.1），涟漪不生成、访客数保持初始值；左上角绿点脉冲动画关闭；悬停与拖动仍可用——每次指针移动/离开重绘一帧，转动即时生效但没有惯性。
- 无障碍：canvas role="img" + aria-label；计数行与气泡为真实文本；装饰性辉光与涟漪无需替代文本；无键盘操作路径（纯指针地球）。
- options.height 调整场景高度（默认 340）；options.reducedMotion 覆盖系统偏好，切换后按新模式重绘。支持同页多实例，更新选项不重挂载；卸载时停止帧循环、断开观察器并移除监听。
