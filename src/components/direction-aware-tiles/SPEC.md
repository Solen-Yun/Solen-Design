# 入边方向浮层 — DirectionAwareTiles

340×340 的作品九宫格：九块瓷砖铺满画面，每块瓷砖是一段写死的抽象渐变画。鼠标（或手指）移进某块瓷砖时，说明浮层从光标进来的那一条边滑入盖住整块瓷砖——从上边进来就自上滑入、从左边进来就自左滑入，以此类推；光标移向另一块瓷砖时，旧浮层朝离开的方向滑出、新浮层从新进入的方向滑入；光标整体离开九宫格时，浮层朝最后一次的离开方向滑走。键盘 Tab 聚焦到某块瓷砖时，浮层固定从顶部滑入、失焦时固定向底部滑出。

## 布局与材质

- 340×340px 场景卡，圆角 30px，溢出裁切，内边距 18px，底色 #F1EEE8（写死的浅米色，不随深浅色切换），外圈 1px 线色描边，下方 0 30px 60px -36px 强阴影。场景内是 3 列 3 行网格，间距 8px，铺满可用区域；容器变窄时整景按 `min(1, 可用宽 / 340)` 等比缩小，不重排。
- 每块瓷砖是一个原生按钮：圆角 12px、无描边、无内边距、溢出裁切、鼠标为指针、内建文字色 #fff。按钮内第一层是绝对定位铺满的画布 `<i>`，写死各自的渐变；第二层是说明浮层，绝对定位铺满、纵向 flex 底部对齐、间距 2px、内边距 10px、底色 rgba(20,18,30,.82)、文字左对齐。
- 浮层文案三层：类别行 9.5px/650、70% 不透明度；项目名 12px/800、行高 1.2、不断词换行；行动行 "View →" 10px/800、顶部留 4px、颜色 #FFD8A8。
- 九块瓷砖的写死画布与文案：
  1. House of Wind / Architecture — 160° 渐变 #ADB5BD 到 #343A40
  2. Salt Studio / Branding — 上 40% #F8F9FA、下 60% #CED4DA
  3. Night Library / App — 径向渐变，圆心在 60% 30%，中心 12% 内 #FFE066、其后 #1B1F3B
  4. Blue Garden / Exhibition — 上 45% #A5D8FF、下 55% #2F9E44
  5. Paper Workshop / Packaging — 135° 渐变，上半 #F8F0E3、下半 #D9B482
  6. Slow Post / Web — 上 55% #FFA8A8、下 45% #C92A2A
  7. Sea Cinema / Film — 上 60% #1864AB，60% 到 63% 为 #FCC419，其余 #0B3D91
  8. Little Bakery / Branding — 150° 渐变 #FFE8CC 到 #E8590C
  9. Forest Sounds / Music — 160° 渐变 #B2F2BB 到 #087F5B
- 浮层未展开时整体位移到瓷砖上方外侧（自上方向外偏移 101%），展开后归位；位移用 `transform` 过渡 0.32s、缓动 `cubic-bezier(.3,.8,.3,1)`。
- 场景令牌浅色与深色两套（`prefers-color-scheme` 切换）：表面 #FFFFFF / #13141C，次级表面 #F5F3EF / #1A1B25，墨色 #16151B / #F4F0E8，三级墨 #8E8A97 / rgba(244,240,232,.42)，线色 rgba(22,21,27,.09) / rgba(255,255,255,.08)，强调色 #6A57F2 / #B7A4FF，强阴影 rgba(40,30,80,.3) / rgba(0,0,0,.72)。本组件自身的底色、浮层底色与文字色都是写死值，不吃令牌；正文使用系统无衬线栈。

## 数据

- 写死数据为一组 9 条 `[项目名, 类别]` 与一组 9 条画布渐变，按下标一一对应，顺序即九宫格的行优先顺序。
- 浮层里的行动文案固定为 "View →"。无网络数据、无外部图片。

## 操作和动效

- 方向判定：进入某块瓷砖时，取光标相对该瓷砖中心点的偏移，横纵各除以瓷砖自身宽高得到归一化偏移；谁的绝对值大就取那一侧，横向偏移为正取右边、为负取左边，纵向偏移为正取下边、为负取上边。四个方向的"藏起来"位移分别是：上 `translate(0,-101%)`、右 `translate(101%,0)`、下 `translate(0,101%)`、左 `translate(-101%,0)`。
- 命中判定用元素命中测试：在场景根上监听指针移动，取该坐标下最靠近的瓷砖元素，因此指针压在浮层上时依然算作命中同一块瓷砖。
- 展开流程：先摘掉过渡类、把浮层瞬间放到"藏起来"的位置，再强制一次布局让浏览器认到起始状态，随后挂上过渡类并把位移归零，浮层于是从选定的那条边滑入盖住瓷砖。
- 收起流程：同样挂上过渡类，把位移设成当前光标相对该瓷砖中心的离开方向，浮层朝那条边滑出；指针整体离开九宫格时也走这条路。
- 键盘操作：瓷砖聚焦时浮层固定自顶部滑入（方向取"上"），失焦时固定朝底部滑出（方向取"下"）；焦点样式为 2px #1E1B2E 外圈、偏移 2px。
- 无障碍：九宫格容器为 `role="group"`，`aria-label` 为 "Nine project tiles"；每块瓷砖是原生按钮，`aria-label` 为"项目名, 类别"；浮层整体 `aria-hidden`，因为同样的信息已由按钮的可访问名给出。
- 减少动态：命中 `prefers-reduced-motion` 时不做位移滑入，浮层直接淡入（0.2s 的透明度过渡），离开时直接淡出；宿主在减少动态下会关闭其余 CSS 过渡与动画。
