Implement the "SpotlightCard" component from zero: a card whose surface is lit by a soft spotlight that follows the pointer — a warm pool of light fills the card, a brighter rim catches the edge nearest the light, an optional grain layer picks up the same falloff, and the light can reach out to nearby cards through a proximity halo before the pointer ever enters. Full specification follows; it must not depend on external pages, videos, images (beyond one tiny inline SVG noise tile), font files, or off-the-shelf effect components.

## Structure & rendering

- Pure React + CSS, two files only: SpotlightCard.jsx and SpotlightCard.css. React >= 18; no runtime dependencies; no WebGL, no canvas — everything is DOM layers plus `radial-gradient()` strings written as inline `background`.
- Root is a `<div class="spotlight-card">` (plus any className): position relative, isolation isolate, overflow hidden, padding 2rem, border-radius 1.5rem, background-color from the theme surface, box-shadow from the theme shadow. Theme palette is injected as inline CSS variables on the root: dark theme — surface #111111, border rgba(255,255,255,0.08), shadow `0 24px 48px -24px rgba(0,0,0,0.6)`; light theme — surface #ffffff, border rgba(24,24,27,0.1), shadow `0 1px 2px rgba(24,24,27,0.04), 0 18px 40px -20px rgba(24,24,27,0.16)`.
- Five paint layers, all absolutely positioned `inset: 0` with `border-radius: inherit` and `pointer-events: none`, in DOM order: (1) `__light` — the fill spotlight, z-index −1, under the content; (2) `__grain` — a noise overlay, z-index −1, background-image a 160×160 inline SVG `feTurbulence fractalNoise baseFrequency 0.85 numOctaves 2` tile desaturated with `feColorMatrix saturate 0`, background-size 160px 160px, mix-blend-mode overlay; (3) the children (content, above the light); (4) `__border` — a static 1px frame, z-index 1, background the theme border, drawn via the padding + `mask-composite: exclude` trick so only the ring shows; (5) `__edge` — the rim light, z-index 1, same 1px ring mask, background written per frame with the edge spotlight gradient.
- Spotlight gradients are generated by a falloff builder: given the spotlight colour and a softness value it emits 15 `color-mix(in srgb, <color> N%, transparent) M%` stops. The core plateau shrinks as softness grows (core = (1 − softness)^1.5 × 0.85 of the radius), then a smoothstep ramp is blended with a gaussian glow term `exp(−4.6·g²)·(1 − g⁶)` — softness 0 gives a hard-edged disc with a soft rim, softness 1 gives a wide diffuse pool. The edge layer always uses softness 1 (fully diffuse).
- Shapes: `circle` renders `radial-gradient(circle <size>px at <x>px <y>px, …)`; `beam` renders a vertical shaft anchored to the top edge — `radial-gradient(<size·0.55>px <reach>px at <x>px 0px, …)` where reach = max(size·0.6, y + size·0.55), so the beam stretches from the top toward the pointer's depth. An unknown shape falls back to circle. The edge layer reuses the same shape geometry at 0.6× size (for a beam, always anchored at y = 0).
- The grain layer is masked by a plain black-to-transparent radial gradient of the same shape/position/size, so the noise fades in only where the light shines; its opacity is presence × grain.

## Motion engine

- All dynamics live in one `useEffect` closure with refs (settings refreshed every render via a settingsRef, so prop changes apply without re-binding listeners). Frame state: light position (x, y), presence 0–1, flare 0–1, pressed flag, ambient clock, focus target, visibility flag.
- Target position: when an element inside the card has keyboard focus (`:focus-visible`), the spotlight aims at that element's centre; otherwise at the last pointer position relative to the card. Target presence: 1 when the pointer is inside the card rect; otherwise, if proximity > 0, `max(0, 1 − gap/proximity)²` where gap is the pointer's distance outside the card rect (0 inside) — so the light breathes in as the pointer nears, reaching neighbouring cards before entry; gap 0 with proximity 0 pins presence to 0 outside.
- Ambient mode: when target presence < 0.6 and ambient is on and the card is visible, the aim point blends toward a slow Lissajous drift — `width·(0.5 + 0.34·sin(0.43t))` × `height·(0.5 + 0.3·sin(0.61t + 1.3))` — blended by (0.6 − target)/0.6, and presence is held at 0.6, so the card idles with a wandering lamp instead of going dark.
- Smoothing: position follows the target with `1 − exp(−dt/(0.015 + smoothing·0.22))` per frame (smoothing 0 snaps); presence fades with time constant 0.1 s when brightening and 0.32 s when dimming; flare eases to 1 while pressed (0.05 s) and back (0.28 s). Presence snaps when within 0.002.
- Painting: fill size = spotlightSize × (1 + 0.2·flare); a boost = 1 + 0.7·flare multiplies both light and edge opacity (fill opacity = presence × intensity × themeFill × boost, capped at 1; edge opacity = presence × borderGlow × themeEdge × boost). Theme multipliers: dark fill 1 / edge 1, light fill 0.28 / edge 0.7 — the same colours read stronger on dark. Gradient strings are cached and only written when changed.
- Frame-loop self-sleep: the loop keeps running only while the position is > 0.1px from target, presence ≠ its target, or flare ≠ its press target (ambient + visible keeps it alive); otherwise one final paint and stop. wake() is triggered by every relevant effect hook.
- Listeners: window `pointermove` (records pointer, wakes when light is on or proximity > 0 or the event is inside the root), window `pointerup`/`pointercancel` (releases press; non-mouse pointers also clear the pointer), document `pointerout` (when leaving the window), window scroll capture (re-mapping), root `pointerdown` (press + flare), root `focusin`/`focusout` (focus tracking). An IntersectionObserver feeds visibility; loops pause when hidden.
- Reduced motion (`prefers-reduced-motion: reduce`): follow and fade rates become 1 (instant), ambient clock stops (static pool), flare is suppressed.
- Unmount: cancel the frame, disconnect the observer, remove every listener, clear the wake hook. Same-page instances are fully independent.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| children | ReactNode | - | Card content, painted above the light layers. |
| className | string | "" | Extra class names for the card. |
| style | CSSProperties | - | Inline styles for the card. |
| spotlightColor | string | - | Colour of the light. Falls back to the theme ink (#ffffff dark / #18181b light). |
| intensity | number | 0.15 | Peak brightness of the fill light, 0–1. |
| spotlightSize | number | 240 | Radius of the light pool in px, floored at 20. |
| softness | number | 0.7 | How diffuse the pool edge is, 0–1; 0 is a crisp disc. |
| shape | "circle" \| "beam" | "circle" | Round pool, or a vertical shaft hanging from the top edge. |
| borderGlow | number | 0.6 | Brightness of the rim light on the 1px frame, 0–1. |
| proximity | number | 80 | How far (px) the light reaches past the card edge; 0 disables. |
| smoothing | number | 0.3 | Pointer lag, 0–1; 0 tracks instantly. |
| ambient | boolean | false | When the pointer is far, the light keeps wandering on its own. |
| flare | boolean | true | Pressing the card blooms the light larger and brighter. |
| grain | number | 0 | Film-grain amount riding the light, 0–1. |
| theme | "dark" \| "light" | "dark" | Card surface, border, shadow and default light colour. |

All numeric props are clamped/ floored as described; a theme name outside dark/light falls back to dark.
