# 解锁成就徽章 — AchievementBadges

制作「解锁成就徽章」卡片：一张 340×340 的成就墙场景，六枚圆形徽章按三列两行排布，默认前三枚已点亮（彩色奖章），后三枚是灰盘挂锁的锁定态并各带一条进度条。点击任意已点亮徽章，徽章绕竖轴 3D 翻面，露出深色背面上的成就名称、描述与获得日期；再点一次翻回正面。按下底部 Unlock 按钮，下一枚锁定徽章依次点亮：进度条先充满，随后灰盘恢复彩色、灰色挂锁向上弹飞消失、一道扫光掠过徽章、奖章图形左右摇晃并弹性放大，同时从奖章中心炸开 14 粒彩色粒子，头部计数胶囊随之 +1。六枚全部点亮后 Unlock 置为禁用。

## 布局与材质

- 340×340px 场景卡，圆角 30px，溢出裁切，背景为固定浅色渐变 linear-gradient(165deg,#F8F9FA,#EDF0F3)，文字基色 #212529；外圈 1px 线色描边加 0 30px 60px -36px 强阴影。场景根是 340×340 的无底色包装层（水平居中），卡片视觉放在其内部的绝对填充层上——文档演示舞台会剥离场景根的背景，卡片底色必须在嵌套层上才能保留。窄容器下整景按 min(1, 容器宽/340) 等比缩小。
- 根元素声明整套场景令牌（CSS 变量 + `light-dark()` 两套值）：浅色面 #FFFFFF / 面 2 #F5F3EF / 面 3 #EAE7E1、墨色 #16151B / 墨 2 #57535F / 墨 3 #8E8A97、线 rgba(22,21,27,.09) / 线 2 rgba(22,21,27,.17)、accent #6A57F2（深色 #B7A4FF）、薄荷 #119C72、警示 #D6731E、危险 #D93A55、阴影 rgba(40,30,80,.14)/强 rgba(40,30,80,.3)；深色套为面 #13141C、墨 #F4F0E8、线 rgba(255,255,255,.08) 等。本卡片的底色与文字用固定浅色值，深浅两套下观感一致。
- 头部在卡内左 20px、右 20px、上 20px：左侧标题「My badges」15px/字重 900、字距 -0.02em；右侧计数胶囊内边距 3px 9px、圆角 999px、白底、内嵌 0 0 0 1px rgba(33,37,41,.08) 描边、文字 10.5px/850 色 #495057、tabular-nums，内容形如「3/6 earned」，带 aria-live="polite"。
- 徽章网格：左 16px、右 16px、上 54px，三等列、列间与行间 9px，容器带 perspective:800px。每枚徽章是 104px 高的原生按钮（type="button"），transform-style:preserve-3d，翻面过渡 0.6s cubic-bezier(.3,1.3,.5,1)。
- 正面（.u386-f）：圆角 16px、白底、阴影 0 6px 16px -10px rgba(33,37,41,.4) 加内嵌 0 0 0 1px rgba(33,37,41,.06)，纵向居中排列。奖章图形 52×52px，为 viewBox 0 0 56 56 的内联 SVG：半径 26 的圆以对角线性渐变填充（每枚一对起止色，见「数据」），内圈半径 21.5 的 1.4px 白色描边环（45% 透明），左上方一枚 rx10/ry5、22% 白色透明度、旋转 -25° 的高光椭圆，中央以白色 2.1px 圆头描边绘制 24 坐标系线性图标。图标下 7px 处为徽章名 11.5px/850、字距 -0.01em。
- 挂锁覆盖图与奖章同位同尺寸：锁环为 #868E96 2.6px 圆头描边弧线，锁体 x19.5/y26.5 宽 17 高 13 圆角 3.5 填充 #868E96，锁孔为圆心 (28,32) 半径 1.8 的白点。锁定态整枚奖章灰度化（grayscale(1)）并降到 28% 透明度，徽章名变 #ADB5BD；点亮后挂锁以 0.45s cubic-bezier(.3,1.6,.5,1) 弹飞——上移 14px、放大 1.4 倍、旋转 -20°、淡出（透明度 0.3s）。
- 锁定徽章的进度行在名称下 5px 处：38×4px 圆角 2 的 #E9ECEF 底槽，内嵌 #ADB5BD 填充条以 scaleX(var(--p)) 从左生长（0.35s ease-out），旁注 9px/800 色 #ADB5BD 的 tabular 分数「9/12」。
- 背面（.u386-k）：预旋转 rotateY(180deg)，圆角 16px、内边距 10px 8px、深色渐变 linear-gradient(150deg,#343A40,#1A1D20)、文字 #F8F9FA、居中三行——徽章名 12px/900 取该徽章主色、描述 10.5px/700 行高 1.35、获得日期行「Earned 2026.03.02」9px/700 色 #ADB5BD、tabular-nums。
- Unlock 按钮：绝对定位水平居中、距底 20px，高 38px、内边距 0 18px、圆角 999px，墨色 #212529 实底、白字 12.5px/850，阴影 0 8px 18px -10px rgba(33,37,41,.8)；禁用时透明度 0.35。徽章与按钮的 focus-visible 均为 2px #212529 外圈（徽章外圈圆角 16px、偏移 3px；按钮偏移 3px）。

## 操作和动效

- 点击已点亮徽章：移除 is-new 后切换 is-flip，徽章以 0.6s cubic-bezier(.3,1.3,.5,1) 绕 Y 轴翻到背面（正反面均 backface-visibility:hidden），再次点击翻回；锁定徽章点击无效。
- 点击 Unlock（全部点亮或正在播放时忽略）：先把该枚进度条填满到目标（0.35s ease-out，分数变为 12/12 等满值），420ms 后（减少动态时为 0ms）执行解锁——busy 释放、已点亮数 +1、刷新计数胶囊与锁定态；徽章加 is-new 触发两段动画：扫光为正面 ::after 覆层（inset -20%，110° 线性渐变，中段 95% 白色）从 translateX(-120%) 扫到 120%，0.9s ease-out、延迟 0.35s；奖章图形摇晃弹出 0.75s cubic-bezier(.3,1.6,.5,1)，关键帧 0% 复位 → 12% 左倾 -10° → 24% 右倾 10° → 36% -6° 且缩 0.9 → 70% 放大 1.16 → 100% 复位。动画结束（animationend 命中奖章图形）时移除 is-new。
- 粒子迸发：解锁瞬间从奖章中心生成 14 个 6×6px 圆点 span，底色按该徽章两色交替，均匀分布在 2π 圆周上、距离 34 + 随机 0–26px，0.8s ease-out forwards、延迟 0.3s，飞散中缩到 0.4 倍并淡出，1200ms 后移除节点。位置按徽章实际渲染坐标换算，整景被缩小缩放时同样准确。
- `prefers-reduced-motion: reduce` 下：徽章翻面、进度条、挂锁弹飞的过渡与扫光、摇晃动画全部关闭（CSS 媒体查询置 none），解锁延时压缩为 0ms，粒子迸发跳过，最终点亮状态完整可见。options.reducedMotion 为 true 时等价生效。
- 无障碍：每枚徽章是原生按钮并带动态 aria-label——锁定为「<名称> badge, locked」，点亮为「<名称> badge, flip」；奖章、挂锁 SVG 均 aria-hidden；计数胶囊 aria-live="polite" 播报变化；Unlock 为原生按钮，全部点亮后 disabled。所有 SVG 渐变 id 带随机后缀，同页多实例互不冲突；更新 options 不重挂载，卸载时清理计时器与监听器。
