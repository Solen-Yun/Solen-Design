Implement the "Carousel" component from zero: a swipeable card carousel where every card sits on its own pose along a track — five switchable transition styles (tilt, slide, scale, fade, cube), a spring engine that glides each selection into place, drag with velocity fling, wheel scrolling, keyboard control, three indicator styles plus optional arrows, and an autoplay timer with pause-on-hover. Cards accept photos with captions, plain text tiles, or arbitrary React content. The whole unit wears an optional frosted frame and comes in dark and light themes. Full specification follows; it must not depend on external pages, videos, or off-the-shelf effect components.

## Structure & rendering

- Pure React + CSS, two files only: Carousel.jsx (entry, geometry, spring engine, input handling) and Carousel.css (all styles). React >= 18. Icon glyphs (chevrons and the default items' little marks) come from the icon packages @hugeicons/react and @hugeicons/core-free-icons; they are the only runtime dependencies. No iframe, no canvas.
- Root is a `<div>` with class carousel-container plus has-frame when the frame is on and is-round when round cards are on: position relative, flex column centered, gap 20px (16px framed), max-width 100%. It carries role="region", aria-roledescription="carousel", aria-label="Carousel", tabIndex 0 so arrow keys land on it.
- Theme tokens are injected as inline CSS variables from the theme prop: dark uses a frosted frame rgba(38,35,46,0.66), tile gradient #3a3644 → #27242f, ink #f4f4f5, muted ink at 60%, hover brightness(1.12) and press brightness(0.8); light uses frame rgba(240,240,243,0.8), tile gradient #ffffff → #f6f6f8, ink #27272a, hover brightness(0.97), press brightness(0.92). Two extra inline vars are derived per render: --carousel-radius (round forces 9999px, otherwise the radius prop) and --carousel-scale (clamped cardWidth/300 in 0.86–1) which scales the card paddings and font sizes.
- Inside is a stage (carousel-stage) holding, when framed: 10px padding, a radius + 10px background of the frame token, a soft frame shadow, backdrop blur(20px) saturate(1.6), overflow hidden, and an absolutely positioned rim span drawing a 1px inset edge plus a 1px top highlight. The viewport (carousel-viewport) is the touch/drag surface: touch-action pan-y, cursor grab while draggable and grabbing while dragging, and its inline style carries height, negative inline margins equal to the bleed, a perspective (cube: 2.6 × cardWidth; tilt: 1000px; others none), overflowX clip and a generated edge-fade mask when clipping is on.
- Each item renders as an absolutely positioned carousel-slide anchored at left: inset, sized cardWidth × cardHeight, holding a carousel-card. The card for an object item is a flex column with padding 20px × scale, the tile gradient, a tile shadow, and a rim span (inset 1px edge + top highlight); a photo item additionally paints an object-fit-cover img (draggable false, async decoding) and a bottom-up black scrim whose opacity equals the slide's focus value; an icon prop renders inside a 32px circle badge (over photos: white at 18% on blur 10px); title at 18px × scale weight 600 and description at 14px × scale muted, both fading with the focus value; over photos the text is forced white (description white at 78%). A string item is treated as { image: string }. A React-element item renders as-is inside a padding-less is-custom card. Every card ends with the rim span.
- Round mode turns every card into a circle: cardWidth = cardHeight = diameter (the slot width when framed, otherwise the slot clamped by the aspect ratio), padding 14%, centered content, text compacted (the description is dropped when the card is narrower than 240px), and the stage border-radius becomes 50% when framed.

## Geometry & pose engine

- baseWidth sets the design width; the container width is min(100%, maxWidth) where maxWidth equals baseWidth, except round + framed which widens it to 20 + (baseWidth − 20) × min(1, 1/aspectRatio) so the circle still fits. The stage is measured by a ResizeObserver into a width state (frame padding of 20px subtracted). aspectRatio is clamped 0.3–4. side padding = 0 for stacked modes (fade/cube) and round + framed, otherwise clamp(peek, 0, width × 0.2); slot = max(40, width − side×2); cardWidth = round ? diameter : slot; cardHeight = round ? diameter : slot/ratio.
- Unframed + non-stacked layouts clip horizontally (overflowX clip) with a bleed of min(48, cardWidth × 0.12) on each side, negative viewport margins, and a symmetric CSS mask built from 8 smootherstep alpha stops per edge so neighbouring cards fade out at the edges; inset = bleed + (width − cardWidth)/2. The per-card step span is cardWidth + max(0, gap).
- pose(index, position) computes, per slide: offset = index − position (shortest wrapped distance when loop), distance, focus = 1 − smoothstep(near) used for scrim/text/opacity focus, layer = 10 − min(9, round(distance × 2)). tilt: translate3d(offset × span) + rotateY(−clamp(offset, −1, 1) × 90deg), hidden beyond distance 1. slide: plain translate3d. scale: pulls cards 6% of cardWidth inward, scales down 12% per step and drops opacity 50% per step. fade and cube are stacked (all cards at the same x): fade cross-dissolves with a smoothstep opacity and a 4% shrink, visible only within distance 1; cube turns cards like cube faces — scale(1 − 0.12 × turn) translateZ(−half) rotateY(±90° × clamped offset) translateZ(half) where turn follows the fractional position, plus a black shade span over each card whose opacity is distance × shade (0.6 dark / 0.3 light theme).

## Motion & input

- One rAF engine. The target position springs toward its goal with stiffness 150 and damping 24, integrated in 240Hz sub-steps of the frame delta (clamped to 50ms); it settles (snaps to target, velocity zeroed) when the position error is under 0.0004 and velocity under 0.004. In loop mode the settled target wraps back into 0..count−1. The loop sleeps when nothing is moving; it wakes from any input, resize, visibility change, or intersect.
- Drag: pointerdown on the viewport records the pointer (mouse must be button 0); movement starts after a 6px slop and is cancelled if vertical intent dominates on non-mouse pointers; pointer capture is taken and the position follows the pointer 1:1 in card units, rubber-banded past the ends when not looping (overhang compressed by an exponential 0.55 falloff to ±30%). Velocity is estimated from the last ~90ms of position samples (clamped ±12 units/s); on release the target is round(position + velocity × 0.2), and if that equals the drag origin it steps one further when |velocity| > 0.8 or |travel| > 0.18. A click captured right after a drag is suppressed so card clicks never fire mid-fling.
- Wheel: only when horizontal intent dominates (|deltaX| > |deltaY|); preventDefault, position advances by deltaX in card units (clamped −0.15..count−0.85 when not looping), and after 120ms without wheel input it snaps to the nearest card. Keyboard: ArrowRight/ArrowLeft step one card, Home/End jump to the ends; keys are ignored while typing in inputs, textareas, selects or contenteditables. Clicking any non-current slide goTo's it.
- goTo picks the shortest wrapped path in loop mode; step clamps to the ends when not looping. Every target change announces the rounded index into React state (so indicators, data-current, aria-current and the counter update) and fires onChange(index) whenever the announced index differs.
- Indicators render under the stage (inside it when framed and not round): dots — 20px buttons with an 8px mark that scales 1.2 and fills with ink when active; bars — flex 1 tracks 3px tall whose fill scaleX shows 1 for passed slides, the autoplay progress (elapsed/delay) for the current one and 0 for the rest; counter — tabular "01 / 05" where the current number slides in 70% from the direction of travel over 320ms cubic-bezier(0.2, 0.8, 0.2, 1) (skipped under reduced motion). none hides indicators. Arrows are 32px circular tile buttons with 16px chevrons, disabled (35% opacity) at the ends when not looping, pressing dips to press brightness and scale(0.92).
- Autoplay: accumulates ms toward autoplayDelay (floored at 600) and steps forward when it elapses; auto-advance past the last card wraps to 0 even when loop is off. It pauses while hovered (with pauseOnHover), focused (any :focus-visible inside), dragging, wheeling, offscreen (IntersectionObserver) or document hidden. aria-live on the viewport is "polite" unless autoplay is on (then "off" to avoid chatter).
- Reduced motion: the spring is bypassed — position snaps straight to the target on every frame — and the counter animation is skipped. Unmount: cancels the frame, disconnects the ResizeObserver and IntersectionObserver, removes all viewport/root/document listeners and clears timers. Multiple instances are fully independent.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| items | ({ id?, image?, alt?, icon?, title?, description? } \| string \| ReactNode)[] | DEFAULT_ITEMS | The cards. Objects may carry a photo URL, caption text and an icon; strings are treated as photo URLs; React elements render as custom cards. The five defaults are text tiles with small icons describing the interactions. |
| baseWidth | number | 300 | Design width of the carousel in px; the container caps at 100% of its parent. |
| aspectRatio | number | 1.25 | Card width ÷ height, clamped 0.3–4. |
| peek | number | 0 | Side padding revealing neighbouring cards, in px; clamped to 20% of the width; 0 for fade/cube and round + framed. |
| gap | number | 16 | Space between cards along the track, in px; negatives are treated as 0. |
| radius | number | 12 | Card corner radius in px; round mode forces a full circle. |
| frame | boolean | true | Shows the frosted frame around the stage. |
| effect | "tilt" \| "slide" \| "scale" \| "fade" \| "cube" | "tilt" | Transition style; unknown values fall back to tilt. |
| indicator | "dots" \| "bars" \| "counter" \| "none" | "dots" | Progress UI under the cards; bars double as the autoplay progress. |
| arrows | boolean | false | Shows prev/next chevron buttons beside the indicator. |
| autoplay | boolean | false | Advances one card every autoplayDelay. |
| autoplayDelay | number | 3000 | Autoplay interval in ms; floored at 600. |
| pauseOnHover | boolean | false | Pauses autoplay while the pointer is over the carousel. |
| loop | boolean | false | Wraps navigation past the ends and always takes the shortest path. |
| draggable | boolean | true | Enables pointer dragging, flinging and horizontal wheel scrolling. |
| round | boolean | false | Renders circular cards (diameter follows the aspect ratio and frame). |
| initialIndex | number | 0 | Which card starts current, clamped into range. |
| theme | "dark" \| "light" | "dark" | Colour theme of frame, tiles and text. |
| onChange | (index: number) => void | - | Called whenever the current card settles on a new index. |
| className | string | "" | Extra class names for the container. |
| style | CSSProperties | - | Inline styles for the container. |
