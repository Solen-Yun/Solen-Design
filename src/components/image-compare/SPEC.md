# 弹性图片对比 — ImageCompare

制作「弹性图片对比」组件。左右显示同一画面的黑白和彩色状态，拖动把手时对比线弯曲，快甩时滑到相应边缘。图片切口和白线始终沿同一条曲线。

## 构图

- 背景 #f4f4f4，画面居中。图片框 270×360px，默认圆角20px，可调0–28px，overflow:hidden。窄于270px时等比缩小，指针位置由实际渲染矩形换算成0–1。
- 内嵌一张3:4竖幅自然风景插画壁纸作为默认图（540×720，base64 JPEG data URI）：冬夜雪山环抱的镜面湖，绿紫极光在湖面完整倒映，湖心小木屋透出暖黄窗光，深蓝夜空主调。两层用同一张图像、相同 object-fit:cover，不做视差。右侧原彩，左侧 grayscale(1) brightness(.77)。支持用同构图的独立图片替换两层。
- 默认 p=.5。白色2px分隔线带 0 0 6px rgba(255,255,255,.5) 柔光。36px圆形把手居中在线的中点，用卡片底色和前景色，阴影 0 2px 12px rgba(23,24,26,.25)。把手中放16×10的双箭头 SVG，路径 M5 1 1 5l4 4M11 1l4 4-4 4，线宽1.8，圆角端点。悬停放大1.08，按住缩至.9，220ms cubic-bezier(.24,1.34,.38,1)。
- Before 和 After 标签距上、左右各12px，圆角胶囊，4px×12px 内边距，半透明深灰 rgba(23,24,26,.36)，背景模糊10px，白色12px/1.45中等字重。透明度分别为 clamp((p-.14)*4,0,1) 和 clamp((.86-p)*4,0,1)。labels 默认 true。
- 将背景、卡片底色、文字、焦点色和字体映射到宿主令牌，在组件根节点提供 #17181a、#fff、#2231dd 和 system-ui, sans-serif 回退。

## 运动与输入

- x=p*270，端点状态 e 初始 .5，速度 v 初始0。每帧 dt 以秒计且最大.033；若有目标 t，p += (t-p)*(1-.0004^dt)，距离小于.0005 时吸附。v += ((p-e)*620-v*44)*dt；e += v*dt。bend=clamp((p-e)*135,-9,9)。没有目标且 |p-e|<.0006、|v|<.002 时停止 RAF 并清零弯曲。
- 端点横坐标 x-bend。可见 SVG 路径 M (x-bend) 0 Q (x+bend) 180 (x-bend) 360。左图 clip-path:path() 在同一段前加 M 0 0 L (x-bend) 0，最后加 L 0 360 Z。把手横坐标 x，纵坐标180。所有坐标都是框内设计像素。由于二次曲线在一半处的权重，曲线中点精确穿过把手。
- 按下捕获一个主指针并滑到按下位置，拖动时把手立即跟指针，弹簧只负责线端。由相邻输入估算每毫秒的归一化速度。松手时最近采样不超过80ms且速度绝对值大于.0025，则按方向滑向0或1。慢拖停在释放点。取消、丢失捕获或页面隐藏时释放手势。
- role=slider、tabindex=0、aria-valuemin=0、aria-valuemax=100，报告四舍五入后的百分比。方向键每次移动10%，Home/End滑到两端。可见2px焦点环。触屏用原生 Pointer Events。减少动态时立即定位并令线保持笔直。生命周期清除 RAF 和监听器。

## 交付

公开 labels、corner、beforeSrc、afterSrc。未指定 beforeSrc 时，左层从同一张彩色图生成灰度。提供 React、Vue、Svelte、Solid、Preact、Vanilla 的原生挂载入口，共享 DOM 核心，每个实例单独维护状态。测试慢拖停留、快甩两端、拖到框外、键盘、触屏、标签和圆角更新、双实例与卸载。
