# 胶片式测速审计 — PageSpeedAudit

制作一张 340×340 的性能审计场景。顶部并排四个环形分数盘（Performance、Accessibility、Best practices、SEO），每个环中央一个大号数字、环外侧一个标签，盘底有一层同色 10% 的圆晕；环按分数着色——90 分以上绿、50 分以上琥珀、更低玫红。中部是一条胶片条，内含 6 格自绘的页面缩略帧，从「空白」到「骨架」「文字」「图片」逐级加深，下方一条细时间轴标着 0.3 s / 0.6 s / 0.9 s / 1.2 s / 1.5 s / 1.8 s，一枚写 "LCP" 的绿色游标停在第 5 帧上方。再下面三行指标（名称、带阈值色带的进度条、右侧数值），色带按绿→琥珀→红三段分布，指针滑到各自位置。最底部是一枚通栏按钮。组件进入视口时自动跑一次审计：六格胶片按 330ms 间隔逐帧亮起，2400ms 后四个环按分数描线、中心数字用三次缓出滚动到目标值，三条指标指针滑到目标位置，按钮文案从 "Auditing…" 变成 "Run again"。

## 布局与材质

- 340×340px 场景卡，圆角 30px，overflow 裁切；底色为表面色纯色，外圈 `0 0 0 1px` 线色描边，下方 `0 30px 60px -36px` 强阴影。
- 分数盘行绝对定位 left 12px / right 12px / top 16px，四列等分 grid、文本居中。每个盘 54×54px、水平居中：SVG 54×54 并整体旋转 -90°，两个 `circle` 均为 r=23、无填充、线宽 5；底环描边为表面色 3 号，进度环描边取该列主色变量 `--c`、圆头端点、虚线阵列 144.5、初始偏移 144.5，过渡 stroke 0.3s。盘心 `b` 绝对铺满、grid 居中、15px / 900、主色、等宽数字（tabular-nums）。盘底伪元素 inset 5px 的圆形，底色 color-mix(in srgb,var(--c) 10%,transparent)。盘下标签 display block、上外边距 5px、9px / 800、次级墨色、单行不换行。
- 胶片区绝对定位 left 12px / right 12px / top 100px，高 86px、内边距 8px、14px 圆角、表面色 2 号底，整块对读屏隐藏。内部 6 格网格为 6 列等分、间距 5px、高 56px。
  - 每格是缩略帧：6px 圆角、表面色底、`0 0 0 1px` 线色描边、overflow 裁切；初始 opacity 0 并下移 6px，点亮后恢复 opacity 1 与原位，过渡 opacity 0.25s、transform 0.35s cubic-bezier(.3,1.5,.5,1)。
  - 帧内元素是若干绝对定位的横条：left 4px / right 4px、2px 圆角，背景默认为表面色 3 号。文字阶段的横条改用 color-mix(in srgb,墨色 18%,transparent)。图片阶段再追加一块高 22px 的图片块，普通阶段为浅墨块，最终阶段改为 `linear-gradient(135deg,#818CF8,#F472B6)` 渐变。
  - 6 帧的阶段序列固定为：空白 → 骨架 → 骨架 → 文字 → 图片 → 图片。含文字横条的帧画三根横条（高 4px、3px、3px，top 分别 5px、13px、19px，第一根宽 40%，第三根右缩 12px）；含图片块的帧再加一块 top 27px 的图片块。
  - 时间轴在帧行下方：高 14px、上外边距 6px、上边框 1px 线色。每个刻度绝对定位、top 3px、8px / 800、三级墨色、水平居中（translateX(-50%)）、等宽数字，横向位置按 (序号 + 0.5) / 6 均分。
  - LCP 游标是一根 2px 宽的绿色竖线（#10B981），绝对定位、top 4px、bottom 20px、水平位置固定在帧条宽度的 75% 处（`calc(8px + 0.75 * (100% - 16px))`），初始 opacity 0，点亮后 0.3s 淡入；顶端挂一枚 4px 圆角小标签，底色 #10B981、白字 8px / 850，文案 "LCP"。
- 指标区绝对定位 left 14px / right 14px / top 196px。每行是 `96px 1fr 48px` 三列网格、间距 8px、垂直居中、行高 24px、10px / 750、次级墨色；名称在首列，数值在末列右对齐、900 字重、主色、等宽数字。
  - 中间色带高 6px、3px 圆角，底色是横向渐变：0–40% 为 color-mix(in srgb,#10B981 25%,transparent)，40–70% 为 color-mix(in srgb,#F59E0B 25%,transparent)，70–100% 为 color-mix(in srgb,#E11D48 25%,transparent)。
  - 指针是一个 12×12px 圆点，top -3px、margin-left -6px、底色取该行主色、`0 0 0 2px` 表面色光圈，初始 left 0；位移过渡 0.8s cubic-bezier(.3,1.2,.5,1)。
- 底部按钮绝对定位 left 14px / right 14px / bottom 14px，高 40px、12px 圆角、无边框、墨色底、表面色字、12px / 850，透明度过渡 0.2s；禁用时 opacity 0.5、光标 default。
- 场景令牌用 CSS `light-dark()` 随 `color-scheme` 切换，浅色 / 深色两套：表面 #FFFFFF / #13141C，表面 2 #F5F3EF / #1A1B25，表面 3 #EAE7E1 / #252632，墨色 #16151B / #F4F0E8，次级墨色 #57535F / rgba(244,240,232,.68)，三级墨色 #8E8A97 / rgba(244,240,232,.42)，线色 rgba(22,21,27,.09) / rgba(255,255,255,.08)，强线 rgba(22,21,27,.17) / rgba(255,255,255,.16)，主色 #6A57F2 / #B7A4FF，主色 2 #2F8FE0 / #7DB4FF，主色淡底 rgba(106,87,242,.12) / rgba(183,164,255,.15)，主色字 #FFFFFF / #0B0C12，薄荷 #119C72 / #7EE8C0，警告 #D6731E / #FFB26B，危险 #D93A55 / #FF7D8C，玻璃 rgba(255,255,255,.58) / rgba(255,255,255,.07)，玻璃线 rgba(255,255,255,.85) / rgba(255,255,255,.18)，阴影 rgba(40,30,80,.14) / rgba(0,0,0,.45)，强阴影 rgba(40,30,80,.3) / rgba(0,0,0,.72)。组件不声明字体族，继承宿主页面字体；按钮统一 `font: inherit`。
- 组件只有 `@media (prefers-reduced-motion: reduce)` 一个媒体查询；场景是固定 340px 宽的等比缩放画布，容器变窄时整景按 `min(1, 可用宽/340)` 缩小，内部用绝对定位，不做响应式重排。

## 数据

- 四个分类与分数固定：Performance 92、Accessibility 100、Best practices 83、SEO 64。分数到颜色的规则：≥90 为 #10B981，≥50 为 #F59E0B，否则 #E11D48；因此前两项为绿，第三、四项为琥珀色。
- 环周长按 r=23 记为 144.5，进度环的目标虚线偏移分别是 11.6（92 分）、0.0（100 分）、24.6（83 分）、52.0（64 分）。
- 6 帧的绘制阶段序列固定为 0 / 1 / 1 / 2 / 3 / 3（0 空白、1 骨架、2 文字、3 图片）。
- 时间轴 6 个刻度固定为 0.3 s、0.6 s、0.9 s、1.2 s、1.5 s、1.8 s。
- 三条指标固定为：Largest paint / 1.2 s / 指针位置 30% / 指针色 #10B981；Layout shift / 0.02 / 指针位置 10% / 指针色 #10B981；Input delay / 310 ms / 指针位置 72% / 指针色 #F59E0B。
- 场景文案：四个分类名、"LCP" 标签、按钮文案（测量中 "Auditing…"，完成后 "Run again"）。按钮初始是空标签，组件进入视口后立刻被第一次自动测量覆盖。

## 操作和动效

- 组件挂载后，若环境支持 IntersectionObserver，则在根节点首次进入视口时自动触发一次审计并立刻断开观察；若不支持则直接开始审计。
- 一次审计的时序：
  - 立即把四个环的进度描边复位到 144.5（禁用过渡）、中心数字归 0，六帧胶片全部熄灭，LCP 游标隐藏，三条指标指针归位到最左；按钮置灰禁用、文案改为 "Auditing…"。
  - 胶片从 300ms 起以 330ms 为间隔逐帧点亮，第 1 帧 300ms、第 2 帧 630ms、第 3 帧 960ms、第 4 帧 1290ms、第 5 帧 1620ms、第 6 帧 1950ms；第 5 帧点亮的同时 LCP 游标淡入。
  - 2400ms 时四个环同时起笔：进度环的虚线偏移改为按分数算出的目标值，过渡为 stroke-dashoffset 1.1s cubic-bezier(.3,.9,.3,1)，四个环依次延迟 0s / 0.1s / 0.2s / 0.3s；同时给每个分类补上无障碍名 "<分类名> <分数>"。
  - 中心数字同步滚动 1200ms，用三次缓出（1 - (1 - q)^3）把 0 推到目标分，q = (当前时间 - 起始时间) / 1200，结束时显示四舍五入后的整数（92、100、83、64）。
  - 三条指标指针同时开始滑动，0.8s cubic-bezier(.3,1.2,.5,1) 到各自的目标位置（30%、10%、72%）。
  - 按钮恢复可用，文案改为 "Run again"。
- 再点一次按钮就重跑同一套流程；新一轮开始会把上一轮的环、帧、游标、指针全部复位，不会叠加。每一步的延时都带代次校验，新一轮开始后旧回调自动作废；元素卸载后回调不再执行。
- 无障碍：四个分类块带 `role="img"`，审计进行时写入 "<分类名> <分数>" 的无障碍名；胶片条整块 `aria-hidden="true"`；底部按钮是原生按钮，focus-visible 时 2px 主色描边、外偏移 2px。
- `prefers-reduced-motion: reduce`（或 `options.reducedMotion` 为真）时：所有延时压到 0ms，环的描线与数字滚动直接落到终值，指针与游标直接就位，帧的淡入过渡关闭；最终画面与功能完全保留。
- 支持同页多实例：查询限定在各自 ShadowRoot 内，不使用全局 id；卸载时清理计时器、帧回调、事件监听与观察器。
