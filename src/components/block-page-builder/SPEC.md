# 堆块页面生成器 — BlockPageBuilder

一张 340×340 的页面搭建场景。左边是一条 86px 宽的「Blocks」面板，竖排五个按钮，每个按钮带一枚缩略示意图标和块名（Hero / Features / Pricing / Reviews / Footer）。右边是画布，顶部一行状态条写着当前块数与一枚绿色「Saved」指示灯；画布初始显示虚线提示「Press a block on the left to start your page」。点左边的块，右侧画布上就长出一块对应的线框占位（标题条、三栏特性、三根价格柱、一条评论、一排页脚链接），线框右上角浮出上移 / 下移 / 删除三枚小按钮，左上角挂着块名标签。删除会收拢折叠这行，上下移动则用 FLIP 位移动画让其它块平滑让位。

## 布局与材质

- 场景根 340×340px，圆角 30px，溢出裁切，底色次级表面，文字墨色；外圈 1px 线色描边（`box-shadow: 0 0 0 1px`），下方 `0 30px 60px -36px` 强阴影。
- 令牌用 CSS `light-dark()` 写在场景根上，浅色 / 深色两套：表面 `#FFFFFF` / `#13141C`；次级表面 `#F5F3EF` / `#1A1B25`；三级表面 `#EAE7E1` / `#252632`；墨色 `#16151B` / `#F4F0E8`；次级墨色 `#57535F` / `rgba(244,240,232,.68)`；三级墨色 `#8E8A97` / `rgba(244,240,232,.42)`；线色 `rgba(22,21,27,.09)` / `rgba(255,255,255,.08)`；强线色 `rgba(22,21,27,.17)` / `rgba(255,255,255,.16)`；强调色 `#6A57F2` / `#B7A4FF`；次强调 `#2F8FE0` / `#7DB4FF`；强调淡色 `rgba(106,87,242,.12)` / `rgba(183,164,255,.15)`；强调字色 `#FFFFFF` / `#0B0C12`；薄荷 `#119C72` / `#7EE8C0`；警示 `#D6731E` / `#FFB26B`；危险 `#D93A55` / `#FF7D8C`；玻璃面 `rgba(255,255,255,.58)` / `rgba(255,255,255,.07)`；玻璃线 `rgba(255,255,255,.85)` / `rgba(255,255,255,.18)`；阴影 `rgba(40,30,80,.14)` / `rgba(0,0,0,.45)`；强阴影 `rgba(40,30,80,.3)` / `rgba(0,0,0,.72)`；渐变 `linear-gradient(120deg,#7B61FF,#3D8BFF 55%,#1FB89A)` / `linear-gradient(120deg,#B7A4FF,#7DB4FF 55%,#A5F2D3)`。组件自身不声明 `color-scheme`，`light-dark()` 跟随宿主的 `color-scheme`。
- 组件 CSS 未声明 `font-family`，字体沿用宿主页继承。
- 左侧面板：绝对定位 left 10 / top 10 / bottom 10、宽 86px，内边距 `10px 7px`，圆角 18px，背景表面色，1px 线色描边；标题 `Blocks` 是 9.5px/850、三级墨色，下边距 6px、左右各内缩 4px。
- 面板里的块按钮：纵向 flex 居中、间距 4px，宽 100%、下外边距 5px，内边距 `6px 0 5px`，圆角 11px，无边框，底色次级表面，文字次级墨色、9.5px/800；悬停（或脚本标记的悬停态）时底色换成强调淡色、文字换成强调色（过渡 0.2s）；按下时整体缩到 0.95 倍（过渡 0.15s）。按钮内的缩略图是 44×22px、圆角 5px 的小窗，底色表面色、内嵌 1px 线色描边，内部用定位的浅灰小条表示内容。
- 顶部状态条：绝对定位 left 106 / right 12 / top 14，flex 居中、间距 6px，10px/800、三级墨色；左侧块数 900 字重、墨色并靠左撑开；右侧「Saved」标记前有一枚 6×6px 的 `#10B981` 圆点。
- 画布：绝对定位 left 106 / right 12 / top 36 / bottom 10，内边距 8px，圆角 16px，背景表面色，1px 线色描边，溢出裁切。
- 空画布提示：绝对定位在画布内缩 8px 处，1.5px 虚线线色描边、圆角 12px，网格居中，10.5px/700、三级墨色居中文案；第一块加入后提示被隐藏。
- 画布内的块列表：无序列表，去掉项目符号与内外边距。
- 每一行块是一个网格容器：行高用 `grid-template-rows: 1fr` 控制，内层 `min-height:0; overflow:hidden` 负责裁切；行与行之间下外边距 5px。展开与收起过渡为 `grid-template-rows 0.4s cubic-bezier(.3,1,.4,1)` + `opacity 0.3s` + `margin 0.4s`；收起态是 `0fr` 行高、透明度 0、外边距 0。
- 块内的线框面板：内边距 7px、圆角 10px、底色次级表面、内嵌 1px 线色描边；悬停、脚本悬停态或键盘焦点落在块内时，描边加粗为 1.5px 强调色（过渡 0.2s）。面板里的所有灰条都是圆角 3px 的三级表面色块。
- 块名标签：绝对定位在面板左上（left 7px、top -1px），内边距 `1px 5px`，圆角 `0 0 5px 5px`，强调色底、白字、7.5px/850；默认透明，悬停 / 脚本悬停态 / 焦点在块内时淡入（0.2s）。
- 操作按钮组：绝对定位在面板右上（right 5px、top 5px），三枚 20×20px 按钮，间距 2px，圆角 6px，无边框，底色表面色、1px 线色描边、次级墨色图标，图标为 9×9px 线性 SVG（上chevron、下chevron、对角叉，1.6px 描边、圆头）；默认透明，悬停 / 脚本悬停态 / 焦点在块内时淡入（0.2s）。删除按钮悬停时图标转为 `#E11D48`。
- 焦点样式：所有按钮 `focus-visible` 为 2px 强调色描边、偏移 1px。
- 场景固定 340px 宽，没有媒体查询断点；容器窄于 340px 时由运行时整体等比缩小（缩放比 = min(1, 容器宽 / 340)），320px 以下的窄容器也不会横向溢出。

## 数据

- 五个块写死：`Hero`、`Features`、`Pricing`、`Reviews`、`Footer`。
- 每个块对应一份写死的线框 HTML：
  - Hero：三条灰条——60% 宽 9px 高的标题条、84% 宽 5px 高（上边距 5px）的副标题条、30% 宽 10px 高（上边距 6px、圆角 5px、强调色）的按钮条。
  - Features：三列等宽网格、列间距 4px，每列一根 22px 高的灰条。
  - Pricing：三列等宽网格、列间距 4px、底端对齐，三根柱子高 24px / 30px / 24px，中间那根是强调色与三级表面按 45% 混合的色。
  - Reviews：横向 flex、间距 5px、垂直居中，左边 16×16px 圆形头像，右边两行灰条（90% 宽 5px、60% 宽 5px 且上边距 4px）。
  - Footer：横向 flex、间距 6px，三根各占 22% 宽、6px 高的灰条。
- 侧栏缩略图也写死，与块一一对应：
  - Hero：左 6px / 上 5px 处 22×4px 灰条 + 左 6px / 上 12px 处 12×5px 强调色条。
  - Features：左右各内缩 5px、上 6px、高 10px 的横条，用 `repeating-linear-gradient(90deg, 三级表面 0 10px, 透明 10px 13px)` 画成虚线列。
  - Pricing：三根竖条，左边距依次 8px / 18px / 28px、宽 8px、高 12px / 14px / 12px、上边距 5px / 3px / 5px，中间一根为强调色。
  - Reviews：左 6px / 上 6px 处 9×9px 圆形头像 + 左 18px / 上 8px 处 20×4px 灰条。
  - Footer：左右各内缩 5px、底部 4px 处一根 4px 高的横条。
- 其余文案写死：面板标题 `Blocks`、空态提示 `Press a block on the left to start your page`、保存标记 `Saved`、块数格式 `N blocks`。全部内置在组件里，没有外部数据来源。

## 操作和动效

- 点侧栏某个块按钮就往画布追加一块同名线框：先插入一个处于「收起」态（行高 0fr、透明度 0、无下外边距）的行，强制回流后立刻切到展开态，于是行高用 0.4s `cubic-bezier(.3,1,.4,1)` 撑开、透明度用 0.3s 淡入、下外边距用 0.4s 补回；同一块可以反复添加，画布里可以有多块同名块。
- 每次改动后统一刷新状态：顶部块数按「未处于收起态的行数」重写为 `N blocks`；有块时隐藏空态提示、无块时恢复提示；「Saved」文字写好并重新播放一次闪烁——移除闪烁类、强制回流后再加上，闪烁动画 0.6s `ease`，在 40% 处透明度降到 0.2，绿点随之闪一下。
- 悬停某个画布块（或焦点落在块内）时，该块的线框描边加粗为强调色、块名标签淡入、右上角三枚操作按钮淡入。
- 点上移按钮：该块与前一个兄弟节点换位；点下移按钮：该块与后一个兄弟节点换位。到头时（没有前一个 / 后一个兄弟）按钮点击不产生任何变化。块之间用 FLIP 位移动画衔接：先记录所有行原来的上边距，插入节点改变顺序后，逐行算出位移差，用 Web Animations API 从 `translateY(差值)` 过渡到 `none`，时长 380ms、缓动 `cubic-bezier(.3,1.2,.5,1)`；位移差为 0 的行不播放动画。移动后同样刷新块数与「Saved」。
- 点删除按钮：该行先进入「收起」态（行高收到 0fr、透明度归 0、下外边距归 0），随后在 420ms 后从 DOM 中移除（减少动态时立即移除）；删除后刷新块数与「Saved」。删除中若数组里还有其它行，块数按未处于收起态的行统计，因此刚点下删除的那一刻计数就已经减一。
- 键盘操作：侧栏块按钮与三枚操作按钮都是原生 `button`，可 Tab 遍历、回车或空格触发；焦点在块内时该块自动进入「聚焦高亮」态（描边加粗、标签与操作按钮淡入）。Escape 没有任何作用。
- 无障碍：缩略图标记 `aria-hidden="true"`，按钮的可读名由 `aria-label` 提供（形如 `Hero — add`）；三枚操作按钮的 `aria-label` 分别是 `Move up`、`Move down`、`Delete`。
- 无自动播放，也没有循环动画；所有动效都由点击、悬停或焦点触发。
- `prefers-reduced-motion` 下块的展开收起过渡关闭（瞬时到位），「Saved」的闪烁动画停止；`options.reducedMotion` 覆盖同一偏好，并额外让 FLIP 位移动画整体跳过、删除时立即从 DOM 移除，但块数、提示显隐与最终顺序完全不变。
