# 地图聚合拆分 — MapClusters

一张 340×340 的街区地图卡：一整块浅米色底子上画着一条淡蓝的河、三块浅绿公园和六条白色主干道，140 家咖啡馆散在六个街区里。地图用 Canvas 绘制，按缩放级别自动聚成带数字的橙色圆簇——数字越大圆越大；点一下簇，圆簇会散开成更小的簇乃至单点的棕色图钉，右上角的胶囊实时报着「Café 140 places · zoom 2/4」。地图可以按住拖动平移，键盘方向键也能平移；点到单个图钉会浮出一张深色小卡，写着这家店的编号与一个星级数字。

## 布局与材质

- 场景根：宽 340px、高 340px、圆角 30px、overflow hidden、position relative；底色 `#F1EFE8`；文字色 `#1F2937`；外描边 `0 0 0 1px var(--ux-line)`，投影 `0 30px 60px -36px var(--ux-shadow-strong)`。地图是固定浅色调，不随主题切换。
- 场景令牌（`light-dark()` 随 `color-scheme` 切换）：surface `#FFFFFF` / `#13141C`，surface-2 `#F5F3EF` / `#1A1B25`，surface-3 `#EAE7E1` / `#252632`，ink `#16151B` / `#F4F0E8`，ink-2 `#57535F` / `rgba(244,240,232,.68)`，ink-3 `#8E8A97` / `rgba(244,240,232,.42)`，line `rgba(22,21,27,.09)` / `rgba(255,255,255,.08)`，line-2 `rgba(22,21,27,.17)` / `rgba(255,255,255,.16)`，accent `#6A57F2` / `#B7A4FF`，accent-2 `#2F8FE0` / `#7DB4FF`，accent-soft `rgba(106,87,242,.12)` / `rgba(183,164,255,.15)`，accent-ink `#FFFFFF` / `#0B0C12`，mint `#119C72` / `#7EE8C0`，warn `#D6731E` / `#FFB26B`，danger `#D93A55` / `#FF7D8C`，glass `rgba(255,255,255,.58)` / `rgba(255,255,255,.07)`，glass-line `rgba(255,255,255,.85)` / `rgba(255,255,255,.18)`，shadow `rgba(40,30,80,.14)` / `rgba(0,0,0,.45)`，shadow-strong `rgba(40,30,80,.3)` / `rgba(0,0,0,.72)`。
- 画布：绝对定位 inset 0、宽高各 100%，光标 grab、touch-action none；拖动时根节点加「拖动中」类，光标变 grabbing。后备缓冲按 `min(2, devicePixelRatio)` 放大，绘制时再按同倍率缩放，保证高分屏不发虚。
- 地图配色：底色 `#F1EFE8`；小街 `#fff`、宽 2.2 倍相机缩放；主干道先画一遍 `#E2DDD0` 的加宽外框（宽 12 倍相机缩放再加 2），再叠 `#fff` 的路面；公园 `#CDEBC4`；河流 `#BFDBFE`、宽 34 倍相机缩放。
- 计数胶囊：绝对定位 left 16px、top 16px，内边距 6px 11px、胶囊圆角、底色 `rgba(255,255,255,.92)`、投影 `0 4px 14px -6px rgba(0,0,0,.25)`，11px、字重 850、tabular-nums、pointer-events none。
- 缩放按钮组：绝对定位 right 16px、top 16px，纵向 flex，圆角 14px、底色 `#fff`、投影 `0 6px 18px -8px rgba(0,0,0,.35)`、overflow hidden；上为放大「+」、下为缩小「−」，各 36×36px、无边框、20px、字重 700、居中排布；两个按钮之间有 1px 的 `#E5E7EB` 分隔；到边界时按钮变 `#CBD5E1` 且不可点。
- 浮出小卡：绝对定位，内边距 6px 9px、圆角 10px、底色 `#1F2937`、白字 10.5px、字重 750、不换行；默认 opacity 0 并以 `translate(-50%,-100%)` 居中于目标点上方，opacity 过渡 .15s。
- 场景不引入自定义字体，字体栈继承宿主页面。
- 响应式：固定 340×340，没有布局断点；容器宽度不足 340px 时整景按 `min(1, 容器宽 / 340)` 等比缩小，缩放锚点在左上角，占位高度同步收缩。

## 数据

- 咖啡馆点位共 140 个，由固定种子的线性同余随机数（种子 11）生成，分散在六个街区：每条街区记录「中心 x、中心 y、散布半径、点个数」，分别是 `(300,320)` 半径 70 共 30 个、`(630,270)` 半径 60 共 25 个、`(480,580)` 半径 55 共 28 个、`(770,640)` 半径 60 共 20 个、`(240,720)` 半径 50 共 18 个、`(580,840)` 半径 65 共 19 个，合计 30+25+28+20+18+19 = 140 个点。坐标落在世界坐标系 0 到 1000 内，位置用近似正态分布（三个均匀随机数求和后缩放）绕街区中心散开。
- 每个点带一个「星级」数字，取 3.6 到 5.0 之间、保留一位小数，只在点到单点时显示。
- 河流折线七个顶点：`(-50,470) (180,500) (330,455) (520,420) (700,500) (860,470) (1050,450)`。
- 公园三块椭圆（中心 x、中心 y、半径 x、半径 y）：`(380,190,70,42)`、`(700,790,85,50)`、`(140,560,48,62)`，统一旋转 0.3 弧度。
- 主干道六条折线：`(-50,300)-(1050,255)`、`(-50,700)-(1050,725)`、`(430,-50)-(455,1050)`、`(760,-50)-(725,1050)`、`(-50,120)-(1050,160)`、`(150,-50)-(120,1050)`。
- 小街网是程序生成的：以 62 为步长在 0 到 1000 上打格，每格画一条竖巷（向右偏移 20）与一条横巷（向上偏移 18），只有在相机缩放大于 0.55 时才出现，透明度按 `(缩放 - 0.55) × 2` 渐入。
- 没有外部数据请求。

## 操作和动效

- 缩放级别共四档（0 到 3），相机缩放按 `0.32 × 2^z` 取值，即 0.32、0.64、1.28、2.56；屏幕中心固定在 `(170, 176)`。
- 聚类算法：按当前级别的网格切分世界坐标，格子边长为 `54 / 相机缩放`，把同一格里的点聚成一簇并取簇心；随后按簇大小从大到小做一次合并扫描，凡是簇心距离小于 `40 / 相机缩放` 的两簇并成一簇（按点数加权求新簇心），避免边界上两个簇在屏幕上叠在一起。
- 簇的画法：点数大于 1 时画一个橙色圆（`#F97316`，半径 `11 + sqrt(点数) × 2.2`），外加一圈半径再加 5px 的半透明橙色光晕（`rgba(249,115,22,.22)`），圆上描 2px 白边，圆心写白色数字（点数超过 9 时字号 11px，否则 12px，字重 800）。点数等于 1 时改画单点图钉：半径 6.5 的深棕圆（`#92400E`）作钉头加一个三角钉身，钉头里再点一个 2.6px 的白点。
- 放大动画：点右上「+」、点某个簇、或按键盘加号都会进入放大。相机与聚类一起在 620ms 内插值：镜头缩放走对数插值（视觉上匀速放大），横纵中心走线性插值，进度用三次贝塞尔缓动（前半段 4k³，后半段 1-(-2k+2)³/2）。放大过程中新簇从它所属的旧簇位置滑向新簇心并从 50% 透明度淡入；缩小时旧簇滑向合并后的簇心。
- 缩小动画：点「−」或键盘减号，簇心按同样 620ms 滑回合并位置。
- 平移：在画布上按住拖动即可平移，位移超过 4px 才算拖动；平移范围被限制在以世界中心 (500,500) 为界、随缩放变化的窗口内；在最远的第 0 级，平移量会被压到实际拖动距离的 30%，手感更像轻微视差。第 0 级松手后地图用 400ms 的三次缓出回到正中的位置。
- 点击判定：未拖动时按指针位置做命中测试，簇的命中半径是 `11 + sqrt(点数) × 2.2`，单点图钉的命中圆心在钉头处（命中中心上移 8px）、半径 9。命中簇且不是最远一级时，进入下一级缩放并把镜头对准该簇心；命中单点时弹出小卡，写着 `Café 编号 · ★星级`（编号从 1 开始）。点空白处收起小卡。
- 键盘：画布可聚焦，方向键每次平移 40 像素（按当前缩放换算成世界距离），在第 0 级方向键不生效；「+」或「=」放大、「−」缩小，其余按键忽略。焦点环为 2px `#F97316` 描边、偏移 -4px。
- 状态播报：计数胶囊带 `aria-live="polite"`，缩放级别变化时朗读 `Café 140 places · zoom N/4`。
- `prefers-reduced-motion`（或 options.reducedMotion 为 true）：缩放与回中的时长为 0，直接跳到目标相机与目标聚类，簇的淡入淡出省略；运行时还会把所有元素的 transition 与 animation 时长归零。

## Props

组件只接受一个 `options` 对象，其内部字段与文档页 API 表一致：

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| height | number | 340 | 场景高度，逻辑像素；窄容器整景按比例缩小 |
| reducedMotion | boolean | 跟随系统 | 覆盖系统的减少动态偏好 |
